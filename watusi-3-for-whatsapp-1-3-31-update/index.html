Watusi 3 for WhatsApp 1.3.31 Adds WhatsApp 26.44 Support and Fixes Hidden-Photo Gaps

Watusi 3 for WhatsApp has reached version 1.3.31. According to the supplied official package information and release notes, this maintenance update adds support for WhatsApp 26.44 and fixes several cases where Hide Picture in Chats failed to conceal images. The package stanza lists firmware 12.0 or newer as a dependency, while the official depiction separately lists iOS 15.1 or later under its support information. Users should therefore check the displayed compatibility target, their WhatsApp build, jailbreak environment, declared dependencies, and any package conflicts before updating. A separate Simplified Chinese language project is also documented, but it is based on Watusi 1.3.9 and should not automatically be treated as fully updated for Watusi 1.3.31.

Key points

  • Watusi 3 version 1.3.31 is described as supporting WhatsApp 26.44.
  • The release fixes Hide Picture in Chats for large photos in new chats, chat-header photos, and photos beside voice messages and group messages.
  • The official depiction lists iOS 15.1 or later, while package metadata lists firmware 12.0 or newer as a dependency.
  • The package lists MobileSubstrate 0.9.5000 or newer, Watusi Tools 2.8.3 or newer, and libmryipc as dependencies.
  • The separate Simplified Chinese language project says it is based on Watusi 1.3.9, so compatibility with Watusi 1.3.31 should be verified rather than assumed.

What is new in Watusi 3 version 1.3.31

Watusi 3 for WhatsApp version 1.3.31 is presented as a maintenance release rather than a new feature expansion. The official package page describes the update as including bug fixes and support for WhatsApp 26.44. The same information identifies the package as com.fouadraheb.watusi3 and gives the release date as November 11, 2026.

The clearest user-facing correction concerns the Hide Picture in Chats option. The developer says the feature previously failed to hide the large photo in new chats, the photo displayed in a chat header, and photos shown beside voice messages and group messages. Version 1.3.31 addresses those listed cases. The release note does not claim that every image display path in WhatsApp has been changed, so the fix should be understood according to the specific scenarios named by the developer.

  • Version: 1.3.31
  • WhatsApp compatibility named in the release notes: 26.44
  • Release focus: bug fixes and compatibility maintenance
  • Specific correction: Hide Picture in Chats now covers several additional photo locations

Why the WhatsApp 26.44 support matters

The official Watusi description lists functions across privacy, protection, statuses, chats, the chat list, media, the user interface, notifications, themes, scheduled messages, auto-reply, hidden chats, contact customization, custom tones, and stickers. Because the tweak changes WhatsApp behavior and interface elements, changes in WhatsApp itself can affect individual Watusi options.

The 1.3.31 release note specifically names WhatsApp 26.44 support, but it does not provide a feature-by-feature compatibility matrix. Therefore, the update should be read as compatibility maintenance for the named WhatsApp version, not as a guarantee that every Watusi option behaves identically in every environment. Users who depend on a particular function should review that function after updating, especially options involving photos, chat headers, media controls, status handling, or injected interface elements.

The package page also identifies Watusi as an all-in-one tweak for WhatsApp and says that its options are configured from inside WhatsApp settings. The source does not provide a separate list of changes to the settings interface in version 1.3.31.

  • The release notes name WhatsApp 26.44 specifically.
  • No new Watusi feature is identified in the 1.3.31 release note.
  • The source does not provide a complete feature-by-feature compatibility table.
  • Users should verify the options they rely on after updating.

Compatibility, dependencies, and package details

The package stanza lists firmware greater than or equal to 12.0, MobileSubstrate 0.9.5000 or newer, Watusi Tools 2.8.3 or newer, and libmryipc as dependencies. The official Sileo depiction separately lists “iOS 15.1+” under Supports. These fields express different compatibility information, so the firmware dependency alone should not be treated as a definitive installation guarantee for every setup. The explicitly displayed support target is iOS 15.1 or later, while the package metadata records firmware 12.0 as a lower-level requirement.

The package architecture is listed as iphoneos-arm. Its installed size is 9,892 KB, while the official depiction reports a size of 2.43 MB. Those figures describe different measurements and should not be treated as interchangeable. The package stanza also lists conflicts with com.fouadraheb.watusi, com.f0u4d.watusi, org.thebigboss.watusi, and com.b4db1r3.cleancopy. Anyone upgrading from an older Watusi package should check whether one of those conflicting identifiers is installed.

The package is maintained and authored by Fouad Raheb. Its description identifies it as “The all-in-one tweak for WhatsApp.” The supplied metadata does not establish support for every jailbreak, injection method, device, or WhatsApp build beyond the requirements and support information explicitly listed.

  • Official depiction support field: iOS 15.1+
  • Package firmware dependency: 12.0 or newer
  • Dependencies include MobileSubstrate, Watusi Tools 2.8.3 or newer, and libmryipc
  • Architecture listed in the package stanza: iphoneos-arm
  • The package declares conflicts with several older Watusi identifiers

What to check before updating

Before installing, users should record their current Watusi version, WhatsApp version, jailbreak or injection environment, and the Watusi options they actively use. The official package information supplies dependency and conflict data, but it does not describe a rollback procedure or explain how settings migrate between versions. Keeping a way to restore the previous package state is therefore a practical precaution, although the source does not say that a rollback is required.

After updating, the most relevant checks follow the 1.3.31 changelog. With Hide Picture in Chats enabled, open a new chat, inspect the chat header, view a conversation containing voice messages, and check rows containing group messages. These checks correspond to the exact display locations mentioned in the release note. Users should also confirm that WhatsApp launches normally and that their other enabled Watusi options remain available.

If a problem appears, it is useful to isolate the affected option before concluding that the entire package is incompatible. The official material does not provide troubleshooting instructions, so this approach is a verification step rather than a publisher-prescribed procedure.

  • Check the WhatsApp build against the release’s stated 26.44 support.
  • Confirm the listed dependencies are present.
  • Review declared package conflicts before upgrading.
  • Test the photo locations named in the changelog.
  • Verify other enabled Watusi options after installation.

The Simplified Chinese language project is separate

The supplied repository metadata describes WatusiZhHans as a Simplified Chinese language project for Watusi 3. Its README says that it is based on Watusi 1.3.9, adds Chinese translations, and uses a minimal runtime hook to add “简体中文” to Watusi’s Other Settings, Language menu.

The documented installation flow is straightforward: install the language package, completely terminate WhatsApp, reopen WhatsApp, then go to Watusi, Other Settings, Language, and select 简体中文. The README also suggests trying Language = Auto when WhatsApp or the system language is Simplified Chinese.

This project should not automatically be described as a localization update for Watusi 1.3.31. Its own documentation identifies Watusi 1.3.9 as the development base, and the supplied material does not confirm complete compatibility with the newer Watusi package. A recent project commit refactored packaging to generate rootful, rootless, and roothide packages and to retain zh-Hans.lproj resources, but that packaging change does not establish compatibility with every internal change in Watusi 1.3.31.

The project’s maintenance notes recommend revisiting its translation overrides, rebuilding packages, checking generated inventories, testing important pages on a device, and rechecking language-related internals when Watusi is upgraded. Those notes reinforce that the language package and the main Watusi package have separate versioning and maintenance concerns.

  • The language project is based on Watusi 1.3.9.
  • Its documented menu path is Watusi → Other Settings → Language → 简体中文.
  • The source does not confirm full compatibility with Watusi 1.3.31.
  • The language project has its own packaging and maintenance process.

Bottom line

Watusi 3 version 1.3.31 is primarily a compatibility and reliability update for WhatsApp 26.44. Its most specific user-facing correction expands the situations covered by Hide Picture in Chats, addressing large photos in new chats, chat-header photos, and photos beside voice messages and group messages.

The update is most relevant to users running the named WhatsApp release or encountering one of those display issues. Compatibility should be checked carefully because the supplied official materials expose more than one version boundary: package metadata requires firmware 12.0 or newer, while the official depiction lists iOS 15.1 or later. Users should also account for the declared substrate and helper-package dependencies, package conflicts, and the separate status of the Simplified Chinese localization project.
