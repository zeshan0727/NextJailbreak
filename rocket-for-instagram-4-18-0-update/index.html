Rocket for Instagram 4.24.0 Adds Reels Controls and OLED Fixes

Rocket for Instagram 4.24.0 adds an option to hide friend suggestions in Reels and corrects black toggle switches under Rocket’s OLED theme. This article has been updated in place from version 4.18.0 and now covers the official changes through 4.24.0.

By Zeeshan Barvi · Originally published September 16, 2026 · Updated October 17, 2026 · Verified against Rocket’s official APT index, changelog and project documentation

What changed in Rocket 4.24.0

The official changelog gives 4.24.0 two focused changes. A new option can hide friend suggestions inside Reels, extending the suggestion controls Rocket already offers for the Stories tray. The update also fixes a display problem that could turn toggle switches black when the OLED theme was active.

  • Reels: adds a setting to hide friend suggestions.
  • OLED theme: fixes black toggle switches so their state remains readable.

These are narrow product changes, not a claim that Rocket removes every recommendation from Instagram. The new setting concerns friend suggestions in Reels, while version 4.18.0 separately introduced a Stories-tray suggestion control.

Official release verification

Rocket’s live package page identifies 4.24.0 as the current version. The official APT repository index, dated October 16, 2026 at 21:41:23 UTC, lists three 4.24.0 package records: iphoneos-arm, iphoneos-arm64 and iphoneos-arm64e. The project’s own README says this repository serves rootful, rootless and RootHide jailbreak builds.

The repository metadata requires iOS 15.0 or later, and the developer page says the App Store edition of Instagram is required. Those package requirements do not mean every device on every iOS 15–27 release currently has a compatible jailbreak.

Profile watching is the biggest addition since 4.18

Version 4.20.0 introduced “Watch profile,” which the developer describes as automatically saving new posts, Stories and Reels from selected profiles. It also added “Save all posts” for downloading a profile’s posts, including every item in a carousel. Version 4.23.2 then reworked profile watching to make it faster and more efficient.

Automatic downloads can consume storage quickly. Rocket 4.20.0 therefore added a Clean Cache view that reports cache usage and can remove cached files. Users should also consider the privacy and terms implications of automatically retaining another account’s content.

Feed, iPad and OLED improvements

Rocket 4.23.0 can make Following the default Home feed while leaving For You in the feed menu. The release also lets users save a Feed post without first opening the collection picker. Version 4.23.2 corrected the For You label in this configuration.

For iPad users, 4.22.0 corrected grid-column and Stories-tray sizing in portrait and landscape and 4.23.1 added further navigation improvements. The OLED theme arrived in 4.21.0; subsequent releases fixed a nearly invisible Continue button and the black-toggle issue addressed by 4.24.0.

Compatibility and jailbreak environments

  • iOS requirement: iOS 15.0 or later, according to the official page and current package metadata.
  • Instagram: the App Store Instagram app is required.
  • Jailbreak builds: the official repository states that it serves rootful, rootless and RootHide packages.
  • Package identifier: me.alfhaily.rocket.
  • Instagram compatibility: the project README says it is compatible with the latest Instagram version, but users should still check the current developer page before updating either component.

Rocket’s iOS compatibility statement describes the tweak package, not jailbreak availability. For example, a device on a supported iOS release still needs an actual jailbreak environment that supports that device and firmware. RootHide users should install the RootHide-specific build supplied by the official repository instead of mixing package architectures.

How to update safely

  1. Open the official Rocket source in Sileo or Zebra and refresh repository metadata.
  2. Confirm the package page reports version 4.24.0 and identifier me.alfhaily.rocket.
  3. Verify that the package manager selects the build for the active rootful, rootless or RootHide environment.
  4. Close Instagram before applying the update.
  5. Review the transaction queue and avoid unofficial mirrors or repackaged Instagram bundles.
  6. After installation, reopen Instagram and verify Rocket settings, saved profiles and the OLED theme before enabling automatic profile downloads.

The developer also documents a sideloading repository for non-jailbroken installations, but this article focuses on the jailbreak packages served through Rocket APT. Do not assume jailbreak and sideloaded builds have identical injection or update behavior.

Privacy and platform limits

Rocket includes controls for media downloads, private Story and direct-message behavior, retained deleted messages and call recording. These features do not override Instagram’s server-side systems or local law. “Retain deleted messages” is described as keeping received messages on the device after the sender unsends them; it does not restore content that was never delivered locally.

Recording calls, retaining messages and automatically saving another person’s content can require consent or violate platform rules depending on jurisdiction and use. The official changelog documents functionality, not legal permission or a guarantee against account enforcement.
