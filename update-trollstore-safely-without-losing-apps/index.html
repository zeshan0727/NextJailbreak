How to Update TrollStore Safely Without Losing Installed Apps

Use TrollStore’s own update control—or its official archive fallback—without uninstalling your existing apps. If an icon-cache reload breaks registrations, repair them instead of reinstalling everything.

By Zeeshan Barvi · Published October 17, 2026 · Verified against official TrollStore 2.1.1 sources

Before updating: confirm you already have a working TrollStore installation. This guide does not extend TrollStore to unsupported firmware, and updating TrollStore is not the same as updating iOS.

Quick answer

Open TrollStore → Settings. If a newer version is available, tap Update TrollStore to 2.1.1. The official README says TrollStore downloads the update, installs it and resprings. The project’s source routes this button through its update flow rather than through the app-uninstall workflow.

If the button is missing or download fails, download TrollStore.tar only from the official 2.1.1 GitHub release, open the archive in TrollStore and allow the prompted install and respring. Do not uninstall TrollStore first, and do not delete your installed apps.

Compatibility comes first

TrollStore depends on a CoreTrust bug, not on a normal App Store entitlement. The official project supports iOS and iPadOS 14.0 beta 2 through 16.6.1, iOS 16.7 RC build 20H18, and iOS 17.0. It explicitly says iOS 16.7.x other than that RC and iOS 17.0.1 or newer cannot be supported unless another CoreTrust bug is found.

An available TrollStore update does not create support for a newer firmware or device. Do not update iOS in an attempt to update TrollStore. If you need a fresh installation, start with the TrollStore installation guide and match the method to the exact device and firmware.

Method 1: use the built-in updater

  1. Open TrollStore and confirm installed apps still appear normally.
  2. Open Settings. When TrollStore detects a newer release, an update button appears at the top.
  3. Read the version shown. For this guide, the current official target is 2.1.1, released April 1, 2026.
  4. Tap Update TrollStore to 2.1.1 and leave TrollStore open while it downloads and installs the archive.
  5. Allow the automatic respring. Do not reboot or remove apps unless TrollStore specifically reports a separate problem.
  6. Reopen TrollStore, return to Settings and confirm the installed version.
  7. Launch one or two existing TrollStore apps. If icons are missing or apps no longer open, refresh registrations as described below.

Method 2: install the official archive

The README documents a manual fallback using the release archive:

  1. Open the official TrollStore 2.1.1 release.
  2. Download the asset named TrollStore.tar. Do not use a repack, mirror, IPA or similarly named file from another account.
  3. Open the downloaded archive in TrollStore.
  4. Confirm the TrollStore update when prompted and allow the respring.
  5. After SpringBoard returns, confirm version 2.1.1 in Settings and test an existing installed app.

The official 2.1.1 release records the archive digest as sha256:144dc741d1b74d582c861e6ed504ddced3745724e216e3de79ab7d37b27d0551. Advanced users can compare a locally calculated SHA-256 value before opening the file.

Will installed apps and their data remain?

The update flow replaces TrollStore itself and resprings. It does not ask you to uninstall the apps TrollStore already manages. TrollStore’s README separately states that those apps are uninstalled from inside TrollStore by tapping an app or swiping left; that is not part of the update steps.

Still, an updater is not a backup tool. TrollStore does not export every installed IPA or app container before updating. Preserve any irreplaceable files through the app’s own export or backup function before maintenance, and keep the original IPA where licensing and distribution terms allow. Do not claim that the update creates a backup—it does not.

If apps disappear or stop opening

The official project warns that an icon-cache reload can revert TrollStore and its apps from System registration to User registration. That can make icons disappear or apps refuse to launch even though their files were not intentionally uninstalled.

  1. If TrollStore opens, go to Settings → Refresh App Registrations.
  2. If TrollStore itself is unavailable, open the system app that hosts your Persistence Helper and use its refresh option.
  3. Return to the Home Screen and test the apps again.
  4. Use Rebuild Icon Cache only when needed. The Settings screen itself warns that rebuilding can make TrollStore apps disappear or stop launching until the Persistence Helper refreshes them.

For the recovery paths and helper-host details, follow the TrollStore Persistence Helper recovery guide.

TrollStore 2.1.1 context

Version 2.1.1 is a small maintenance release. Its public changelog fixes an entitlement typo in TrollStore Lite that could prevent some installed apps from working on Dopamine. That release note does not claim new firmware support and does not mean every classic TrollStore user must move to Lite.

If you are deciding between the two products rather than updating an existing installation, read TrollStore vs TrollStore Lite. To install an IPA after the update, use the TrollStore IPA installation guide.

Verification checklist

  • Settings reports TrollStore 2.1.1.
  • Existing TrollStore apps remain listed.
  • At least one previously installed app launches.
  • The Persistence Helper still opens from its chosen host app.
  • No iOS update was installed as part of this process.

Official sources

  • TrollStore 2.1.1 release — released April 1, 2026, with the official archive and digest.
  • Official TrollStore README — compatibility, in-app update, manual archive update and Persistence Helper behavior.
