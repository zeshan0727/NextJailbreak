# Next Chat 1.0.0 (1)
Unofficial iOS 16+ ChatGPT companion. The official web interface provides login, history, projects, model selection and uploads subject to web compatibility. Native features: persistent session, saved links, resume, downloads/preview/share, settings, device lock, privacy cover, dictation and local prompts, widgets and shortcuts.
Build on macOS: install XcodeGen and Python Pillow, run python3 generate_icon.py, xcodegen generate, then xcodebuild -scheme NextChat -sdk iphoneos CODE_SIGNING_ALLOWED=NO build. Sign for your device or use a compatible installer. No private ChatGPT endpoints or API key.
Limitations: Safari and embedded WebKit sessions are separate; authentication, website uploads, generated links, device security, widget install and keyboard require physical-device tests. The native saved links are not synchronized history. Dictation uses explicit copy/paste. Share extension is not included; native file sharing is available. No claim of official voice equivalence or background generation.
