Regram 7.2 Adds Ghost Mode, Content Filters and Direct Updates for Instagram

Regram for Instagram 7.2 is an update for jailbroken and sideloaded iOS installations. Released on November 26, 2026, it brings compatibility updates for Instagram 457, new privacy controls, expanded filtering tools, configurable chat filters, Media Vault improvements, playback changes, follow safeguards and installation diagnostics. The release also introduces Direct Update in beta for sideloaded Regram on iOS 18 or later. Compatibility information differs between the package metadata and the Sileo depiction, so users should verify the requirements for their installation method before updating.

Key points

  • Regram 7.2 is paired with Instagram version 457.0 and includes compatibility updates and bug fixes for that release.
  • Ghost Mode temporarily hides activity status, typing, seen states, story views and view-once seen activity.
  • New filters cover Feed, Reels, Stories and Explore, including account, word, date and content-type controls.
  • Direct Update is a beta feature for sideloaded Regram on iOS 18 or later and requires the certificate used for installation.
  • Setup Check reports issues involving signing, entitlements and app extensions.
  • The package metadata declares firmware 14.0 or later, while the Sileo depiction lists support as iOS 15.1 or later.

Regram 7.2 targets Instagram 457

Fouad Raheb’s Regram for Instagram 7.2 is described as an all-in-one enhancement for jailbroken or sideloaded iOS devices. The release is dated November 26, 2026, and its listed sideloading builds are paired with Instagram 457.0. The table includes standard Instagram, a no-plugins edition, a duplicate-bundle edition and a TrollStore edition.

The update notes specifically call out bug fixes and compatibility changes for Instagram 457. The supplied material does not explain which internal Instagram changes required the compatibility work, so the clearest practical conclusion is that Regram 7.2 is the release intended for the listed Instagram 457.0 builds.

The package is identified as com.fouadraheb.regram, uses the iphoneos-arm architecture and declares dependencies on firmware version 14.0 or later and MobileSubstrate version 0.9.5000 or later. The Sileo depiction separately lists support as iOS 15.1 or later. Because those source entries do not match, users should check the compatibility information shown by their package manager and consider their exact jailbreak or sideloading setup before installing.

  • Regram version: 7.2.
  • Listed Instagram version: 457.0.
  • Release date: November 26, 2026.
  • Package architecture: iphoneos-arm.
  • Package dependencies include firmware 14.0 or later and MobileSubstrate 0.9.5000 or later.

Ghost Mode adds temporary privacy controls

Ghost Mode is one of the main additions in Regram 7.2. According to the release notes, it temporarily turns off Activity Status and hides typing, seen, story-view and view-once-seen indicators. When the temporary mode ends, the previous settings are restored.

The feature can be started by holding the Activity Status button, using Quick Controls, applying a Daily Schedule or using Shortcuts links. Its settings are located under Settings › Privacy › Ghost Mode. This gives users a temporary privacy state rather than requiring them to change several individual controls each time they want to reduce visible activity.

Activity Status also gains more flexible time controls. Holding its button in the direct-message inbox or Quick Controls can turn the status off or on for 15 minutes, one hour, four hours, until the following morning or until a chosen time. The release also fixes the control covering long usernames and verified badges. Finally, Hidden Chats, Media Vault and Settings Lock gain a Use Face ID switch. Turning that switch off allows passcode-only unlocking for those protected areas.

  • Ghost Mode hides Activity Status, typing, seen, story-view and view-once-seen indicators.
  • It can be launched from Quick Controls, the Activity Status button, schedules or Shortcuts.
  • Activity Status supports preset and custom time windows.
  • Protected areas can use Face ID or, when disabled, passcode-only unlocking.

Expanded filters cover more of Instagram

Regram 7.2 adds a Filters area with tabs for Feed, Reels, Stories and Explore. The release notes say users can hide content using criteria such as date, type, words and accounts, along with other available filtering options.

Hidden Accounts can hide someone’s posts, reels and stories without unfollowing, muting or blocking that person. The option is also available through Quick Controls, making it possible to adjust the experience without changing the underlying relationship between accounts.

A new Filter action appears in the action menus for Feed, Reels and Stories. It can hide similar posts with one tap, while the resulting toast offers an undo action. Reels behavior has also been adjusted. A reel opened from Feed, Explore or a chat should continue to open even when a filter or ad-hiding rule affects surrounding content, rather than sending the user to another reel. Filters still apply to the reels viewed afterward.

  • Separate filter areas are provided for Feed, Reels, Stories and Explore.
  • Hidden Accounts suppresses content without unfollowing, muting or blocking.
  • The one-tap Filter action can be reversed through its toast.
  • Reel-opening behavior was corrected when filters or ad hiding are active.

Messaging, Media Vault and playback changes

Messages gain configurable Chat Filters under Settings › Messages. Users can choose which filters appear above their chats and drag them into their preferred order. This change focuses on organizing the inbox while leaving the underlying conversations unchanged.

Media Vault smart folders and filters can now select several users at once. Users can also exclude people so their items do not appear in a vault view. These changes extend Regram’s existing media tools, which the project describes as supporting downloads and organization for several types of Instagram content.

The video player adds a rotate button for watching videos and photos in landscape in areas including Vault, Downloads and Expand. The rest of Instagram remains portrait-oriented. Stories also gain small but useful copying actions: a long press on a profile in the Mentions list can copy its username or profile link, while a long press on a viewer in Stories Archive › People can copy that viewer’s username.

The release also includes corrections for Profile Analyzer follow and unfollow history, Activity Alerts seen alerts and history, and incorrect Last Active displays that could show January 1, 1970 when Instagram provided no last-active time.

  • Chat Filters can be selected and reordered.
  • Media Vault filters support multiple included users and excluded users.
  • The player adds landscape rotation in specified Regram views.
  • Stories menus gain username and profile-link copying actions.
  • Several Profile Analyzer, Activity Alerts and message-status issues are fixed.

Follow safeguards and installation diagnostics

Warn Before Re-Following adds a confirmation step for a particular repeat-follow situation. Regram remembers people who were unfollowed when they were not following the account back, then asks before following them again. These accounts appear under a new Unfollowed filter.

The new Setup Check is available under Settings › Regram › Troubleshooting. It checks how the installation was signed and reports problems involving the certificate, entitlements such as push notifications, app groups and keychain access, and the application’s extensions. Share Report creates a copy of the diagnostic information for support requests.

These checks are especially relevant to sideloaded installations because the project documents different behavior for different signing methods. The README says that non-developer signing can expire after seven days. It also states that sideloaded installations require a distribution or ad-hoc signing certificate for push notifications, except for supported TrollStore installations. The result depends on the certificate, entitlements and installation method actually used.

  • Warn Before Re-Following remembers selected unfollowed accounts and requests confirmation.
  • Setup Check examines certificates, entitlements and extensions.
  • Share Report prepares diagnostic information for support.
  • Push notifications and expiration behavior depend on signing and installation details.

Direct Update beta and installation considerations

Regram 7.2 introduces Direct Update in beta for sideloaded Regram on iOS 18 or later. The documented process requires the user to add the certificate used to install Instagram through Settings › Support › Direct Update. Once configured, the user can tap Update on This iPhone when a new release becomes available, without using a computer or signing app.

The source limits this feature to the stated sideloading scenario. It should not be treated as a universal update method for every iOS version, jailbreak arrangement or signing service. Users outside the documented conditions should follow the installation process appropriate to their setup.

For jailbroken devices, the project’s instructions direct users to add its package source to a compatible package manager and install Regram there. For sideloading, the README lists separate standard, no-plugins, duplicate-bundle and TrollStore builds. It also says that an existing Instagram installation with the same bundle identifier should not already be installed when using AltStore-style installation.

Before updating, users should compare the Instagram build, bundle identifier, iOS requirement, signing method and notification needs with their own configuration. The differing minimum-version information in the supplied package sources is another reason to verify compatibility rather than relying on a single label.

  • Direct Update is beta-only and documented for sideloaded Regram on iOS 18 or later.
  • The installation certificate must be added before using Update on This iPhone.
  • Separate builds are listed for standard sideloading, no-plugins, duplicate-bundle and TrollStore use.
  • The package metadata and Sileo depiction provide different minimum iOS signals.

Frequently asked questions

What is new in Regram 7.2?

The release adds Instagram 457 compatibility updates, Ghost Mode, expanded Feed, Reels, Stories and Explore filters, Chat Filters, a Direct Update beta for qualifying sideloaded iOS 18 or later installations, Setup Check diagnostics, Media Vault improvements, landscape playback rotation, follow-request warnings and several bug fixes.

Does Regram 7.2 work on iOS 14?

The package stanza declares a firmware dependency of iOS 14.0 or later, while the Sileo depiction lists support as iOS 15.1 or later. Because these source entries differ, users should check the current package-manager information and their exact jailbreak or sideloading method before installing.

What does Ghost Mode hide?

According to the release notes, Ghost Mode temporarily hides Activity Status, typing, seen receipts, story views and view-once-seen activity. It can be started from the Activity Status button, Quick Controls, a schedule or Shortcuts, and the previous state is restored afterward.

Can sideloaded users update Regram without a computer?

The Direct Update beta is documented for sideloaded Regram on iOS 18 or later. Users must first add the certificate used to install Instagram under Settings › Support › Direct Update, after which the source says they can use Update on This iPhone.

Will push notifications work with every sideloading method?

No guarantee is given for every method. The README states that sideloaded installations need a distribution or ad-hoc signing certificate for push notifications, except for supported TrollStore installations. The result depends on the certificate and entitlements present.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
