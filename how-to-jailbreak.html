How to Jailbreak iOS 16 with palera1n on Mac, Linux or Windows

This guide follows palera1n’s current official workflow for supported checkm8 devices. It covers the compatibility checks that must happen before DFU mode, the correct Mac and Linux commands, the palen1x route for Windows, and Sileo installation after the first boot.

By Zeeshan Barvi · Originally published October 28, 2024 · Completely revised October 25, 2026 · Verified with the official palera1n installation and palen1x guides

Important: palera1n is not a jailbreak for every device running iOS 16. Confirm the hardware first. A11 devices have major passcode and SEP restrictions, and the official guide says an A11 device on iOS 16 must be erased before jailbreaking if a passcode has previously been set.

1. Check whether your iPhone is supported

palera1n is based on the checkm8 bootrom exploit, so support is determined by hardware as well as iOS. The official guide describes support for A11 and earlier devices on iOS 15.0 and later; the project repository gives the broader hardware scope as A8 through A11 and Apple T2 devices.

For iOS 16 iPhones, the practical range includes iPhone 6s/6s Plus, iPhone SE (1st generation), iPhone 7/7 Plus, iPhone 8/8 Plus and iPhone X, subject to the project’s current compatibility chart. Newer iPhones—iPhone XS/XR and later—cannot use palera1n merely because they run iOS 16.

2. Understand the A11 passcode warning

On A11 devices, palera1n requires the passcode to remain disabled in the jailbroken state. The official documentation groups passcode, Face ID/Touch ID and Apple Pay under SEP functionality that will not be available until the device boots back into stock iOS.

The more serious iOS 16 condition is historical passcode use: if an A11 device on iOS 16 has had a passcode set, the official guide says it must be erased with Erase All Content and Settings before it can be jailbroken. Back up and verify important data before making that irreversible decision. Disabling the passcode now is not presented by the project as a substitute for that erase requirement.

3. Choose the correct computer route

ComputerOfficial routeWhat not to use
macOSInstall with the official shell script, then run palera1n -l.Do not download lookalike packages from unrelated sites.
Native LinuxRun usbmuxd in the foreground, install with the official script, then run sudo palera1n -l.The guide warns about Ubuntu-family and AMD Ryzen issues.
WindowsBoot the official palen1x live environment from removable media.Do not use WSL, VirtualBox or VMware; the official guide says those routes will not work.

You need the computer again after a full reboot because palera1n is semi-tethered. The device can boot stock iOS by itself, but the palera1n flow must be repeated to restore the jailbroken state.

4. Prepare the cable and connection

The official guide warns that USB-C-to-Lightning connections can cause DFU problems. If DFU entry or device detection repeatedly fails, use a USB-A-to-Lightning cable and, where necessary, a USB-C-to-USB-A adapter. Avoid hubs while troubleshooting.

On Apple Silicon Macs, palera1n notes that users connected through a USB-C port may need to unplug and reconnect the device after Checkmate! appears in the log. This is a host-specific step, not a reason to disconnect at random during the rest of the process.

5A. Install and run palera1n on macOS

  1. Back up the device and confirm its exact model, chip and iOS version.
  2. Open Terminal.
  3. Run the official installer:
/bin/sh -c "$(curl -fsSL https://static.palera.in/scripts/install.sh)"

Press Enter when the installer offers the latest release. If it asks to add palera1n to PATH, type Y and press Enter.

  1. Connect the iPhone and run the rootless command:
palera1n -l
  1. Press Enter when ready and follow the onscreen instructions for your device to enter DFU mode.

5B. Install and run palera1n on Linux

The official Linux flow uses two Terminal windows. In the first, stop the system usbmuxd service and start usbmuxd in the foreground:

sudo systemctl stop usbmuxd
sudo usbmuxd -f -p

Leave that first window running. In a second Terminal window, run the official installer:

/bin/sh -c "$(curl -fsSL https://static.palera.in/scripts/install.sh)"

Accept the latest release and the PATH prompt if shown. With the iPhone connected, start the rootless flow:

sudo palera1n -l

Press Enter when prompted, then follow palera1n’s device-specific DFU instructions. Do not substitute generic button timings from another iPhone model.

5C. Use palen1x on Windows

palera1n does not provide the ordinary native-Windows flow implied by the old version of this article. The official Windows route is palen1x: a small bootable Linux environment.

  1. Use a removable drive of at least 128 MB and back up anything on it because preparing the drive erases it.
  2. Download the latest palen1x release and Ventoy from the links in the official palen1x guide.
  3. Use Ventoy to install to the selected USB drive, then copy the palen1x ISO onto that drive.
  4. Reboot, disable Secure Boot if required, and select the USB drive from the computer’s boot picker.
  5. At the Ventoy screen, boot palen1x and select Shell.
  6. Run:
palera1n -l
  1. Follow the onscreen DFU instructions.

WSL and a Linux virtual machine do not provide an equivalent shortcut. The official guide explicitly says VirtualBox, VMware and Windows Subsystem for Linux will not succeed for this workflow.

6. Complete DFU and handle the A9 workaround

DFU mode is a blank-screen firmware state, not the recovery screen with a cable graphic. Let palera1n provide the correct button sequence for the detected model. If the device returns to recovery, reconnect it and repeat the prompt rather than guessing a different device’s timings.

The official guide documents a separate issue for A9(X) and earlier devices: they may stop midway in pongoOS. In that case, press Control+C in the Terminal and rerun the same palera1n command. The workaround may be required on each rejailbreak.

7. Install Sileo from the palera1n loader

After the jailbreak boots, unlock the device and open the palera1n loader app. Tap Sileo. The loader will prepare the bootstrap, then prompt for the password used by command-line tools. Sileo should appear on the Home Screen after the process finishes.

Install only packages that explicitly support the rootless environment and your iOS version. See how to install a tweak safely with Sileo and the tweak compatibility checklist before building a queue.

8. Re-jailbreak after a full reboot

A normal restart returns the iPhone to stock mode. Your user data and installed jailbreak packages remain, but tweak injection is inactive. Reconnect the device to the same host route and rerun palera1n -l—or sudo palera1n -l on Linux—then complete DFU again.

Do not reinstall every package or erase the bootstrap after an ordinary reboot. If the device boot-loops only when tweaks are active, use the recovery steps in the bad-tweak recovery guide as general diagnostic context, while following palera1n-specific safe-mode controls from its current interface.

Common problems

The iPhone will not enter DFU mode

Use the onscreen sequence for the exact model, start from the requested recovery state, try USB-A-to-Lightning, remove USB hubs and repeat the timing carefully.

Linux cannot see the device

Confirm that the foreground sudo usbmuxd -f -p process is still running in the first Terminal and run palera1n with sudo in the second. The official guide also warns about Ubuntu-based distributions and AMD Ryzen hosts.

The process stops in pongoOS

For A9(X) and earlier devices, press Control+C and rerun the same palera1n command, as documented by the official guide.

Sileo does not appear

Open the palera1n loader after the jailbroken boot and complete the Sileo/bootstrap installation. Do not download an unrelated Sileo IPA.

Can I use the palera1n 3 beta GUI instead?

Beta 3 adds GUI AppImages for Linux, but it remains a pre-release. This guide follows the official release installer. Read the beta 3 release explainer before choosing the experimental build.

Frequently asked questions

Can palera1n jailbreak every iPhone on iOS 16?

No. It is limited by the checkm8-vulnerable hardware family. iPhone XS/XR and newer models are not supported by palera1n.

Is palera1n computer-free?

No. You need a Mac, native Linux host or bootable palen1x environment for the first jailbreak and again after each full reboot.

Can I keep a passcode on iPhone X while jailbroken?

The official guide says A11 devices must disable the passcode and lose SEP functionality while jailbroken. On iOS 16, a previously configured passcode triggers the documented erase requirement.

Is rootless the recommended command?

The official iPhone guide currently instructs users to run palera1n -l. This article does not use the old rootful -f flow.

Does the latest package’s iOS range prove my phone is supported?

No. Hardware, firmware, host and jailbreak-environment requirements must all match. An iOS version string alone does not establish jailbreak availability.
