EeveeSpotify 7.0.0 Adds iOS 26 Liquid Glass, Custom Tabs and Word-Synced Lyrics

EeveeSpotify 7.0.0 is a ground-up interface overhaul: it adds optional native Liquid Glass on iOS 26, rebuilds tab navigation and settings, expands custom lyrics, exposes Spotify remote flags, and ships a substantial batch of privacy and stability changes.

By Zeeshan Barvi · Published October 14, 2026 · Release checked against SideloadLabs’ official GitHub repository

Independent project: EeveeSpotifyReincarnated is an unofficial Spotify modification and is not affiliated with or endorsed by Spotify. The project warns that several subscription-dependent features remain server-side and cannot be enabled by the tweak.

What changed in EeveeSpotify 7.0.0?

The October 5, 2026 release replaces the older settings and appearance layer with a broad redesign aimed at Spotify 9.1.x. The headline addition is a native iOS 26 Liquid Glass mode, but the update also changes navigation, lyrics, privacy controls and troubleshooting.

  • Native Liquid Glass on iOS 26: separate switches can apply system glass to the tab bar, Now Playing bar, player, lyrics, search, Home and page headers.
  • Custom tabs: users can reorder or hide tabs, remove labels, select the launch tab and pin Spotify pages through spotify: URIs.
  • Word-synced lyrics: the custom lyrics view now supports per-word timing, configurable inactive-line blur, line-synced fallback sources and source attribution.
  • Remote flag browser: Spotify’s server-provided feature flags can be searched, overridden, filtered to changed values and reset individually.
  • Privacy switches: optional controls block several third-party tracking SDKs and App Store rating prompts, while Hide Jam removes Jam entry points.

Liquid Glass is limited to iOS 26

The tweak’s minimum system requirement is iOS 16.1, but the native Liquid Glass rendering path is specifically for iOS 26. The project says the appearance layer is opt-in and requires restarting Spotify after changing it. Users on iOS 16 through iOS 18 can use the other 7.0.0 features but will not receive native iOS 26 glass effects.

The implementation uses genuine UIKit glass surfaces rather than a generic blurred image. For example, the project describes a real UITabBar placed over Spotify’s hidden navigation bar, with taps forwarded to Spotify’s own items.

Custom navigation and appearance controls

Version 7.0.0 can turn Liked Songs, Downloads, Podcasts or Queue into fixed tabs, and it can pin other in-app destinations from Spotify URIs. Appearance controls include an AMOLED black theme, accent and background colours, rounded library artwork, album-derived backgrounds and per-page Home gradients.

The redesigned settings app groups options under Listening, Looks and Advanced. Pages have previews and individual reset controls, while a new troubleshooting area can export or clear debug logs.

Lyrics now follow the playing track

The release notes identify stale lyrics as a major fixed bug. Previously, the custom lyrics screen could remain attached to the song that was playing when it opened. In 7.0.0 it follows track changes, resets scroll and line state, and fetches the next song’s lyrics when needed.

The project also documents Spicy Lyrics API support, Musixmatch, LRCLIB, PetitLyrics and Genius in its README. Provider behavior differs: not every source offers synchronized timing, and some require the user’s own token or API key.

Privacy and stability fixes

The new privacy options can block Firebase, Facebook, Branch and other analytics integrations, suppress App Store review prompts, and remove Jam surfaces. These switches are disabled by default and require restarting Spotify.

Stability work covers an access-token race crash, karaoke long-press scope handling, settings tint leaks and iPad Liquid Glass sizing. The iPad tab bar now has a 50-point minimum height, and mini-player artwork clipping is applied consistently.

What still does not work?

The official README says very-high audio quality, native playlist downloads, remote Spotify Connect streaming, AI DJ and AI Playlist remain server-controlled. Version 7.0.0 does not claim to unlock those features. The release also notes that Clean Share Links still cannot remove Spotify’s si tracking parameter from the direct Messages route.

Should you update?

Version 7.0.0 is worth reviewing for users already on a supported EeveeSpotify setup because it combines a new interface architecture with concrete crash, iPad and lyrics-state fixes. Before updating, verify the installed Spotify build, iOS version, installation method and package architecture. Keep a copy of the working previous package or signed app so you can return if Spotify changes break compatibility.

Frequently asked questions

Does EeveeSpotify 7.0.0 require iOS 26?

No. The official minimum is iOS 16.1. Only the native Liquid Glass rendering requires iOS 26.

Does version 7.0.0 support every Spotify release?

No. Its release notes target Spotify 9.1.x. New Spotify versions can change private interfaces and should be checked against current project guidance.

Can I install it without a jailbreak?

The project documents a signed-IPA route and separate DEB packages for jailbroken devices. Use only legally obtained app files and an installation method already available to you.

Does it enable native Spotify downloads or very-high audio quality?

No. The project explicitly lists those as server-side restrictions that the tweak cannot provide.
