NextUp 3 v1.1.2: Upcoming-Track Controls in the Now-Playing UI

NextUp 3 version 1.1.2, by Yves, is listed as a media tweak that shows the upcoming track and provides a way to skip it from the now-playing UI. The package description lists Apple Music, Apple Podcasts, YouTube, YouTube Music, and Spotify, along with the Lock Screen, Control Center, and Dynamic Island. The package has iphoneos-arm and iphoneos-arm64 variants.
