Prism 1.2.0-2: Capture, Annotate, and Pin On-Screen Content

Prism is a System & Utilities tweak by blacknoisy. Release 1.2.0-2 is listed for the iphoneos-arm64 architecture and is described as providing tools to capture, annotate, and pin what matters on screen. Its package metadata lists firmware >= 16.0, mobilesubstrate >= 0.9.7100, com.opa334.ccsupport, and preferenceloader as dependencies.
