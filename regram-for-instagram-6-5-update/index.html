Regram 6.5 updates Instagram compatibility, follow-request tracking and Messages Only controls

Regram for Instagram 6.5 is a substantial maintenance and feature release for the jailbroken and sideloaded versions of Instagram. The update, released October 20, 2026, adds compatibility updates for Instagram 451 and 452, fixes a crash connected to the Reels Limit feature on Instagram 452, and introduces several changes to follow-request management. It also adds a dedicated Messages Only settings page, expands link-tracking removal, improves Media Watch handling, and addresses several interface and navigation bugs.

Key points

  • Regram 6.5 is listed as supporting Instagram versions 451 and 452, with sideloaded builds based on Instagram 452.0.1.
  • The release fixes a crash that could occur when opening a reel from the feed with Reels Limit enabled on Instagram 452.
  • Follow Requests gains a Received tab, request tracking, filters, badges, repeat-requester indicators and a warning for previously rejected requests.
  • Messages Only now has its own settings page, in-place switches, scheduling controls, an optional Profile tab and Shortcuts links.
  • The package metadata lists iOS 14.0 or later and MobileSubstrate 0.9.5000 or later as dependencies, while the depiction separately lists support as iOS 15.1+. Readers should resolve that difference against their installation method and device setup.

What Regram 6.5 changes

Regram 6.5 was released on October 20, 2026, according to the project’s package depiction and changelog. The release is centered on keeping the Instagram modification aligned with newer Instagram builds while adding several controls for messages, follow requests, media tracking and the feed interface.

The project describes Regram as an all-in-one enhancement tool for the official Instagram app on jailbroken or sideloaded iOS devices. Its existing feature set includes profile analysis, story archiving, media downloads, feed and Reels filtering, privacy controls, messaging enhancements and configurable interface changes. Version 6.5 extends those areas rather than introducing a completely separate app experience.

  • Compatibility and bug-fix updates for Instagram 451 and 452.
  • Sideloading entries in the official README are based on Instagram 452.0.1 and Regram 6.5.
  • The package identifier is com.fouadraheb.regram and the package version is 6.5.

Instagram 452 support and Reels fixes

The most important compatibility item is the stated update for Instagram 451 and 452. The project’s README lists four Regram 6.5 sideloading variants using Instagram 452.0.1: the standard Instagram bundle, a No-Plugins build, a duplicate-bundle build and a TrollStore build.

Reels Limit also receives a targeted repair. The changelog says Regram 6.5 fixes a crash when opening a reel from the feed on Instagram 452. This is particularly relevant for users who rely on the feature introduced in Regram 6.3, which can limit reels by daily count or minutes and provide usage statistics, charts and break reminders.

The release also fixes Instagram freezing on Reels when the Share button is hidden. That is separate from the Reels Limit repair, but both changes address instability involving Reels-related customization. The changelog further notes fixes for ads and Hide Reels in the Explore grid.

  • Reels Limit: crash fixed when opening a feed reel on Instagram 452.
  • Reels: freezing fixed when the Share button is hidden.
  • Reels Buttons: users can hide Instagram’s new Shop Similar button.
  • Feed: an option can hide the full-screen button displayed over reels.

Follow Requests becomes a more complete tracking tool

Follow Requests receives the most visible workflow expansion in this release. Regram can now warn before sending a follow request to someone who previously rejected one. The source says this warning is enabled by default, giving users an opportunity to reconsider before repeating the request.

A new Received tab tracks incoming follow requests and records whether they were approved, declined or withdrawn. Users can confirm or delete requests directly from the list, while repeat requesters are marked and new requests receive badges. The project says this tracking must be enabled through the Track Received Requests setting.

The list itself has also been redesigned. Filter chips now show counts, and empty states are clearer. These changes make the feature less dependent on manually checking individual profiles, although the source does not describe how long request history is retained or whether the information is synchronized outside the device.

  • Warning before sending a request to someone who rejected an earlier request.
  • Received tab for incoming requests and their status.
  • Confirm or delete requests from the list.
  • Badges for new requests and markers for repeat requesters.
  • Filter chips with counts and clearer empty states.

Messages Only adds scheduling and faster controls

Messages Only now has its own settings page rather than relying on a more general configuration area. The changelog says switches can be changed in place without restarting, which should make temporary messaging changes easier to apply.

The feature also gains automatic scheduling based on times and days. Users can configure the switch to change instantly or ask first. An optional Profile tab and Shortcuts links are included as additional access points. The source does not provide a complete list of which messaging behavior is controlled by the schedule, so readers should inspect the relevant settings before relying on it.

Regram’s broader messaging feature set includes reading direct messages without sending seen receipts, manually marking messages as seen, keeping unsent messages, disabling typing and screenshot notifications, downloading audio messages and converting video to audio. Version 6.5 specifically documents the Messages Only organization and control changes; it does not claim that every messaging behavior was changed.

  • Dedicated Messages Only settings page.
  • In-place switches that do not require a restart.
  • Schedules based on selected times and days.
  • Option to switch immediately or ask for confirmation.
  • Optional Profile tab and Shortcuts links.

Link privacy, Media Watch and profile tracking updates

Remove Tracking from Links now strips Instagram’s newer random tracking parameters, with the changelog giving rpxt and dlrf as examples. This builds on Regram’s existing link-related controls, but the release note does not claim that every possible Instagram parameter is removed.

Media Watch receives both reliability and management improvements. New posts that were not saved are now addressed, failed saves are retried, and the refresh interface indicates when the system is paused. The Media screen gains Select All, while Delete All Saved Media can be used for every account at once from the accounts list or settings.

Profile Tracking’s Watchlist can once again sort by Recently visited. When visits are being recorded, opened profiles move to the top. The broader Profile Tracking system can monitor watched accounts and, in the preceding release, was expanded around profile changes and saved media; 6.5 specifically calls out the sorting behavior and repairs Profile Tracking badges that failed to open when tapped.

  • New Instagram tracking parameters such as rpxt and dlrf are removed from links.
  • Media Watch retries posts that failed to save.
  • Refresh status now indicates when Media Watch is paused.
  • Select All and Delete All Saved Media improve cleanup.
  • Recently visited sorting returns to the Profile Tracking Watchlist.

Other fixes and interface changes

The update improves restart messaging with clearer Restart Now and Later buttons and an explanation that the change has already been saved. This distinction matters because users can postpone relaunching without assuming that their configuration was discarded.

Several navigation problems are also addressed. Custom tabs should open correctly after adding an account or logging out, and profiles opened from Stories Archive viewers and other lists should appear on top of the current screen instead of closing all screens first.

The changelog also lists fixes for Profile Tracking badges, Explore-grid ads and Hide Reels behavior. These are targeted corrections rather than a promise that all Instagram interface changes will remain compatible indefinitely.

  • Clearer restart choices and saved-change messaging.
  • Custom tabs fixed after account additions or logout.
  • Profiles from archive and list views open without closing the existing navigation stack.
  • Explore-grid ads and Hide Reels behavior fixed.

Compatibility and installation considerations

The package stanza lists a firmware dependency of iOS 14.0 or later and MobileSubstrate 0.9.5000 or later. However, the Sileo depiction separately lists support as iOS 15.1+. That difference should be treated as an item to resolve before installation rather than assumed compatibility. The package metadata and depiction may describe different installation contexts, so users should check the project’s current instructions for their specific jailbreak, iOS version and Instagram build.

For jailbroken devices, the official README instructs users to add the project’s package source to a compatible package manager such as Cydia, Zebra or Sileo, then install Regram from there. The package metadata also lists a conflict with com.b4db1r3.cleancopy, which users should account for if that package is installed.

For non-jailbroken devices, the project documents sideloading through AltStore, certificate-based signing and TrollStore on supported iOS 14 through 16.6.1 scenarios. The README says AltStore installation requires a macOS or Windows computer, an internet connection and an Apple ID; iOS 16 users may need Developer Mode. It also warns that another Instagram app with the same bundle identifier should not already be installed.

Signing details affect longevity and notifications. The README says a non-developer Apple account causes an app to expire after seven days, while AltStore can automate re-signing when connected to a computer. Push notifications are not available for sideloaded builds unless the app is properly signed with a Distribution or Ad-Hoc certificate, except for TrollStore on supported devices. A paid certificate should use the original bundle build and a Distribution or Ad-Hoc certificate for notifications.

  • Check the discrepancy between the package’s iOS 14.0 dependency and the depiction’s iOS 15.1+ support listing.
  • Match the build to the intended Instagram version and bundle identifier.
  • Remove or account for conflicting packages before a jailbroken installation.
  • Confirm signing, expiration and push-notification limitations for sideloading.
  • Use only the project’s documented official installation routes and verify the current release notes before proceeding.

Frequently asked questions

What is Regram 6.5?

Regram 6.5 is an enhancement package for the official Instagram app on jailbroken or sideloaded iOS devices. The release adds Instagram 451 and 452 compatibility updates, bug fixes and new controls for follow requests, messages, links, media tracking and interface elements.

Which Instagram version is used by the Regram 6.5 sideloaded builds?

The official README lists the sideloaded variants with Instagram version 452.0.1 and Regram 6.5. The changelog describes compatibility updates for Instagram 451 and 452.

Does Regram 6.5 fix a Reels crash?

Yes. The changelog specifically says Reels Limit’s crash when opening a reel from the feed on Instagram 452 has been fixed. It also lists a separate fix for Instagram freezing on Reels when the Share button is hidden.

What is new in Follow Requests?

The update adds a warning before sending a request to someone who previously rejected one, a Received tab for tracking incoming requests, request-status information, direct confirm and delete actions, new-request badges, repeat-requester indicators and filter chips with counts.

Does Messages Only require a restart after changing switches?

The 6.5 changelog says Messages Only switches can be changed in place without a restart. It also adds scheduling by times and days, with an option to switch immediately or ask first.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
