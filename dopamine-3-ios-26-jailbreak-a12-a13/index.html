The Dopamine 3.x README documents iOS 26 compatibility specifically for A12 and A13 devices. This should not be treated as general support for every arm64e or arm64 device. The README lists separate ranges for arm64e, A12/A13, and arm64, so the device category must be checked alongside the iOS version. Dopamine is described as a rootless semi-untethered jailbreak.

Dopamine 3 compatibility ranges by device category

These ranges should be kept distinct when checking a device. The A12/A13 iOS 26 entry does not expand the arm64e range, and the arm64 range does not establish iOS 26 support. Likewise, the arm64e endpoint at iOS 17.3.1 should not be extended to later iOS 17 point releases.
