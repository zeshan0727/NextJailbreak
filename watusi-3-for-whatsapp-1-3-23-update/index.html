Watusi 3 for WhatsApp 1.3.23 Targets WhatsApp 26.36.X Compatibility

Watusi 3 for WhatsApp version 1.3.23 is a maintenance release focused on compatibility and bug fixes. The official release notes mention support for WhatsApp 26.36.X, a fix for a crash that could occur when opening links with the In-App Browser enabled, and a repair for the chats-list statuses bar when WhatsApp uses its newer internal status storage. The package description continues to list extensive privacy, status, chat, media, notification, scheduling, auto-reply, theme, hidden-chat, tone, and sticker features. A separate Simplified Chinese language-pack project adds translations and a language-menu entry, but its README identifies Watusi 1.3.9 as its base, so compatibility with Watusi 1.3.23 should be verified rather than assumed.

Key points

  • Watusi 3 version 1.3.23 is described as supporting WhatsApp 26.36.X.
  • The update fixes a crash associated with opening links while the In-App Browser is enabled.
  • It addresses the chats-list statuses bar when WhatsApp uses newer internal status storage.
  • The package stanza lists firmware 12.0 or later and dependencies including MobileSubstrate, Watusi Tools 2.8.3 or later, and libmryipc.
  • The official depiction separately lists support for iOS 15.1 or later, so users should check compatibility in their own package environment.
  • The separate Simplified Chinese language pack is documented as being based on Watusi 1.3.9, not explicitly on 1.3.23.

A maintenance-focused Watusi update

Watusi 3 version 1.3.23 is presented as an all-in-one tweak for WhatsApp Messenger, but the current release itself is principally a compatibility and stability update. The official changelog lists general bug fixes and support for WhatsApp 26.36.X rather than announcing a new major feature category.

That distinction is useful because Watusi modifies a broad range of WhatsApp areas. Its package description covers privacy controls, status tools, chat behavior, chat-list organization, media handling, notifications, themes, scheduled messages, auto-replies, hidden chats, contact presentation, custom tones, and sticker management. Version 1.3.23 should therefore be understood as maintenance for that existing feature set.

  • Version: 1.3.23
  • WhatsApp compatibility named in the release notes: 26.36.X
  • Release focus: bug fixes and compatibility work
  • Date shown in the official depiction: September 11, 2026

In-App Browser crash fix

The official feature list includes an In-App Web Browser under Watusi’s Chats section. For version 1.3.23, the changelog specifically reports a fix for a crash when opening a link with the In-App Browser enabled.

The supplied release note does not identify a more precise trigger, affected link type, or claim that every browser-related issue has been resolved. The supported conclusion is narrower: the update addresses the reported crash scenario. Users who depend on Watusi’s in-app browsing option have a concrete reason to review this release, especially if opening links previously caused WhatsApp to close unexpectedly.

  • The fix concerns links opened through Watusi’s In-App Browser.
  • The source describes a crash fix, not a complete redesign of the browser feature.
  • The changelog does not provide additional troubleshooting or rollback instructions.

Chats-list statuses and newer internal storage

The second named fix concerns the statuses bar displayed in WhatsApp’s chats list. According to the official release notes, the bar could show no statuses when WhatsApp used its newer internal status storage. Version 1.3.23 is described as fixing that behavior.

The same note says the newer storage system is rolling out to more users. That means WhatsApp installations may not expose identical status behavior at the same time. The update is intended to address the newer storage path, but the source does not specify every affected WhatsApp build or explain how the rollout is controlled.

This change fits the broader status functionality listed for Watusi. The package description includes statuses in the chats list, status downloads, manual marking as viewed, status archiving, preservation of deleted contact statuses, long-video splitting, privacy groups, and controls for status-tab badges. The 1.3.23 note specifically confirms only the chats-list statuses-bar repair described above.

  • Affected interface: the statuses bar in the chats list.
  • Reported cause: WhatsApp’s newer internal status storage.
  • Rollout condition: the newer storage system is being introduced to more users.

What Watusi already includes

The package page describes privacy options such as freezing Last Seen, disabling read, typing, recording, and delivery indicators, disabling Internet access, hiding call controls, blocking incoming calls, and automatically switching Last Seen privacy. Protection options include app protection, chat protection, and hiding the last message.

Status and chat tools include status downloads, status archiving, chat details, continued audio messages, call confirmation, tap-to-record, continuous-playback controls, message forwarding, forwarding-contact limits, sticker-send confirmation, an in-app browser, and broadcast-chat actions. Chat-list functions include filtering and sorting, unlimited pinned chats, archive locking, groups lists, swipe actions, and a clear-chats button.

The listed media and interface controls cover custom sharing, profile-photo saving, photo limits, media forwarding and deletion, captured-media saving, large-emoji behavior, seconds on timestamps, keyboard visibility, landscape and large-title controls, picture and button visibility, sound settings, fullscreen modes, and iPad fullscreen support. Notifications, themes, message scheduling, auto-reply rules, hidden chats, contact customization, custom tones, and sticker-pack management are also listed.

The package description also says that a Control Center toggle is included. CCSupport must be downloaded and activated through Control Center settings before that toggle can be used. These capabilities are part of Watusi’s documented feature set; they are not presented as new additions in version 1.3.23.

  • Privacy and protection controls
  • Status, chat, and chat-list customization
  • Media, notification, theme, and interface options
  • Message scheduling and configurable auto-reply tools
  • Hidden chats, contact customization, tones, and sticker packs
  • Optional Control Center integration through CCSupport

Package requirements and compatibility checks

The official package stanza identifies the package as com.fouadraheb.watusi3 and lists a firmware dependency of version 12.0 or later. It also requires MobileSubstrate version 0.9.5000 or later, Watusi Tools version 2.8.3 or later, and com.muirey03.libmryipc. The stanza lists the architecture as iphoneos-arm and declares conflicts with several older or alternative Watusi package identifiers.

The official Sileo depiction separately states support for iOS 15.1 or later. Because the package stanza and depiction provide different compatibility fields, neither should be treated as a complete substitute for checking the actual device and jailbreak environment. Users should rely on the package manager’s dependency resolution and verify that the installed WhatsApp version matches the release’s stated 26.36.X target.

The sources also show different size figures: the depiction reports 2.45 MB, while the package stanza reports 2,729,004 bytes. These may reflect different calculations or presentation methods. Storage needs are best judged through the package manager rather than inferred from one field.

  • Firmware field in the package stanza: 12.0 or later
  • iOS support field in the official depiction: 15.1 or later
  • Required Watusi Tools version: 2.8.3 or later
  • Other listed requirements: MobileSubstrate and com.muirey03.libmryipc
  • Conflicts are declared for several older Watusi package identifiers

The separate Simplified Chinese language pack

The supplied repository metadata identifies a separate project named WatusiZhHans. Its description says it provides a Chinese language pack for Watusi 3, and the README says the project adds Chinese translations and uses a minimal runtime hook to add “简体中文” to Watusi’s Language menu under Other Settings. The repository metadata identifies Tune as the project author; the supplied sources do not establish a broader maintenance classification.

The documented installation flow is straightforward: install the language-pack deb, fully terminate WhatsApp, reopen it, then navigate to Watusi, Other Settings, and Language before selecting 简体中文. The README also suggests trying Language set to Auto when WhatsApp or the system language is Simplified Chinese.

There is an important version caveat. The README explicitly says the language pack is based on Watusi 1.3.9, while the current Watusi package in the supplied material is version 1.3.23. Earlier package metadata for the language pack declared an exact dependency on Watusi 1.3.9; a later revision shown in the source declares the Watusi package without an exact version. That change does not prove compatibility with 1.3.23.

The project’s maintenance notes recommend rechecking the language hook, language-list construction, and FRSListCell-related signatures after a Watusi upgrade. Those notes indicate that localization behavior can require adjustment when Watusi changes. Users should therefore treat the language pack as a separate, version-sensitive component.

  • Adds Simplified Chinese translations.
  • Adds a 简体中文 option to Watusi’s language menu through a runtime hook.
  • README base version: Watusi 1.3.9.
  • Compatibility with Watusi 1.3.23 is not explicitly confirmed in the supplied sources.
  • The documented flow requires fully closing and reopening WhatsApp after installation.

Who should consider updating

Users running WhatsApp 26.36.X may want to review 1.3.23 because the official release notes specifically target that compatibility range. The update is also relevant to users who rely on the In-App Browser or who encountered an empty statuses bar in the chats list after WhatsApp moved them to newer internal status storage.

Before installing, check the package manager’s dependency results, the device’s firmware and jailbreak architecture, and any conflicts with an older Watusi package. The changelog describes fixes, but it does not guarantee that every configuration will behave identically after an update.

Anyone using the Simplified Chinese localization should perform a separate compatibility check. A language pack based on Watusi 1.3.9 should not automatically be treated as a version-matched add-on for Watusi 1.3.23.

  • Confirm the WhatsApp version and the stated 26.36.X compatibility target.
  • Verify firmware, architecture, dependencies, and package conflicts.
  • Review the In-App Browser and chats-list status fixes if those features matter to you.
  • Check the Chinese language pack separately instead of assuming version compatibility.
  • Do not infer successful installation or universal behavior from release notes alone.
