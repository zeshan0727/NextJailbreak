Watusi 3 for WhatsApp 1.3.30 adds WhatsApp 26.42 support and fixes Share Sheet failures

Fouad Raheb’s Watusi 3 for WhatsApp has reached version 1.3.30. According to the official package information and depiction, the release adds bug fixes and support for WhatsApp 26.42, repairs sending failures affecting multiple Share Sheet content types, and fixes Watusi failing to load on RootHide after conversion with RootHide Patcher. The package is listed for iOS 15.1 and later, while its package dependencies require firmware 12.0 or newer, MobileSubstrate 0.9.5000 or newer, and Watusi Tools 2.8.3 or newer.

Key points

  • Watusi 3 version 1.3.30 is listed as supporting WhatsApp 26.42.
  • The release fixes Share Sheet sending for photos, videos, documents, camera captures, contacts, and locations.
  • The update addresses Watusi not loading on RootHide after conversion with RootHide Patcher.
  • The official depiction lists support for iOS 15.1 and later; package metadata also requires firmware 12.0 or newer.
  • The package conflicts with several older Watusi package identifiers, so an existing installation should be checked before updating.
  • A separate Simplified Chinese language project has been reworked to generate rootful, rootless, and roothide packages, but its README says the translations are based on Watusi 1.3.9.

What changed in Watusi 3 version 1.3.30

Watusi 3 for WhatsApp version 1.3.30 is described by its official package page as a maintenance release focused on compatibility and bug fixes. The listed target is WhatsApp 26.42, making this update primarily relevant to users who have moved to that WhatsApp version and rely on Watusi features integrated into WhatsApp’s sharing and launch behavior.

The release notes identify one broad functional repair: photos, videos, documents, camera captures, contacts, and locations were not sending from the Share Sheet. The update is therefore more than a version-label change for affected users. It addresses several content categories within the same iOS sharing workflow, although the source does not provide additional technical details about the underlying cause or the exact WhatsApp builds affected beyond the stated WhatsApp 26.42 support.

  • Version: 1.3.30
  • Release date shown by the official depiction: November 3, 2026
  • Listed WhatsApp target: 26.42
  • Share Sheet fixes cover six named content categories
  • RootHide loading issue fixed after conversion with RootHide Patcher

RootHide compatibility is part of the release focus

The second specific fix concerns RootHide. The official changelog says Watusi was not loading on RootHide after being converted with RootHide Patcher, and that behavior is fixed in 1.3.30. This is a compatibility correction for a particular conversion and deployment path, not a general statement that every RootHide configuration is supported.

Readers using RootHide should still distinguish between the release note and a guarantee for their own setup. The available source does not list every supported RootHide version, conversion sequence, jailbreak environment, or WhatsApp build combination. Before updating, users should compare their environment with the package’s current requirements and retain a recovery plan for reverting or removing the tweak if WhatsApp does not load as expected.

Compatibility, dependencies, and package identity

The official depiction lists Watusi 3 as supporting iOS 15.1 and later. The package stanza separately declares a firmware dependency of 12.0 or newer, along with MobileSubstrate 0.9.5000 or newer and Watusi Tools 2.8.3 or newer. These entries should be read together rather than treated as interchangeable: the depiction’s published support field says iOS 15.1+, while the package dependency expresses the minimum firmware requirement accepted by the package manager.

The package is identified as com.fouadraheb.watusi3, uses the iphoneos-arm64 architecture, and has a listed package size of 2,547,296 bytes. It conflicts with older or alternate Watusi identifiers, including com.fouadraheb.watusi, com.f0u4d.watusi, org.thebigboss.watusi, and com.b4db1r3.cleancopy. Those conflicts mean users should check for an existing package under one of these identifiers before proceeding, particularly if their package manager proposes a removal or replacement.

The official description presents Watusi as an all-in-one WhatsApp tweak with settings covering privacy, protection, statuses, chats, chat-list behavior, media, interface controls, notifications, themes, message scheduling, auto-replies, hidden chats, contact customization, custom tones, and sticker management. The 1.3.30 notes do not announce new features in those areas; the documented changes are compatibility and repair work.

  • Published support field: iOS 15.1+
  • Declared firmware dependency: 12.0 or newer
  • Declared MobileSubstrate dependency: 0.9.5000 or newer
  • Declared Watusi Tools dependency: 2.8.3 or newer
  • Architecture: iphoneos-arm64
  • Package identifier: com.fouadraheb.watusi3

What to verify before updating

The most important check is the WhatsApp version currently installed. Watusi 1.3.30 specifically lists support for WhatsApp 26.42, so users should not assume that the same compatibility statement applies to an unrelated WhatsApp release. The official changelog also shows that recent Watusi versions have tracked changing WhatsApp builds, including earlier 26.41, 26.38, 26.37, 26.36, 26.32, 26.30, and 26.29 branches. That history makes version matching particularly important.

Next, verify the jailbreak environment and dependency state. The package metadata names MobileSubstrate and Watusi Tools requirements, while the changelog calls out a RootHide conversion issue. A package manager should resolve declared dependencies, but users should still review the proposed transaction and confirm that it is not removing a required component or leaving an older conflicting Watusi package installed.

Finally, back up or otherwise safeguard important WhatsApp data according to the user’s normal maintenance process. The source does not claim that the update changes chats or media, and it does not provide a backup guarantee. It is therefore better to treat the update as a tweak replacement affecting WhatsApp’s runtime and sharing behavior, rather than as a risk-free application update.

  • Check the installed WhatsApp build against the stated 26.42 target.
  • Review package-manager dependency and conflict warnings.
  • Confirm whether the device uses a RootHide conversion workflow.
  • Keep a recovery option available if WhatsApp fails to launch.
  • Do not infer support for unlisted jailbreak or WhatsApp combinations.

Simplified Chinese language pack receives packaging changes

A separate official GitHub project provides a Simplified Chinese language pack for Watusi 3. Its README describes the project as based on Watusi 1.3.9 and says it adds Chinese translations plus a small runtime hook that inserts 简体中文 into Watusi’s Other Settings > Language menu.

The project’s latest supplied commit describes a packaging refactor. It adds a unified build_packages.sh process that serially generates rootful, rootless, and roothide installation packages, restructures localization generation by target stage, and retains zh-Hans.lproj as the localization resource. The commit also removes older duplicated Chinese localization paths from the shown layout changes.

This language project should not be confused with a localization update for Watusi 1.3.30. Its README explicitly says the translations are based on Watusi 1.3.9, and the project’s maintenance notes say that a future Watusi upgrade would require rechecking the language hook, language-list construction, and FRSListCell-related signatures. Users pairing it with newer Watusi builds should therefore verify that the language menu and translated resources remain compatible.

  • The language pack adds Simplified Chinese translations.
  • The README instructs users to fully terminate WhatsApp and reopen it after installation.
  • The language can be selected through Watusi > Other Settings > Language.
  • Auto language selection may be attempted when WhatsApp or the system uses Simplified Chinese.
  • The project’s stated translation base is Watusi 1.3.9, not 1.3.30.

They should confirm that their setup uses the conversion path addressed by the changelog, review dependency and conflict warnings, and keep a recovery option available. The source does not list every RootHide or WhatsApp configuration covered by the fix.
