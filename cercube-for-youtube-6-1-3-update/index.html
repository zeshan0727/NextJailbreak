Cercube for YouTube 6.1.3 adds dislike counts, sponsor skipping, and iOS 15–16 support

Cercube for YouTube version 6.1.3 is available through the Havoc repository with a changelog focused on YouTube playback and discovery improvements. The release adds dislike counts to video descriptions, automatic sponsored-segment skipping, support for 14 languages, and what the developer describes as a more integrated playback experience. The package metadata requires firmware 15.0 or newer and mobilesubstrate, while the package depiction lists iOS versions from 15.0 through 26.0.1. However, the changelog specifically calls out compatibility for iOS 15–16, so users on newer versions should confirm support in their package manager before proceeding.

Key points

  • Cercube for YouTube 6.1.3 is package version 6.1.3 for the identifier com.cercube.ios.
  • The release adds dislike counts to video descriptions and automatic sponsored-segment skipping.
  • The changelog lists support for 14 languages, including English, Arabic, French, German, and Spanish.
  • The package requires firmware 15.0 or newer and mobilesubstrate.
  • The depiction lists iOS 15.0–26.0.1, but the changelog specifically mentions iOS 15–16 compatibility; users should resolve that discrepancy before installing.
  • The tweak requires the YouTube app from the App Store. The official material does not provide a detailed bug-fix list or explain the exact implementation of each new feature.

What is new in Cercube 6.1.3

Cercube for YouTube 6.1.3 is presented as an update centered on video discovery, playback convenience, and broader localization. Its changelog says the release adds dislike counts, automatic sponsored-segment skipping, and a more integrated playback experience. It also records minor bug fixes and improvements, without listing those fixes individually.

The clearest user-facing change is the addition of a dislike count to video descriptions. The source does not say whether the count appears on every video, how frequently it refreshes, or whether it depends on a particular YouTube app version. Those details should therefore be treated as unconfirmed until they are documented by the developer.

  • Dislike counts are added to video descriptions.
  • Sponsored segments can be skipped automatically, according to the changelog.
  • The release adds support for 14 languages.
  • The changelog mentions minor bug fixes and improvements without providing a complete itemized list.

Dislike counts return to the viewing experience

Cercube’s 6.1.3 description specifically says that dislike counts have been added to video descriptions. For users who use engagement information when deciding whether to watch or trust a video, that places an additional signal alongside the existing description and video details.

The official material does not explain the data source for the count, its update interval, or whether it is available for videos with limited public engagement information. It is safest to understand this as a feature advertised by the tweak rather than assume universal availability across all videos or YouTube app releases.

Automatic sponsored-segment skipping

The other prominent addition is automatic skipping of sponsored segments. The changelog identifies this as a new capability, while the main description lists sponsored-segment skipping among the tweak’s features. The source does not define which segments are recognized, how detection works, or whether every sponsored segment will be skipped successfully.

That distinction matters because the feature is described as automatic, but no coverage guarantee is made. Users should not interpret the listing as a promise that all promotions, advertisements, or sponsor messages will be removed. The same depiction separately describes blocking supported video, feed, and Shorts ads, so ad blocking and sponsored-segment skipping should be treated as separate advertised functions.

  • Sponsored segments and supported YouTube advertisements are described separately in the official listing.
  • The source does not specify detection coverage, supported content types beyond the listed ad categories, or behavior when a segment is not recognized.

Language support expands to 14 languages

Cercube 6.1.3 adds support for 14 languages. The changelog explicitly names English, Arabic, French, German, and Spanish among them, while the feature description also lists English, Spanish, and Arabic as examples.

The official material does not provide the complete language list. As a result, readers should rely on the language selector or package documentation available in their installation environment for the remaining supported languages rather than assume that every part of the YouTube app or every Cercube setting has been translated.

Existing capabilities listed by the package

The official depiction continues to describe Cercube as a broad YouTube customization tweak rather than a single-purpose extension. It requires the YouTube app from the App Store and lists media caching for offline playback, Picture in Picture, background video and audio playback, and blocking supported video, feed, and Shorts advertisements.

The package also advertises separate default playback-quality controls for Wi-Fi and cellular data, tab reordering or hiding, startup-page selection, automatic video replay, dislike counts, queuing support, and the newly listed sponsored-segment skipping. These are descriptions of the package’s stated capabilities; the supplied source does not include a detailed compatibility matrix for each individual function.

  • Requires the YouTube app from the App Store.
  • Advertised playback features include Picture in Picture and background video or audio playback.
  • The listing describes media caching for offline playback.
  • Playback quality can be selected separately for Wi-Fi and cellular data, according to the depiction.
  • The tweak advertises tab customization, startup-page selection, replay, and video queuing.

Compatibility and dependency details

The package stanza identifies version 6.1.3 as an arm64 iPhoneOS package and declares two dependencies: firmware at version 15.0 or newer and mobilesubstrate. That means an installation environment must satisfy the package manager’s firmware requirement and provide the listed substrate dependency before the package can be configured.

The depiction’s information section lists iOS versions from 15.0 through 26.0.1. At the same time, the 6.1.3 changelog says that compatibility for iOS 15–16 was added. Those statements are not identical: one presents a wider version range, while the other specifically calls out iOS 15 and 16. The supplied source does not explain whether the wider range reflects tested support, a repository metadata range, or a broader intended target.

For that reason, users should check the compatibility shown by their package manager and confirm that their installed YouTube version and tweak-injection environment are supported. The package listing alone does not establish that every feature works identically across all versions in the displayed range.

  • Declared firmware requirement: 15.0 or newer.
  • Declared dependency: mobilesubstrate.
  • Package architecture: iphoneos-arm64.
  • The depiction lists iOS 15.0–26.0.1.
  • The changelog specifically mentions compatibility for iOS 15–16, creating a compatibility detail that should be clarified before installation.

Package size and release information

The package metadata reports an installed size of 3,384 units and a download size of 2,017,412 bytes. The user-facing depiction rounds the package size to 1.92 MB. These figures describe the package and may be displayed differently depending on whether a package manager is showing compressed download size or a rounded presentation value.

The official depiction dates version 6.1.3 to September 14, 2026. The seller is identified as cercube, and the package author and maintainer fields also identify cercube. The source does not include a separate developer statement explaining the release schedule or the individual minor fixes.

What to verify before installing

Before installing Cercube 6.1.3, confirm that the device meets the declared firmware requirement and that mobilesubstrate is available in the intended environment. Also confirm that the official YouTube app from the App Store is installed, since the depiction identifies it as a requirement.

The iOS compatibility wording deserves particular attention. The depiction displays iOS 15.0 through 26.0.1, while the changelog specifically references iOS 15–16. Users outside iOS 15 or 16 should not assume compatibility solely from the broader range shown in the information panel. Checking the package manager’s current compatibility warning and any developer-provided clarification is the prudent step.

Finally, users should remember that the source describes capabilities but does not document support for every YouTube release. YouTube changes can affect injected tweaks, playback behavior, ad handling, and interface integrations. The supplied release notes do not identify a required YouTube app version, so that detail should be checked separately before applying the update.

  • Confirm the device is on firmware 15.0 or newer.
  • Confirm mobilesubstrate is present and compatible with the installation environment.
  • Install or retain the official YouTube app from the App Store.
  • Resolve the difference between the displayed iOS 15.0–26.0.1 range and the changelog’s iOS 15–16 wording.
  • Check for YouTube app-version requirements or warnings in the package manager before updating.

Frequently asked questions

What is Cercube for YouTube 6.1.3?

It is version 6.1.3 of the Cercube for YouTube package, identified as com.cercube.ios. The official description presents it as a tweak designed to add playback, customization, ad-handling, and media features to the YouTube app.

What are the main new features in version 6.1.3?

The changelog lists dislike counts in video descriptions, automatic sponsored-segment skipping, support for 14 languages, compatibility for iOS 15–16, and minor bug fixes and improvements. It also describes the release as providing a more integrated playback experience.

Which iOS versions are supported?

The package metadata requires firmware 15.0 or newer. Its depiction lists iOS 15.0 through 26.0.1, while the changelog specifically says compatibility for iOS 15–16 was added. Because those statements differ in scope, users should confirm support for their exact iOS version before installation.

Does Cercube require the YouTube app?

Yes. The official depiction says it requires the YouTube app from the App Store.

Does Cercube 6.1.3 block all advertisements?

The depiction advertises blocking supported video, feed, and Shorts ads. It does not promise that every advertisement will be blocked. Sponsored-segment skipping is listed separately and likewise comes without a stated coverage guarantee.
