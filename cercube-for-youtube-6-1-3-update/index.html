Cercube 6.3.0 Adds iPad Sidebar Layouts and a Cache “All” Filter

Cercube 6.3.0 is a focused interface update for the YouTube jailbreak tweak. Released October 1, 2026, it introduces full-screen iPad settings and cache views with a sidebar, adds one place to see every cached item, and refreshes several cache-screen visuals.

The short version

  • Current version: 6.3.0, released October 1, 2026.
  • Main change: a full-screen iPad settings and cache interface organized with a sidebar.
  • Cache browsing: a new “All” filter combines cached items in one view.
  • Visual refresh: updated cache thumbnails, duration badges and settings icon.
  • Package requirements: the YouTube app, a compatible jailbreak and tweak injection; Havoc marks the package as rootless-compatible.
  • Listed package range: iOS 15.0–26.0.1. This does not establish jailbreak availability for every device on every version in that range.

What Cercube 6.3.0 changes

The official 6.3.0 changelog is short and specific. Cercube now gives iPad users full-screen settings and cache interfaces using a sidebar layout. The change should make better use of the larger display instead of presenting the phone-oriented view at iPad scale.

The release also adds an All filter to the cache screen. Cercube’s media-cache feature can save supported content for offline playback; the new filter is intended to surface the complete cache without requiring users to move between narrower categories.

Finally, the developer refreshed cache thumbnails, duration badges and the settings icon so those elements fit the surrounding YouTube interface more closely. Havoc does not claim new download formats, expanded jailbreak coverage or a new YouTube-version requirement in this release.

Why the iPad layout matters

Cercube already advertises offline media caching, Picture in Picture, background playback, supported ad blocking, video queuing and interface customization. On iPad, managing those options inside a compact phone-style panel wastes screen space and makes a large cache harder to scan.

The 6.3.0 sidebar design directly addresses navigation on the larger canvas. It is an interface change, not a claim that playback or downloading is faster. Readers should update for the revised layout and cache organization—not expect an undocumented engine rewrite.

What remains from Cercube 6.1.3

Version 6.3.0 follows the September 18 release covered earlier on this page. The official history still attributes these additions to 6.1.3:

  • Dislike counts in video descriptions.
  • Automatic sponsored-segment skipping.
  • Fourteen interface languages, including English, Arabic, French, German and Spanish.
  • Compatibility work for iOS 15 and iOS 16.

Those earlier features remain part of the current package description. The 6.3.0 notes do not say that any were removed or substantially changed.

Current compatibility and requirements

Havoc lists Cercube 6.3.0 as a free, 1.94 MB, rootless-compatible jailbreak tweak for iOS 15.0 through 26.0.1. The listing also states that the official YouTube app from the App Store is required.

That firmware range describes the package’s declared compatibility. It does not mean every iPhone or iPad on iOS 15–26 has a public jailbreak. Your exact device, firmware, jailbreak and tweak-injection environment must be supported independently. A package manager displaying the tweak is not proof that a jailbreak exists for the device.

The 6.3.0 release notes do not identify a minimum or maximum YouTube app build. Because YouTube interface updates can break injected tweaks, check the live Havoc depiction and any package-manager warning before changing the YouTube app version.

Should you update?

iPad users have the clearest reason to install 6.3.0 because the new full-screen sidebar interfaces target their settings and cache workflows. Users with large offline caches may also benefit from the new All filter.

iPhone users receive the refreshed thumbnails, duration badges and settings icon, but the headline layout change is iPad-focused. If 6.1.3 is already stable on your setup, the official notes provide no urgent security or crash-fix claim that would require immediate action.

Before updating, keep a record of the currently working Cercube and YouTube versions. If your jailbreak supports package downgrades, confirming that the older package remains available provides a practical rollback path.
