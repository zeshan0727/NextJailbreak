Cyanide 1.16.0 Adds Reversible Supervision and Restores Background Live Tweaks

Released October 30, 2026, Cyanide 1.16.0 adds a reversible supervised-state control, moves Gravity Lite out of the Installer, and fixes several live-tweak failures. It still is not a full jailbreak: it runs a maintained set of in-memory tweaks through a kernel primitive, and its narrow firmware windows and A18/M4 reliability warning matter more than the version number alone.

What changed in Cyanide 1.16.0

  • Supervision control: Settings → System → Supervision can mark a personal device as supervised under the organization name “Cyanide,” enabling supervised-only configuration-profile restrictions. It does not enroll the device in mobile-device management.
  • Reversible state: the control saves the prior state, takes effect after reopening Settings, survives a reboot, and can restore the previous state. Cyanide leaves a device already supervised by a real organization alone.
  • Gravity Lite: activation and deactivation now live on Gravity Lite’s Settings page instead of an Installer package. Cyanide only offers a full exploit run there when it cannot recover saved kernel access.
  • Background live tweaks: Gravity Lite, StatBar, NSBar, NiceBar Lite, Axon Lite and LiveWP can update while Cyanide is backgrounded when “Keep app alive in background” remains enabled.
  • Stability fixes: toggling Location Services from Control Center or Shortcuts no longer crashes SpringBoard while a live tweak runs, and the iPad Dock is resized after SBCustomizer adds extra Dock icons.
  • Faster launch path: the global sandbox-escape launch option is gone because File Browser, Cache Cleaner, System Info and Lara tools now lift their own sandbox only when opened.

Supported and unsupported devices

The developer lists two supported firmware windows for iPhone and iPad: iOS/iPadOS 17.0 through 18.7.1, and 26.0 through 26.0.1. A package or IPA installing successfully does not expand that range.

Explicitly unsupported versions are iOS/iPadOS 16 and earlier, 18.7.2 through 25.x, and 26.1 or later. The project also excludes every iPhone 17 model using A19 or A19 Pro and devices using M5 because Memory Integrity Enforcement blocks the required exploit. Other hardware on a supported build is intended to work without a separate model whitelist.

Cyanide’s README points users on iOS 15 or 16 to a conventional jailbreak instead. If that describes your device, use the Dopamine recovery guide for failure recovery and keep Cyanide out of the decision entirely.

A18 and M4 users should plan for kernel panics

The 1.16.0 release retains a serious A18/M4 caveat: the developer estimates that a fresh run has roughly an even chance of rebooting the device with a kernel panic instead of succeeding. This is described as a hardware-chain limitation, not as a new regression fixed by repeatedly reinstalling the IPA.

After one successful run, kernel access remains usable until the next device restart. If repeated fresh runs panic, Settings → Launch Options exposes the exploit path (pe_v3 by default, with pe_v1 and pe_v2 alternatives), memory shaping, interleaved search and bounded search. Change one option at a time and remember that each setting applies to the next fresh run; there is no developer-published “best” combination for every A18 or M4 device.

What supervision does—and does not do

Cyanide’s supervision switch changes the local supervised flag so configuration profiles that require supervision can be accepted. It does not connect the device to an MDM server, impose restrictions by itself, or grant a remote administrator control. Reopening Settings is enough to see the new state; no full reboot is required for activation.

Before turning it on, remove any uncertainty about who owns or manages the device. If Settings already identifies a school, company or other real organization, Cyanide is designed to refuse the change. On a personally owned device, use Deactivate to restore the saved state before troubleshooting profile behavior or handing the device to someone else.

Gravity Lite and background-tweak troubleshooting

  1. Open Gravity Lite’s own Settings page; the old Installer entry is no longer the correct control surface in 1.16.0.
  2. If Activate offers a full exploit run, Cyanide could not find saved kernel access. On A18/M4, apply the release’s panic warning before proceeding.
  3. For StatBar, NSBar, NiceBar Lite, Axon Lite, LiveWP or Gravity Lite that stops updating after app switching, verify “Keep app alive in background” is enabled in Cyanide.
  4. If Location Services previously caused a SpringBoard crash during a live tweak, update to 1.16.0 before retrying the Control Center or Shortcuts action.
  5. On iPad, reapply SBCustomizer and let the Dock resize before judging whether an extra icon is still squeezed against the left edge.

If Cyanide itself is being installed from the official IPA, first follow the IPA/TIPA SHA-256 verification guide. The GitHub release reports a SHA-256 digest of b7112333052219a9b8152a07d82d154d4c7ae1ac17d79a78766a72cd68815b1f for Cyanide-1.16.0.ipa; verify the downloaded file rather than copying a third-party mirror.

Cyanide is not a conventional jailbreak

The developer describes Cyanide as a tweak runner for kernel research. Its supported tweaks are applied in memory for the current boot, and ordinary changes can be undone by a respring. It does not create the broad package environment expected from Dopamine or another full jailbreak, and it should not be presented as universal jailbreak support for every device inside a listed iOS range.

That distinction also explains why iOS 17 support overlaps some jailbreakable hardware. Cyanide can be useful where its in-memory model is desirable, while users who need Sileo, broad tweak injection or persistent package management should choose an actual jailbreak compatible with their exact device and firmware.

Frequently asked questions

What is the current Cyanide version?

The latest official stable release checked for this update is Cyanide 1.16.0, published by Kolbicz on October 30, 2026.

Does Cyanide 1.16.0 support iOS 26.1?

No. The official supported iOS 26 window ends at 26.0.1. Version 26.1 and later are explicitly excluded.

Does it support iPhone 17 or M5 iPad?

No. The developer says Memory Integrity Enforcement on A19/A19 Pro and M5 blocks the exploit and lists those devices as unsupported.

Is supervised mode the same as MDM enrollment?

No. Cyanide changes the supervised flag locally so supervised-only profile restrictions can be used; it does not enroll the device in a management server or apply restrictions on its own.

Why does an A18 or M4 device reboot during Run?

The developer documents an approximately 50/50 fresh-run kernel-panic risk on those chips. After a successful run, access remains until restart; alternate launch options may help but no universally reliable combination is promised.

Before installing: verify the exact firmware build and hardware, download only the official release asset, and back up important data. Cyanide is a kernel-research tweak runner, not a general-purpose jailbreak.
