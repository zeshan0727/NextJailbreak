Cyanide 1.17.0 Adds Locked-App Previews and Respring Controls

Released November 8, 2026, Cyanide 1.17.0 adds notification previews for Face ID-locked apps, applies supported Installer changes one tweak at a time, and exposes Respring and Reboot through Shortcuts and Control Center. It remains a kernel-research tweak runner—not a full jailbreak—and its exact firmware and hardware exclusions still decide whether it can run.

What changed in Cyanide 1.17.0

  • Locked App Previews: on iOS 18, notification content can appear again for apps protected with “Require Face ID.” The normal Always, When Unlocked or Never preview choice still governs what is shown, and opening the app still requires Face ID.
  • Immediate supported changes: when saved kernel access is available, activating or deactivating a supported tweak applies only that tweak instead of putting every change into a queue. OTA, Hide Home Bar and repository tweaks still use the queue.
  • Apply Now: a tweak that becomes pending after reopening Cyanide or respringing can be reapplied by itself from its own page.
  • System controls: Respring and Reboot are available as Shortcuts/Siri/Action button actions on iOS 17 and later, plus Control Center controls on iOS 18.
  • Optional URL schemes: cyanide://respring and cyanide://reboot can be enabled in Settings → Launch Options, but are off by default because any app can open them once enabled.
  • State and undo fixes: seven DarkSword tweaks now restore their changes without a respring, persistent SpringBoard tweaks no longer all show as pending after Cyanide closes, iPad Dock can be disabled after reopening, and the run log no longer turns black.

Supported and unsupported devices

The developer lists two supported firmware windows for iPhone and iPad: iOS/iPadOS 17.0 through 18.7.1, and 26.0 through 26.0.1. A package or IPA installing successfully does not expand that range.

Explicitly unsupported versions are iOS/iPadOS 16 and earlier, 18.7.2 through 25.x, and 26.1 or later. The project also excludes every iPhone 17 model using A19 or A19 Pro and devices using M5 because Memory Integrity Enforcement blocks the required exploit. Other hardware on a supported build is intended to work without a separate model whitelist.

Cyanide’s README points users on iOS 15 or 16 to Dopamine instead. That is a different environment with package management and tweak injection, so first check the Dopamine 3 device and firmware guide; if a bad package later causes a crash loop, use the Dopamine recovery guide.

A18 and M4 users should plan for kernel panics

The 1.17.0 release retains a serious A18/M4 caveat: the developer estimates that a fresh run has roughly an even chance of rebooting the device with a kernel panic instead of succeeding. This is described as a hardware-chain limitation, not as a new regression fixed by repeatedly reinstalling the IPA.

After one successful run, kernel access remains usable until the next device restart. If repeated fresh runs panic, Settings → Launch Options exposes the exploit path (pe_v3 by default, with pe_v1 and pe_v2 alternatives), memory shaping, interleaved search and bounded search. Change one option at a time and remember that each setting applies to the next fresh run; there is no developer-published “best” combination for every A18 or M4 device.

How to use the new controls safely

  1. Update from the developer’s official 1.17.0 release and verify the downloaded IPA before installing; do not substitute a mirror.
  2. Run Cyanide once and confirm kernel access before expecting immediate activation, Reboot, or Apply Now to work. Without saved access, Cyanide falls back to its normal queue or fresh-run path.
  3. Leave “Apply Installer changes right away” enabled unless you intentionally want the queue. Toggle one tweak and verify its effect before changing another.
  4. For Locked App Previews, first set iOS notification previews to Always, When Unlocked or Never as desired. The tweak follows that choice; it does not bypass Face ID when opening the protected app.
  5. Prefer the built-in Shortcuts or Control Center actions. Enable the URL schemes only if another trusted automation needs them, because the developer warns that any app can invoke enabled links.
  6. After a respring or reboot, expect in-memory tweaks to become pending again. Use Apply Now for one tweak instead of assuming every installed item must be rerun.

For a repeatable download check, follow the IPA/TIPA SHA-256 verification guide and compare the file you actually install with the official release asset. This page does not mirror the IPA or invent a checksum that the developer did not publish in the visible release notes.

Cyanide is not a conventional jailbreak

The developer describes Cyanide as a tweak runner for kernel research. Its supported tweaks are applied in memory for the current boot, and ordinary changes can be undone by a respring. It does not create the broad package environment expected from Dopamine or another full jailbreak, and it should not be presented as universal jailbreak support for every device inside a listed iOS range.

That distinction also explains why iOS 17 support overlaps some jailbreakable hardware. Cyanide can be useful where its in-memory model is desirable, while users who need Sileo, broad tweak injection or persistent package management should choose an actual jailbreak compatible with their exact device and firmware.

Frequently asked questions

What is the current Cyanide version?

The latest official stable release checked for this update is Cyanide 1.17.0, published by Kolbicz on November 8, 2026.

Does Cyanide 1.17.0 support iOS 26.1?

No. The official supported iOS 26 window ends at 26.0.1. Version 26.1 and later are explicitly excluded.

Does it support iPhone 17 or M5 iPad?

No. The developer says Memory Integrity Enforcement on A19/A19 Pro and M5 blocks the exploit and lists those devices as unsupported.

Does Locked App Previews bypass Face ID?

No. It restores notification content according to the normal iOS preview setting, but opening an app protected with “Require Face ID” still requires authentication.

Why does an A18 or M4 device reboot during Run?

The developer documents an approximately 50/50 fresh-run kernel-panic risk on those chips. After a successful run, access remains until restart; alternate launch options may help but no universally reliable combination is promised.

Before installing: verify the exact firmware build and hardware, download only the official release asset, and back up important data. Cyanide is a kernel-research tweak runner, not a general-purpose jailbreak.
