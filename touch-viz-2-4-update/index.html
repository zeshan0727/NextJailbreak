Touch-Viz 2.4 Fixes Settings Navigation and Morph Effects as Official Listings Show a Newer Version

Touch-Viz is a jailbreak tweak that displays visual indicators for touch interactions on iPhone and iPad. The supplied package stanza identifies com.82flex.touchvis as version 2.4, requires firmware 15.0 or later, and declares mobilesubstrate and preferenceloader as dependencies. The official depiction separately lists version 4.1.1, an update date of September 8, 2026, and support information covering iOS 15.0 through 26.0.1. Because the two official records describe different versions, users should confirm which build their package manager offers before installing or upgrading.

Key points

  • The supplied package metadata identifies Touch-Viz as version 2.4 and lists firmware 15.0 or later, mobilesubstrate, and preferenceloader.
  • The official depiction separately lists version 4.1.1, with iOS versions shown as 15.0 through 26.0.1.
  • The version 2.4 changelog records fixes for the settings-page navigation bar and the morph effect.
  • The tweak displays visual indicators for touch interactions, supports multi-touch and iPad, and is described as not blocking touch input.
  • The depiction names Dopamine, Dopamine RootHide, Relaxin, NathanLR through iOS 17.0, Bootstrap RootHide through iOS 17.0, and palera1n through iOS 18.3.
  • The official description advises users to proceed at their own risk when their device or jailbreak environment is not listed.

What the supplied Touch-Viz package metadata says

The package stanza identifies the tweak as Touch-Viz, with the package identifier com.82flex.touchvis. Its short description is “Displays your touch interactions!” The entry places it in the Tweaks section and identifies 82flex as both maintainer and author. The supplied package version is 2.4, and the listed architecture is iphoneos-arm.

The package metadata declares firmware version 15.0 or later as a requirement. It also lists mobilesubstrate and preferenceloader as dependencies. These fields describe what the package expects at installation time; they do not, by themselves, confirm compatibility with every jailbreak environment or every device running a later firmware version.

  • Package identifier: com.82flex.touchvis
  • Package version: 2.4
  • Minimum firmware dependency: 15.0
  • Declared dependencies: mobilesubstrate and preferenceloader
  • Architecture: iphoneos-arm

What changed in version 2.4

The official depiction’s changelog associates version 2.4 with July 28, 2024. It records two changes: the settings-page navigation bar was fixed, and the morph effect was fixed.

The 2.4 changelog does not list a new compatibility range or introduce the later features documented in subsequent entries. Those two fixes should therefore be treated as the specific maintenance changes attached to the 2.4 release record, rather than as a summary of every capability found in the newer depiction.

  • Fixed the navigation bar in the settings page.
  • Fixed the morph effect.

Why the version records need to be checked

The supplied official materials contain two different version records. The package stanza identifies version 2.4, while the Information section of the official depiction identifies version 4.1.1. That depiction gives an update date of September 8, 2026, and lists the supported iOS range as 15.0 through 26.0.1.

The depiction’s changelog extends well beyond 2.4. For example, version 3.1 added Quick Path Effect, an Auto Rotate option for Image Effect, a higher window level, and behavior intended to keep Touch-Viz visible after Face ID authentication. Version 4.0.1 added an Emoji picker and fixed an issue involving replacement images in some scenarios. Version 4.1.1 is described as fixing a crash on iOS 26.

Those entries belong to the versions named in the depiction. They should not automatically be attributed to the separate 2.4 package record. Anyone installing the package should compare the version shown by their package manager with the version and changelog they intend to use.

  • The package stanza says version 2.4.
  • The depiction’s Information section says version 4.1.1.
  • The depiction lists an update date of September 8, 2026.
  • Later changelog fixes should not be assumed to exist in a 2.4 installation.

Core functions described by the project

The official description presents Touch-Viz as a tweak that displays visual indicators for touch interactions on the screen. It specifically says the tweak does not block touch input, supports multi-touch, and supports iPad. It also highlights better animation and drawing performance.

The description lists several display and control behaviors. Touch-Viz can automatically hide in Reachability mode. An optional Control Center toggle is available when CC Support is present. The depiction also highlights Emoji support. The changelog records additional interface and appearance options over time, including custom images, opacity, corner-radius controls, Tracking Effect colors, Quick Path Effect, and extra slider adjustment buttons.

  • Displays visual indicators for touch interactions.
  • Does not intentionally block touches, according to the official description.
  • Supports multi-touch and iPad.
  • Can hide automatically in Reachability mode.
  • Can be toggled through Control Center when CC Support is available.
  • Includes Emoji support in the listed feature description.

Compatibility information from the official depiction

The depiction states that Touch-Viz is compatible with a jailbroken iPhone or iPad running iOS 15 through 26. It separately names Dopamine, Dopamine RootHide, and Relaxin. It lists NathanLR for iOS 17.0 or earlier, Bootstrap RootHide for iOS 17.0 or earlier, and palera1n for iOS 18.3 or earlier.

The depiction’s Information section gives a more precise range of iOS 15.0 through 26.0.1. This is separate from the package stanza’s firmware dependency, which only establishes firmware 15.0 or later. A minimum dependency should not be read as a guarantee that every later iOS release or jailbreak environment is supported.

The source explicitly warns users to use the tweak at their own risk if their device or jailbreak environment is not listed. That warning matters because the package record and the depiction do not provide identical information about the available build.

  • Dopamine and Dopamine RootHide.
  • Relaxin is listed without an upper bound in the environment list.
  • NathanLR through iOS 17.0.
  • Bootstrap RootHide through iOS 17.0.
  • palera1n through iOS 18.3.
  • The depiction’s stated iOS range is 15.0 through 26.0.1.

Project details, localization, and credits

The depiction provides localization information and identifies Vietnamese language support in the version 3.6 changelog. It also credits open-source code used in part by the project: LNTouchVisualizer under the MIT License and MCEmojiPicker under the MIT License.

The depiction identifies 82flex and launchctl in its Sellers section. These project and seller details are distinct from the package dependencies and do not alter the compatibility information supplied for the tweak.

  • Localization information is provided by the project.
  • Version 3.6 added Vietnamese language support.
  • The depiction credits LNTouchVisualizer under the MIT License.
  • The depiction credits MCEmojiPicker under the MIT License.

What to verify before installation

Start by checking the exact version presented by the package manager. The supplied package record says 2.4, while the official depiction identifies 4.1.1. The distinction determines which changelog entries can reasonably be associated with the installed build.

Next, compare both the device’s iOS version and its jailbreak environment with the explicit list in the depiction. The package’s firmware dependency is not a substitute for that environment-specific information. Confirm that the declared dependencies, especially mobilesubstrate and preferenceloader, are available in the intended setup.

Finally, remember that the Control Center option is conditional on CC Support, and that the official depiction advises caution for combinations it does not list. The supplied materials do not establish that every feature behaves identically across every supported environment.

  • Confirm the version number offered by the package manager.
  • Compare the device and jailbreak environment with the depiction’s list.
  • Check mobilesubstrate and preferenceloader.
  • Treat the Control Center option as dependent on CC Support.
  • Do not assume later 3.x or 4.x fixes are included in version 2.4.
