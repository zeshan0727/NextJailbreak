Touch-Viz 4.1.1 Is Now Free as Developer Ends Support

Touch-Viz reached end of life and became free on October 26, 2026. The final Havoc release remains version 4.1.1, which fixes an iOS 26 crash while retaining customizable touch indicators, trails, multi-touch support and an optional Control Center toggle.

By Zeeshan BarviUpdated October 26, 2026Verified against Havoc’s live package data
Status on October 26, 2026: the official description says Touch-Viz has reached end of life, is now free, and will no longer receive support. Havoc still lists version 4.1.1, updated September 9, 2026.

What changed today?

The change is commercial and support-related, not a new binary release. The developer added an end-of-life notice to the official package description and removed the purchase price. Existing users can continue using the available package, while new users can obtain it through Havoc without paying.

End of life also changes the risk calculation. Touch-Viz may keep working on the combinations Havoc currently lists, but users should not assume that future iOS, jailbreak or dependency changes will be addressed. There is no 4.1.2 release attached to the October 26 notice.

What Touch-Viz 4.1.1 fixes

Version 4.1.1 fixes a crash on iOS 26. It followed version 4.1, which fixed track tracing on iPhones without a full-screen display. Those are the only changes Havoc attributes to the two 4.1 releases; the end-of-life announcement does not claim another stability or compatibility fix.

Earlier 4.x releases added an Emoji picker, fixed image replacement in some cases and stopped brush effects from remaining active when the global toggle was disabled on iOS 17.0 with NathanLR. Those older changes explain the current feature set but are not new October 26 work.

What the tweak does

Touch-Viz overlays visual indicators wherever the user touches the screen. It is aimed at tutorials, demonstrations, screen recordings and presentations where viewers need to see taps, swipes and multi-touch gestures. The official description highlights:

  • Emoji-based indicators and custom visual styles.
  • Touch visualization without intentionally blocking the underlying touch.
  • Multi-touch and iPad support.
  • Improved animation and drawing performance.
  • Automatic hiding in Reachability mode.
  • An optional Control Center toggle when the separate CC Support component is available.

Customization options shown by the developer

The official interface screenshots show controls for fill and border colors, opacity, indicator size, border width, corner radius, animation duration and lift scale. They also demonstrate a trail made from repeated circular touch positions rather than a single static dot.

The Only for Recording switch is useful for people who want Touch-Viz visible in captured tutorials but not during normal device use. A separate global enable switch makes it possible to disable the tweak without uninstalling it.

Compatibility needs two separate checks

Havoc lists iOS 15.0 through 26.0.1, rootless support and a jailbreak requirement. The iOS range describes what the package is designed to run on; it does not prove that every device on every listed firmware has a public jailbreak.

Before installation, confirm both the device/firmware jailbreak and the package architecture used by that jailbreak. A rootless badge alone does not establish RootHide compatibility, and the current official page does not make a separate RootHide guarantee.

Should you install an end-of-life tweak?

Touch-Viz remains useful when a visible tap overlay is needed and the device already has a compatible jailbreak. Becoming free makes it easier to try, but it does not remove the maintenance risk. Back up important data, install only from Havoc, and keep a way to disable tweak injection if SpringBoard becomes unstable.

For a long-lived production setup, the lack of future support matters more than the zero price. If an iOS or jailbreak update breaks the overlay later, the developer has explicitly said support will not continue.

Install or update through the official source

  1. Refresh the Havoc repository in Sileo or Zebra.
  2. Open Touch-Viz and verify package ID com.82flex.touchvis.
  3. Confirm the package manager offers version 4.1.1 and shows it as free.
  4. Install or update, then respring if the package manager requests it.
  5. Open the preference pane and test one basic indicator style before enabling trails or recording-only behavior.

Use the Sileo tweak-installation guide if you need package-manager steps. If a tweak causes a crash loop, follow the Dopamine bad-tweak recovery guide.

Frequently asked questions

Is Touch-Viz free now?

Yes. The official Havoc description says it became free on October 26, 2026 after reaching end of life.

What is the latest Touch-Viz version?

Havoc lists version 4.1.1, released September 9, 2026. Its changelog says it fixes a crash on iOS 26.

Will Touch-Viz receive more updates?

The developer says support will no longer be provided. Users should not rely on future compatibility or bug-fix releases.

Does Touch-Viz work without a jailbreak?

No. Havoc marks a jailbreak as required. The listed iOS range does not establish jailbreak availability for every device.

Does the rootless badge guarantee RootHide support?

No. Rootless package compatibility is not the same as an explicit RootHide compatibility claim.
