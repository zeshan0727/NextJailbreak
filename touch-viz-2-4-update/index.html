ShowMyTouches 2.0 vs Touch-Viz 4.2: Which Touch Visualizer Should You Use?

ShowMyTouches offers newer Morph and Comet effects with an iOS 13 starting point; Touch-Viz has a broader mature feature history and named jailbreak support, but version 4.2 is explicitly end-of-life. Both are currently free.

By Zeeshan BarviPublished September 14, 2026Updated November 1, 2026
Current versions checked: ShowMyTouches 2.0, released October 28, 2026; Touch-Viz 4.2, released October 26, 2026. Current Havoc page data marks both packages free.

What changed in ShowMyTouches 2.0

Version 2.0 fixes taps being swallowed while a touch indicator fades out. That is the most important functional change for normal device use: a visualizer should illustrate input without preventing the underlying keyboard tap or gesture.

The update adds two combinable effects. Morph stretches the indicator behind the finger like a liquid drop and gathers it back; Comet leaves a fading trail. Resting touches can use an idle breathing animation, and a Photos image can replace the normal indicator while keeping its proportions inside a 180×180-pixel area.

ShowMyTouches also documents multi-touch, pass-through input, configurable colors, border, size, corner radius and animation duration. Its preferences live in Settings and do not require a respring. Havoc lists iOS 13.0–26.0.1 and rootless support; the linked project README additionally claims rootful, rootless and RootHide builds.

What Touch-Viz 4.2 offers now

Touch-Viz 4.2 is not a new feature release. Its October 26 changelog says DRM was removed, matching the developer’s notice that the tweak became free and reached end of life. Existing features remain useful, but users should not expect future jailbreak or firmware fixes.

The current description includes multi-touch and iPad support, Emoji indicators, improved drawing and animation performance, Reachability hiding and an optional Control Center toggle through CC Support. Its longer history documents custom images, opacity, tracking and Quick Path effects, landscape support, Face ID persistence and fixes for SnowBoard and screenshot-stitching conflicts.

Havoc lists Touch-Viz for iOS 15.0–26.0.1 and rootless packaging. Its compatibility notice specifically names Dopamine, Dopamine RootHide, RootHide Bootstrap, Relaxin RootHide, NathanLR and palera1n. That named list is more precise than treating the broad firmware range as proof of support everywhere.

Which touch visualizer should you choose?

  • Choose ShowMyTouches 2.0 if you want the newest feature work, need iOS 13 or 14, prefer an open-source project, or specifically want Morph, Comet and idle breathing.
  • Choose Touch-Viz 4.2 if Quick Path, Emoji, Control Center, iPad or its named jailbreak support matches your workflow and you accept that the project is end-of-life.
  • For RootHide, verify the package variant. A normal rootless package and a RootHide build are not interchangeable merely because their iOS ranges overlap.
  • For tutorial recording, start simple. Enable recording-only mode and a basic dot first. Add trails or images only after typing and system gestures remain reliable.

Compatibility does not equal jailbreak availability

A Havoc firmware range describes what the package targets, not which devices can currently be jailbroken. An iOS 26 listing does not establish a public jailbreak path for every iPhone on iOS 26. Check the exact device and firmware against the current jailbreak status and the relevant jailbreak’s documentation.

Likewise, “supports rootless” does not automatically prove RootHide support. Confirm the dedicated build or conversion route and review the RootHide Patcher guide before changing package architecture.

Install and test safely

  1. Refresh Havoc in Sileo or Zebra and verify the package ID: com.dvntm.showmytouches or com.82flex.touchvis.
  2. Confirm the offered version is ShowMyTouches 2.0 or Touch-Viz 4.2 and that the package variant matches the jailbreak environment.
  3. Install only one touch visualizer at first. Two simultaneous system-wide touch overlays make conflict diagnosis ambiguous.
  4. Test the keyboard, Control Center, Notification Center, app switching, recording and multi-touch before enabling elaborate effects.
  5. If taps disappear or SpringBoard becomes unstable, disable tweak injection, remove or disable the visualizer, then respring. Use the Dopamine bad-tweak recovery guide for a crash loop.

Troubleshooting differences

Typing misses taps: update ShowMyTouches to 2.0 because its changelog specifically addresses swallowed taps during fade-out. With Touch-Viz, disable tracking or image effects and check whether another gesture tweak also hooks touch events.

Indicators appear in normal use: enable the recording-only option, then start a fresh recording. Verify the setting rather than assuming the overlay follows the recorder automatically.

RootHide preference pane does not load: confirm that both the tweak and PreferenceLoader components match RootHide. Do not replace a dedicated RootHide package with a standard rootless build simply because it installs.

Frequently asked questions

Are ShowMyTouches and Touch-Viz free?

Yes. Current Havoc data marks both free. Touch-Viz became free when version 4.2 removed DRM and the developer announced end of life.

Which supports older iOS versions?

ShowMyTouches starts at iOS 13; Touch-Viz starts at iOS 15. Both list iOS 26.0.1 as the upper package-compatibility bound.

Which is better for RootHide?

Both claim RootHide options. The safer choice is the one with a confirmed package variant for your exact bootstrap.

Can both be installed together?

They may install, but two system-wide touch overlays create unnecessary hook overlap. Test one at a time unless a developer documents coexistence.

Does iOS 26 compatibility mean every iOS 26 iPhone can use them?

No. Package compatibility does not create a jailbreak for unsupported hardware or firmware.
