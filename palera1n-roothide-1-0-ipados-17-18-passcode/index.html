Palera1n RootHide 1.0 Supports Passcode-Set iPads on iPadOS 17 and 18

RootHide’s first stable Palera1n RootHide release is aimed at checkm8-era arm64 hardware, not every iPad that can run iPadOS 17 or 18. Here is the exact device boundary, what the passcode claim covers, which official host file to use and how the TrollStore-to-RootHide workflow differs from standard palera1n.

By Zeeshan Barvi · Published October 31, 2026 · Verified from release 1.0, its tagged README and the underlying palera1n device list

Compatibility first: the release note says “all iPadOS 17/18 versions” with a passcode set, but that statement applies only to hardware supported by this checkm8/palera1n-based project. It does not add A12 or newer iPads, and it does not establish a jailbreak path for every device on those firmware families.

What changed in Palera1n RootHide 1.0

RootHide published version 1.0 on October 25, 2026. Its concise release note makes one material claim: full compatibility with iPadOS 17 and 18 versions on supported iPads while a passcode is set. That matters because passcode and Secure Enclave restrictions are a central limitation of ordinary palera1n on some device and firmware combinations.

This is not a new firmware exploit. Palera1n RootHide remains tied to the checkm8-era arm64 hardware supported by palera1n. The project repository describes an iOS 15.0–18.x target, while upstream palera1n explicitly says arm64e devices will never be supported.

Passcode support: what the release actually promises

The stable release’s wording is narrower than “palera1n now supports passcodes everywhere.” It promises compatibility for supported iPads across iPadOS 17 and 18 with the passcode set. It does not say that the usual A11 iPhone passcode restrictions have disappeared, and it does not retroactively change the standard palera1n documentation.

If passcode retention is the reason you are considering this build, verify that you are using an iPad model in the supported arm64 list and that the current RootHide release page still carries the same claim. Do not apply this article’s iPad-specific conclusion to an iPhone 8, iPhone X or a newer iPad.

How the RootHide flow differs from standard palera1n

The tagged script runs palera1n in rootless mode with RootHide’s custom PongoOS, KPF and jbinit components. After a successful device boot, the project says a Home Screen prompt appears and automatically installs TrollStore after you continue. The README then directs you to install RootHide Dopamine to finish the environment.

That is a different chain from standard palera1n’s ordinary loader-and-Sileo flow. Do not mix the two sets of bootstrap instructions, and do not assume that a package built only for conventional rootless iphoneos-arm64 will behave as a RootHide iphoneos-arm64e package. Read our current Dopamine RootHide status page before choosing RootHide-specific packages.

Practical setup sequence

  1. Back up the iPad and record the exact model and iPadOS build.
  2. Confirm the model is in palera1n’s official arm64 device list.
  3. Download the correct 1.0 ZIP or ISO from RootHide’s GitHub release page and verify its SHA-256.
  4. For Windows, write the ISO to a spare USB drive and boot the PC from it. For macOS or Linux, extract the ZIP and run the supplied project script from a native host.
  5. Follow the tool’s device-specific recovery and DFU prompts. Do not substitute timings for a different iPad.
  6. After the device boots, unlock it and use the official Palera1n RootHide prompt to continue TrollStore installation.
  7. Follow the tagged README’s RootHide Dopamine link and current installation instructions; do not use mirrored IPA or TIPA files.

Troubleshooting

The computer does not detect the iPad

Use a native macOS or Linux host, or boot the supplied palen1x ISO on a Windows PC. Avoid WSL and virtual machines. Remove USB hubs, try another data-capable cable and reconnect from recovery mode.

DFU mode fails repeatedly

Follow the detected model’s onscreen timing, not a generic video. A USB-A cable through a reliable adapter can be more dependable than USB-C-to-Lightning during checkm8 workflows.

The device boots but the TrollStore prompt does not appear

Unlock the iPad, wait for SpringBoard to finish loading and confirm that the boot completed with the RootHide files from the same 1.0 archive. Rebooting normally or mixing standard palera1n components can leave you outside the documented flow.

A RootHide package will not install

Confirm the package architecture and environment. Package-level iOS compatibility does not prove that its build targets RootHide, and conventional rootless packages should not be treated as interchangeable.

Can I use this on an M1 or M2 iPad?

No. The release’s iPadOS wording does not override palera1n’s arm64/checkm8 hardware boundary. M-series iPads are not supported by this path.

Should you update from a beta?

Version 1.0 is the current official stable release and is the sensible reference point for a fresh setup. Keep a copy of the exact release assets and hashes, but do not replace a working environment casually: read the current release notes and RootHide support guidance first, especially if your installed beta already has a functioning bootstrap and passcode configuration.
