WhatAMess 1.4 Expands Messages Customization With Button Platters, Extension Support and iOS 17 Fix‌

WhatAMess has reached version 1.4 with a substantial Messages customization update. The official changelog lists better iOS 17 support, new button platters inspired by iOS 26, theming for Messages app extensions, experimental Liquid Glass support and several fixes for view updates, blur behavior and general reliability. The project documentation describes compatibility with rootless jailbreaks on iOS 15 through iOS 18, while also warning that several injection methods remain uncertain or may not work. Readers should note that the supplied package stanza identifies the package as version 1.0.1, whereas the official project metadata and Havoc depiction identify the current release as 1.4, so the version shown by the package manager should be checked before proceeding.

Key points

  • WhatAMess 1.4 adds configurable button platters to the Messages navigation interface and a related bottom search-bar blur option.
  • Messages extensions are now included in the theming scope, covering notification replies, notification haptic-touch views and the share sheet according to the official changelog.
  • The release includes better iOS 17 support, fixes for views failing to update between contacts or appearance modes, and general blur fixes.
  • Experimental Liquid Glass support applies only to button platters and is described by the developer as unfinished.
  • The README states support for rootless jailbreaks on iOS 15 through iOS 18, but compatibility with several jailbreak and injection environments is explicitly uncertain.
  • The supplied repository package stanza says version 1.0.1, while the official README, changelog and Havoc depiction say 1.4; verify the package version and source metadata before installing.

What changed in WhatAMess 1.4

WhatAMess is a jailbreak tweak focused on customizing Apple’s Messages app. Its documented controls cover colors, backgrounds, message bubbles, navigation elements, conversation lists, chat views, presets and light- or dark-mode-specific appearance settings. The project describes itself as designed with iOS 16 in mind, while listing support for iOS 15 and iOS 17 in its README. Its package depiction lists the supported range as iOS 15.0 through iOS 18.0.

Version 1.4 expands that feature set with a more prominent navigation treatment: button platters. The release also extends theming into Messages-related app extensions and introduces experimental Liquid Glass support. Together, these changes make the update more than a small color-picker revision, although the project continues to describe some elements as experimental and acknowledges remaining issues.

  • Button Platters can be enabled from NavBar Settings.
  • A platter color can be selected separately.
  • Bottom Screen Blur has its own toggle and tint control.
  • The preference description says the platter feature requires Modern NavBar.
  • The project describes the design as inspired by iOS 26, not as an official Apple component.

Button platters and the redesigned navigation treatment

The official 1.4 changelog describes button platters as being inspired by iOS 26 and places the setting in NavBar Settings. The accompanying preference definitions provide a switch for the feature, a control for choosing platter color, a Bottom Screen Blur switch and a separate tint selector for that blur.

According to the preference description, button platters add blurred platter-style backgrounds behind navigation buttons. They also enable a bottom search bar in the conversation list. Bottom Screen Blur adds a tinted, progressive blur behind that lower search area, using a similar visual principle to the tweak’s Modern NavBar feature. The same description says Modern NavBar must be enabled for the platter controls to work as intended.

This is a configurable visual treatment rather than a single fixed theme. Users can combine the navigation settings with the tweak’s wider controls for app-wide tinting, cell tinting, custom backgrounds and appearance-mode customization. The project also includes preset browsing, saving, importing and exporting, allowing users to manage groups of settings rather than adjusting every value individually.

  • The platter switch is located in the navigation-bar settings.
  • The feature includes independent color controls.
  • Bottom Screen Blur is designed for the conversation-list search area.
  • The source material does not provide performance measurements or guarantee identical behavior on every device.

Messages extensions are now part of the theme

One of the most practical changes in version 1.4 is support for Messages-related extension experiences. The official changelog says the update themes replying from a notification, haptic-touching a notification and using the share sheet. These interfaces can appear outside the main Messages application, so extending the tweak’s scope can make the overall experience more consistent.

The supplied source changes add MessagesViewService to the tweak’s executable filter alongside the main Messages bundle and the existing notification and transcript extension executables. That implementation detail is consistent with the changelog’s description of broader extension support. It does not, however, establish that every Messages-related system surface is covered or that every extension behaves identically across all supported firmware versions.

The underlying customization remains centered on Messages presentation. The README lists controls for conversation-list gradients and images, preview and timestamp colors, pinned-conversation elements, custom navigation titles, separators and search backgrounds. In chat views, users can configure backgrounds, bubble colors, bubble text, timestamps, the message bar, input fields, send controls, camera and app-drawer tinting, and link bubbles.

  • Notification reply interfaces are listed as supported by the 1.4 changelog.
  • Notification haptic-touch views are included in the release description.
  • The share sheet is also named as part of the extension theming work.
  • MessagesViewService was added to the executable filter in the supplied release changes.

iOS 17 fixes and known limitations

The release notes specifically call out better iOS 17 support. They say some views that failed to update correctly when switching between contacts or between dark and light mode were fixed. The changelog also lists fixes for blur issues across all versions, along with additional general bug fixes.

Those improvements do not mean every view is guaranteed to be problem-free. The current README continues to list several limitations. Text such as “2 Replies” may occasionally return to the system tint on iOS 17. “Notify Anyway,” shown after sending a message to another user in Do Not Disturb mode, may also revert to the system color after leaving and reopening a window. Link bubbles in pinned-message previews can sometimes appear as a square instead of a bubble.

The 1.4 README update removed an earlier note about the Contact Info view being slightly broken on iOS 17. That means the issue is no longer listed in the current README, but the source does not state that every iOS 17 problem has been eliminated. Users should therefore treat the release as an improvement with documented remaining caveats, not as a universal compatibility guarantee.

  • The changelog claims fixes for views that failed to update between contacts or appearance modes on iOS 17.
  • Blur-related issues were addressed across all versions, according to the release notes.
  • The README continues to list occasional tint regressions and pinned-preview link-bubble problems.
  • The project describes itself as a first tweak and says additional issues may take time to address.

Liquid Glass support remains experimental

WhatAMess 1.4 also introduces experimental Liquid Glass support. The changelog limits this feature to button platters and describes the implementation as currently very rough, adding that it may be revisited later. The README similarly lists Liquid (Gl)ass support as experimental.

That qualification matters for users selecting a visual style. Liquid Glass should be treated as an optional experiment rather than a mature, general-purpose appearance system. The supplied preference files and preset data show values associated with platter blur and tinting, but the source material does not provide performance measurements, stability testing or a promise of consistent behavior across devices and firmware versions.

  • Liquid Glass support applies only to button platters.
  • The official changelog calls the implementation scuffed.
  • The developer may revisit the feature in a future release.
  • No device-by-device performance claims are provided in the source material.

Compatibility and package details to verify

The project README says WhatAMess is compatible with devices using a rootless jailbreak on iOS 15 through iOS 18. The Havoc depiction presents the supported range as iOS 15.0 through 18.0. The package stanza lists mobilesubstrate version 0.9.5000 or newer as a dependency and identifies the package architecture as iphoneos-arm64.

Compatibility outside the stated target is less certain. The README says NathanLR 1.0, specifically its non-iOS 17 version, is questionable. It also says other semi-jailbreaks and injection methods such as Serotonin likely do not work. The document separately records reports involving Roothide or Bootstrap, Palera1n and Palehide, but those entries include qualifications, individual reporters and, in some cases, specific device and firmware details. They should not be read as universal support statements.

There is also a notable version discrepancy. The supplied package stanza identifies WhatAMess as version 1.0.1, while the official GitHub release commit is titled “1.4 Release,” the current README reflects the 1.4 feature set, and the Havoc depiction lists version 1.4 with a September 10, 2026 update date. This may indicate stale package metadata or a packaging mismatch. Users should check the version displayed by their package manager before installation.

  • Documented target: rootless jailbreaks on iOS 15 through iOS 18.
  • The package metadata lists mobilesubstrate at version 0.9.5000 or newer as a dependency.
  • The package stanza specifies iphoneos-arm64 architecture.
  • NathanLR 1.0 and Serotonin are explicitly described as questionable or likely non-working.
  • Reported compatibility with other environments should be checked against the exact device and firmware.
  • The supplied sources disagree on whether the package version is 1.0.1 or 1.4.

What users should check before installing

The safest reading of the source material is that WhatAMess 1.4 is a broad Messages customization release whose behavior depends on both iOS version and jailbreak environment. Confirm that the device uses a rootless jailbreak, review the project’s warnings for the specific injection method, and verify that the package manager is offering the intended release rather than the 1.0.1 metadata shown in the supplied package stanza.

Users who rely on notification replies, notification haptic-touch actions or share-sheet behavior may find the extension support especially relevant. Those primarily interested in conversation colors and backgrounds should still review the known issues, particularly when using iOS 17 or pinned-message link previews. Liquid Glass should be considered optional because the developer explicitly labels it experimental and unfinished.

The package’s listed dependency, architecture and version are additional details worth checking before installation. If the package manager presents information that conflicts with the official release description, users should resolve that discrepancy before proceeding rather than assuming that the installed files correspond to version 1.4.

  • Confirm the jailbreak type and exact iOS version.
  • Check that the package manager shows version 1.4 if that is the intended release.
  • Review the listed dependency and architecture information.
  • Read the project’s compatibility warnings for the specific jailbreak or injection method.
  • Treat Liquid Glass as experimental and review the known iOS 17 limitations.

Frequently asked questions

What is WhatAMess?

WhatAMess is a jailbreak tweak for customizing Apple’s Messages app. Its documented controls include app-wide and per-contact colors, backgrounds, message bubbles, navigation elements, presets and appearance-mode customization.

What is new in WhatAMess 1.4?

The official 1.4 changelog lists better iOS 17 support, button platters inspired by iOS 26, Messages extension support, experimental Liquid Glass support, fixes for view-update problems, blur fixes and general bug fixes.

What are button platters?

They are a configurable Messages navigation treatment that adds blurred or tinted platter-style backgrounds behind buttons. The preference description says the feature also enables a bottom search bar in the conversation list and requires Modern NavBar.

Does WhatAMess support iOS 17?

The project documentation states support for rootless jailbreaks on iOS 15 through iOS 18, and the 1.4 changelog specifically mentions better iOS 17 support. The README still lists some iOS 17 tint regressions, so support should not be read as a guarantee that every view is issue-free.

Does it work with every jailbreak?

No universal claim is made. The README identifies rootless jailbreaks on iOS 15 through iOS 18 as the target, while describing NathanLR 1.0 and Serotonin as questionable or likely non-working. Other environments have reported compatibility, but users should verify their exact setup.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
