ReplyActions 1.0.3 Adds Root Path Handling and Media Refactoring for Jailbroken iPhones

ReplyActions is a jailbreak tweak designed to make replying to messages faster through popup previews, quick actions, scheduling, Quick Compose, and support for several third-party messaging services. The official package stanza identifies version 1.0.3, while the package depiction also lists later 2.0.0, 2.5.0, and 3.0.0 changelog entries. For users specifically evaluating version 1.0.3, the documented changes are improved root-path checking for rootful and rootless setups, an updated icon, refactored media handling, and Always Expand enabled by default. The available source also contains a version discrepancy, so users should confirm the version displayed by their package manager before proceeding.

Key points

  • The official package stanza identifies ReplyActions as version 1.0.3 for the iphoneos-arm architecture.
  • The 1.0.3 changelog documents improved root-path detection for both rootful and rootless environments.
  • Version 1.0.3 also updates the icon, refactors media handling, and enables Always Expand by default.
  • The tweak’s description advertises popup message previews, quick replies, scheduling, service switching, Quick Compose, media sharing, and customization.
  • The depiction claims support for iOS 14.0 through 26.0.1, but the package stanza itself does not list an iOS range.
  • The source presents a version inconsistency: package metadata says 1.0.3, while the depiction’s information panel lists 3.0.0 and later changelog entries.

What ReplyActions is designed to do

ReplyActions is described by its maintainer as a tweak for sending messages more easily. Its official depiction presents it as a BiteSMS-like experience adapted for modern iOS, centered on an interactive popup preview that appears when a message is received.

The advertised feature set goes beyond a simple reply field. The depiction lists quick actions for scheduling a message, marking a message as read, switching between iMessage and SMS, starting a FaceTime audio or video call, and displaying toast messages for selected actions. It also lists profile picture viewing, image sending and receiving through the popup preview, Quick Compose for iMessage and SMS, Liquid Glass styling on older iOS versions, and full user-interface customization.

  • Popup modal preview for incoming messages
  • Quick actions for scheduling and marking messages read
  • iMessage/SMS service switching
  • FaceTime audio and video call controls
  • Image sharing through the popup preview
  • Quick Compose for iMessage and SMS

What changed in version 1.0.3

The package stanza identifies the release as ReplyActions 1.0.3. Its corresponding changelog entry lists four changes: an improved method for checking root paths for both rootful and rootless environments, an updated icon, refactored media handling, and Always Expand enabled by default.

The root-path change is the most technically relevant item for jailbreak users. Rootful and rootless setups use different filesystem arrangements, so a path-detection improvement is intended to make the tweak’s environment checks more suitable across both configurations. The source does not claim that every jailbreak or every iOS release is supported, however, so this should be treated as a release-note improvement rather than a universal compatibility guarantee.

The media-handling refactor is also notable because ReplyActions advertises sending and receiving images from its popup interface. The changelog does not describe the internal implementation or specify which media bugs were addressed. Users should therefore avoid assuming that the refactor fixes a particular failure unless that behavior is documented separately.

  • Improved root-path checking for rootful and rootless environments
  • Updated application icon
  • Refactored media handling
  • Always Expand enabled by default

Features available beyond the 1.0.3 changelog

The depiction lists a wider ReplyActions feature set, including support for third-party messaging applications. It specifically names Messenger, Twitter direct messages, Instagram direct messages, Telegram, WhatsApp, and Viber, and says that core functions such as replying, receiving, and scheduling work with third-party messaging apps too. The wording comes from the official description, so users should still check whether their particular app version and jailbreak environment behave as expected.

ReplyActions also supports gestures. Swiping down or up expands or collapses the view, while swiping right dismisses it. Holding and swiping the send button to the left switches services, including in the stock Messages app. The photo button selects images, with a long press showing the current selection. The video or phone button starts a FaceTime call, while holding the phone button uses the Phone app. Pressing Volume Down and Volume Up opens Quick Compose.

The depiction says the tweak supports 11 languages: Arabic, German, Spanish, French, Japanese, Russian, Ukrainian, Vietnamese, Simplified Chinese, and Traditional Chinese. The source describes these as supported languages, but does not explain whether every feature is translated equally.

  • Third-party messaging support is advertised for several popular apps
  • Gestures control expansion, dismissal, service switching, media selection, and calls
  • Volume Down plus Volume Up opens Quick Compose
  • The depiction lists support for 11 languages

Compatibility and dependency details

The package stanza lists the architecture as iphoneos-arm and declares dependencies on mobilesubstrate version 0.9.5000 or newer and preferenceloader. These dependencies matter because a package manager may refuse installation when the required framework or preference component is absent.

The package metadata does not state an iOS version range. Separately, the depiction’s information panel lists iOS 14.0 through 26.0.1. Because those two source sections describe different aspects of the package and the same depiction also contains a later version listing, readers should verify the compatibility information shown for the exact package version available to them.

The depiction includes a specific warning for palera1n users: rootful palera1n on iOS 15 and newer is described as deprecated, and the maintainer says support will not be provided for rootful palera1n. The same page asks affected users to switch to rootless. This is an explicit support policy, not proof that every rootless configuration will work.

  • Architecture listed: iphoneos-arm
  • Requires mobilesubstrate 0.9.5000 or newer
  • Requires preferenceloader
  • The depiction lists iOS 14.0–26.0.1, while the package stanza gives no iOS range
  • The maintainer warns that rootful palera1n on iOS 15 and newer is deprecated and unsupported

Important version discrepancy before installation

The supplied source does not present a single unambiguous current version. The official package stanza identifies ReplyActions as version 1.0.3, with a package size of 128,450 bytes and an installed size of 840. However, the package depiction’s information section lists version 3.0.0, size 620.68 KB, and an update date of September 6, 2026. That same depiction includes changelog entries for 2.0.0, 2.5.0, and 3.0.0 after the 1.0.3 entry.

This matters because the 3.0.0 entry claims a complete rewrite, crash fixes, optimization, Liquid Glass support for older iOS versions, new customization settings, persistent scheduled replies, a companion app, and testing across iOS 14, 15, 16, 17, 18, and 26. Those claims belong to the 3.0.0 changelog and should not be attributed to the 1.0.3 package stanza without confirming which build is actually being offered.

Before installation, users should compare the version, package size, dependencies, and compatibility information shown in their package manager with the release they intend to install. They should also review the maintainer’s support warning if using palera1n and keep in mind that the source does not provide independent test results.

  • Package metadata: version 1.0.3
  • Depiction information panel: version 3.0.0
  • The depiction contains later 2.0.0 and 2.5.0 changelog entries
  • Confirm the exact version offered before installing

What users should verify first

The safest preparation is to identify the exact build and environment rather than relying only on the tweak’s broad feature list. Check that the package manager shows the expected version, that mobilesubstrate and preferenceloader are available, and that the device’s jailbreak setup matches the maintainer’s stated support position.

Users should also review notification behavior and privacy expectations. ReplyActions is designed to display message content in a popup preview and can expose actions such as replying, calling, and sending media from that interface. The source does not provide a separate privacy policy, so users should examine the tweak’s settings and decide whether previews are appropriate on the lock screen or around other people.

Finally, the depiction states that refund requests submitted within 24 hours will be considered regardless of reason, while issues affecting the tweak’s main purpose or device functionality are specifically discussed. The page encourages users to contact the developer first about crashes, bugs, or unexpected behavior.

  • Confirm the exact package version and dependencies
  • Check whether the jailbreak environment falls within the stated support policy
  • Review popup and lock-screen behavior before enabling message previews
  • Keep the maintainer’s refund and support terms in mind
