ReplyActions 3.0.1 Adds RootHide Support and Fixes UI Regressions

ReplyActions 3.0.1 is a same-day maintenance update to the modern BiteSMS-style messaging tweak. It adds an official RootHide build and fixes a random keyboard regression, Home Screen status-bar gestures, appearance-slider state and the Liquid Glass shader. Havoc lists the standard rootless package for iOS 14.0–26.0.1; that package range does not prove jailbreak availability for every device.

By Zeeshan Barvi · Published September 14, 2026 · Updated November 13, 2026 · Current version verified: 3.0.1

ReplyActions is a tweak, not a jailbreak. Havoc’s iOS range describes the package only. Confirm that the exact device, firmware and jailbreak environment can load tweaks before purchasing.

What changed in ReplyActions 3.0.1

Havoc’s live package data identifies version 3.0.1, updated November 13, 2026 at 01:42:59 UTC. The developer’s changelog lists five specific changes:

  • Official RootHide support through a separate developer-published package.
  • A fix for a random keyboard regression reported on some devices.
  • A fix for status-bar gestures not working on the Home Screen.
  • A fix for appearance sliders retaining the wrong state.
  • A fix for a Liquid Glass shader bug.

These are targeted fixes; the source does not claim a new iOS range, universal app-version compatibility or performance improvements on every device.

What ReplyActions does beyond the 3.0.1 fixes

ReplyActions displays an interactive popup for incoming messages. Its current official description lists quick replies, scheduled messages, mark-as-read, iMessage/SMS switching, FaceTime audio and video buttons, profile pictures, image sending and receiving, Quick Compose, Liquid Glass styling on older iOS versions and interface customization.

The developer also advertises core reply, receive and scheduling features for third-party services including Messenger, X/Twitter direct messages, Instagram direct messages, Telegram, WhatsApp and Viber. That is a developer compatibility claim, not a promise that every future app update will keep working.

Version 3.0.0 was the major rewrite: Havoc says it added persistent scheduled replies that survive resprings and rejailbreaks, a companion app for managing them, built-in customization and testing on iOS 14, 15, 16, 17, 18 and 26. Version 3.0.1 keeps that foundation and repairs the regressions above.

Safer update checklist

  1. Confirm the package manager shows ReplyActions 3.0.1 and package ID com.sergy.replyactions.
  2. Identify the environment before installing: conventional rootless or RootHide. Do not install both package architectures.
  3. For RootHide, confirm the Havoc purchase first and verify the downloaded DEB against the developer-published SHA-256.
  4. Record the current ReplyActions appearance and gesture settings before updating.
  5. After respringing, test the keyboard, one status-bar gesture, one appearance slider and one scheduled reply before enabling every option.
  6. Review lock-screen notification privacy because popup previews can expose message content and contact information.

Troubleshooting ReplyActions 3.0.1

The keyboard still behaves incorrectly

First confirm 3.0.1 is installed rather than 3.0.0. Disable other keyboard or message-composer tweaks temporarily, respring, and test ReplyActions alone. The changelog confirms a keyboard-regression fix but does not identify every conflicting tweak.

Status-bar gestures still fail on the Home Screen

Verify that the status-bar gesture is enabled in ReplyActions, then respring after changing it. If another gesture tweak owns the same action, disable the overlap and test again; 3.0.1 specifically fixes the ReplyActions Home Screen path.

Liquid Glass or appearance controls look wrong

Check that the appearance slider values remain selected after leaving Settings, then respring. If the problem continues, temporarily disable other blur, shader or system-wide appearance tweaks. The release fixes a shader bug and a slider-state bug, not every possible theme conflict.

SpringBoard enters Safe Mode

Restart with tweak injection disabled, remove ReplyActions or disable competing notification, messaging and gesture tweaks, then respring. Reinstall only the package built for the current environment. Use the Dopamine bad-tweak recovery guide if normal package removal is blocked.

A scheduled reply disappears after a reboot

The developer says schedules persist on disk across resprings and rejailbreaks. Persistence is not the same as guaranteed delivery while the phone is unjailbroken, offline or after an app changes. Reopen the companion app and verify the schedule after rejailbreaking before relying on it.

Frequently asked questions

What is the current ReplyActions version?

Havoc and the developer’s RootHide release both identify version 3.0.1, published November 13, 2026.

Does ReplyActions 3.0.1 support RootHide?

Yes. The developer provides a separate arm64e RootHide DEB, but the release explicitly requires a legitimate Havoc purchase. It should not be treated as a free mirror of the paid tweak.

Does it support every iPhone on iOS 14–26.0.1?

No. Havoc lists that package range, but a compatible jailbreak and tweak-injection environment must also exist for the exact device and firmware.

Will scheduled replies always send after a reboot?

The developer says schedules persist across resprings and rejailbreaks. That does not guarantee execution while the device is unjailbroken, offline or affected by a messaging-app update.
