CCBackgrounder17 Adds a Control Center Background Mode Toggle for iOS 17+

CCBackgrounder17 is an open-source project by 0xkuj that adds a “Toggle Background Mode” action to Control Center on iOS 17 and newer. Its README describes the purpose as allowing apps to run in the foreground when they move into the background. The project description and package metadata also mention an optional auto-toggle for chosen apps. The package control file lists version 1.0.0, the iphoneos-arm64 architecture, firmware 17.0 or newer, and dependencies on MobileSubstrate, CCSupport, and AltList. The repository currently presents the package version in metadata, but its page shows no published releases, so version 1.0.0 should not be described as a formal repository release.
