PodsGrant Adds Newer AirPods Support to Older Jailbroken iPhones

PodsGrant is a compatibility tweak for users pairing newer AirPods or Beats hardware with an older jailbroken device. Its preferences expose device-identification options that iOS would not normally provide on that setup.

Version0.5.4
Listed supportVaries by build; iOS 17 needs 0.5.5 prerelease 3
PriceFree / open source
SourceGitHub releases

What PodsGrant actually changes

The tweak works by letting users apply support information for newer audio products on older software. The real preference screenshots show model options and advanced identification controls rather than a generic AirPods icon.

This package needs extra care because its release notes contain build-specific warnings. Do not install a file merely because the version number appears to match.

  • Expose compatibility options for newer AirPods and selected Beats products on older devices.
  • Choose or map the product identity used by the tweak from its preferences.
  • Apply settings through the package's service-restart controls.
  • Provide separate packages for traditional rootful and modern rootless architectures where offered.

Compatibility and requirements

  • Version 0.5.4 includes rootful arm and rootless arm64 assets.
  • The developer states that 0.5.4 does not work on iOS 17.
  • iOS 17 users are directed to release 0.5.5 prerelease 3.
  • The first 0.5.4 arm package is reported by the developer as not working on their machine; the rebuilt arm asset is the corrected choice for that branch.
Important: Critical release warning: do not use PodsGrant 0.5.4 on iOS 17. The official release notes direct iOS 17 users to 0.5.5 prerelease 3. Rootful users on 0.5.4 should also avoid the original arm asset and read the note about the rebuilt package.

Installation checklist

  1. Open the official GitHub releases page and read the notes for the exact release.
  2. Match iOS version and jailbreak architecture before selecting any asset.
  3. On iOS 17, follow the developer's link to 0.5.5 prerelease 3 instead of 0.5.4.
  4. For the 0.5.4 rootful branch, use the developer-designated rebuilt arm asset rather than the original non-working upload.
  5. After installation, change only the setting needed for your headphones and keep a record of the previous value.
