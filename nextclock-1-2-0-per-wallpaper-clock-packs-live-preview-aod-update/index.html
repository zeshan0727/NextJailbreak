NextClock 1.2.0 Adds Per-Wallpaper Clock Packs, Live Preview and Experimental AOD

NextClock 1.2.0 adds a separate image-based clock pack for each Lock Screen, a draft preview with Apply, optional double-tap favorite switching and date-font controls. The stable package is rootless iOS 15–18; iOS 16–17 and Always-On Display behavior remain experimental.

By Zeeshan Barvi · Published November 23, 2026 · Latest stable release checked against the developer's v1.2.0 GitHub tag and APT package index

Compatibility boundary: NextClock 1.2.0 is a rootless jailbreak package. Its dependency range is firmware 15.0 or later but below 19.0, so iOS 19–27 are outside the declared range. A package's firmware range does not prove that a compatible jailbreak exists for every device and build. The developer also says TrollStore alone cannot inject this tweak.

What is new in the stable 1.2.0 release?

The developer published NextClock 1.2.0 on November 13, 2026 at 18:11:26 UTC. The latest stable GitHub release and the developer's APT package index both identify 1.2.0 as the current stable version checked on November 23. The separate 1.2.0 beta tags are prereleases, not newer stable releases.

  • Separate clock packs for Lock Screens: choose a pack in Settings → NextClock → Configure clock and assign it to the current wallpaper. The developer says wallpaper-pack switching was tested on iPhone X / iOS 16.7.5; other devices and versions still need testing.
  • Animated draft preview: preview a pack and appearance changes before applying them. The preview uses actual pack assets and current time, but is illustrative; the Lock Screen does not change until you tap Apply.
  • Favorite packs: mark at least two packs as favorites and optionally enable double-tap switching on visible clock digits. The gesture is off by default and skips deleted or unavailable packs.
  • Date font customization: choose System, Rounded, Serif or Monospaced; set relative size from 60% to 160%; and select System, Regular, Medium, Semibold or Bold weight. Existing profiles keep the system appearance by default.
  • Experimental Always-On Display rendering: the release describes minute-by-minute updates and the return of seconds/animations on wake. The developer's beta notes identify an iPhone 14 Pro on iOS 16.2 for this test; this is not a guarantee for every AOD-capable iPhone.
  • Maintenance controls: Export Diagnostics, Restart SpringBoard and Reset Settings are available from the main settings page. Diagnostics are shared only when you choose to send them.

Compatibility: rootless iOS 15–18, with important caveats

The v1.2.0 README lists rootless iOS 15–18 and includes arm64 and arm64e binaries. Package metadata declares firmware >= 15.0 and < 19.0, with mobilesubstrate (>= 0.9.5000) and preferenceloader dependencies. The developer's November 16 APT-repository update also marks rootless iOS 15–18 as supported.

Install or update through the developer's repository

  1. Add RAtnik00's official APT repository in Sileo or Zebra.
  2. Refresh sources and locate com.ratnik00.nextclock. Confirm the stable version is 1.2.0, not a beta build.
  3. Let the package manager resolve the declared substrate and PreferenceLoader dependencies. Do not install the DEB as a TrollStore IPA.
  4. Open Settings → NextClock, select a pack and use the preview before applying changes to the current Lock Screen.
  5. Test wallpaper assignment and charging/wake behavior on one Lock Screen first. If something fails, export diagnostics before changing several settings at once.

The official GitHub release also provides the rootless DEB. Its published SHA-256 is 8e91de85b597330be331c29ced4949b2d6d8961c92b546f19e15e8b743a44e0f; compare this only with com.ratnik00.nextclock_1.2.0_iphoneos-arm64.deb.

Practical troubleshooting

  • The stock clock remains visible: confirm the jailbreak is active, SpringBoard tweak injection is working and PreferenceLoader is installed. The developer says the modern adapter checks for compatible runtime methods and keeps the system clock when those methods are unavailable.
  • The preview changes but the Lock Screen does not: tap Apply. A draft preview is not committed until you apply it.
  • Double-tap does nothing: enable favorite switching and select at least two available packs. Tap visible clock digits; the gesture is optional and disabled by default.
  • AOD or wake animation behaves inconsistently: treat it as experimental. Record the exact device, iOS build and jailbreak, then export diagnostics.
  • Wallpaper gallery shows an unexpected clock: 1.2.0 includes a fix for a duplication issue associated with NextClock being disabled. If it persists, capture exact steps and the diagnostic report.

For a useful bug report, include the iPhone model, exact iOS version/build, jailbreak, installed NextClock version and reproducible steps. The exported structural report is local until you choose to share it; the developer says it does not automatically upload or collect notification text. Stable 1.1.1 remains in the release archive for rollback, but it predates 1.2.0's iOS 18 package range and lacks the new 1.2.0 features.

Frequently asked questions

Does NextClock 1.2.0 work on iOS 27?

No. Its published package metadata is limited to firmware 15.0 and later but below 19.0. iOS 19–27 are outside the declared range.

Can I use NextClock without a jailbreak?

No. The developer requires a compatible jailbreak with tweak injection and PreferenceLoader. TrollStore alone is not enough.

Is iOS 16–17 fully supported?

No. The developer describes the modern adapter as experimental and documents limited, feature-specific device checks.

Does 1.2.0 guarantee Always-On Display support?

No. AOD rendering is experimental. The release notes describe a test on iPhone 14 Pro with iOS 16.2, not broad device certification.

Is there a RootHide or rootful package?

The official release is rootless. The developer does not document a rootful or RootHide-specific package for 1.2.0, so those environments are unverified.
