SideDock 1.0.1 Fixes Home Screen Icon Overlap

SideDock moves the iPhone Dock to the right edge, adds macOS-style icon magnification and can appear inside apps as a switcher. Version 1.0.1 fixes the key layout problem by making the Home Screen grid leave room for the floating Dock.

By Zeeshan BarviPublished October 19, 20266 min read
Release snapshot: Havoc lists SideDock 1.0.1 at $2.99, released October 19, 2026, for rootless jailbreaks on iOS 17.0–18.7.9. A seven-day trial is included. Package compatibility does not prove jailbreak availability for every device in that range.

What SideDock 1.0.1 changes

The 1.0.1 changelog contains one focused fix: the Dock no longer covers Home Screen icons. SideDock now changes the grid so icons and widgets make room at the right edge, shrinking slightly where necessary. That matters because the tweak’s main interface remains visible beside the page rather than replacing only the stock bottom Dock.

The developer distinguishes this fixed layout from auto-hide behavior. When auto-hide is off, the grid reserves space for the Dock. When auto-hide is enabled, the Dock can pass over the page temporarily and disappear again after a chosen delay.

  • Fixed layout: icons and widgets fit beside the vertical Dock instead of sitting underneath it.
  • Floating Dock: pinned apps stay at the right edge with a compact background.
  • Recent apps: one to five recent apps can appear beneath a divider.
  • Magnification: sliding a finger over the Dock enlarges nearby icons before they settle back.
  • In-app switching: a right-edge swipe can open the Dock over another app for quick switching.

What the vertical Dock looks like

The official screenshot shows a translucent vertical panel carrying apps on the right side while the regular icon grid remains usable. The Search control moves to the bottom of the page, where the stock horizontal Dock previously sat.

Users can change Dock size and vertical position, drag apps into, out of and within the Dock, or swipe the Dock to the right to hide it. A right-edge swipe or a small handle brings it back.

Home Screen controls beyond the Dock

SideDock also modifies the wider icon layout. It can hide app labels, use a denser grid up to six columns by eight rows and apply a custom corner radius ranging from square icons to circles. The developer says folders preserve their appearance and notification badges remain intact.

Compatibility and tested devices

Havoc lists package identifier com.koh.sidedock, version 1.0.1, rootless support and an iOS range of 17.0 through 18.7.9. The developer specifically names Dopamine and palera1n, and reports testing on an iPhone 15 Pro Max running iOS 17.3.1 and on iOS 18.6.2.

Those tests are not a universal device matrix. The package range does not mean every iPhone or iPad on iOS 17 or 18 has an available jailbreak. Confirm that the exact device, firmware, bootstrap and tweak-injection environment are supported before purchasing. The official listing does not explicitly claim RootHide compatibility.

On iOS 18, SideDock’s settings page requires a PreferenceLoader build that supports iOS 18. The package itself may install while its preferences fail to load if that dependency is outdated.

Crash guard and known limits

SideDock includes a SpringBoard crash guard. If SpringBoard fails to start several times consecutively, the tweak turns itself off. That safeguard is useful, but it is not evidence that the tweak supports an undocumented device or environment.

The developer also notes that changing grid size, floating mode, auto-hide or Dock size requires a respring so the Home Screen layout can recalculate. If a crash loop occurs, leave SideDock disabled and capture a full report with the KrashKop crash-log guide before re-enabling it.

Trial, purchase check and privacy note

A fresh installation works for seven days before SideDock verifies the Havoc purchase online. The official description says the check runs again when Settings is opened and that a verified device continues working offline afterward.

The licensing request sends the device UDID and model to the SideDock license server, which asks Havoc for purchase status. The developer states that nothing is stored. Users should still understand that this identifier exchange is part of activation before installing the paid package.

How to install or update safely

  1. Open Havoc in Sileo or Zebra and refresh sources.
  2. Confirm the package is SideDock 1.0.1 with identifier com.koh.sidedock.
  3. Verify that the active jailbreak is rootless and the device is within the listed iOS 17.0–18.7.9 range.
  4. On iOS 18, confirm PreferenceLoader is a compatible build before relying on the Settings pane.
  5. Review the package-manager queue for unexpected removals or architecture conversions.
  6. Install, complete the requested respring and start with the default grid before increasing density.

For a full transaction checklist, use the safe Sileo installation guide. Readers comparing broader Home Screen customization can also see Atria versus Lynx 2; those tools target different iOS ranges and broader layouts rather than SideDock’s iOS 17–18 vertical-switcher design.

Frequently asked questions

What is the latest SideDock version?

Havoc lists SideDock 1.0.1, released October 19, 2026.

What does version 1.0.1 fix?

It makes the Home Screen grid reserve room for the Dock so icons and widgets no longer sit underneath it.

Does SideDock support iOS 16 or iOS 26?

No such support is listed. The official compatibility range is iOS 17.0–18.7.9.

Does SideDock support RootHide?

The listing says rootless and names Dopamine and palera1n, but it does not explicitly promise RootHide support.

Can SideDock switch apps while another app is open?

Yes. The developer says swiping from the right edge can show the Dock over an app; tapping outside or swiping it away closes it.
