Relaxin 0.5.7 Adds Experimental tvOS, visionOS and iOS 16.1 Support

Relaxin 0.5.7 expands its experimental targets to older iOS 16 releases, three Apple TV 4K generations and the M2 Vision Pro. It also changes the bundled package source and managers, fixes file-picker and TrollStore Lite failures under jailbreak hiding, and improves recovery from interrupted package installations.

By Zeeshan Barvi · Published September 29, 2026 · Updated November 8, 2026 · Current official release: 0.5.7

Experimental does not mean universal. The project names exact Apple TV and Vision Pro targets but describes iOS/iPadOS 16.1–16.4.1 only as experimental support on compatible devices. Do not extend that claim to every iPhone or iPad.

Current version and release date

The official Relaxin release timeline lists version 0.5.7 on November 1, 2026. It supersedes 0.5.6, which added A10/A10X and A11 support, and the 0.5.4 version previously covered on this page. The official archive provides separate IPA and TIPA files with a SHA-256 digest and exact byte size for each.

Relaxin is a RootHide-oriented jailbreak. A package saying it supports a firmware version does not prove that Relaxin supports every device on that firmware, and a conventional rootless package is not automatically compatible with the RootHide environment.

What Relaxin 0.5.7 changes

  • Experimental iOS/iPadOS 16.1–16.4.1 support: the release adds this range for compatible devices but does not publish a complete chip-by-chip matrix for the new path.
  • Experimental Apple TV support: the first three Apple TV 4K generations receive named semi-untethered ranges.
  • Experimental Vision Pro support: the M2 model is listed for visionOS 1.0–1.0.3.
  • Jailbreak-hiding repairs: excluded apps can again open files through the file picker, and affected TrollStore Lite apps should launch with hiding enabled.
  • Package recovery: rerunning the jailbreak can recover more reliably from an incomplete package installation.
  • Updated package stack: the bundled source changes from Procursus to OwnGoal Stripe; Sileo becomes 2.5.1-15, Irisin 5.1.4 and Umbra 2.2.2.
  • Irisin architecture change: the release explicitly removes rootless support from Irisin. That does not turn RootHide packages into conventional rootless packages.

Safe update order

  1. Record the current Relaxin version, selected package manager and excluded apps. Export a tweak list where possible.
  2. Download only from the official timeline or linked GitHub release and verify its matching hash.
  3. Close package managers and finish any pending installs before replacing the app. Do not interrupt dpkg or a userspace reboot.
  4. Open 0.5.7 and let it detect the existing environment. If it reports incomplete packages, use its recovery path before installing another tweak.
  5. After the first successful jailbreak, confirm Sileo, Umbra and one simple package operation work before adding repositories.
  6. Test file picking and TrollStore Lite apps that use jailbreak hiding. Re-add exclusions one at a time if behavior changed.

Package managers and RootHide boundaries

Version 0.5.7 bundles Sileo 2.5.1-15, Irisin 5.1.4 and Umbra 2.2.2, and moves its bundled source from Procursus to OwnGoal Stripe. This is a migration of Relaxin’s packaged environment, not a signal to manually remove every Procursus package before updating.

The changelog says Irisin no longer supports rootless. Here, “rootless” and “RootHide” are different package environments. Do not add a conventional rootless repository merely because it works on Dopamine, and do not force-install an architecture-mismatched DEB. Use packages documented for RootHide or a current conversion workflow, then review the transaction before approving it.

Troubleshooting 0.5.7

  • Interrupted package installation: reopen Relaxin, rerun the jailbreak and allow recovery to finish. Do not queue more packages while dpkg is inconsistent. If needed, use the dpkg and Sileo repair guide.
  • An excluded app cannot open a document: confirm 0.5.7 is active, remove and re-add the app to jailbreak hiding, then retest the system file picker.
  • A TrollStore Lite app will not launch: verify the app launches without an injected tweak, then retest with the 0.5.7 hiding fix. The release cannot guarantee every detection system.
  • Sileo or Umbra is missing: finish the first jailbreak and userspace reboot, then use Relaxin’s package-manager reinstall control rather than importing an unrelated bootstrap package.
  • The device watchdog-restarts: start without tweak injection if offered, preserve the new crash report and remove the last installed package before retrying.

What this release does not prove

The tvOS and visionOS work is explicitly experimental. The release notes do not claim production stability, support for every peripheral or feature parity with the iPhone/iPad build. The new iOS/iPadOS 16.1–16.4.1 line also does not identify every compatible chip. Treat an absent model as unconfirmed.

Jailbreak hiding reduces some visible traces but cannot guarantee that banking, game or work apps will accept a jailbroken environment. Those apps can change detection methods independently of Relaxin.
