Relaxin 0.5.4 Jailbreak Update Adds Umbra 2.0, Irisin and Reliability Fixes

Relaxin v0.5.4 was released on September 24, 2026. The update replaces Relaxin's bundled RootHide Manager with Umbra 2.0, adds Irisin 4.4.1 as an optional package manager, improves A12 reliability, fixes failures on some PPL-based devices and expands jailbreak-trace hiding for excluded apps. Here is what changed and which devices and firmware versions the official project currently supports.

Relaxin 0.5.4: key changes

  • RootHide Manager bundled with Relaxin has been replaced by Umbra 2.0.
  • Irisin 4.4.1 is now an optional package manager during initial setup, with reinstall options available after jailbreaking.
  • Jailbreak reliability has been improved on A12 devices.
  • The release fixes jailbreak failures affecting some PPL-based devices.
  • A problem that could leave the Sileo icon missing on some devices has been fixed.
  • More jailbreak traces are hidden from excluded apps on iOS and iPadOS 16.
  • Crash-report collection for system and helper processes is improved on iOS/iPadOS 17 and later.

Umbra 2.0 replaces the bundled RootHide Manager

The most visible change in Relaxin 0.5.4 is the move from the previously bundled RootHide Manager to Umbra 2.0. This is an official change documented in the project's 0.5.4 release notes, not a separate community modification.

For existing Relaxin users, this means the management component included with the jailbreak has changed. Users updating an existing setup should follow the prompts and options presented by Relaxin rather than mixing components from unrelated jailbreak environments.

Irisin 4.4.1 becomes an optional package manager

Relaxin 0.5.4 also adds Irisin 4.4.1 as an optional package-manager choice. The project says the choice is available during initial setup and that reinstall options remain available after the device has been jailbroken.

This does not mean Sileo has been removed. In fact, the same release specifically fixes an issue where the Sileo icon could fail to appear on some devices.

Reliability fixes for A12 and PPL-based devices

The release notes specifically call out improved jailbreak reliability on A12 hardware. Relaxin 0.5.4 also fixes jailbreak failures on some PPL-based devices. These are reliability changes rather than an announcement of a new universal firmware range.

That distinction is important because Relaxin's current compatibility depends on the chip family. Do not assume that every A12–A17 device supports the same iOS versions.

Relaxin supported devices and iOS versions

According to the official Relaxin project, A12 and A13 devices currently support iOS/iPadOS 16.5 through 18.7.1 and 26.0 through 26.0.1. This includes devices such as the iPhone XS/XR family and iPhone 11 family.

A14 through A17 devices currently have a different range: iOS/iPadOS 16.5 through 17.3.1. The same 16.5–17.3.1 range is listed for M1 and M2 iPads. Therefore, an iPhone 15 Pro on a supported 17.x firmware and an iPhone 11 on iOS 26 are not equivalent compatibility cases.

  • A12/A13: iOS 16.5–18.7.1 and 26.0–26.0.1.
  • A14–A17: iOS 16.5–17.3.1.
  • M1/M2: iPadOS 16.5–17.3.1.

Better jailbreak hiding for excluded apps

Relaxin uses a RootHide-oriented architecture, and version 0.5.4 extends its handling of excluded applications. The official changelog says more jailbreak traces are hidden from excluded apps on iOS and iPadOS 16. It also adds custom URL-scheme replacements while keeping jailbreak-only links hidden from excluded apps.

This should be read as a technical improvement to Relaxin's isolation behavior, not as a guarantee that every application with jailbreak detection will work. Individual apps can use different detection techniques and can change them through updates.

Should existing Relaxin users update?

Version 0.5.4 is primarily a management, reliability and compatibility-maintenance release. It is especially relevant to users affected by A12 reliability issues, PPL-device jailbreak failures or the missing Sileo icon. Users interested in Umbra 2.0 or the optional Irisin package-manager path also gain those changes.

Before updating, confirm your exact device chip and firmware against the current official compatibility information. If your device is outside the documented range, the 0.5.4 changelog should not be interpreted as newly adding support for it.

Frequently asked questions

What is new in Relaxin 0.5.4?

Umbra 2.0 replaces the bundled RootHide Manager, Irisin 4.4.1 becomes an optional package manager, and the release adds A12/PPL reliability fixes, Sileo-icon fixes, additional jailbreak-trace hiding and improved crash reporting.

Does Relaxin 0.5.4 support iOS 26?

Officially, iOS 26.0–26.0.1 support is currently listed for A12 and A13 devices. A14–A17 devices are listed for iOS 16.5–17.3.1 instead.

Does Relaxin 0.5.4 remove Sileo?

No. The release adds Irisin as an optional package manager and also fixes an issue where the Sileo icon did not appear on some devices.
