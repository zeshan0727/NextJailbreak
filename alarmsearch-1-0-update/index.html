AlarmSearch 1.0 Adds Search to the Clock App’s Alarm List

AlarmSearch is a version 1.0 iOS tweak from iCraze that adds a search bar to the Clock app’s alarm list. Its official package stanza identifies the package as com.icraze.alarmsearch, lists iphoneos-arm64 as the architecture, and declares mobilesubstrate version 0.9.5000 or newer as a dependency. The available source material does not provide an iOS version range, device list, jailbreak-environment classification, configuration instructions, or details about how search behaves.

Key points

  • AlarmSearch is published as version 1.0 under package identifier com.icraze.alarmsearch.
  • Its stated purpose is to add a search bar to the Clock app alarm list.
  • The package lists iphoneos-arm64 as its architecture.
  • The declared dependency is mobilesubstrate version 0.9.5000 or newer.
  • The supplied material does not specify supported iOS versions, devices, or jailbreak environments.
  • The associated public repository contains an AlarmSearchApp project, but its visible README provides only the project title and its recent commits concern index.html presentation changes.

What AlarmSearch 1.0 changes

AlarmSearch is presented as a focused modification for Apple’s Clock app. The official package description says that it “adds a search bar to the Clock app alarm list.” That is the complete user-facing feature described in the supplied package material. The package is named AlarmSearch, is attributed to iCraze, and is placed in the Tweaks section.

The feature’s intended scope is therefore narrow: it adds search to the list where alarms are displayed. This could be useful to someone managing many alarms, but the source does not explain the search implementation. It does not say whether results update as text is entered, which alarm fields are searched, how matching is handled, or what appears when there are no results. It also does not describe changes to alarm creation, editing, synchronization, or scheduling.

Because those details are not included in the official material supplied here, they should not be treated as confirmed features. The strongest supported description remains that AlarmSearch adds a search bar to the Clock app alarm list.

  • Name: AlarmSearch
  • Version: 1.0; package identifier: com.icraze.alarmsearch
  • Author and maintainer listed in the package stanza: iCraze
  • Package section: Tweaks

Declared dependency

AlarmSearch declares mobilesubstrate version 0.9.5000 or newer as a dependency. This is the only dependency named in the supplied package stanza. The source does not explain which environments provide it, whether another compatibility layer can satisfy the requirement, or how the package behaves when the requirement is absent.

The dependency should be treated as an explicit package requirement rather than as a general statement that every iphoneos-arm64 device can use AlarmSearch. Architecture and dependency describe different parts of the package metadata: the architecture identifies the package target recorded by the repository, while the dependency identifies software required by the package declaration.

The supplied stanza does not list conflicts, optional components, preferences, daemons, configuration panels, respring instructions, removal procedures, or rollback behavior. It also does not document any installation outcome associated with an unsatisfied dependency. Accordingly, the available source supports only the factual statement that mobilesubstrate 0.9.5000 or newer is declared as required.

  • Declared dependency: mobilesubstrate (>= 0.9.5000)
  • No additional dependencies are listed in the supplied stanza.
  • No conflicts or configuration instructions are provided in the supplied package material.

The next changes the logo positioning from top 20 pixels and right 20 pixels to top 10 pixels and right 30 pixels. Why the package details matter

AlarmSearch’s appeal is its clearly defined purpose. Instead of claiming to redesign the Clock app, the official description identifies one change to one area: adding a search bar to the alarm list. That makes the package easy to characterize without assuming undocumented filtering options or broader alarm-management features.

At the same time, version 1.0 and the limited supplied documentation call for a precise reading of the available evidence. The package confirms the search-bar feature, package identity, architecture, maintainer, and dependency. It does not confirm an iOS support range, a device list, a jailbreak model, or detailed runtime behavior.

For readers evaluating the package, the most useful facts are therefore the declared requirements and the boundaries of what is known. AlarmSearch targets iphoneos-arm64, depends on mobilesubstrate 0.9.5000 or newer, and is described as adding search to the Clock app alarm list. Claims beyond those points require additional source material that is not included here.

  • Confirmed feature: a search bar in the Clock app alarm list.
  • Confirmed version: 1.0.
  • Confirmed architecture: iphoneos-arm64.
  • Confirmed dependency: mobilesubstrate 0.9.5000 or newer.
  • Unconfirmed in the supplied material: iOS versions, device support, jailbreak type, and detailed search behavior.
