iFetch 6.0.0: System Diagnostics and CLI Fetch for iOS 14–17 Jailbreak Devices

iFetch 6.0.0 is an updated System & Utilities package from weeka. Its supplied description identifies it as an advanced system diagnostics, process monitor, and CLI fetch tool for rootless and RootHide jailbreak devices on iOS 14–17. The release is listed for the iphoneos-arm64 architecture and has dependencies on firmware 14.0 or newer but below 18.0, mobilesubstrate, and com.opa334.ccsupport.
