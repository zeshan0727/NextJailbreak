Watusi 3 for WhatsApp 1.3.29 Adds WhatsApp 26.42 Support as Simplified Chinese Pack Gets a Packaging

Watusi 3 for WhatsApp has reached version 1.3.29, according to the official package information and depiction. The release is described as a bug-fix update with support for WhatsApp 26.42. The official listing identifies iOS 15.1+ support, while the package stanza declares a firmware requirement of iOS 12.0 or later and dependencies on MobileSubstrate and Watusi Tools. Separately, the WatusiZhHans project has reorganized its Simplified Chinese language-pack build process to produce rootful, rootless, and roothide packages, while continuing to describe the localization as based on Watusi 1.3.9.

Key points

  • Watusi 3 for WhatsApp version 1.3.29 is listed as a bug-fix release with support for WhatsApp 26.42.
  • The official depiction lists iOS 15.1+ support, while the package stanza declares firmware version 12.0 or later.
  • The tweak depends on MobileSubstrate version 0.9.5000 or later and Watusi Tools version 2.8.3 or later.
  • Watusi includes privacy, chat, status, media, notification, theme, scheduling, auto-reply, hidden-chat, custom-tone, and sticker-management options described by the official listing.
  • The Simplified Chinese language project now describes a unified build process for rootful, rootless, and roothide packages, but its README still identifies Watusi 1.3.9 as the development baseline.
  • Readers should distinguish the main Watusi package from the separate Chinese localization package and check the dependency and version relationship before installation.

Watusi 1.3.29 targets WhatsApp 26.42

The official Watusi package is now listed at version 1.3.29. Its release note is short: bug fixes and support for WhatsApp 26.42. That makes this primarily a compatibility-maintenance release rather than an announcement of a new feature category.

The official package page identifies November 2, 2026 as the release date. Because the listed change does not describe individual fixes, readers should not infer that a particular Watusi option was repaired in this build. The supported conclusion is narrower: the update is intended to address bugs and accommodate the cited WhatsApp 26.42 release.

  • Package name: Watusi 3 for WhatsApp.
  • Package identifier: com.fouadraheb.watusi3.
  • Current version: 1.3.29.
  • Release note: bug fixes and support for WhatsApp 26.42.

Compatibility and dependencies need careful reading

The official Sileo depiction lists support for iOS 15.1 and later. The package stanza separately declares a firmware dependency of version 12.0 or later. These are different pieces of package information, so users should treat the depiction's iOS 15.1+ line as the publisher's displayed support statement and avoid assuming that every device running iOS 12, 13, or 14 is supported merely because the dependency accepts firmware 12.0 or newer.

The package is built for the iphoneos-arm64 architecture. It also depends on MobileSubstrate version 0.9.5000 or later and Watusi Tools version 2.8.3 or later. Those dependencies are part of the package declaration, not optional add-ons described as unnecessary by the source. A package manager should therefore be checked for the required components before installation.

The package also declares conflicts with several older or alternative Watusi identifiers, including com.fouadraheb.watusi, com.f0u4d.watusi, org.thebigboss.watusi, and com.b4db1r3.cleancopy. This means an existing conflicting package may need to be removed or replaced rather than installed alongside 1.3.29.

  • Displayed depiction support: iOS 15.1+.
  • Declared firmware dependency: 12.0 or later.
  • Architecture: iphoneos-arm64.
  • Required dependencies: MobileSubstrate 0.9.5000 or later and Watusi Tools 2.8.3 or later.
  • Conflicts are declared with multiple older or alternative Watusi package identifiers.

What the tweak offers

The official description presents Watusi as an all-in-one tweak for WhatsApp Messenger. Its feature list spans several areas, although the 1.3.29 release note does not say that these features were newly added in this version.

Privacy controls include freezing Last Seen, disabling read, typing, recording, and delivery indicators, disabling WhatsApp internet access, blocking incoming calls, and automatically switching Last Seen privacy. Protection options include app protection, chat protection, and hiding the last message.

Status tools include downloading statuses, manually marking statuses as viewed, archiving personal statuses, keeping deleted contact statuses, splitting long videos into multiple statuses, disabling automatic advance, and creating privacy groups. Chat and chat-list options include continued audio messages, chat details, call confirmation, tap-to-record, forwarding controls, filters and sorting, unlimited pinned chats, archive lock, group lists, swipe actions, and a clear-chats button.

Other sections cover custom sharing, saving profile photos, media deletion, interface changes, private notifications, themes, scheduled messages, advanced auto-replies, hidden chats, contact-name and photo changes, custom notification tones, and sticker-pack creation or importing. The package also includes a Control Center toggle; the official description says CCSupport must be downloaded and activated through Control Center settings.

  • Privacy and protection controls are central parts of the published feature set.
  • Status tools include downloading, archiving, viewing controls, and long-video splitting.
  • Chat-list and media options add filtering, sorting, pinned-chat, sharing, and deletion controls.
  • Separate modules cover themes, message scheduling, auto-reply, hidden chats, custom tones, and stickers.
  • Control Center integration requires CCSupport according to the official description.

Simplified Chinese localization project changes its build layout

A separate official GitHub project, WatusiZhHans, provides a Simplified Chinese language pack for Watusi 3. Its README says the project adds Chinese translations and uses a minimal runtime hook to add “简体中文” to Watusi's Other Settings > Language menu.

The latest supplied commit, dated May 16, 2026, says the project introduced a unified build_packages.sh workflow that serially generates rootful, rootless, and roothide installation packages. It also says the localization-generation logic was reorganized to output resources by target stage and retain only zh-Hans.lproj. The same commit removes several older Chinese locale resource paths from the roothide layout.

This is a packaging and resource-organization change, not evidence that the language pack has been updated for Watusi 1.3.29. The project README continues to describe the pack as based on Watusi 1.3.9. An earlier package-control change also changed the language-pack version from 1.3.9-2 to 0.0.1 and removed an exact Watusi 1.3.9 dependency, leaving a general dependency on com.fouadraheb.watusi3. That looser declaration does not itself establish compatibility with every Watusi release.

  • The language pack adds Chinese translations and a Simplified Chinese language-menu entry.
  • The latest build workflow is described as producing rootful, rootless, and roothide packages.
  • The project README identifies Watusi 1.3.9 as its development baseline.
  • The language-pack source does not provide a release-specific statement confirming compatibility with Watusi 1.3.29.

Installation notes and checks before updating

The language-pack README supplies a specific usage sequence: install the language-pack deb, completely terminate WhatsApp, reopen it, then navigate to Watusi > Other Settings > Language and select Simplified Chinese. It also suggests trying Language = Auto when WhatsApp or the system language is Simplified Chinese.

For the main Watusi package, readers should use the official package-management route and confirm that the required substrate and Watusi Tools dependency versions are available. The supplied sources do not provide a general step-by-step installation procedure for Watusi 1.3.29 itself, so it would be inappropriate to present additional installation steps as official instructions.

Before combining Watusi 1.3.29 with the Chinese pack, check the localization project's current package metadata, its stated Watusi baseline, architecture, and whether the package manager resolves the dependency cleanly. The project itself recommends rechecking language-hook details, the language-list construction method, and FRSListCell-related signatures after a Watusi upgrade. That warning is particularly relevant because 1.3.29 is newer than the Watusi version named in the README.

  • Terminate and reopen WhatsApp after installing the Chinese language pack, as instructed by its README.
  • Check Watusi's displayed iOS support separately from its package firmware dependency.
  • Confirm MobileSubstrate and Watusi Tools meet the declared minimum versions.
  • Review conflicts before upgrading from an older Watusi package.
  • Do not assume the Chinese pack's Watusi 1.3.9 baseline guarantees compatibility with 1.3.29.

Frequently asked questions

What changed in Watusi 3 version 1.3.29?

The official release note lists bug fixes and support for WhatsApp 26.42. It does not enumerate individual bug fixes or announce a new feature.

What iOS versions are listed as supported?

The official depiction lists iOS 15.1+. The package stanza declares firmware version 12.0 or later, so users should not treat the latter as a complete substitute for the publisher's displayed support statement.

What dependencies does Watusi 1.3.29 require?

The package declares MobileSubstrate version 0.9.5000 or later and com.f0u4d.watusitools version 2.8.3 or later.

Does Watusi 1.3.29 include Simplified Chinese?

The official Watusi description lists English, Arabic, German, Spanish, French, Italian, Portuguese, and Turkish. Simplified Chinese is supplied by a separate WatusiZhHans language-pack project, whose README describes a runtime hook that adds it to the language menu.

Is the Chinese language pack confirmed for Watusi 1.3.29?

The supplied source does not confirm that. The language-pack README says it is based on Watusi 1.3.9, while Watusi 1.3.29 is a later release. Users should check the package metadata and project maintenance status before combining them.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
