CatMCP 1.3.0 Adds Lock-State Queries, Unlock and Power-Key Control

CatMCP 1.3.0 expands the jailbroken-iOS MCP server with lock-state queries, optional-passcode unlocking, and Power-key actions for sleep, wake and the power-off menu. The paid rootless package remains listed at $9.99 for iOS 14.0–18.7.1, but its powerful shell, file and device controls make careful network isolation essential.

What CatMCP 1.3.0 changes

The official Havoc version history dates CatMCP 1.3.0 to October 26, 2026. Its three release notes are narrowly defined but significant for device automation:

  • Lock state and unlock: an MCP client can query whether the device is locked and request an unlock, with an optional passcode.
  • Power-key actions: the server can invoke the Power key for sleep, wake and the power-off menu.
  • Honest key errors: unknown key codes now return a clear error instead of silently reporting success.

The last point should make automation easier to debug: a client can distinguish an unsupported key from a successful command instead of continuing from a false-positive response.

The 1.2.x foundation is still relevant

Version 1.3.0 builds on two releases shipped shortly before it. CatMCP 1.2.0, dated September 27, added UI inspection through a ui_elements tool that returns an element tree for the frontmost app. CatMCP 1.2.1, dated October 25, fixed bugs including a SpringBoard crash in that UI-inspection path. Version 1.1.0 had previously added iOS 18 compatibility for Dopamine.

Together, UI inspection and the new lock and Power controls make CatMCP more useful for repeatable testing flows: an agent can inspect a screen, interact with it, and now reason about whether the device is awake or locked. This article describes the developer’s published capabilities; Next Jailbreak has not independently tested the paid package.

What the MCP server exposes

According to the official product description, CatMCP lets compatible tools such as Claude, Cursor and other MCP clients control a jailbroken iPhone or iPad over the local network. The documented tool set includes:

  • screenshots with configurable quality and scale;
  • tap, swipe and long-press input;
  • keyboard input including Home, volume and arrow keys;
  • launching, terminating and listing applications;
  • reading, writing and browsing files;
  • brightness, volume, clipboard and URL controls;
  • shell-command execution;
  • battery, IP-address and device-name queries; and
  • frontmost-app UI inspection.

Those are remote-control and data-access capabilities, not merely a chat interface. CatMCP’s package identifier is com.catmcp.daemon, and Havoc lists the current download at about 1.66 MB.

Setup: same network, default port 9000

  1. Install CatMCP from its official Havoc page through your package manager.
  2. Open Settings → CatMCP and enable the server.
  3. Note the iPhone or iPad’s local IP address and the port shown in Settings; the default is 9000.
  4. Tap Copy MCP Config and add the copied configuration to the supported desktop AI client.
  5. Keep the iOS device and the computer running the client on the same local network. The documented endpoint format is http://device-ip:9000/mcp.

If Sileo holds an older build, see our guide to checking and removing an ignored package update. If package-manager icons disappear after a jailbreak restart, use the Dopamine jailbreak-app recovery steps.

Security: treat CatMCP as high-privilege remote access

The official feature list includes shell execution, file access, application control and device input; version 1.3.0 adds unlocking with an optional passcode. That combination deserves a stricter threat model than an ordinary visual tweak.

  • Use only a trusted, preferably isolated local network.
  • Do not forward port 9000 or otherwise expose the MCP endpoint to the public internet.
  • Enable the server only while actively using it, then switch it off.
  • Review every configuration before giving it to an AI client, and prefer a dedicated test device over a daily device containing sensitive data.

The Havoc listing does not document transport encryption, authentication, per-tool approval prompts or a complete security model. We therefore cannot claim those protections exist. The optional passcode mentioned in the unlock command is not, by itself, proof that access to the server is authenticated.

Compatibility and availability

Havoc lists CatMCP 1.3.0 as a rootless package requiring a jailbreak, compatible with iOS 14.0 through 18.7.1. It costs $9.99 and is sold by 0x530c. The listing’s firmware range describes package compatibility only: it does not mean a jailbreak exists for every device and iOS version in that range, nor does it confirm RootHide support.

Use the official Havoc page as the download source and confirm the displayed version before purchasing. Next Jailbreak does not mirror the package.

Frequently asked questions

What changed in CatMCP 1.3.0?

The release adds lock-state queries, unlocking with an optional passcode, Power-key control for sleep, wake and the power-off menu, plus clear errors for unknown key codes.

Does CatMCP 1.3.0 require a jailbreak?

Yes. Havoc marks it as a rootless jailbreak package for iOS 14.0–18.7.1. That range does not establish jailbreak availability for every device or firmware.

How does an AI agent connect?

Enable CatMCP in Settings, copy its MCP configuration, and add it to a compatible client. The device and client must share a local network; the default port is 9000.

Is it safe to expose CatMCP to the internet?

No such deployment is documented by the developer. Because CatMCP exposes shell, file, app and device controls, keep it on a trusted local network and do not forward its port to the public internet.

How much does CatMCP cost?

The official Havoc listing shows CatMCP 1.3.0 at $9.99 as of October 26, 2026.

Before installing: verify version 1.3.0, the iOS 14.0–18.7.1 rootless range and your exact jailbreak environment on the live Havoc page. Package compatibility is not proof of jailbreak availability.
