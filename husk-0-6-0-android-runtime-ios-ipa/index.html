Husk 0.6.1 Expands Android Apps on iPhone After 0.6.0 Translation Layer Launch

Husk crossed an important milestone with version 0.6.0: its experimental Android Translation Layer could run selected Android apps directly inside iOS. Version 0.6.1 followed on October 5 with more compatibility, including Minecraft, Geometry Dash and Wi-Fi support for Unity games.

By Zeeshan Barvi · Published October 5, 2026 · Source checked against Leviidev/Husk 0.6.0 and 0.6.1

Current version: Husk 0.6.1 is newer than 0.6.0. The 0.6.0 release introduced the experimental Android Translation Layer; 0.6.1 is the recommended build to test unless you specifically need the older release.

What is Husk?

Husk is an open-source Android app launcher and emulator project for iPhone and iPad. Its README describes the goal simply: drop in an APK, tap it, and open the Android app full-screen on iOS. The project is still experimental, so this should not be read as universal Android compatibility.

Husk is not an App Store app. The developer says the project requires capabilities including get-task-allow and a debugger attaching at runtime, and publishes unsigned IPA builds for sideloading. The official README names AltStore, SideStore and TrollStore as installation routes.

Husk 0.6.0: the Android Translation Layer milestone

Version 0.6.0, published October 4, 2026, added an implementation of the experimental Android Translation Layer. The developer's release notes give the test path as Settings → Android Translation Layer → Add APK → choose the APK → Run Translation Layer Attempt.

According to the 0.6.0 release notes, the translation layer could fully run Flappy Bird and Subway at 60 FPS in the developer's testing. That is a significant proof of concept, but it does not mean any random APK will launch successfully. Android apps can depend on APIs, services, graphics behavior and native libraries that the translation layer may not yet implement.

Husk 0.6.1 is already available

Only hours after 0.6.0, Husk 0.6.1 was published on October 5. Its official changelog adds Wi-Fi support for Unity games, Geometry Dash support and Minecraft support.

The developer also notes that 0.6.1 changes only the Android Translation Layer. Husk's separate fully emulated Android OS path was not changed in this build. That distinction matters because Husk is experimenting with more than one approach to running Android software on iOS.

How to install Husk

  1. Download the official Husk.ipa using the button above.
  2. Install it with a compatible sideloading method. The project README specifically mentions TrollStore, SideStore and AltStore.
  3. If you already use TrollStore, open the downloaded IPA in TrollStore or select it from TrollStore's IPA file picker. Our TrollStore IPA installation guide covers that process.
  4. Open Husk and follow its current settings for the runtime mode you want to test.
  5. For the Android Translation Layer, add your APK from Settings → Android Translation Layer and run the translation-layer attempt.

Can Husk run every APK on iPhone?

No. Husk is a rapidly developing experimental project, not a complete replacement for an Android phone or a mature Android compatibility platform. Version 0.6.0 demonstrated selected apps, while 0.6.1 explicitly adds support for several more workloads. Unsupported APKs may fail to start, crash, show graphical problems or depend on Android services that are not available.

The upstream Android Translation Layer project itself documents that random apps commonly expose missing classes, methods or service behavior. Husk's iOS integration therefore remains a compatibility-development project rather than a promise that every Android package will run.

Why this matters for iOS

Android emulation on iPhone has traditionally meant virtualizing or emulating a larger guest system, with substantial CPU, memory and JIT constraints. A translation-layer approach is interesting because it aims to map Android application behavior into the host environment more directly. Husk 0.6.0 is notable because that experimental path moved from source-level work into a user-testable iOS IPA release.

For jailbreak and TrollStore users, the practical value is clear: if compatibility continues to improve, Android-only utilities or games could become testable from a single iOS app without requiring a conventional Android device. The current releases are still early enough that compatibility should be checked app by app.
