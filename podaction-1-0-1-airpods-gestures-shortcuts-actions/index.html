PodAction 1.0.1 Maps AirPods Gestures to Shortcuts and System Actions

aronsz26’s PodAction turns AirPods presses, swipes and double taps into Shortcuts, Focus changes, camera launches and other iOS actions. Version 1.0.1 fixes the single-press path for newer AirPods used on older iOS releases and makes recognition after connecting more reliable.

By Zeeshan BarviPublished October 25, 2026Verified against the official Havoc listing
Latest verified release: Havoc lists PodAction 1.0.1, updated October 25, 2026, for $1.99. The listing declares iOS 14.0–26.0.1, rootless support and a jailbreak requirement. That firmware range describes the package, not jailbreak availability for every device.

What changed in PodAction 1.0.1

The official 1.0.1 changelog contains two targeted fixes:

  • Press Once compatibility: a single press no longer does nothing when the connected AirPods model is newer than the iOS release. The developer’s example is AirPods Pro 3 on iOS 16.
  • Connection recognition: PodAction should identify AirPods more reliably after they connect.

Neither note claims new gestures or actions. Version 1.0.1 is a reliability update for the existing mapping system, particularly useful when recent AirPods are paired with an older jailbroken iPhone.

Supported gestures depend on the AirPods model

AirPods familyGestures listed by the developerImportant limit
AirPods Pro, AirPods 3 and laterPress once, twice or three times; press and holdPress and hold works only while that gesture is set to Noise Control.
AirPods Pro 2 and laterSwipe up and swipe downA swipe cannot be detected at the lowest or highest volume.
AirPods 1 and 2Separate left and right double tapsPodAction temporarily changes the Bluetooth double-tap setting to distinguish sides, then restores it when Default is selected.

Unassigned gestures keep their standard behavior. The listing also says the AirPods still play their normal click or chime, so an assigned action does not suppress that hardware feedback.

Actions you can assign

Each supported gesture opens its own action picker. The official list includes:

  • Flashlight
  • Camera modes: photo, selfie, video, portrait and portrait selfie
  • Focus
  • Voice Memo, Recognize Music, Translate and Magnifier
  • Dark Mode, Low Power Mode, Orientation Lock, Wi-Fi, Bluetooth and Airplane Mode
  • Any Shortcut
  • Accessibility features

The Shortcut option is the broadest because it can hand the gesture to an automation the user has already built. That does not mean every Shortcuts action will work identically while the phone is locked; privacy prompts, authentication and app state can still affect a shortcut.

How the playback safeguard works

For each mapping, PodAction offers Only When Nothing Is Playing. When enabled, the custom action runs only while no music or video is playing; during playback, the same gesture keeps its original function. This is useful for gestures that normally control tracks or playback, because it avoids sacrificing the familiar media command all the time.

Choosing Default leaves a gesture entirely unchanged. A cautious setup is to remap just one gesture, verify it while the phone is locked and unlocked, then add more mappings one at a time.

Compatibility: what the iOS range does and does not mean

Havoc declares iOS 14.0 through 26.0.1, rootless support and a jailbreak requirement. The description additionally says both rootless and rootful environments are supported. Those claims describe the package’s intended runtime range. They do not establish that every iPhone or iPad on those versions has a public jailbreak.

Before buying, confirm that the specific device and firmware can run a compatible jailbreak and that Havoc offers the correct package architecture inside the package manager. Users of RootHide or another environment with architecture conversion should not infer compatibility from the rootless badge alone.

Installation and safe testing

  1. Add or refresh the official Havoc repository in Sileo or Zebra.
  2. Open PodAction and confirm that the transaction shows version 1.0.1, package ID com.aronsz26.podaction, and the expected $1.99 price.
  3. Install only from the official listing; no mirrored package is linked here.
  4. Open Settings → PodAction, enable the tweak and assign one non-critical gesture.
  5. Disconnect and reconnect the AirPods, then test the gesture with media stopped and playing.
  6. If behavior is wrong, return that gesture to Default before trying another action.

For a package-manager walkthrough, use the Sileo tweak-installation guide. If the device enters a crash loop after any tweak install, follow the Dopamine bad-tweak recovery guide.

Who should consider version 1.0.1?

The update is most relevant to users pairing newer AirPods with an older jailbroken iOS release, or anyone whose AirPods were not consistently detected immediately after connecting. The tweak itself is useful when a hardware gesture would be more valuable as a flashlight, camera, Focus or Shortcut trigger than its default function.

It is less compelling if every AirPods gesture already has an essential media function, or if the device is not on a supported jailbreak. The package is new and the changelog only documents the two fixes above, so broader stability or battery-life claims would be premature.

Frequently asked questions

What did PodAction 1.0.1 fix?

It fixed single-press actions on AirPods newer than the installed iOS version and improved recognition after the AirPods connect.

Can PodAction run any Shortcut?

The developer lists “Any Shortcut” as an assignable action. Individual shortcuts may still be limited by lock-screen permissions, authentication requirements or the apps they call.

Does PodAction support AirPods Pro 3?

The 1.0.1 changelog explicitly uses AirPods Pro 3 on iOS 16 as its example for the Press Once fix. Other available gestures still depend on the AirPods family and hardware.

Does PodAction work without a jailbreak?

No. Havoc marks a jailbreak as required. Package support through iOS 26.0.1 does not imply a jailbreak is available for every device on that firmware.
