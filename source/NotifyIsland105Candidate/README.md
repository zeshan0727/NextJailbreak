# Notify Island 1.0.5 candidate — NOT a release

Target: iPhone 14 Pro Max, iOS 16.0, RootHide. Existing category identifier: com.nextsolution.nextaura.notification-island. The current 1.0.4 package is a 1,384-byte category wrapper; runtime package is com.nextsolution.nextaura.runtime.island 1.0.0; settings runtime is shared with other categories. Archived engine source was recovered from 615613b853d52c46be185959a96e46e225e9a65d, not verified as an exact source match to the 1.0.0 runtime binary. Do not replace the installed version until the binary baseline, private API behavior and packaging are verified.

The candidate adds guarded authentication-based privacy, transient-banner-only suppression with reversible per-view state, fresh-arrival filtering for shared list cells, safe-area window layout, main-thread presentation, bounded in-memory delivery deduplication, local-only content, preferences cache and separate native Settings pages with existing domain/keys. Unknown authentication state fails closed; unsupported banner hierarchy fails open. The UI mock is not a device screenshot.

Build in sequence: compile-fix.py; layout-date.py; prepare-v450.py; prepare-v105.py; Theos RootHide make. The Settings bundle is separate; build with Theos under prefs/. CI compiles candidate binaries only, not an installable or published package. The current modular runtime and category package control files must be inspected before packaging; do not overwrite shared Aura preferences or deploy a duplicate dylib.

Acceptance tests on iOS 16.0 RootHide: (1) locked with Face ID not recognized, then authenticated while remaining on Cover Sheet; relock with card visible; verify no preview flash; (2) iOS preview policy Never; (3) app/lock screen notifications appear immediately in native list, one island and no extra top banner, swipe/scroll/reopen list without replay; (4) portrait to landscape and back during compact/expanded presentation and when island disabled in landscape; (5) burst notifications and repeated request callbacks; (6) preference disable mid-banner restores stock; (7) dismiss/open/timeout must not clear or hide list; (8) real notifications during test preview, low memory, respring, native media/live activities, gesture and touch pass-through; (9) settings navigation and persistence, no impact to other modular tweaks. The old-source candidate does not establish successful on-device delivery or privacy validation. Do not publish to NS Transfer before tests and correct package assembly.

## Test 2 packaging
The original 1.0.4 wrapper and runtime DEBs are checked against their known hashes. The isolated replacement retains the original loader entry path, preference domain and package ID, bundles its own Settings controller, and conflicts with/replaces the old island-only runtime. It does not replace the shared Aura preferences package. After successful build and static package verification, CI publishes an explicitly marked on-device test to NS Transfer. The exact runtime source match, Face ID behavior, iOS per-app preview policy and live notification list behavior are not established until device testing; do not treat it as stable. Rollback requires removing 1.0.5 and reinstalling the original 1.0.4 category with runtime dependency via Sileo.

## 1.0.6 Visual Studio
Based on the 1.0.5 Test 2 engine that the device owner confirmed works. Adds a native table-header Studio with a local interactive preview, four style swatches, a full-range normalized placement slider and top/middle/bottom shortcuts, timing slider, animation toggle, and real test notification. Old vertical preferences are honored until new placement is chosen. The animation uses an approximate portrait aperture origin for iPhone 14 Pro Max; in landscape/reduced motion it fades instead. Generation checks prevent an old animation completion from removing a new card; rotation cancels obsolete animations. The shared notification list, privacy and stock banner hooks are unchanged. Static checks do not establish animation appearance or Preferences layout on the device; verify before stable release. Rollback to 1.0.5 Test 2 if needed.
