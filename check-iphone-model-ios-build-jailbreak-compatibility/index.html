How to Check Your iPhone Model and iOS Build Before Jailbreaking

Before downloading a jailbreak, record four things: the exact model, chip family, iOS or iPadOS version, and build identifier. A matching package version or broad “iOS 17 support” label is not enough to prove that your device has a usable jailbreak path.

By Zeeshan Barvi · Published November 15, 2026 · Source-checked against Apple Support, Dopamine 3.0.13, palera1n 3.0.0 beta 3 and TrollStore 2.1.1

Quick answer: open Settings → General → About. Write down iOS Version, Model Name and the hardware model number. Keep the serial number, IMEI, EID and Apple Account private. Then compare the model or chip and the exact version/build with the current official project—not with a tweak package listing.

Step 1: record the software version without exposing private data

Apple’s current support instructions use Settings → General → About and the iOS Version or iPadOS Version field. If the device cannot open Settings, Apple also documents checking the connected device in Finder on a current Mac, Apple Devices on Windows, or iTunes on older systems.

Take a note rather than sharing a full unredacted screenshot. A compatibility check normally needs the version and build—not the serial number, IMEI, EID, Wi-Fi address or carrier identifiers shown on the same page.

The build becomes essential when a project names one exact release candidate or beta. For example, TrollStore’s official README supports iOS 16.7 RC build 20H18, but not the general 16.7.x releases. Likewise, Dopamine 3.0.13’s tagged Momentarius manifest includes A12/A13 build exceptions 23B5044l, 23B5059e and 23B5064e—the first three iOS 26.1 betas—while its normal A12/A13 range ends at iOS 26.0.1. “iOS 26.1” alone does not identify which case you have.

Step 2: identify the model—not only the marketing family

Apple says the About screen shows Model Name and initially displays the part number beside Model Number. Tap that part number to reveal the hardware model number. This is useful when a product name covers several generations or regional variants.

For jailbreak selection, the chip family is often the decisive field. The official palera1n device selector maps each listed iPhone to its SoC. Common checkpoints include:

Do not guess a chip from the iOS version. Two iPhones running the same firmware can have completely different exploit and installation options.

Step 4: identify the environment after installation

If the device is already modified, also record the active environment: conventional rootless Dopamine, Dopamine RootHide, RootHide Bootstrap, palera1n rootless, TrollStore or TrollStore Lite. These names are not interchangeable. A rebooted semi-untethered phone can still show Sileo while tweak injection is inactive.

Use the rootful vs rootless vs RootHide guide to identify the filesystem lane, then use the tweak compatibility checklist before installing packages. A package declaring iOS 16 support does not create a jailbreak for every iPhone on iOS 16.

A practical decision sequence

  1. Write down the exact version and build. Do not round 17.0.1 down to 17.0 or treat an RC as the public release.
  2. Confirm Model Name and hardware model number. Keep personal identifiers redacted.
  3. Map the model to its chip. Use the selected jailbreak’s official device documentation.
  4. Open the latest official release and tagged documentation. Dopamine 3.0.13, palera1n 3.0.0 beta 3 and TrollStore 2.1.1 are the current versions checked for this guide.
  5. Match every condition. A supported firmware with an unsupported chip is unsupported; so is a supported chip on an unlisted build.
  6. Choose the installation path only after compatibility is established. Continue with the Dopamine 3 download guide, palera1n guide or TrollStore method guide.

Common wrong conclusions

  • “The screenshot shows iOS 27, so iOS 27 is jailbroken.” No. It is an Apple Support identification screenshot. Check the current iOS 27 status hub for the actual public boundary.
  • “The tweak supports iOS 18, so my iPhone supports a jailbreak.” Package compatibility and jailbreak availability are separate checks.
  • “TrollStore works, so I have rootless tweak injection.” TrollStore permanently installs eligible IPA files on supported firmware; it is not a conventional jailbreak.
  • “A12 and A14 are both arm64e, so the same range applies.” Dopamine’s current documentation gives A12/A13 additional ranges that do not automatically extend to A14 or newer hardware.
  • “Every iOS 16.7 build is the same.” TrollStore’s 20H18 exception is exactly why the build identifier must be checked.

Frequently asked questions

Is the iOS version enough to check compatibility?

No. Match the device or chip family, firmware version and any exact build exception.

Does the Apple screenshot prove iOS 27 jailbreak support?

No. It only demonstrates where to find the identification fields.

Why does the model number matter if I know the product name?

It resolves variants and gives you a durable hardware identifier when a project’s device list is more precise than the marketing name.

Should I share the whole About screen for help?

No. Share only the model, version and build needed for troubleshooting. Redact serial, IMEI, EID, Apple Account and network identifiers.
