Horythia 1.1.2 Fixes Hide Jailbreak on iOS 17 and 18

The current Horythia release fixes a failure where tapping an app marked for per-app Hide Jailbreak did nothing on iOS 17 and iOS 18 or later. It also records the most recent hide/restore sequence locally so support can diagnose failures.

By Zeeshan Barvi · Published October 17, 2026 · Updated November 1, 2026 · Verified against the official Havoc product data, version history and ichitaso documentation

Compatibility is not jailbreak availability: Havoc’s iOS range describes the package. It does not mean every device on every listed firmware has a public jailbreak or supports tweak injection.

What 1.1.2 changes

Horythia 1.1.2 was published on October 30, 2026. Its focused fix covers the per-app Hide Jailbreak action: on iOS 17 and iOS 18 or later, tapping a marked app could previously do nothing. The developer says the current build now hides the jailbreak and opens that app as expected.

The release also writes the latest hide/restore sequence to /var/jb/var/mobile/.horythia_hide_last.txt. This is a diagnostic trail, not a promise that every app’s jailbreak detection can be bypassed. The official listing explicitly warns that kernel-level anti-tamper can still detect a jailbreak.

Current compatibility and requirements

Havoc currently lists Horythia 1.1.2 for iOS 14.0–26.0.1, with a $4.99 price and rootless support. The developer documentation additionally describes rootful and separately supplied RootHide builds. Hide Jailbreak itself requires Dopamine; basic per-app automation is not the same feature.

How to troubleshoot a failed hide or restore

  1. Confirm Havoc or your official RootHide source shows Horythia 1.1.2; do not diagnose the iOS 17/18 launch bug on 1.1.0 or 1.1.1.
  2. Make sure the target app is marked for Hide Jailbreak and that Dopamine is the active jailbreak. This action is not supported by palera1n merely because other Horythia features work there.
  3. Before testing, back up the Home Screen layout with IconOrder. Dopamine temporarily unregisters jailbreak apps while hiding, and the developer warns their icons can return in a different order.
  4. Cold-launch the marked app once. If it still does not open, leave the hide state and inspect /var/jb/var/mobile/.horythia_hide_last.txt before contacting support. Review any file contents yourself before sharing them.
  5. Do not treat a successful launch as proof that detection is defeated. Some apps use checks Horythia cannot bypass.

Other changes since 1.0.0

Version 1.1.0 added per-app ad blocking, Dopamine Hide Jailbreak, Clean Jailbreak Traces and per-app language selection. Version 1.1.1 added rootful iOS 14 support and an optional rootful trace-cleaning configuration. The developer says rootful trace cleaning is intended before removing a jailbreak or performing Restore RootFS—not for normal day-to-day use.

The original per-app automation remains: Horythia can change Wi‑Fi, cellular data, Bluetooth, brightness, volume, orientation lock, VPN, focus, power and app-scoped location settings while an app is foregrounded, then restore the prior state. If SpringBoard restarts while a configured app is open, review those settings manually because some may remain changed.

Install or update safely

  1. Use the official Horythia page on Havoc and verify version 1.1.2, seller ichitaso and package ID com.ichitaso.horythia.
  2. Confirm your exact device, firmware and jailbreak environment can load tweak injection. The Sileo installation guide explains how to review the dependency queue.
  3. RootHide users should follow the developer’s official instructions for the separate package and review the RootHide injection guide. Do not substitute the normal Havoc build.
  4. If an injection controller blocks Horythia, review the Choicy per-app guide and allow only what you understand.
  5. Test with one non-critical app first, then confirm the jailbreak restores after leaving it.
