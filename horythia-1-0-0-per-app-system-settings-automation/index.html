Horythia 1.0.0 Automates System Settings Per App on iOS 15–26

Horythia changes selected system settings when a chosen app enters the foreground, then restores the previous state after you leave. The 1.0.0 release covers networking, display, sound, focus, power and app-scoped location controls without requiring a respring.

By Zeeshan Barvi · Published October 17, 2026 · Verified against ichitaso’s official Havoc product data, screenshots and developer documentation

Availability note: Havoc lists package support, not universal jailbreak availability. Confirm that your exact device, iOS build and jailbreak can load tweak injection before buying.

What Horythia does

Horythia 1.0.0 is a per-app automation tweak. You choose an installed app and attach one or more system-setting changes to it. Opening that app applies the configured state; leaving it restores the settings that were active before launch.

Examples from the developer include raising brightness and volume for a video app, disabling orientation lock for playback, turning on Do Not Disturb inside a work app, or disabling selected radios for an app that does not need them. The developer says changes apply immediately and do not require a respring.

Quick access, backup and conflict prevention

A Home Screen icon long-press can open Horythia’s configuration for that app. The main settings page supports export and import, resets for one app or the entire configuration, and a searchable list that keeps configured apps at the top.

Horythia also locks mutually exclusive choices so options such as “Wi‑Fi on” and “Wi‑Fi off” cannot be enabled together. An optional Control Center toggle is available as a separate add-on and requires CCSupport.

Compatibility and requirements

Havoc lists Horythia 1.0.0 at $4.99 with an iOS 15.0–26.0.1 compatibility range and rootless support. The developer’s description additionally names rootful and RootHide environments, noting that the RootHide package is supplied separately because Havoc does not host it directly.

Location spoofing has narrow scope

Horythia’s spoofing feature changes the location data delivered to the configured app; it does not replace the iPhone’s system-wide location. The developer states that it uses a UIKit filter, that advanced detection or server-side verification may still reveal the real location, and that other location-modification tools can interfere.

Apps and games may prohibit altered location data in their terms. Use the feature only where permitted; the tweak is not presented as a way to defeat server-side checks.

Important recovery notes

  • If SpringBoard restarts while a configured app is open, some changed settings may remain active instead of being restored. Review Wi‑Fi, cellular, DND, brightness, volume and other affected toggles after a crash or respring.
  • The target app must accept tweak injection. If Choicy or another injection controller blocks Horythia, its per-app rules cannot run.
  • Export a working configuration before making broad changes. Horythia offers both per-app and global reset options.
  • The support-email action drafts device details, including the model, iOS version, UDID and installed package list. Review and edit that draft before sending it.

Installing Horythia safely

  1. Open the official Horythia page on Havoc and confirm version 1.0.0, seller ichitaso and package ID com.ichitaso.horythia.
  2. Verify your device, firmware and jailbreak environment. RootHide users should obtain the separate build only through the developer’s official instructions.
  3. Review Sileo’s dependency queue for MobileSubstrate or ElleKit and PreferenceLoader before confirming. The safe Sileo installation guide explains the checks.
  4. Start with one low-risk app and one reversible setting. Confirm that the prior state returns after leaving the app before configuring more controls.
  5. If injection is disabled for the target app, use the Choicy per-app guide carefully or review the RootHide injection guide for that environment.
