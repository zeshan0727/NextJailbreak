NextAlarmSX 2.0.0 Adds iOS 17 and iOS 18 Support

NextAlarmSX brings the next scheduled alarm into view without opening the Clock app. The 2.0.0 release expands the official compatibility claim to iOS 17 and iOS 18, but it remains an extension for SleeperX rather than a standalone alarm tweak.

By Zeeshan BarviPublished October 20, 20265 min read
Release snapshot: Havoc lists NextAlarmSX 2.0.0 at $1.99, released October 20, 2026, for iOS 15.0–18.7.9 on a compatible rootless jailbreak. The official changelog for 2.0.0 is concise: iOS 17 and iOS 18 compatibility.

What changed in NextAlarmSX 2.0.0

The confirmed change is platform support. Version 2.0.0 updates NextAlarmSX for iOS 17 and iOS 18, extending the live Havoc listing beyond the iOS 15 and iOS 16 generations covered by the original release. The developer does not publish a longer 2.0.0 fix list on the product page, so readers should not assume undocumented redesigns, new gestures or reliability fixes.

This is still a meaningful major update. Alarm and Lock Screen tweaks interact with system interfaces that Apple regularly changes, so an explicit compatibility update matters more than a broad package-manager range copied from an older build. The live listing now states iOS 15.0 through 18.7.9 and rootless support.

What NextAlarmSX does

NextAlarmSX exposes the next alarm in two places. On the Lock Screen, it adds a line below the date and time with the alarm time, label and remaining interval. Inside Apple’s Clock app, it can show a countdown beneath individual alarms so the user can see how long remains without doing the calculation.

The tweak is designed around SleeperX. Its alarm information and skip behavior extend SleeperX rather than replacing it, which means NextAlarmSX should be evaluated as an add-on. If SleeperX is not part of the intended setup, NextAlarmSX is not the right purchase.

Compatibility: the package range is not a jailbreak matrix

Havoc marks NextAlarmSX as rootless and lists iOS 15.0–18.7.9. That describes where the package is intended to run; it does not prove that every iPhone and every firmware in that span has a public jailbreak. The actual usable set is the intersection of the listed package range, a jailbreak available for the device and firmware, compatible tweak injection, and a supported SleeperX installation.

In particular, an iOS 18 compatibility label should not be read as a universal iOS 18 jailbreak announcement. Confirm the exact device, firmware and jailbreak first. The listing does not advertise rootful or RootHide support, so those environments should not be inferred.

Check the dependency plan before buying

The current product description identifies NextAlarmSX as exclusively an extension for SleeperX. Package managers normally resolve declared dependencies at install time, but the public page does not expose a current minimum SleeperX version in its visible 2.0.0 details. Review Sileo or Zebra’s queue and the live package metadata instead of relying on dependency numbers from the original 1.0.0 release.

  1. Refresh Havoc in Sileo or Zebra.
  2. Confirm the package is NextAlarmSX 2.0.0 with identifier com.joshuaseltzer.nextalarmsx.
  3. Verify the device is already using a compatible rootless jailbreak within the official iOS 15.0–18.7.9 range.
  4. Open the dependency queue and confirm the current SleeperX requirement can be satisfied without removing core bootstrap packages.
  5. Install and respring, then test the Lock Screen display and the Clock app countdown before relying on skip actions.

The safe Sileo installation guide explains queue review and recovery. If a dependency update should be held temporarily, use the Sileo ignore-update guide and document the reason so the hold is not forgotten.

Who should update

Existing users moving to a supported jailbreak on iOS 17 or iOS 18 are the clearest audience for 2.0.0. Users already satisfied on iOS 15 or iOS 16 still benefit from staying on the current release, but the public changelog does not identify a separate bug fix that makes the upgrade urgent for those versions.

New buyers should choose it only if the SleeperX-centered workflow fits: glanceable next-alarm details, countdowns in Clock and access to SleeperX skip integration. Anyone seeking a standalone alarm replacement should look elsewhere.

Frequently asked questions

What is new in NextAlarmSX 2.0.0?
