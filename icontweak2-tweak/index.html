IconTweak2: Open a Control Menu by Swiping Home Screen Icons

IconTweak2 turns a swipe on a Home Screen icon into a shortcut menu. It is aimed at users who want quicker app-specific controls without digging through several Settings screens.

Version1.0.2 feed build
Listed supportiOS 15.0–26.0.1
Price$2.99
SourceHavoc

What IconTweak2 actually changes

The official description is concise: swipe icons to show a control menu. The important difference from the old generic illustration is visible in the real screenshots—the tweak places a native-looking action sheet directly over the Home Screen.

Its settings screen is used to control the gesture and menu behavior. Because the available actions can change between builds, the current official listing and the menu on your device are the reliable references.

  • Open a control menu with a swipe on an app icon.
  • Keep app-specific actions close to the icon that they affect.
  • Configure the tweak from a dedicated preference pane.
  • Use a rootless-compatible build on the iOS versions listed by Havoc.

Installation checklist

  1. Check the official Havoc page against your iOS version and jailbreak.
  2. Install only the package provided through the official listing.
  3. Respring if requested, then open the tweak's preferences.
  4. Choose a gesture that will not conflict with another Home Screen tweak.
  5. Test the menu on one non-essential app before using any maintenance action.
