5Row Pro 1.19.0 Adds a Custom Number and Symbol Row to the Stock iPhone Keyboard

The paid tweak keeps Apple’s keyboard services while adding a fifth row that can switch, remap and resize—provided you use an iPhone in portrait orientation.

Published October 8, 2026 · Verified from the official Havoc listing and developer release post

5Row Pro 1.19.0 arrived on Havoc on October 8, 2026 for $2.49. It adds a row of digits above the stock letter keyboard, switches that row to punctuation and symbols with Shift or 123, and lets Pro users remap every position. The developer says the core fifth-row integration was rebuilt for this release and activation now only needs an internet connection once.

Compatibility in one line: Havoc advertises iOS 15.0–26.0.1, rootless support and a separate RootHide build, but the developer’s stated testing is narrower. It is an iPhone-only, portrait-only stock-keyboard tweak; iPad, landscape, handwriting and third-party keyboards are not supported.

What changed in 1.19.0

The official Havoc changelog calls this the initial Havoc release. It says the core was reworked so the fifth row is added to the stock keyboard more accurately and efficiently. The accompanying developer post says the rewrite addresses incorrect characters appearing after switching keyboard planes; in a follow-up, the developer separately notes a native RootHide build for the free 5Row package.

Activation is also steadier: after a successful first activation through the Havoc account used to buy the tweak, 5Row Pro is designed to continue working offline. The developer says an optional encrypted diagnostic log records app, tweak and keyboard build information—not typed content.

Free 5Row versus 5Row Pro

The basic 5Row concept is adding the fixed number and symbol rows. The paid Pro controls are the reason to choose this release: complete key remapping, per-plane row selection, emoji or accented-character assignments, adjustable key height, and control over whether the 123 plane keeps five rows. Users who only want a fixed number row should review the developer’s free 5Row repository before purchasing Pro.

Compatibility: advertised range versus tested setups

Havoc lists the package for iOS 15.0 through 26.0.1, marks it rootless, and says both rootless and RootHide builds are included. The developer specifically reports testing on iOS 15.0.2 with RootHide and iOS 17.2.1 with Dopamine rootless; user reports cited by the developer cover iOS 15.4, 16.4–16.7 and 17.0.

Do not read the package range as a jailbreak chart. 5Row Pro requires an already compatible jailbreak on your exact iPhone and firmware. A package declaring iOS 26.0.1 support does not create a jailbreak for every device running that version. See our rootless, rootful and RootHide explainer before choosing a build.

The hard interface limits matter just as much: only the portrait stock keyboard on iPhone is supported. The tweak does not cover iPad layouts, landscape keyboards, handwriting input or third-party keyboards such as Gboard and SwiftKey.

How to install and activate 5Row Pro

  1. Open the official 5Row Pro Havoc page and confirm that it shows version 1.19.0.
  2. Sign in to the same Havoc account in Sileo or Zebra, then purchase and install the package.
  3. Select the build that matches the active rootless or RootHide environment; do not substitute one build for the other.
  4. Open 5Row Pro’s Settings pane, activate it once while online, and respring.
  5. Test the stock keyboard in portrait mode before remapping keys or changing the keyboard height.

If the fifth row does not appear, first check that the app is not excluded, the stock keyboard is selected, the phone is in portrait orientation and the correct environment build was installed. Our Sileo source troubleshooting guide covers repository refresh and package visibility problems.
