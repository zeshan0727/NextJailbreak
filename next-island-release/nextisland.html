Next Island

The original NextAura Dynamic Island notification experience, now available as its own independent tweak.

FREEVERSION 1.0.0ROOTHIDE · iOS 16

Island-first notifications

Connected cardsNotifications emerge beneath the Dynamic Island using the proven original runtime.
Location controlChoose Lock Screen, Home Screen and inside-app presentation independently.
Stock-banner controlOptionally suppress the standard banner while preserving Notification Center history.
Notification stackingKeep up to three recent alerts available while only the latest alert expands.

Gestures and actions

Double tapOpen the app that produced the notification.
Swipe down or holdExpand the latest alert with its native actions.
Swipe to dismissDismiss upward or sideways without disturbing Notification Center.
Live previewTest and adjust the card directly while editing Settings.

Appearance studio

Four background modesUse stock black, clear, custom hue or app-derived color.
Native blurEnable dark, light or system material and control its strength.
Flexible sizingAdjust compact width, height, expanded width and text scale.
Feedback controlsConfigure display duration, app icon, priority glow and haptics.

Seamless migration

Next Island keeps the original preference keys, so settings previously configured inside NextAura carry over automatically. The Dynamic Island runtime itself is copied without functional modification.
