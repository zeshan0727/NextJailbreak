How to Install TrollStore in 2026: Choose the Right Method for Your iPhone

TrollStore’s install route depends on the exact iOS or iPadOS release and the device’s chip generation. The current installer matrix includes a device-limited TrollRestore path for 15.8.7–15.8.8 on A8/A9–A11 devices. That is a TrollStore installation route—not proof that Dopamine or another jailbreak works on the same firmware.

Before you start: check the exact version

Open Settings → General → About and record the Software Version and build. If the device says iOS 16.7, the build number matters: the official TrollStore README supports only iOS 16.7 RC (20H18), not the later public 16.7.x releases. The project supports iOS 17.0, but says iOS 17.0.1 and newer are unsupported unless another CoreTrust bug is discovered.

The TrollStore 2.1.1 README lists iOS 14.0 beta 2–16.6.1, iOS 16.7 RC (20H18), and iOS 17.0. The current installer matrix linked by that README also lists a device-specific TrollRestore route for iOS/iPadOS 15.8.7–15.8.8 on A8 and A9–A11 devices. Those two point releases are not repeated in the README’s short version summary, so treat this as a method-specific matrix entry and verify the exact device column before proceeding. It does not establish jailbreak availability.

How to choose the correct installer

The installation guide linked from the TrollStore README contains a live matrix with three device columns: A8, A9–A11, and arm64e devices covering A12–A17 plus M1–M2. Match both your exact operating-system row and your device column. Do not choose an installer solely because its name is familiar.

  • TrollHelperOTA is assigned to many earlier supported combinations, including broad portions of iOS 14 and early iOS 15.
  • TrollInstallerX covers many A9–A11 and arm64e combinations, but not every row. It is not the 15.8.7 route: the Dopamine maintainer’s issue tracker records that KFD puaf_landa was patched on 15.8.7, so Dopamine and TrollInstallerX no longer work on that build.
  • TrollInstallerMDC appears for specific A8 version bands where the matrix assigns it.
  • TrollMisaka is listed for the narrow A8(X) iPad path on iOS 15.7.2–15.8.6. The current method guide calls it extremely unreliable; treat it as a last resort rather than the default.
  • TrollRestore is the current matrix route for iOS/iPadOS 15.8.7–15.8.8 on A8 and A9–A11, as well as the exact 16.7 RC build and selected iOS 17.0 combinations. It requires a computer and a modified-backup restore.
Important distinction: TrollRestore can install TrollStore through a different path; it does not jailbreak the device. In particular, the Dopamine issue tracker says iOS/iPadOS 15.8.7 patched puaf_landa and that Dopamine and TrollInstallerX no longer work on 15.8.7. Do not infer a jailbreak from a TrollStore installer entry.

Because one installer does not cover every supported device, use the current installation-method table, then open the linked method-specific instructions from that table. The table is a living device/firmware chooser; the TrollStore README remains the source for the project’s CoreTrust compatibility statement.

Find your device generation

If you do not know whether the device is A8, A9–A11 or arm64e, identify the exact iPhone or iPad model in Settings and verify its chip on Apple’s technical specifications page. Our iPhone model and iOS build guide explains how to record the exact identifiers. The method table groups devices by chip, not by marketing age. An iOS version alone is not enough to select an installer.

  1. Record the device model, chip and exact iOS/iPadOS version.
  2. For iOS 16.7, tap the version to reveal the build and look specifically for 20H18.
  3. For 15.8.7–15.8.8, confirm that your device is in the A8 or A9–A11 column; the current matrix marks the A12–A17/M1–M2 column Not Applicable.
  4. Use the matching row and device column in the current TrollStore guide.
  5. Download only from the project or installer page linked by that guide.

What to prepare for TrollRestore

For the 15.8.7–15.8.8 matrix entry, TrollRestore is a computer-assisted installer. The current method guide requires Python 3, iTunes on Windows, and the matching TrollRestore build for Windows, Apple silicon macOS, Intel macOS or Linux. Because it restores a modified backup, disable Find My before starting; it can be re-enabled after the installation. When prompted, choose a system app to host the helper (the guide suggests Tips). After the device reboots, open that app and tap Install TrollStore, then install a persistence helper from TrollStore Settings.

Recovery caveat: TrollRestore’s README says the chosen system app’s main binary is replaced; restoring the original app requires deleting it and reinstalling it from the App Store. The Intel macOS build is not notarized. These are installer constraints, not evidence of a jailbreak or tweak-injection support.

Install the persistence helper

TrollStore uses a CoreTrust issue to install system-style apps, but an icon-cache reload can make TrollStore and its installed apps stop launching. The official README explains that a persistence helper can re-register them so they launch again. After the initial installation, follow TrollStore’s Settings option to install the persistence helper into an eligible system app when the chosen method instructs you to do so.

On jailbroken iOS 14 installations that use TrollHelper, the helper lives in /Applications and serves as the persistence helper. That detail is specific to the documented jailbroken iOS 14 flow and should not be generalized to other versions.

Update TrollStore after installation

The latest official GitHub release checked on November 24, 2026 remains TrollStore 2.1.1, published on April 1, 2026. Its release note fixes a TrollStore Lite entitlement typo that could prevent installed apps from working as expected under Dopamine. This does not expand the normal TrollStore compatibility range.

When an update is available, TrollStore displays an update button in Settings. The official README also documents a fallback: download TrollStore.tar from the official GitHub release and open it in TrollStore. Do not replace that file with a third-party mirror.

What TrollStore can—and cannot—do

TrollStore permanently signs and installs IPAs using a CoreTrust validation bug. It is not a jailbreak. The project also lists important limits: TrollStore does not provide proper platformization, cannot spawn a launch daemon, and cannot inject a tweak into a system process. For a full rootless jailbreak, use a separately compatible jailbreak and verify its device/firmware requirements.

If your goal is to compare permanent IPA installation with a rootless jailbreak, read Dopamine 3 vs TrollStore. For jailbreak compatibility, use the Dopamine 3 compatibility hub; TrollStore support never proves Dopamine support for the same device.

Frequently asked questions

Is TrollStore a jailbreak?

No. It is a permasigned jailed app for installing IPAs. Its official README separately lists capabilities that require a jailbreak and are not provided by TrollStore.

Can I use TrollStore on iOS 15.8.7 or 15.8.8?

The current iOS CFW Guide method matrix lists TrollRestore for A8 and A9–A11 devices on iOS/iPadOS 15.8.7–15.8.8; the A12–A17/M1–M2 column is Not Applicable. The short TrollStore README version list does not name those point releases, so confirm the exact device row in the live matrix before starting.

Can I jailbreak iOS 15.8.7 with Dopamine?

No. The Dopamine maintainer’s issue tracker records that iOS/iPadOS 15.8.7 patched KFD puaf_landa and that Dopamine and TrollInstallerX no longer work on that build. TrollRestore installs TrollStore through a different method; it does not provide a jailbreak.

Can I install TrollStore on iOS 17.0.1 or newer?

No under the currently documented CoreTrust bugs. The official project says iOS 17.0.1 and newer will not be supported unless another CoreTrust bug is discovered.

Does iOS 16.7 work?

Only iOS 16.7 RC with build 20H18 is supported. Other 16.7.x versions are excluded by the official project.

Why are there several TrollStore installers?

Different device generations and iOS versions expose different installation paths. Use the current method matrix rather than assuming one installer works everywhere.

What is the latest TrollStore version?

The latest official GitHub release checked on November 24, 2026 remains TrollStore 2.1.1, published April 1, 2026. Its release note fixes a TrollStore Lite entitlement typo affecting apps under Dopamine.

Important: Confirm the exact device, chip, firmware version and build before starting. The 15.8.7–15.8.8 TrollRestore entry is limited to the device columns named by the live matrix. A package’s iOS compatibility or a TrollStore installation route does not prove jailbreak availability.
