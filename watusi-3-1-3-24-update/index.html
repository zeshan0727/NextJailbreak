Watusi 3 v1.3.24 updates WhatsApp 26.36.74 support with refreshed install packages

Fouad Raheb has published Watusi 3 version 1.3.24 for WhatsApp on iOS. The accompanying project documentation updates the supported WhatsApp build from 26.35.74 to 26.36.74 and refreshes the available IPA packages for standard WhatsApp, WhatsApp Business and duplicate installations. The official Watusi page lists iOS 15.1 and newer as compatible. The published materials do not describe a new feature list or a detailed behavioral changelog for this release, so the clearest change is the application compatibility update and the refreshed distribution files.

Key points

  • Watusi 3 is listed at version 1.3.24, updated September 14, 2026.
  • The associated WhatsApp and WhatsApp Business packages now target version 26.36.74 rather than 26.35.74.
  • The official Watusi page lists compatibility with iOS 15.1 and newer.
  • Packages are documented for jailbroken devices, ordinary sideloading, linked duplicate installations and TrollStore.
  • The source material does not identify a new Watusi feature or a specific bug fix for version 1.3.24.
  • TrollStore packages require the stated TrollStore or proper signing conditions; the README warns that they can crash otherwise.

What changed in Watusi 3 v1.3.24

The project’s recent update is centered on a version alignment change. Watusi 3 moves from version 1.3.23 to 1.3.24, while the WhatsApp application listed in the sideloading tables moves from 26.35.74 to 26.36.74. The same update is reflected across the standard WhatsApp, WhatsApp Business, duplicate and no-plugin package entries.

The official repository commits describe the change as an update for v1.3.24. The published README revisions replace the previous package references with refreshed files carrying the newer WhatsApp build and Watusi 3 version. This is important for users who maintain modified WhatsApp installations because the tweak package and its host application need to match the release combination documented by the developer.

  • Watusi 3: 1.3.23 → 1.3.24.
  • WhatsApp and WhatsApp Business host build listed by the project: 26.35.74 → 26.36.74.
  • The README’s latest package references were refreshed on September 14 and 15, 2026.
  • No detailed feature-by-feature changelog for 1.3.24 is included in the supplied source material.

Compatibility and supported configurations

The official Watusi product page lists iOS 15.1 and newer as compatible. That is the broad compatibility statement for the current Watusi 3 listing; it should not be interpreted as a promise that every installation method works identically on every device or signing setup.

The README separates packages by installation method. Jailbroken users are directed to install Watusi through the developer’s package source. Users without a jailbreak are given sideloading packages with the Plugins folder removed and fixes intended to avoid crashes when the app is not signed with the required entitlements or a developer account.

The project also documents TrollStore-specific packages. Those files retain their original entitlements but are described as fake-signed for the TrollStore use case. The README explicitly warns that these packages can crash when used outside TrollStore or without a properly signed certificate and the required entitlements.

  • Official Watusi listing: iOS 15.1+.
  • Jailbroken installation uses the developer’s package repository through a compatible package manager.
  • Sideloading packages are prepared differently from TrollStore packages.
  • TrollStore packages are intended for the device and operating-system ranges supported by TrollStore, as stated in the README.
  • The source does not provide a complete device-by-device compatibility matrix for Watusi itself.

Available WhatsApp variants

The refreshed package tables cover more than the standard WhatsApp application. Users can choose the normal WhatsApp bundle, WhatsApp Business, or duplicate variants with separate bundle identifiers. The duplicate option is relevant to the linked-device workflow documented by the developer, where the App Store copy remains available while the modified duplicate is used for Watusi features.

The project also lists no-plugin TrollStore packages for WhatsApp and WhatsApp Business. These are presented as an option when users encounter notification problems related to injecting into WhatsApp extensions. The README does not claim that every notification issue will be resolved, but it identifies the no-plugin builds as an alternative to try in that situation.

Several optional tweaks, including Stalky, OnlineNotify and ContactSync, are disabled by default and can be enabled inside Watusi Settings. That default state applies to the documented packages and is separate from the core Watusi feature set.

  • Standard WhatsApp package.
  • WhatsApp Business package.
  • Duplicate WhatsApp and WhatsApp Business packages.
  • TrollStore no-plugin packages for standard WhatsApp and WhatsApp Business.
  • Stalky, OnlineNotify and ContactSync are disabled by default.

What Watusi adds to WhatsApp

The official product page continues to describe Watusi as an all-in-one WhatsApp tweak with controls across privacy, protection, status, chats, media, notifications, themes and the user interface. Listed controls include hiding read, typing, recording and delivery indicators; protecting the app or individual chats; downloading statuses; changing chat-list behavior; customizing media actions; and modifying interface elements.

The page also lists larger modules such as message scheduling, advanced auto-reply, hidden chats, contact spoofing, custom notification tones and sticker-pack management. These are capabilities listed for Watusi as a product, not newly announced features of version 1.3.24. The available release material does not establish that any of them was added or changed in this update.

Configuration is performed from inside WhatsApp Settings. The package page lists English, Arabic, German, Spanish, French, Italian, Portuguese and Turkish as supported languages, and it notes that a Control Center option requires the CCSupport package.

  • Privacy controls for indicators, last seen and internet access.
  • Chat, status, media and interface customization.
  • Message scheduling and auto-reply tools.
  • Hidden chats, themes, custom tones and sticker management.
  • In-app configuration rather than a separate configuration application.

Installation considerations before updating

The developer’s documentation distinguishes between installation paths, and choosing the wrong package can cause avoidable problems. For ordinary sideloading, the README requires a computer, an internet connection and an Apple ID when using AltStore. On iOS 16, Developer Mode may be required. The instructions also say that another WhatsApp with the same bundle identifier should not already be installed when adding the selected IPA.

A non-developer signing account is described as having a seven-day expiration, while AltStore can automate re-signing when it remains connected to the computer. The README separately describes signing-certificate distribution as a way to keep an installation valid for one year, but readers should verify the signing provider, certificate status and terms independently before relying on that route.

Push notifications and iCloud features are not generally available to sideloaded installations according to the FAQ, with the README identifying supported TrollStore setups as an exception. The linked-device method is documented as a workaround: the original App Store WhatsApp remains installed, while a duplicate Watusi app is linked to it. The instructions require enabling local notifications temporarily during linking and disabling that option afterward because leaving it enabled is known to cause a logout.

  • Choose a package that matches the intended bundle identifier and installation method.
  • Back up important chats before replacing an existing WhatsApp installation.
  • Check signing duration, entitlements and notification expectations before installing.
  • Do not use TrollStore-specific files in an unsupported signing environment.
  • For linked duplicates, follow the developer’s sequence and disable local notifications after linking.

Chat backup limitations

The README states that iCloud chat backups cannot be restored directly to sideloaded Watusi. It instead documents a manual Files-based backup and restore process. The installed application must expose the Document Browser feature, which the README says is enabled by default in Watusi IPAs.

The documented process involves copying the WhatsApp folder contents to a separate backup folder, deleting and reinstalling the application, then copying the saved contents back before completing registration. This is a procedure to review carefully rather than an assurance that every backup will restore successfully. Users using a duplicate as a linked device do not need this method for synchronization because the README says chats are synced from the main WhatsApp installation.

  • Direct iCloud restoration is not supported for sideloaded Watusi according to the README.
  • Manual Files backup and restore is documented as the alternative.
  • Linked-device duplicates use synchronization from the main WhatsApp installation.
