vphone-cli 2.9.5 Adds Apple TV Guests and tvOS 27 Research Support

The newest vphone-cli release expands the Apple Silicon research platform beyond iPhone and iPad guests: version 2.9.5 can create an Apple TV HD guest, adds an experimental Apple TV 4K path for tvOS 26.6 and 27.0, fixes Unity rendering, and improves failed first-boot recovery.

What changed in vphone-cli 2.9.5

Lakr Aream published vphone-cli 2.9.5 on October 16, 2026 at 06:29 UTC. It replaces the 2.9.2 release previously covered on this page. The release combines Apple TV guest work, a graphics correction, external-volume handling and a recovery path for stalled virtual-device setup.

The important boundary has not changed: vphone-cli runs virtual Apple devices through Apple’s Virtualization framework and PCC research VM infrastructure on a Mac. It is not a physical-device exploit, an Apple TV jailbreak, or proof that tvOS 27 can be jailbroken on retail hardware.

Apple TV HD becomes a first-class guest

Version 2.9.5 adds an Apple TV HD (AppleTV5,3) guest using the new tvos preset. The official firmware catalog pairs tvOS 26.6 build 23L773 with cloudOS 26.4. Launchpad’s New Machine sheet now exposes Apple TV devices, while the command-line path can create one with vm create --device AppleTV5,3.

The preset deliberately omits iOS-specific payloads that have no tvOS port and disables templates and slimming. The guest runs a tvOS-targeted vphoned-tvos helper, allowing Home and Control Center input. Arrow keys and Return navigate; Escape goes back; holding the title-bar Home button or the Mac Home key sends the TV-button hold used for Control Center.

The project reports successful boots to TVSetup, Settings and the home screen at 1080p. That is narrower than full Apple TV compatibility: activation, Apple services, audio, video playback, third-party apps and long-term stability are untested or limited in the developer’s research notes.

Experimental Apple TV 4K and tvOS 27 support

The release also introduces an experimental Apple TV 4K (AppleTV14,1) path behind the tvos-4k preset. Apple does not publish a restore IPSW for this model, so fw prepare --device AppleTV14,1 stages its OTA package. The installer lays the 4K device’s arm64e userland over the Apple TV HD 26.6 base image and retargets the paravirtual GPU driver.

The developer says this prototype boots at 2160p on tvOS 26.6 and tvOS 27.0 build 24J361. However, the display can stop updating after a while. It is research support with a known stability issue, not a production-ready virtual Apple TV.

Unity graphics no longer use the wrong heap offset

On cloudOS 26.4’s paravirtual GPU driver, Unity games could render scrambled meshes when an index buffer began at least 64 KiB into a heap. The new system-paravirt_gpu-cfw-heap_index_offset guest patch makes indexed draws use 64-bit offsets so the driver reads the intended buffer. It is enabled by the standard preset.

Existing 2.9.x machines can receive this guest change without a restore: stop the machine, select Change Core Bundle…, choose 2.9.5 and turn on Update guest environment. Apple TV guests must be created as new machines.

Setup and storage reliability fixes

  • Stalled first boot: if first-boot app expansion stops progressing for 180 seconds, setup records installd and DataMigrator diagnostics, reboots once and waits again instead of consuming the full 600-second deadline.
  • External volumes: when macOS resource keys incorrectly report zero free bytes, custom-firmware installation falls back to statfs rather than failing the 50 GiB space check.
  • OTA catalog data: fw catalog --json now reports an OTA pairing’s build and the cache files it requires.
  • Launchpad cache state: an Apple TV 4K pairing is marked downloaded only when both its OTA and base IPSW are present.

Requirements and compatibility limits

  • Host: a physical Apple Silicon Mac running macOS 15 or later; the project says it does not work inside a macOS VM.
  • Storage: the project still requires substantial room for firmware and virtual disks; the custom-firmware installer enforces a 50 GiB availability check.
  • Network: guest restore needs a connection to obtain signing tickets.
  • Host security: the official setup adjusts research-guest and debugging restrictions from macOS Recovery while leaving SIP enabled.
  • Guest scope: package managers, patched firmware and “jailbreak” capabilities remain inside the research VM.

For physical iPhones, consult the iOS 27 jailbreak status report or the Dopamine versus palera1n comparison. Neither the tvOS guest nor its virtual package environment changes device-side jailbreak availability.

Download and upgrade carefully

The 2.9.5 release includes VPhone-2.9.5.zip and vphone-launchpad-2.9.5.zip. The developer explicitly says the CI-built Launchpad archive is unsigned. The project’s download guide lists 2.9.2 as the newest notarized Launchpad in the 2.9 series.

Launchpad 2.9.x can use any VPhone.bundle 2.9.x and install the latest bundle through Core Bundle. Users who need the new Apple TV choices in the graphical New Machine sheet need Launchpad 2.9.5 and should understand macOS will block an unsigned app on first open. Download only from the official release page.

Bottom line

vphone-cli 2.9.5 is a meaningful research-platform update because it extends the same Apple Silicon virtualization work to tvOS, including an experimental tvOS 27 Apple TV 4K guest. Its Unity fix and setup recovery are practical improvements for existing labs. The project’s own limits are equally important: the Apple TV 4K route is experimental, the release’s Launchpad build is unsigned, and none of this is a jailbreak for a physical iPhone or Apple TV.
