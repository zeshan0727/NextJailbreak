CustomizeCC 1.4.3: Control Center Colors, Borders, and Glow Effects

CustomizeCC 1.4.3 is a Control Center tweak with options described for changing colors, hiding selected visual elements, and enabling borders or glow effects. The package description lists iOS 15 support, while the metadata lists iphoneos-arm and iphoneos-arm64 builds and mobilesubstrate 0.9.5000 or newer as a dependency.

What CustomizeCC changes

  • Changes the color of Control Center glyphs.
  • Changes the color of Modules, Brightness, and Volume controls.
  • Changes the color of Toggles and launchers.
  • Hides the background for the listed Control Center elements.
  • Hides the overlay for all Toggles.
  • Enables borders for Modules, Toggles, and launchers and provides a border color setting.
  • Enables glow effects for Modules, Toggles, and launchers and provides a glow color setting.
