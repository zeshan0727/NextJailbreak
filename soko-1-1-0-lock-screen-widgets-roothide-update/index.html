Soko 1.1.0 Fixes Home Button Layout and Improves RootHide Support

Soko brings the bottom Lock Screen widget position from iOS 26 to jailbroken iOS 16–18 devices. Version 1.1.0 fixes placement on iPhones with a Home Button, supports Liquid (Gl)ass’s large-clock layout, improves rootless and RootHide compatibility, and provides separate rootful, rootless and RootHide packages.

By Zeeshan Barvi · Published October 28, 2026 · Current version, packages, hashes and visuals checked against the developer’s official sources

“iOS 26 style” does not mean iOS 26 support. Soko backports that layout, but the official Havoc range is iOS 16.0–18.7.9. Your device and firmware still need a compatible jailbreak.

What changed in Soko 1.1.0

  • Home Button layout fixes: widgets now sit at the intended iOS 26-style height on iPhone 8, iPhone SE and similar devices.
  • Notification indicator fix: the “Notifications” label is centered below the widgets on Home Button devices.
  • Liquid (Gl)ass compatibility: Soko follows the large clock’s widget position and keeps notifications above the widgets so the clock can resize.
  • New-install default: the current wallpaper’s widgets start at the bottom after a new installation. Updating does not change existing wallpaper layouts.
  • Bootstrap support: the developer says rootless and RootHide compatibility was improved.

How Soko works

Soko does not add a separate Settings pane. Open the Lock Screen editor, customize a wallpaper, then swipe the widget row down to place it near the flashlight and camera buttons. Swipe the row up to restore Apple’s standard position below the clock.

The choice is stored per Lock Screen. One wallpaper can keep the lower layout while another keeps widgets under the clock. The developer also says notifications and Now Playing remain above the lower widget row rather than being covered by it.

Free GitHub build versus the Havoc package

Soko costs $0.99 on Havoc, while the developer provides the same functionality free from the official GitHub release. The project README explicitly says the paid and free versions will always have the same features and no paid-exclusive functionality; buying through Havoc supports development.

Use one official route and avoid repackaged builds. Package-manager users can install from Havoc. Advanced users downloading a Debian package can compare its full SHA-256 with the digest on the official 1.1.0 release, then follow the safe DEB installation guide.

Practical checks if the layout is wrong

  1. Confirm that the installed package reports version 1.1.0, especially on an iPhone with a Home Button.
  2. Confirm that the package architecture matches rootful, conventional rootless or RootHide.
  3. Enter the Lock Screen editor for the affected wallpaper and swipe the widget row down; Soko stores the choice per wallpaper.
  4. If you updated from an older build, remember that 1.1.0 deliberately preserves existing wallpaper positions.
  5. Temporarily compare without another Lock Screen layout tweak if both try to move the same widget or notification views.

Soko’s 1.1.0 notes specifically document compatibility with Liquid (Gl)ass’s large clock. That does not automatically establish compatibility with every other clock, notification or widget-position tweak.

Frequently asked questions

Does Soko 1.1.0 support RootHide?

Yes. The official GitHub release includes a separate iphoneos-arm64e package and says RootHide compatibility was improved.

Does Soko work on iOS 26?

No. It copies the iOS 26 widget position, but Havoc lists iOS 16.0–18.7.9 as the supported range.

How do I move widgets back to the top?

Customize that Lock Screen and swipe the widget row upward. Each wallpaper remembers its own layout.

Is the free GitHub version limited?

No. The developer says the free GitHub and paid Havoc versions have the same features and functionality.

Will updating force every wallpaper to the bottom layout?

No. The new default applies to new installations. Version 1.1.0 preserves existing wallpaper layouts during an update.
