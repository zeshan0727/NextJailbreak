Soko 1.2.0 Brings the Depth Effect to Bottom Lock Screen Widgets

Soko 1.2.0 keeps wallpaper Depth Effect working with bottom Lock Screen widgets, fixes editor, swipe and notification layout issues, and ships separate rootful, rootless and RootHide packages for jailbroken iOS 16–18.7.9.

By Zeeshan Barvi · First published October 28, 2026 · Updated November 22, 2026 · Latest official release checked against the 1.2.0 GitHub tag

“iOS 26 style” is a layout description, not iOS 26 compatibility. Havoc lists Soko for iOS 16.0–18.7.9 and marks a jailbreak as required. A package’s firmware range does not prove that a public jailbreak is available for every device and firmware combination.

What changed in Soko 1.2.0

The headline change is the wallpaper Depth Effect. Stock iOS normally turns that effect off when Lock Screen widgets are added. Soko 1.2.0 keeps the effect available when its widget row is moved to the bottom, so users can keep the lower widget layout without automatically giving up the wallpaper treatment.

  • Depth Effect with bottom widgets: wallpapers that use the effect now keep it on the Lock Screen even when widgets sit at the bottom.
  • iOS 18 editor and Lock Screen: the release notes say the effect works with widgets at either the top or bottom, both while editing and on the Lock Screen itself.
  • iOS 16 editor behavior: the editor can enable the effect while widgets are at the bottom. With Liquid (Gl)ass’s large-clock style, the effect can be enabled at any widget position.
  • Wallpaper switcher previews: previews now retain the Depth Effect when that wallpaper uses bottom-positioned widgets.

Additional fixes in the same release

  • Depth Effect and appearance controls no longer overlap the Lock Screen quick-action buttons when widgets are at the bottom; the controls sit above the widgets.
  • Swiping the widget row between top and bottom no longer intermittently fails on certain wallpapers.
  • Widget outlines in the Lock Screen editor are corrected so they align with, and remain visible around, bottom widgets.
  • On iOS 16, notifications no longer slide down over the widgets after the notification list is scrolled. The developer highlights Home Button devices using Gestures16 as the main affected case.
  • Astronomy wallpaper planets no longer appear in the wrong position when widgets are at the bottom.
  • The Lock Screen editor no longer opens the clock at the wrong size with Liquid (Gl)ass’s large-clock style.

How to move widgets and keep each wallpaper’s layout

Open the Lock Screen editor, choose the wallpaper you want to change, and swipe its widget row down to move it toward the flashlight and camera buttons. Swipe the row up to return it below the clock. Soko stores the position per Lock Screen, so different wallpapers can keep different layouts. The project README says the layout is changed in the Lock Screen editor rather than through a separate Settings pane.

Compatibility and the correct package

Havoc’s package listing gives Soko an iOS 16.0–18.7.9 compatibility range and marks it as jailbreak-required. Soko brings an iOS 26-style arrangement to older Lock Screens; it does not make the tweak compatible with iOS 26. The actual install still depends on a jailbreak for the specific device and firmware. Free GitHub build or the Havoc package?

Soko is listed at $0.99 on Havoc. The developer also publishes the project on GitHub and states in the README that the free GitHub and paid Havoc versions have the same features, with no paid-exclusive functionality. Buying through Havoc is an optional way to support development; it is not a feature unlock.

For a package-manager install, use the official Havoc listing. For a direct Debian download, use only the official 1.2.0 GitHub release. Avoid third-party reuploads and do not convert a package to a different jailbreak layout unless the developer documents that route.

Practical checks if the effect or layout looks wrong

  1. Check the exact version. Confirm that Sileo or Zebra reports 1.2.0 before troubleshooting a fix that is new to this release.
  2. Change the wallpaper you are actually using. The widget position is stored per Lock Screen; changing one wallpaper does not change every other one.
  3. Use the documented iOS behavior. The release notes explicitly describe iOS 18 top/bottom support and iOS 16 editor behavior. They do not spell out a separate iOS 17 Depth Effect rule, so do not assume those details are identical on every iOS 17 setup.
  4. Check package environment. If the package fails to load, verify the rootful, rootless or RootHide build instead of repeatedly reinstalling a mismatched DEB.
  5. Look for overlapping Lock Screen tweaks. If a third-party layout or wallpaper tweak still moves notifications or widgets, temporarily compare with that tweak disabled before reporting a Soko regression.

Frequently asked questions

Does Soko 1.2.0 support iOS 26?

No. “iOS 26 style” describes the widget placement. Havoc lists iOS 16.0–18.7.9 and requires a jailbreak.

How does the Depth Effect work in 1.2.0?

The release notes say iOS 18 supports the effect with widgets at the top or bottom in the editor and on the Lock Screen. On iOS 16, the editor can enable it with bottom widgets, or at any position when Liquid (Gl)ass’s large-clock style is used.

Do the release notes specify the iOS 17 Depth Effect behavior?

They do not describe a separate iOS 17-specific behavior. Do not assume the iOS 16 or iOS 18 details apply identically without checking the exact device and setup.

Which package should I install?

The official 1.2.0 release labels separate builds for rootful iphoneos-arm, conventional rootless iphoneos-arm64 and RootHide iphoneos-arm64e. Match the build to the jailbreak environment you actually run.

Is the GitHub build limited compared with Havoc?

No. The developer’s README says the free GitHub and paid Havoc versions have the same features and no paid-exclusive functionality.
