Airaw 1.7.1 expands CarPlay Host controls and stabilizes Split View

Airaw 1.7.1 is a substantial CarPlay-focused update that improves how users launch and control Host Mode apps, makes the Host Menu easier to operate, and adds more direct interaction with Split View. The release also addresses crashes linked to Split View, repeated Host app launches, and CarPlay disconnection. An Alternative Display Path option has been added for Host Scene display problems. The official product page currently lists Airaw as supporting jailbroken iOS 14 through iOS 26, while the supplied package stanza identifies version 1.5.1 with an iOS 13 minimum. Users should therefore check the version shown by their package manager and review the current requirements before proceeding.

Key points

  • Airaw 1.7.1 adds tap-based launching for Host Mode or Host Scene apps.
  • The Host Menu gains a larger grab area, better swipe responsiveness, outside-tap dismissal, and automatic hiding after five seconds.
  • Split View can now be resized by dragging, with its central menu opened by a long press or double tap.
  • The update fixes several crash and stability problems, including Safe Mode after disconnecting CarPlay during Split View.
  • The official product page lists iOS 14 through iOS 26 support, while the supplied package metadata still describes version 1.5.1 and an iOS 13 minimum; verify the package actually offered to your device.

What is new in Airaw 1.7.1

Airaw is a jailbreak tweak designed to customize CarPlay’s appearance and behavior. Its feature set includes Home screen layout controls, wallpaper changes, status bar customization, widgets, per-app display settings, and support for launching apps through Airaw’s Host features. Version 1.7.1 concentrates less on visual customization and more on interaction, app hosting, and stability.

The most visible change is the ability to launch Host Mode, also described by the developer as Host Scene, apps by tapping. Previously, users may have had to rely on other interaction paths depending on the configuration. The new tap-based launch option should make hosted applications more accessible from the CarPlay interface, although the official documentation still warns that apps not designed for CarPlay can behave differently from native CarPlay apps.

  • Tap to launch Host Mode or Host Scene apps.
  • Host Menu interaction has been refined.
  • Split View now supports direct divider resizing.
  • Several crashes and restart-related problems have been addressed.

Host Menu changes improve everyday control

The Host Menu receives several usability changes in this release. The grabber now has a larger hit area, and swipe responsiveness has been improved. These are small interface changes, but they matter because CarPlay controls are used at a distance and often through a vehicle display rather than directly on the iPhone.

The menu can now close when the user taps outside the panel or in an empty area. It also hides automatically after five seconds. In full-screen mode, the Host Menu bar can be opened with a tap as well as a swipe, and swipe responsiveness has been improved there too. Together, these changes are intended to reduce the amount of gesture precision required when moving between hosted content and CarPlay controls.

  • Larger Host Menu grabber hit area.
  • Improved swipe response.
  • Tap outside the panel to close the menu.
  • Automatic hiding after five seconds.
  • Full-screen Host Menu bar opens by tap or swipe.

Split View gets direct resizing and crash fixes

Airaw 1.7.1 also updates Split View interaction. Users can resize the divider by dragging it. The central Split View menu is opened with a long press or double tap, while a single tap remains reserved for dragging. This distinction is important: it gives the divider a dedicated resize gesture without removing access to its configuration menu.

The release notes also identify multiple Split View fixes. Disconnecting CarPlay while Split View was active could cause the system to enter Safe Mode in Standard and Native modes; that issue is listed as fixed. The update also addresses a crash triggered when closing Split View from the divider menu.

Split View is not part of the base tweak’s general compatibility story by itself. The official product page says the Airaw Split Native and Airaw Split Standard add-ons require Airaw 1.7.0 or later and iOS 16 or later. Anyone using those add-ons should compare the installed Airaw version with those requirements before expecting the new divider behavior.

  • Drag the divider to resize Split View.
  • Use a long press or double tap for the central menu.
  • Single tap remains reserved for dragging.
  • Fixes Safe Mode entry after CarPlay disconnection during Split View.
  • Fixes a crash when closing Split View from the divider menu.

Host Scene stability and display troubleshooting

The update fixes a SpringBoard crash caused by repeatedly opening and closing the Host app. It also changes the Host Scene lifecycle: the Host Scene is now immediately destroyed when the Host app exits. According to the release notes, this addresses problems encountered during later restarts.

For devices experiencing display glitches, Airaw 1.7.1 adds an Alternative Display Path option for Host Scene. The release also clarifies the difference between iPhone scale and CarPlay scale and recommends Host Scene in the relevant descriptions. Those wording changes are useful because hosted content can be rendered using different scaling approaches, and the result may vary from the appearance of a standard CarPlay app.

The developer cautions that apps not designed for CarPlay may fail to launch, show layout problems, or exhibit unexpected touch behavior. DRM-protected videos may also be unavailable. These limitations are especially relevant to users considering Airaw for full-screen or hosted media applications.

  • Fixes a SpringBoard crash from repeatedly opening and closing Host apps.
  • Host Scene is destroyed immediately when the Host app exits.
  • Adds an Alternative Display Path option for display glitches.
  • Clarifies iPhone-scale versus CarPlay-scale behavior.
  • DRM-protected videos may not display.

Compatibility and dependencies to check

The current official Chariz product page lists Airaw as supporting jailbroken iOS 14 through iOS 26 on arm64 and arm64e devices. It lists support for both Rootful and Rootless jailbreak environments and names ElleKit or Substrate, PreferenceLoader, Cephei, and CCSupport among the required packages. The page also states that Hosted Scenes and Split View require iOS 16 or later.

Widget compatibility is more specific. Module widgets are listed as compatible with iOS 14 and later. HTML widgets are listed as compatible with iOS 14 and iOS 15. Although the settings interface can add HTML widgets on iOS 16 and later, the official documentation says they do not currently function correctly on CarPlay there and recommends module widgets instead.

There is an important version discrepancy in the supplied source material. The package stanza identifies Airaw as version 1.5.1, declares a firmware minimum of iOS 13.0, and lists dependencies including mobilesubstrate, PreferenceLoader, Cephei-related components, RocketBootstrap, ColorPicker, and other support libraries. The current product page instead describes the 1.7.1 release and a minimum of iOS 14. Because these records do not describe the same release state, users should rely on the version and dependency information displayed by their authorized package source before updating.

  • Current product-page compatibility: iOS 14 through iOS 26.
  • Hosted Scenes and Split View require iOS 16 or later.
  • Module widgets support iOS 14 and later.
  • HTML widgets are documented for iOS 14 and iOS 15; they are not currently working correctly on CarPlay in iOS 16 and later.
  • Check the actual package version and dependencies because the supplied metadata also lists Airaw 1.5.1 with an iOS 13 minimum.

What to verify before updating

Airaw requires a jailbroken device, and the official page describes it as an unofficial CarPlay extension. Before updating, confirm that the package manager presents version 1.7.1 rather than the older 1.5.1 metadata included in the supplied package record. Also check whether your jailbreak is Rootful or Rootless and whether the required substrate, preference, and support packages are available for that environment.

Users relying on CarBridge or CarCast should check their setup separately. The official documentation says CarCast or CarBridge is required only when adding apps that do not support CarPlay to the Home screen; Airaw itself can customize the Home screen layout, wallpaper, status bar, and widgets without those products. Apps added through those methods may still look or behave differently from native CarPlay software.

Finally, test changes only while parked. The product documentation explicitly warns users not to operate apps while driving and notes that results can vary with the iOS version, jailbreak environment, app, vehicle, and CarPlay display. If reporting a problem, the developer asks for the iOS version, device model, jailbreak tool and mode, Airaw version, whether CarCast or CarBridge is installed, the affected app and Bundle ID when relevant, and reproduction steps.

  • Confirm the package manager shows the intended Airaw version.
  • Check jailbreak mode and required support packages.
  • Review whether CarBridge or CarCast is actually needed for your use case.
  • Expect compatibility differences with non-CarPlay apps, vehicles, and displays.
  • Do not operate apps while driving.

Frequently asked questions

What does Airaw 1.7.1 add?

It adds tap-based launching for Host Mode or Host Scene apps, improves Host Menu gestures and dismissal behavior, adds draggable Split View resizing, and introduces an Alternative Display Path option for devices with Host Scene display glitches.

Does Airaw 1.7.1 fix crashes?

The official release notes list fixes for Safe Mode entry after disconnecting CarPlay during Split View, a crash when closing Split View from its divider menu, and a SpringBoard crash caused by repeatedly opening and closing the Host app.

Which iOS versions are supported?

The current official product page lists iOS 14 through iOS 26. Hosted Scenes and Split View require iOS 16 or later. The supplied older package stanza lists version 1.5.1 with an iOS 13 minimum, so users should verify the version-specific compatibility information shown by their package manager.

Can Airaw use HTML widgets on iOS 16 or later?

The official documentation says HTML widgets are compatible with iOS 14 and iOS 15. They can be added through settings on iOS 16 and later, but they currently do not function correctly on CarPlay there. Module widgets are recommended for iOS 16 and later.

Is CarBridge required to use Airaw?

Not for Airaw’s general customization features. The official page says Airaw can independently customize the Home screen layout, wallpaper, status bar, and widgets. CarCast or CarBridge is required only when adding apps that do not support CarPlay to the Home screen.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
