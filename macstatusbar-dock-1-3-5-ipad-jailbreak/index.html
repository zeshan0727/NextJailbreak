MacStatusBar&Dock 1.3.6 Expands Stage Manager to Seven Windows

The free rootless tweak now supports seven Stage Manager windows per desktop, fixes several multi-window failures and records an initial iPadOS 16.0 user confirmation.

By Zeeshan Barvi · Published October 5, 2026 · Updated October 5, 2026 · Version 1.3.6 released October 5, 2026

What changed in version 1.3.6?

MacStatusBar&Dock 1.3.6 raises the Stage Manager engine’s desktop limit from four windows to seven. With Fit to Window enabled, the first four windows remain tiled while later windows open normally over those tiles. Desktop icons also appear with app icons immediately after a respring instead of arriving several seconds later with the windows.

The update fixes several multi-window failures. Closing one Safari window should no longer close the app’s other windows or neighboring apps; minimizing one window should no longer hide another; and switching away from Stage Manager and back without respringing should no longer leave the Home Screen hidden. Force Quit from an app-icon menu now waits for that menu to close before dismissing the selected app window.

These changes build on version 1.3.5, which put Stage Manager windows over the usable Home Screen, kept restored windows on the current desktop and corrected placement, rotation and menu-targeting problems.

A Mac-like layer, not macOS on iPad

The tweak replaces parts of the iPad interface with a Mac-inspired menu bar, magnifying Dock, Finder-like desktop and movable app windows. Earlier 1.3 releases added desktop files and folders, a Wi-Fi menu, a simple text editor and drag-and-drop access to Downloads. It still runs iPadOS apps; this is not macOS, a virtual machine or a way to run Mac software.

Version 1.3.3 also added right-to-left menu-bar layouts for Arabic, Hebrew, Persian and Urdu. That is useful beyond appearance: app menus and status items mirror to match the writing direction.

Compatibility needs careful reading

The developer describes MacStatusBar&Dock as an iPad-only rootless tweak for iPadOS 15 and 16. It does nothing on iPhone. iPadOS 17 and later remain experimental and are disabled by default unless the user chooses “Enable Anyway.” The package declares a minimum firmware of iPadOS 15.0, but that package range does not mean every iPad or every firmware has a usable jailbreak.

The documented developer test devices are an M1 11-inch iPad Pro on iPadOS 15.6.1 with Dopamine and a 9.7-inch iPad Pro on iPadOS 16.7.7 with palera1n. An iPad Pro 10.5-inch on 16.6.1 is listed as a user report. Version 1.3.6 records a user confirmation that basic Stage Manager behavior—opening, resizing and traffic-light controls—works on iPadOS 16.0, and that the Mac menu bar works beside Apple’s own Stage Manager. The project still labels 16.0 Untested until it receives a longer test, so this is useful evidence rather than a blanket support declaration. A reported M2 iPad Pro crash on 16.1 remains documented with the suggestion to use Aerial 5.0 instead.

Dependencies and window engines

The package requires a compatible hooking platform—ElleKit, libhooker or Substrate—plus AltList. The project also calls for Choicy or iCleaner Pro so only one window engine is injected at a time. Optional engines include Aerial 3.0 or 5.0, MilkyWay4 0.1.1 for iPadOS 15, and Zetsu 1.6.2 or 1.6.6. Mixing multiple engines is a likely source of conflicts, so follow the project’s configuration notes before respringing.

Where to get it—and what to verify

MacStatusBar&Dock is free and GPL-3.0 licensed. The developer’s release ledger identifies 1.3.6 with source commit b60c9a75cc5e23081abe018bf70847a0751fd0b0 and publishes SHA-256 9f9bfdc11bfcf3cdf14dab0179b91a74408db71820dcca0cfb3d0b703400747d for the 1,216,294-byte rootless package. Use the official repository rather than a re-upload, and confirm the version and checksum before installing.

If you are deciding between package managers, see our Sileo vs Zebra comparison. For a safer first launch, work through the tweak compatibility checklist and disable other window-management tweaks until you know the base setup is stable.
