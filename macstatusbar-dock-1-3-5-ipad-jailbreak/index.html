MacStatusBar&Dock 1.8.7.5 Fixes Charge Limits, Stage Manager and Crash Recovery

Version 1.8.7.5 is a practical stability update for the iPad-only desktop tweak. It repairs charge controls, Stage Manager window behavior, crash recovery, window-engine edge cases and several update/uninstall problems while improving the Mac Switcher and visual refresh behavior.

By Zeeshan Barvi · Published October 5, 2026 · Updated November 16, 2026 · Current official developer-repository package: 1.8.7.5

This is an iPad-only conventional rootless tweak. The developer says it does nothing on iPhone, publishes no RootHide build and supports iPadOS 15 through 18. A package’s iPadOS range does not create a jailbreak for an unsupported iPad.

Current version: developer repo 1.8.7.5, Havoc 1.8.7.4

The developer’s public changelog and release ledger identify 1.8.7.5 as the latest build, published November 15, 2026 from source commit f40e769c61a2632e904b481541d81260aedfc86f. Havoc’s own page data listed 1.8.7.4 when checked on November 16. The two official channels are therefore one maintenance build apart.

To get 1.8.7.5, add https://besiktasliseba.github.io/repo/ to Sileo or Zebra and verify package identifier com.besiktasliseba.macstatusbaranddock. If using Havoc, check the version shown in your package manager rather than assuming its artifact already includes the 1.8.7.5 fixes.

What 1.8.7.5 changes

  • Charge controls: Run on Power Adapter and Charge Limit should no longer stop working until toggled off and on again.
  • Safer crash recovery: a crash caused by a larger Menu Bar Size now falls back to Small, and disabling one crashing part no longer immediately disables the entire tweak. Settings continues to offer Turn Back On for parts recovery disabled.
  • Stage Manager fixes: closing an app’s last window with the red light now quits it, resize handles remain visible, minimized windows use less memory, restored windows no longer leave blank snapshots, and Home Minimizes Windows also closes an open folder.
  • Other window engines: Zetsu and MilkyWay4 no longer make a second tiled window jump when another becomes full screen. MilkyWay4 also handles desktop window state and Launch As Window more accurately.
  • Visual consistency: light menu-bar background colors switch text and icons to dark, resize-handle tint changes apply immediately, and the Mac Switcher uses the selected Desktop Picture.
  • Maintenance: Activity Monitor now sorts CPU Time correctly, a damaged Choicy setting no longer blocks the background helper, older split-package upgrades are repaired, iCleaner results appear reliably, and uninstall removes the tweak’s diagnostic files.

Why this is more than a small changelog bump

The update addresses three high-impact paths: battery charging controls, SpringBoard crash recovery and Stage Manager window lifecycle. It also follows 1.8.7’s external-display settings and separate Mac Switcher desktops, then folds in the rapid 1.8.7.1–1.8.7.4 fixes for Aerial launch behavior, Dock freezes, landscape swipe-to-quit, background-app cards, keyboard focus and battery-percentage rendering.

If you use Charge Limit, Run on Power Adapter, Stage Manager, Mac Switcher or a Medium/Large menu bar, the current build directly targets documented failures in those paths. If the setup is stable and none apply, there is no need to change window engines or enable extra features merely because an update exists.

Verify the official 1.8.7.5 package

The developer release ledger records the rootless DEB as 2,807,054 bytes with SHA-256 110b601c4bf52c0626d13dd9d91c31447e664d2c94174902bd7812bd31b0a27f. Its source commit is f40e769c61a2632e904b481541d81260aedfc86f.

That digest applies to the DEB in the developer repository. Do not use it to reject a marketplace package unless the developer states that the artifacts are byte-identical. For a local check, run shasum -a 256 file.deb on macOS or sha256sum file.deb on Linux and compare every character.

Safe update order

  1. Save open files in Finder or TextEdit and finish file transfers.
  2. Record the current window engine, Dock position and any charge-control setting. Disable unrelated injected window-management tweaks.
  3. Refresh the developer repository in Sileo or Zebra and confirm version 1.8.7.5 and the exact package identifier.
  4. Install the update and respring once. Do not switch window engines during the first startup.
  5. Test the menu bar, Dock, one window and one charge-control change before restoring a large multi-desktop session.
  6. Re-enable optional window engines and keyboard integrations one at a time.

1.8.7.5 troubleshooting checklist

  • Charge Limit still appears stuck: confirm the installed build is 1.8.7.5, respring once, then change the limit. Do not assume every adapter can pause charging; the developer notes that unsupported adapter/device combinations continue charging normally and Settings should say so.
  • Stage Manager leaves a stale or blank window: close the app, respring and retry with only Stage Manager selected as the window engine. Do not load Aerial, Zetsu or MilkyWay4 beside it.
  • A feature turned itself off: open the tweak’s Settings page. Automatic Crash Recovery should identify what it disabled and provide Turn Back On. If Menu Bar Size caused the crash, 1.8.7.5 resets it to Small.
  • The background helper is missing: verify Choicy or the official iCleaner Pro is installed, then reinstall the tweak. Version 1.8.7.5 specifically repairs a damaged Choicy setting that could block the helper.
  • Havoc still shows 1.8.7.4: that package does not contain the final 1.8.7.5 maintenance fixes. Wait for Havoc to update or use the developer repository.

Recover from Safe Mode

  1. Start the jailbreak with tweak injection disabled or enter its Safe Mode.
  2. Disable MacStatusBar&Dock and all but one window engine through Choicy or iCleaner Pro, or remove the package in Sileo/Zebra.
  3. Respring and verify the stock Home Screen, Dock, Control Center and App Switcher.
  4. Reinstall MacStatusBar&Dock alone. Leave KeyPilot and side-Dock positioning off for the first test.
  5. Add one window engine, then re-enable optional features one at a time.

Do not delete Finder’s Desktop or Trash directories as a generic fix; they can contain user files. For wider recovery steps, see the Dopamine bad-tweak recovery guide and the rootless environment explainer.

Frequently asked questions

What is the current MacStatusBar&Dock version?

Version 1.8.7.5 is current in the developer repository and release ledger as of November 16, 2026. Havoc listed 1.8.7.4 when checked.

Does it work on iPhone?

No. The developer documents it as iPad-only and says it does nothing on iPhone.

Does it support RootHide?

No separate RootHide package is documented. The official project describes a rootless build tested with Dopamine and palera1n.

Does the tweak provide a jailbreak or Stage Manager support?

No. It needs an already-supported rootless jailbreak, and a window engine is optional. Apple Stage Manager still requires supported hardware or a separately supported enablement method.
