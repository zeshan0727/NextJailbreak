MacStatusBar&Dock 1.8.3 Adds Keyboard Window Tiling and KeyPilot Support

Version 1.8.3 brings macOS-style Globe-Control window shortcuts, new-window fill and title-bar actions, a public window API for KeyPilot and refinements for the side Dock introduced in the 1.8.2 line. The developer repository is currently newer than Havoc.

By Zeeshan Barvi · Published October 5, 2026 · Updated November 7, 2026 · Current official developer-repository package: 1.8.3

This is an iPad-only conventional rootless tweak. The developer says it does nothing on iPhone, publishes no RootHide build and supports iPadOS 15 through 18. A package’s iPadOS range does not create a jailbreak for an unsupported iPad.

Current version: official repo 1.8.3, Havoc 1.8.0.1

The project’s public source commit and package release ledger published MacStatusBar&Dock 1.8.3 on November 7, 2026. The official Havoc page still reported 1.8.0.1 when checked the same day. Both are developer-controlled sources, but they are not currently on the same release.

To get 1.8.3, add https://besiktasliseba.github.io/repo/ to Sileo or Zebra and verify package identifier com.besiktasliseba.macstatusbaranddock. If you prefer Havoc, wait until its displayed version catches up rather than assuming its older build contains the 1.8.3 features.

What 1.8.3 adds

  • Keyboard window tiling: an optional Window Tiling Shortcuts switch adds macOS 15-style Globe-Control keys. Examples include Globe-Control-Left for the left half, Globe-Control-F to fill, Globe-Control-C to center and Globe-Control-R to restore.
  • Keyboard remapping: a hardware keyboard without a Globe key can assign another modifier to Globe in iPadOS Modifier Keys.
  • New Windows Open at Fill: new windows can fill the desktop while Fit to Window leaves those windows out of its automatic tiling.
  • Double-tap title-bar actions: choose Fill, Zoom, Minimize or Do Nothing. Fill and Zoom can be reversed with another double tap.
  • KeyPilot integration: the tweak now exposes a public window API that KeyPilot can use for custom shortcuts, app launching and URL actions. KeyPilot is optional and separate.
  • Edit-mode cleanup: Finder, Launchpad, Downloads and Trash now jiggle with other Dock icons and do not open when tapped during Home Screen editing.

The release also fixes Aerial 5 Fit to Window alignment, sideways Handoff/recent icons with a side Dock, Stage Manager layout persistence after rotation, missed hardware volume-key taps and a dark line above the menu bar in full-screen apps.

What changed in the 1.8 series

Version 1.8.0 introduced a Mac-style Control Center, selectable Control Center and banner styles, and consistent Small, Default or Large new-window sizes across the supported engines. The 1.8.1 line extended the Mac Control Center on iPadOS 18 and repaired Lock Screen and menu-bar transitions.

Version 1.8.2 added a Dock position control for the left or right edge in landscape. Windows, Home Screen icons, banners and the Today panel keep clear of it; portrait keeps the Dock at the bottom. The 1.8.2.1 and 1.8.2.2 maintenance builds then fixed Stage Manager placement, Control Center crashes, side-Dock menus, minimized-window recovery and Downloads search on iPadOS 18.

Verify the official 1.8.3 package

The developer release ledger records the rootless DEB as 2,363,024 bytes with SHA-256 243821ff794b0d31dfef65489a61714e7acc8930cf8fcefb46279a1952f776d0. Its source commit is f0bd4ccfc468b437e77dceb7cae8af9d0af3ccfc.

That digest applies to the DEB in the developer repository. Do not use it to reject a marketplace package unless the developer states that the artifacts are byte-identical. For a local check, run shasum -a 256 file.deb on macOS or sha256sum file.deb on Linux and compare every character.

Safe update order

  1. Save open files in Finder or TextEdit and finish file transfers.
  2. Record the current window engine and Dock position. Disable other injected window-management tweaks.
  3. Refresh the developer repository in Sileo or Zebra and confirm version 1.8.3 and the exact package identifier.
  4. Install the update and respring once. Do not switch window engines during the first startup.
  5. Test the menu bar, Dock, one window and one keyboard shortcut before restoring a large multi-desktop session.
  6. Enable New Windows Open at Fill, double-tap actions and KeyPilot only after the base setup remains stable.

Choosing the new keyboard controls

Start with the built-in Window Tiling Shortcuts if you want predictable macOS-style layouts from a hardware keyboard. They operate on the front window and do not require KeyPilot. Use KeyPilot only when you need your own app, URL or window-layout shortcuts; it relies on the new API but remains a separate package with its own compatibility and update cycle.

On a keyboard without Globe, change a modifier in iPadOS Modifier Keys instead of installing an unrelated keyboard-remapping tweak immediately. If Globe-Control volume keys behave unexpectedly, confirm 1.8.3 is active—the release specifically fixes taps being missed.

Side Dock and window-engine troubleshooting

  • Dock menu appears sideways or off-screen: confirm 1.8.3 or at least 1.8.2.2, then respring after selecting left or right.
  • Stage Manager window moves after rotation: update to 1.8.3; its changelog fixes menu-placed windows losing their layout and Fit to Window state.
  • Zetsu window does not return from the Dock: 1.8.2.2 contains the side-Dock recovery fix. Disable other engines before retesting.
  • Mac Control Center crashes SpringBoard: use 1.8.0.1 or later, which fixes the slow-start Safe Mode problem; newer builds add further module-resize fixes.
  • Havoc still shows 1.8.0.1: that is the current marketplace listing, not evidence that 1.8.3 is unavailable from the developer repository.

Recover from Safe Mode

  1. Start the jailbreak with tweak injection disabled or enter its Safe Mode.
  2. Disable MacStatusBar&Dock and all but one window engine through Choicy or iCleaner Pro, or remove the package in Sileo/Zebra.
  3. Respring and verify the stock Home Screen, Dock, Control Center and App Switcher.
  4. Reinstall MacStatusBar&Dock alone. Leave KeyPilot and side-Dock positioning off for the first test.
  5. Add one window engine, then re-enable optional features one at a time.

Do not delete Finder’s Desktop or Trash directories as a generic fix; they can contain user files. For wider recovery steps, see the Dopamine bad-tweak recovery guide and the rootless environment explainer.

Frequently asked questions

What is the current MacStatusBar&Dock version?

Version 1.8.3 is the newest build in the developer repository and release ledger as of November 7, 2026. Havoc still listed 1.8.0.1 when checked.

Does it work on iPhone?

No. The developer documents it as iPad-only and says it does nothing on iPhone.

Does it support RootHide?

No RootHide package is documented. The published architecture is iphoneos-arm64 for a conventional rootless environment.

Does KeyPilot come with the tweak?

No. KeyPilot is an optional separate companion that can use the new public window API.
