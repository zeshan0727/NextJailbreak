SnowBoard vs LumenBoard 1.2.1 vs MarkTheme 0.3.3: Which iOS Theme Engine Fits?

SnowBoard has the broadest legacy ecosystem, LumenBoard is the simplest modern replacement with RootHide builds, and MarkTheme offers the most deliberate import and theme-mixing workflow. The correct choice starts with your firmware and jailbreak environment.

Published November 27, 2026Official releases checked
Quick answer: use SnowBoard for its established extension ecosystem on firmware covered by its official listing; use LumenBoard 1.2.1 for straightforward SnowBoard-format icon themes on a compatible iOS 17–26 rootless or RootHide setup; use MarkTheme 0.3.3 for validated imports, theme mixing and broader system-icon surfaces on a compatible iOS 17–18 setup. Install only one theme engine.

Choose SnowBoard for the mature extension ecosystem

SparkDev’s current package page labels 1.5.37-Beta4-rootless as the latest SnowBoard version and lists iOS 7.0–17.6. Its advantage is not merely changing icons: optional extensions cover docks, labels, badges, icon effects, fonts, respring logos, status bars, Settings icons and more. That modular design lets users install only the surfaces their theme needs.

The trade-off is maintenance. The official SnowBoard repository says it is no longer in active development, although the primary tweak may still receive updates. That makes SnowBoard attractive when a favorite theme or extension depends on it, but less compelling as a default for a new iOS 17+ RootHide setup. The official package page does not advertise a RootHide build, so do not infer RootHide compatibility from a theme’s own iOS range.

Choose LumenBoard for a focused modern replacement

LumenBoard 1.2.1 is the newest release in this comparison. The November 21 release fixes a crash when opening icon-shape settings; version 1.2.0 added an optional Home Screen double-tap action for choosing an icon per app. The project supports common SnowBoard, Anemone and WinterBoard theme formats and reads themes from /Library/Themes or /var/jb/Library/Themes on rootless systems.

The developer publishes two distinct 1.2.1 packages: iphoneos-arm64 for conventional rootless jailbreaks such as Dopamine or palera1n, and iphoneos-arm64e for RootHide environments. The official release checksums are 757ecc6bc636af3316d1e3421797dedaa8c717b599a7faacba9ab3648cb6bfb3 and 94b12d55032331f4aa6722803612ecdb56e40fbdc04136a78dba555f8c8906d9, respectively. Choose the package for the environment you actually use.

Choose MarkTheme for controlled imports and mixing

MarkTheme is built around previewing and validating a theme before applying it. It can import ZIP, DEB, TAR archives or a directory, diagnose invalid assets, and mix icons from different themes. Its supported surfaces include Home Screen and Notification Center icons, folders, badges, Spotlight, Settings, Phone, Photos and system share icons.

Version 0.3.3 adds a GraphicIcon path for Settings icons and fixes AirDrop identity and share-sheet icon handling, legacy mappings and a repeated .png diagnostic. The release publishes separate rootless and RootHide packages with SHA-256 values 1d0270e0a979127bc11b852a4173f7d58a0a6026243c4fc39ab77aca8fc79cba and 602a0304c6e9037a045093a0be8a3702d0d4207126b0e8bbaa9b97df243ce20e. Its documentation says iOS 17.x–18.x is actively maintained, iOS 16 is unsupported and later releases are not promised.

Compatibility is a two-part check

A theme engine’s iOS range describes the package, not the existence of a jailbreak for every device on that firmware. LumenBoard advertising iOS 26 does not mean every iPhone or iPad on iOS 26 can run it. First verify your exact device, chip, firmware and jailbreak; then match the package architecture to the environment. Use the jailbreak tweak compatibility checklist before installing.

  • Conventional rootless: use the iphoneos-arm64 build supplied for rootless setups.
  • RootHide: use the project’s explicit iphoneos-arm64e RootHide build. A conventional rootless package is not interchangeable.
  • Rootful: MarkTheme does not support it. SnowBoard remains the only candidate here with an official traditional-package history; verify the exact package before installing.

Safe switching and recovery

  1. Do not keep two engines enabled. LumenBoard explicitly warns against using another theme engine at the same time, and overlapping icon-cache or hook behavior can produce inconsistent results.
  2. Save the name and source of every installed theme and extension. Disable the current theme, respring, then remove the old engine before trying a replacement.
  3. Install only from the official project or package page. For LumenBoard and MarkTheme, compare the downloaded package checksum with the official release value above.
  4. Apply a small theme first, respring and check Home Screen, Spotlight, Settings, share sheets and notification icons before importing a larger collection.
  5. If SpringBoard crashes or icons disappear, boot with tweak injection disabled, remove the most recent engine or theme package, then rebuild or refresh icons using the recovery option supplied by your jailbreak. Follow the Dopamine bad-tweak recovery guide if needed.
