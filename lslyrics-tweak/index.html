LSLyrics Places Time-Synced Song Lyrics on the iPhone Lock Screen

LSLyrics displays time-synced words from the current song directly on the Lock Screen. A full-screen presentation can hide normal Lock Screen elements so the lyrics and artwork take priority.

Version2.0
Listed supportiOS 14.0–17.7.11
Price$1.49
SourceHavoc

What LSLyrics actually changes

The tweak is for people who want to follow a song without opening the music app. The active lyric line changes with playback and remains visible on the Lock Screen.

Its official images show both the normal presentation and the more immersive full-screen option. They also show that the package has preferences rather than being a fixed one-style overlay.

  • Display time-synced lyrics on the Lock Screen while music is playing.
  • Use a full-screen lyrics mode that can hide standard Lock Screen elements.
  • Adjust the presentation from the tweak's settings.
  • Use the package on both iPhone and iPad according to the current listing.

Compatibility and requirements

  • Havoc lists iOS 14.0 through iOS 17.7.11.
  • The current package listing identifies rootless support.
  • The public price was $1.49 when checked.
  • Lyrics depend on supported playback information and availability for the current song.
Important: A lyrics overlay and another Lock Screen customization can target the same space. Test LSLyrics without competing Lock Screen tweaks if text, notifications or controls are hidden unexpectedly.

Installation checklist

  1. Check the current Havoc compatibility range for your device.
  2. Purchase and install LSLyrics through the official listing.
  3. Respring if requested, then begin playback in your normal music app.
  4. Lock the device and confirm that synced lyrics are available for the song.
  5. Enable full-screen mode only after checking how it affects notifications and controls.
