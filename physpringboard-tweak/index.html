Physpringboard 1.9.23: Configurable Physics for SpringBoard Icons

Physpringboard 1.9.23 is a Home Screen tweak by WeWaffles. Its listed function is to let users shake SpringBoard icons loose with configurable physics on rootless Dopamine. This release is cataloged for the iphoneos-arm64 architecture and lists mobilesubstrate and preferenceloader as dependencies. The supplied metadata does not confirm a specific iOS version.
