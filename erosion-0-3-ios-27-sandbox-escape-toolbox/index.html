Erosion 0.3 Brings Its Sandbox-Escape Toolbox to iOS 27.3 Beta 1

The Erosion team released version 0.3 on November 9, replacing the bad_query sandbox escape with worse_query and documenting support through iOS 27.3 beta 1. It remains a jailed customization toolbox—not a jailbreak—and the project's own iOS 26 documentation currently conflicts on the upper supported version.

By Zeeshan Barvi · Published November 10, 2026 · Verified against the official 0.3 release, tagged README and tagged source code

Erosion is not a jailbreak. It does not install Sileo, create a conventional rootless environment or prove that packages can run on every listed firmware. It is a jailed customization toolbox that uses a sandbox escape.

What changed in Erosion 0.3

The official November 9 release has one major technical change: Erosion replaced bad_query with worse_query. The maintainer says this expands the published target list to iOS and iPadOS 26, iOS and iPadOS 27.0–27.2, and the first iOS/iPadOS 27.3 beta.

The release contains one downloadable asset, Erosion_v0.3.ipa. GitHub reports a 2,484,800-byte file and publishes the SHA-256 digest below. Verify it before installation; a matching hash only confirms that the file matches the official release asset, not that your device is supported.

Official SHA-256: 40f379ca7a4a2a9590f7d6b75c43382ff27f2eed138b7152b748ccba3387767b

Why opening the app is not proof of support: the 0.3 tagged source currently makes its isSupported() function return true unconditionally, with a comment describing temporary zero-day conditions. Use the written version/build list—not the absence of an in-app block—as the compatibility test.

What iOS 26 users cannot assume

The tagged README explicitly says Erosion has limited functionality on iOS 26 because worse_query cannot write MobileGestalt there. That means MobileGestalt-based options are unavailable even if the IPA installs and launches. It also warns that tweaks are device- and server-dependent, so a successful action on one supported device is not a universal compatibility guarantee.

This distinction matters for jailbreak readers: Erosion's OS support is not a Dopamine, RootHide or Sileo compatibility matrix. For the current public jailbreak boundary, see the iOS 27 jailbreak status and the Dopamine 3 compatibility guide.

Signing and App Groups troubleshooting

The maintainer warns that enterprise and paid certificates may fail to sign the required App Groups entitlement correctly. If Erosion installs but cannot initialize its shared container, the official recommendation is to sideload with your own Apple ID through SideStore, Impactor or another method that preserves the entitlement.

  1. Back up the device first. The project warns users to create a backup before applying any customization.
  2. Confirm the exact firmware and build. For iOS 27.3, beta 1 build 24C5037i is the only documented target.
  3. Download only the official 0.3 release asset and compare its SHA-256 with the digest above.
  4. If App Groups initialization fails, change signing method. Reinstall using a personal Apple ID rather than repeatedly retrying an enterprise certificate.
  5. Allow the first container scan to finish. Custom Wallpapers and Dialer Themer can take about 30 seconds on first launch while Erosion discovers application container paths.
  6. If wallpapers are missing, reset PosterBoard Collections using Erosion's provided recovery control, then retry.
  7. Undo old MobileGestalt changes first. The README advises resetting changes made by other toolboxes before applying Erosion options.

Compare signing behavior and refresh requirements in our TrollStore, SideStore and AltStore guide. Erosion's own release specifically recommends an Apple-ID signing route when certificate entitlements fail.

What this release does not establish

  • It does not provide a jailbreak, bootstrap or package manager.
  • It does not establish support for iOS 27.3 beta 2, later betas or the final release.
  • It does not resolve the project's conflicting iOS 26.6.2 versus 26.7.2 statements.
  • It does not prove every listed tweak works on every device in the documented OS range.
  • It does not make third-party mirrors or re-signed IPAs official.
