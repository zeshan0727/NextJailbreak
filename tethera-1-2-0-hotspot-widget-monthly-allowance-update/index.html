Tethera 1.2.0 Adds Hotspot Widgets, Monthly Caps and Wi-Fi Automation

Tethera 1.2.0 adds practical controls around the Personal Hotspot rather than a new way to evade a carrier plan: a Home and Lock Screen widget, a monthly usage allowance, Wi-Fi departure automation and an IPv6 switch. The important limits are easy to miss: the widget needs iOS 16.1 or later, and one Wi-Fi-sharing fix requires jailbreak injection into the Wi-Fi service.

By Zeeshan BarviPublished November 21, 20267 min read
Release snapshot: Tethera 1.2.0 is the newest entry in Havoc's version history checked on November 21, 2026. Havoc's changelog displayed a relative age of “4 days ago”; the independent iOS Repo Updates feed groups the package update under November 16. The official changelog does not expose an exact calendar timestamp, so this article preserves that date discrepancy rather than inventing one. Havoc's package metadata lists $7.99, iOS 15.0–26.0.1, jailbreak required and rootless support.

These are separate controls. The monthly allowance is a data cap, the Wi-Fi rule is a network-based automation, and the widget is a quick status and toggle surface. None of them changes the carrier plan itself.

The widget has a narrower iOS requirement than the package

Havoc's package metadata lists Tethera for iOS 15.0–26.0.1 and marks it as a jailbreak-required rootless package. The new widget changelog entry is more specific: it requires iOS 16.1 or later. That means an iOS 15 device can fall inside the package range without receiving this particular widget feature.

The widget reports whether the hotspot is on, which devices are connected and today's hotspot data. The compact widget is a status surface; the larger widget adds a button for switching the hotspot on or off. Do not assume that every widget interaction is available on iOS 15 just because the tweak itself lists iOS 15.

Monthly allowance: useful, but not a carrier-plan bypass

Set the monthly allowance to match the hotspot quota in your mobile plan, then choose the day the allowance renews. Tethera displays the usage, notifies at 80%, and can turn the hotspot off after the configured allowance is reached. The developer marks this control off by default, so installing 1.2.0 does not silently impose a new cap.

Tethera does not provide free or extra data. Your carrier can still detect, count and charge for hotspot use, and its terms continue to apply. The allowance is a local guardrail; it is not a way to change the carrier's billing or tethering policy.

When Leaving Wi-Fi and IPv6 controls

When Leaving Wi-Fi lets you select a home or work network and automate Personal Hotspot around that network. With the feature enabled, the hotspot starts roughly a minute after the iPhone leaves the selected Wi-Fi and switches off again when the iPhone returns. It is off by default, so check the rule before expecting it to run.

The IPv6 setting is on by default. Turning it off gives connected hotspot devices IPv4-only service where the carrier provides IPv6. This is a compatibility switch for client devices and networks, not a speed boost; leave it enabled unless a client or network actually needs IPv4-only behavior.

Wi-Fi sharing fixes and the Dopamine caveat

The 1.2.0 changelog addresses two related cases when the iPhone shares a Wi-Fi connection. On some devices, starting the hotspot could make the iPhone lose its own Wi-Fi connection, causing the hotspot to restart and drop repeatedly. The update says it now stops once and reports the reason in Connected Clients. A second fix helps the iPhone keep its own Wi-Fi connection the next time the hotspot starts.

That second fix has a specific environment requirement: the developer says it needs a jailbreak that loads tweaks into the Wi-Fi service, giving Dopamine as an example. This is not stated as a blanket requirement for every Tethera feature. If the Wi-Fi-sharing behavior is the reason you are installing the update, verify that your exact jailbreak supports injection into that service.

The update also improves the Share From error message when the selected connection cannot be shared, adds a shortcut to the relevant setting, and ensures a shortened custom hotspot name is cut on a whole character rather than splitting an emoji.

Compatibility: what the listing does and does not establish

  • Package range: Havoc lists iOS 15.0–26.0.1, jailbreak required, with rootless support.
  • Widget: iOS 16.1 or later, according to the 1.2.0 changelog.
  • Wi-Fi service fix: requires a jailbreak that loads tweaks into the Wi-Fi service; Dopamine is the developer's example.
  • RootHide: the 1.1.0 changelog mentioned a fix for RootHide installs converted with the RootHide Patcher on iOS 26. That is a specific historical fix, not a blanket guarantee for every RootHide build.
  • Rootful: the current package metadata marks rootless support; it does not provide a general rootful compatibility statement.

A package's iOS range is not proof that a jailbreak exists for every iPhone model and firmware in that range. Check your exact device and build against the jailbreak's own support matrix before buying or installing. Our iPhone model and iOS build checklist explains what to verify first.

Update safely and check the defaults

  1. Confirm that your package manager shows Tethera by AADiOS and package identifier com.aadios.tethera. Use the current version history rather than an older cached package-summary snippet; some indexed copies of the overview still show 1.0.0 while the changelog lists 1.2.0.
  2. Back up important data and confirm your exact device, firmware and jailbreak support. The package is paid at $7.99 on Havoc; do not use third-party mirrors or assume a converted package is equivalent.
  3. Install the update through your package manager using the official Havoc source. If Personal Hotspot was in use while the update installed, the developer recommends restarting the iPhone.
  4. After restarting, check the monthly allowance and Wi-Fi departure rule. Both are off by default. The IPv6 switch is on by default.
  5. If you are installing mainly for the Wi-Fi-sharing fix, confirm that your jailbreak can load tweaks into the Wi-Fi service before treating that fix as available.

Practical troubleshooting

The new widget does not appear

Check the iOS version first. The widget is documented for iOS 16.1 and later; the package's broader iOS 15 minimum does not lower the widget requirement.

The monthly limit or Wi-Fi automation does nothing

Both controls are off by default. Enable the monthly allowance and choose its reset day, or enable When Leaving Wi-Fi and select the network to watch. Do not assume that installing 1.2.0 turns either feature on automatically.

Wi-Fi sharing still drops the iPhone's own connection

Confirm the update is installed, then check whether the active jailbreak injects tweaks into the Wi-Fi service. The developer specifically calls out this requirement for the connection-retention fix. If the issue continues, capture the device model, iOS build, jailbreak and Tethera version before contacting AADiOS.

Hotspot behavior changed immediately after updating

If Personal Hotspot was active during installation, restart the iPhone as the developer recommends. Recheck the selected Share From source and the Connected Clients explanation before changing several network settings at once.
