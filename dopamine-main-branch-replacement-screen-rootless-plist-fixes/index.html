Dopamine Main Branch Fixes Replacement-Screen Touch and Rootless Plists

Two changes merged after Dopamine 3.0.11 address different edge cases: dead touch after userspace reboot on some aftermarket displays, and system preference files being redirected into the rootless jailbreak area.

By Zeeshan Barvi · Published October 15, 2026 · Verified with Dopamine’s official source and release pages

Release status: these fixes landed on Dopamine’s 3.x development branch on October 14, 2026. They are newer than the current 3.0.11 release and are not a tagged 3.0.12 download. Regular users should stay on official releases.

The two fixes at a glance

  • Replacement-screen touch: Dopamine now skips Apple’s mtmergeprops launch daemon after a userspace reboot, because reloading the touch-controller firmware a second time can leave touch unresponsive on some aftermarket displays.
  • Rootless preference redirection: the rootless hook now excludes ReportSystemMemory.plist, TokenBucketRateLimiter.plist and PerfPowerServices.plist from redirection into /var/jb.
  • Commit date: both changes were committed on October 14, 2026, less than two days after 3.0.11 was published.
  • Availability: source branch only at publication time; no new IPA or TIPA is attached to these commits.

Why some replacement screens lost touch

The touch fix comes from pull request 1039 and references an older report, issue 296. Dopamine’s launchd hook was allowing com.apple.mtmergeprops.plist to run after a userspace reboot. The merged comment explains that this daemon reloads the touch-controller firmware even though that already happened during the initial boot.

According to the commit, some aftermarket displays do not recover from the second firmware reload. The new code removes that daemon from the userspace-reboot launch set. This is a targeted fix for affected replacement screens; it is not a claim that every touch failure has the same cause.

What the rootless plist fix changes

Dopamine’s rootless hooks decide whether preference files should use the jailbreak’s /var/jb path. The second commit adds three Apple system plist names to the existing exclusion list so they remain on their system-side path instead of being treated like jailbreak preferences.

The diff is deliberately small: it adds ReportSystemMemory.plist, TokenBucketRateLimiter.plist and PerfPowerServices.plist to BaseBin/rootlesshooks/cfprefsd.x. The commit does not promise a broad performance improvement or expanded jailbreak support, so users should read it as correctness work inside the rootless environment.

These commits are not Dopamine 3.0.12

The official releases page still lists Dopamine 3.0.11, published October 12, 2026, as the newest tagged build. Its release notes cover iOS 26.0 beta 1 support, boot-logo cleanup during sbreload, and updated opainject and litehook components. The two October 14 commits came later and therefore are not included in that release.

Do not download an unofficial file labeled 3.0.12 on the strength of these source changes. Wait for opa334 to publish a tagged release and verify it on the official GitHub page or Dopamine website. When that happens, use the safe Dopamine update guide rather than replacing files inside the active jailbreak manually.

Current device and firmware scope

Neither commit expands compatibility. Dopamine 3.0.11’s official README documents the following ranges:

  • arm64e: iOS 15.0–17.3.1.
  • A12 and A13: iOS 15.0–18.7.1, plus iOS 26.0–26.0.1.
  • arm64: iOS 15.0–18.7.1.

A listed firmware range is still tied to the documented device category. The replacement-screen change does not create a jailbreak path for unsupported hardware or firmware, and the plist change is internal rootless behavior rather than a new exploit.

What affected users should do now

  1. If 3.0.11 works normally, keep using the official release.
  2. If touch becomes unresponsive only after a userspace reboot and the device has a replacement display, note the exact screen and firmware details for a useful developer report.
  3. Use a full reboot only if it is safe for the device and you understand that Dopamine is semi-untethered and must be run again afterward.
  4. Avoid self-built or renamed IPAs unless you can audit and compile the source yourself.
  5. Check the official release page before updating; a commit on 3.x is not an installation announcement.

Frequently asked questions

Is Dopamine 3.0.12 available?

No tagged 3.0.12 release was available when this article was verified. Dopamine 3.0.11 remains the newest official release.

Are these fixes already in 3.0.11?

No. The 3.0.11 release was published on October 12, while both fixes were committed on October 14.

Does every replacement screen need the touch fix?

No. The commit specifically says some aftermarket displays can fail to recover after the touch-controller firmware is reloaded during a userspace reboot.

What is /var/jb?

It is the rootless jailbreak prefix used for jailbreak files. The plist fix prevents three Apple system preference files from being redirected there.

Should I install a development build?

Most users should wait for an official tagged release. Development builds can change and do not have the same release packaging or update guarantees.
