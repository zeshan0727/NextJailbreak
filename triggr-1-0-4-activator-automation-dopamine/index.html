Triggr 2.1.0 vs RemoteCompanion 4.5.0: Which Activator Alternative Fits?

Compare Triggr 2.1.0 and RemoteCompanion 4.5.0 by triggers, automation, remote control, privacy, firmware and jailbreak-environment support.

Originally published October 6, 2026 · Updated November 24, 2026 · Checked against official project repositories, package metadata and release notes

Short answer: choose Triggr if you want a local-first Activator-style trigger engine with button, gesture and event assignments, conditional actions and no always-on web server. Choose RemoteCompanion if you want a wider automation hub with a command-line client, Web UI, SSH, integrations, add-ons, configuration backup and remote control of another device. They overlap, but they are not the same kind of tool.

Version check for November 24, 2026: Jond-ie’s official package index lists Triggr 2.1.0; the package-index commit that introduced it is dated November 10. The official RemoteCompanion GitHub release record lists v4.5.0, published November 22 at 12:07 UTC. Its changelog heading is dated November 11, so the GitHub release timestamp and changelog date are not identical.

Triggr 2.1.0: a lighter local-first Activator replacement

Triggr’s 2.1.0 package update is documented in Jond-ie’s repository commit dated November 10, 2026. That commit specifically lists Run Now, Undo, a confirmation before restart actions and a clearer main page, with Rootless and RootHide builds. The current package index contains version 2.1.0 for both arm64 and arm64e.

  • Triggers: hardware buttons, Touch ID, the ringer switch, screen edges, status-bar taps and swipes, Home Screen gestures, multi-finger gestures, sensors, Wi-Fi and Bluetooth changes, notifications, calls, music, battery state and schedules.
  • Actions: system navigation, power controls, switches, media, brightness, volume, app and Settings launches, Shortcuts, URLs, text, commands, haptics and actions supplied by other tweaks.
  • Logic: Only If conditions, If / Otherwise blocks, ordered action sequences, pauses, menus and different assignments for Anywhere, Home Screen, In Apps, Lock Screen or one selected app.
  • Profiles: the project page documents profiles, export / import, search, recently used actions and a Test button.

Triggr’s main appeal is restraint. The developer says unassigned triggers do nothing, there is no continuous polling, and nothing listens on the network. Its optional API and command-line access are off by default. The project also says Triggr 2.0 and later are closed source; the older 1.x code remains GPL-3.0 and the developer extension library, libtriggr, is MIT licensed.

RemoteCompanion 4.5.0: a broader automation and remote-control hub

RemoteCompanion’s official v4.5.0 GitHub release was published on November 22, 2026. Its release notes add several capabilities that go beyond a compact trigger-to-action tweak:

  • Full configuration backup and restore: one export can include settings, integrations, triggers, add-ons, gestures, notification filters, variables, SSH hosts and the app blacklist. The same export / import flow is available through the rc command line.
  • Add-ons: another tweak or app can add actions, conditions, banners and triggers through a JSON file. The developer documents validation and a Settings screen that shows which add-ons loaded or failed.
  • Remote RC actions: configure another device as a Remote RC client, then run normal RemoteCompanion actions on it through its Web UI without setting up a separate SSH action for each command.
  • Cleaner trigger list: the Triggers screen starts empty; built-in triggers are added from the picker, so unused rows do not fill the list.
  • Duplicate actions: duplicate individual actions or complete If / Repeat blocks in the app and Web UI.
  • Compatibility fixes: the 4.5.0 notes mention Control Center and App Switcher fixes on iOS 18, Quick Shortcuts and Camera-mode fixes on iOS 26, and a crash fix for Lua objc_call arguments.

RemoteCompanion also documents a desktop-class Web UI at the device’s local IP on port 8080, a command-line client, SSH commands, REST API actions, Home Assistant, Keyboard Maestro, MQTT, NFC triggers and Lua scripting. That breadth is useful when you want a Mac, another phone, a home automation service or a script to control the jailbroken device.

Compatibility: do not confuse a tweak range with jailbreak availability

Triggr

The current Jond-ie project page states iOS 15–27 support on Rootless or RootHide. Its named real-iPhone test list is narrower:

The developer separately reports virtual iPhone checks under RootHide on iOS 18.6.2, 26.6.2 and 27.0.1. Those virtual checks are not equivalent to named real-device tests on those firmware versions.

RemoteCompanion

The current project README lists iOS 14–17 and says iOS 26 is partially supported and needs broader testing. It also lists Rootless, Rootful and RootHide environments, including Dopamine, palera1n, unc0ver, Taurine, XinaA15 and NathanLR. Version 4.5.0 contains targeted iOS 18 and iOS 26 fixes, but those individual fixes do not establish complete support for every build in either range. The README does not provide a named device/build test matrix for 4.5.0.

Important: neither tweak creates a jailbreak. A package may declare support for a firmware version while no public jailbreak is available for your exact device and build. Check the jailbreak itself first, then confirm the package’s rootful, rootless or RootHide build and architecture.

Use our rootless, rootful and RootHide basics guide and RootHide tweak-injection guide before choosing a package. If you are unsure whether your device can be jailbroken, verify the exact model and build rather than relying on the package’s iOS range.

Privacy and network exposure

Triggr’s developer says the optional API is off by default and the tweak does not listen on the network. That makes it the more conservative starting point if all you need is local button and gesture automation.

RemoteCompanion’s Web UI and API are optional, but they create a network control surface when enabled. The project documents an API token for privileged commands and access modes for any network, trusted networks or the iPhone itself. Before enabling the Web UI, set an API token and restrict access to trusted Wi-Fi or the device itself. Do not port-forward its Web UI to the public internet.

Which one should you install?

  • Choose Triggr 2.1.0 if you want local-first Activator-style assignments, button and gesture triggers, conditional sequences, profiles and a smaller network footprint. It also has the clearer published iOS 15–27 Rootless / RootHide range, with the real-device and virtual-test limits listed above.
  • Choose RemoteCompanion 4.5.0 if you need the CLI, Web UI, SSH, integrations, add-ons, full backup and restore, or actions sent to another device. It is also the documented option here for Rootful environments, but its iOS 26 support remains explicitly partial.
  • If you want to test both, start with one tweak and one low-risk trigger. Both can claim button and gesture events; the developers do not publish a compatibility guarantee for running both together. Add overlapping assignments one at a time and watch for double-firing or suppressed native behavior.

Install and test safely

  1. Record the exact iPhone model, chip, iOS build, jailbreak and bootstrap. Confirm that a jailbreak exists for that combination before installing either tweak.
  2. For Triggr, add Jond-ie’s official repository in Sileo or Zebra, find com.johndie.triggr and confirm version 2.1.0. The repository provides Rootless and RootHide builds.
  3. For RemoteCompanion, use the official v4.5.0 release or the installation source documented in the project README. Confirm the package manager has selected the build for your jailbreak environment.
  4. Create one reversible assignment first. Test the native button action, emergency behavior and respring recovery before adding power or shell-command actions.
  5. If you enable RemoteCompanion’s Web UI, set the API token and restrict access before connecting another device.
  6. If SpringBoard enters Safe Mode, remove the new package in Sileo. Our Dopamine bad-tweak recovery guide explains how to disable injection and remove a problematic tweak.

For package-manager basics, see how to install a jailbreak tweak with Sileo. Do not install a rootful package into a rootless bootstrap or assume a RootHide-compatible build is interchangeable with every other package variant.
