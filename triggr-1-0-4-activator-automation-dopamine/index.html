Triggr 1.0.4 Brings Activator-Style Automation to Rootless Dopamine

Triggr 1.0.4 adds an app, iOS 18 side-button triggers, per-app assignments and extensible automation for rootless Dopamine on iOS 15–18.

Published October 6, 2026 · Verified from developer source, package metadata and official screenshots

Triggr 1.0.4 is a new Activator-style automation tweak for rootless Dopamine. Released on October 6, 2026, it pairs configurable device events with actions and now gives those assignments a dedicated Home Screen app rather than relying only on a Settings bundle.

Compatibility boundary: the stable package is documented for rootless Dopamine on iOS 15–18. The developer has a separate experimental RootHide build, but RootHide is not part of the stable 1.0.4 package’s supported environment.

What is new in Triggr 1.0.4

  • Dedicated app: Triggr now appears on the Home Screen, with trigger search, a Recently Used section and a Test button. Its Settings interface remains available.
  • iOS 18 side-button triggers: supported Face ID devices can assign single, double and triple side-button presses. The double press can replace Wallet, while triple press can replace the Accessibility Shortcut.
  • More trigger families: version 1.0.4 adds status-bar gestures, Home Screen gestures, proximity and notification triggers.
  • Per-app assignments: actions can be scoped to one selected app instead of firing everywhere.
  • Extension support: third-party trigger and action providers can integrate with Triggr; the developer identifies EQELinker as the first extension.

What Triggr can automate

The project includes hardware-button, status-bar, Home Screen, proximity, Wi-Fi, Bluetooth, notification, time, app-open and battery triggers. Assignments can run system actions, power controls, switches, media controls, brightness or volume changes, app and Settings launches, Shortcuts, URLs, text actions, commands, menus and extension actions.

Assignments can be scoped to Anywhere, Home Screen, In Apps, Lock Screen or one Specific App. That matters when the same gesture should behave differently in an app than it does on the Home Screen.

iOS 18 side-button behavior

On supported Face ID devices, Triggr can map side-button single, double and triple presses. Because those gestures already have system roles, replacing double press can affect Wallet and replacing triple press can affect the Accessibility Shortcut. The developer says Emergency SOS is not modified and the button still wakes the device, but users should test essential system behavior before depending on a custom assignment.

The tweak also exposes power actions and shell-command actions. Power actions can interrupt work, and shell commands run as the mobile user through /var/jb/bin/sh -c. Only use commands you understand and keep recovery access available.

Privacy and performance design

According to the source documentation, Triggr’s main component runs in SpringBoard and uses event hooks rather than continuous network listening or polling. The optional local API is disabled by default. Built-in and user-created assignments are the intended execution path.

On iOS 18, command actions use the included triggrd daemon; on iOS 15–17, SpringBoard launches them. These are developer-documented implementation details, not independent battery or performance benchmarks.

Installation from the verified source

  1. Add Jond-ie’s official repository to Sileo or Zebra.
  2. Find Triggr and confirm the package identifier is com.johndie.triggr.
  3. Confirm the installed version is 1.0.4 and that your environment is rootless Dopamine.
  4. Install the package, open Triggr from the Home Screen, and create one low-risk test assignment first.
  5. If SpringBoard enters Safe Mode, uninstall Triggr from Sileo and submit the crash log through the project’s GitHub issues page.

The official repository lists an iphoneos-arm64 package of 200,452 bytes with SHA-256 81c58a9a1a93e9f3108e27799adf06a1e0a822e170ca28c5a714745e2e86f720. Its listed dependencies are MobileSubstrate, PreferenceLoader, AltList, UIKit Tools and firmware 15.0 or later. Next Jailbreak links to the official repository rather than mirroring the package.

RootHide and early-release caveats

The developer initially answered that only Dopamine was supported, then published a separate experimental RootHide build in a beta repository after a RootHide crash report. That beta should not be confused with the stable package described here. A second user also reported a Settings crash on one Dopamine/iOS 17.3.1 device; the developer requested a crash log. Those reports show why a cautious first assignment and a recovery plan are sensible, but they do not establish a universal fault.
