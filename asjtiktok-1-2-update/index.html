ASJTikTok 1.2 adds saved-story storage controls and expands TikTok customization

ASJTikTok 1.2 is a rootful iOS tweak for TikTok that combines privacy, download, messaging, feed, and playback controls. This release adds a storage screen for saved stories, with cleanup options organized by account or age and a displayed size before deletion. The changelog also states that the library holds 20,000 items and that saved content is not deleted automatically to make room. Version 1.2 further tightens story-view privacy and extends content-country controls across more of TikTok. The official package information lists iOS 14.0 through 26.0.1, while the changelog says the package was built against TikTok 46.7.0.

Key points

  • ASJTikTok 1.2 is listed as version 1.2 and was built against TikTok 46.7.0.
  • The update adds a storage screen for saved stories, including cleanup by account or age and a size preview before deletion.
  • The saved library is stated to hold 20,000 items, and the changelog says saved content is not automatically deleted to make room.
  • Story-view privacy is stricter in this release, including behavior after a story has been marked as seen.
  • The package description lists iOS 14.0–26.0.1, while package metadata identifies a mobilesubstrate dependency and iphoneos-arm architecture.
  • The package filename identifies the release as rootful, so users should confirm that their jailbreak environment matches that format.

What ASJTikTok 1.2 is

ASJTikTok is a TikTok-focused jailbreak tweak from developer asjrx. Its official description presents it as a collection of privacy, download, messaging, feed, and playback controls accessed through one panel opened from TikTok’s own menu. It is therefore designed to modify the TikTok experience rather than operate as a separate TikTok client or replacement application.

The repository package stanza identifies the package as com.ahmad.asjtiktok, lists version 1.2, and records an installed size of 2,380 KB. The compressed package size is listed as 664,496 bytes, while the user-facing depiction reports 648.92 KB. Those figures reflect package reporting details and should not be treated as the total storage required for downloaded TikTok media or package-management operations.

The main change: storage management for saved stories

The clearest addition in version 1.2 is a dedicated storage screen for saved stories. According to the changelog, users can clear space by account or by age, and the interface shows the size before deletion is initiated. This gives users more information and more targeted control when managing a large saved-story collection.

The release notes also state that nothing saved is deleted to make room and that the library holds 20,000 items. Together, these statements describe a library with a stated capacity and manual cleanup tools, not an automatic system that removes older content whenever storage pressure rises. The changelog does not explain what happens when the stated capacity is reached, so users should not infer an automatic deletion policy from the capacity figure alone.

The supplied material does not specify whether cleanup can be undone, whether the screen offers sorting methods beyond account and age, or where saved files are stored. Those details should be checked in the installed interface before using bulk deletion. Users should also review the displayed size carefully because the feature is intended to make the consequences of cleanup clearer before confirming an action.

  • Cleanup can be organized by account or by age.
  • The size of selected content is shown before deletion begins.
  • The stated library capacity is 20,000 saved items.
  • The changelog says saved content is not deleted automatically to make room.

Stricter privacy behavior for story views

ASJTikTok’s existing description advertises options for viewing profiles and stories without appearing, as well as controls for read receipts, typing status, and active status. Version 1.2 specifically changes story-view handling: the changelog says hiding story views is stricter and that marking one as seen also sticks.

This wording indicates a change in how the tweak handles the viewed state after TikTok records an interaction. It should not be expanded into a universal guarantee that every story action is invisible. The official material describes the feature and its stricter behavior, but it does not document every server-side condition or every type of story interaction.

Users who depend on these privacy controls should review the relevant setting before opening content. They should also avoid assuming that changing a setting afterward will reverse an event that TikTok has already recorded. The source does not provide a detailed explanation of the underlying implementation.

Content-country controls reach more of the app

The 1.2 changelog says that content country reaches more of the app. The main description already lists the ability to choose a For You country, so the update indicates broader coverage for that country-related control. However, the official notes do not identify every additional screen or function affected.

That limitation matters when setting expectations. The source confirms wider coverage of the content-country option, but it does not promise access to every region’s catalog, remove TikTok’s regional restrictions, or state that every change will appear immediately. Users should regard this as an app-level customization described by the developer, not as a guarantee of account eligibility or content availability in a particular market.

Other controls included in the package

The package depiction lists a broad group of existing ASJTikTok functions. Privacy options include viewing profiles and stories without appearing, hiding read receipts, hiding typing status, and hiding active status. Messaging features are described as retaining deleted messages and their media and allowing any audio file to be sent as a voice message.

The download section lists videos, photos, sounds, profile pictures, and stories, with the description stating that these downloads can be made without a watermark. Feed and playback controls include removing ads, selecting a For You country, automatic scrolling, and stopping playback from looping. A Clear Display option is also listed for keeping the interface out of the way while watching.

These points are features stated in the official package description. The supplied source does not establish that every control behaves identically across all TikTok releases. The changelog identifies TikTok 46.7.0 as the build reference, so the installed TikTok version remains an important consideration before installation.

  • Privacy: profiles, stories, read receipts, typing status, and active status.
  • Messages: retained deleted messages and media, plus any audio file as a voice message.
  • Downloads: videos, photos, sounds, profile pictures, and stories without a watermark, according to the description.
  • Feed and playback: ad removal, For You country selection, auto-scroll, and loop control.
  • Viewing: Clear Display mode.

Compatibility and package details to check

The official depiction lists iOS Versions as 14.0–26.0.1. The package stanza identifies iphoneos-arm as the architecture and lists mobilesubstrate as a dependency. These entries describe the package’s published requirements, but users should still compare them with their jailbreak environment, architecture, package manager, and installed TikTok build.

The package filename identifies version 1.2 as a rootful Debian package. A rootful package should not be assumed to be interchangeable with a rootless build. The supplied source does not list a rootless variant. Users should therefore confirm their environment before installing and should avoid treating the listed iOS range as the only compatibility check.

The changelog says ASJTikTok 1.2 was built against TikTok 46.7.0. That wording identifies the version used as the build reference; it does not by itself establish compatibility or support for that TikTok version, and it says nothing about other TikTok versions. Users should look for current developer information if TikTok updates independently or if the tweak behaves unexpectedly after an app update.

  • Confirm that the device is within the listed iOS 14.0–26.0.1 range.
  • Confirm that the jailbreak environment supports the rootful package format.
  • Check that the required mobilesubstrate dependency is available.
  • Compare the installed TikTok version with the stated 46.7.0 build reference without assuming compatibility.
  • Use the official package source rather than unofficial or modified copies.

Why this release matters

For users who save many TikTok stories, the storage screen is the most concrete quality-of-life improvement in version 1.2. It adds a size preview and narrower cleanup choices by account or age, allowing users to make a more informed decision before deleting content. The stated 20,000-item library capacity also clarifies the scale described by the developer, while the no-automatic-deletion note emphasizes that saved content is not removed simply to make room.

The privacy and content-country changes are broader behavioral updates. Stricter story-view handling may matter to users who want privacy settings to remain consistent after content is marked as seen. Wider content-country coverage may make the existing For You customization available in more areas of the app. Both features depend on TikTok’s implementation, which is why users should treat the build reference as descriptive rather than as a compatibility promise and should verify their environment before proceeding.
