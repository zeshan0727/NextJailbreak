Regram 6.2 Adds Stacked Notifications, Reels Controls and Expanded Local Spoofing

Regram for Instagram 6.2 is a substantial update for jailbroken and sideloaded iOS installations. Released on September 21, 2026, it includes compatibility updates for Instagram 447, a new stacked notification system, filterable Notification History, expanded Reels playback controls, Stories Tray filtering, consolidated ad settings, Crash Logs and a reorganized profile-spoofing page. The release also fixes several issues affecting story controls, signed apps and other interface features.

Key points

  • Regram 6.2 includes bug fixes and compatibility updates for Instagram 447.
  • Notifications can appear in stacked Banner or Toast styles and can be reviewed in Notification History.
  • Reels gain scrubbing, speed controls from 0.5× to 2×, auto-advance, Picture in Picture, frame saving and other playback options.
  • Stories Tray filtering and a new Ads section organize controls for Instagram-inserted cards and advertising surfaces.
  • Profile spoofing now includes a master switch, live preview, username and display-name options, plus existing follower, following, post and badge controls.
  • The official documentation describes jailbroken, AltStore-style sideloading and TrollStore installation paths, with signing and compatibility details varying by method.

What Regram 6.2 changes

Regram is described by its developer as an all-in-one Instagram enhancement tool for jailbroken or sideloaded iOS devices. Its listed features cover profile analysis, media downloads, Stories and Reels controls, messaging options, privacy settings, interface customization and local profile utilities.

Version 6.2 was released on September 21, 2026. The package is identified as com.fouadraheb.regram and lists version 6.2, an iphoneos-arm64 architecture, firmware 14.0 or newer and MobileSubstrate 0.9.5000 or newer as dependencies. The package depiction separately lists support as iOS 15.1+. Those entries describe different parts of the distribution information, so users should check the instructions for their particular installation method.

The official sideloading table lists four builds paired with Instagram 447.0: the standard Instagram bundle, a No-Plugins build, a duplicate using the Regram bundle identifier and a TrollStore build.

  • The release notes identify Instagram 447 as the compatibility target.
  • Regram settings are available from inside Instagram, including through the Instagram settings menu or by long-pressing the Home button.
  • The package conflicts with com.b4db1r3.cleancopy, which should be considered before installation.

Stacked notifications and Notification History

The most prominent interface change is a new in-app notification system. Regram 6.2 can display several notifications at once in a stacked layout rather than showing only one notification at a time.

Two notification appearances are available. Banner is described as the full-width default, while Toast is a smaller pill-style presentation. The appearance can be selected globally or configured separately for individual features under Settings > Notifications.

The release also adds Notification History. Regram notifications shown in the app can be retained there and filtered by feature. Tapping an entry opens the destination associated with what the original notification would have opened, according to the release notes.

  • Several Regram notifications can appear together.
  • Banner and Toast styles can be selected globally or per feature.
  • Notification History is filterable by feature and stores notifications shown by Regram.

Expanded Reels playback controls

Regram 6.2 adds a Reels Playback Controls sheet that can be opened in three ways: by long-pressing the three-dot button, using a floating button that can be dragged around the Reel, or selecting the Regram action button.

The control sheet includes play and pause, a scrubber with elapsed and remaining time, and six playback-speed choices ranging from 0.5× to 2×. It also includes auto-advance, mute, full screen, Picture in Picture, saving the current frame and a volume control specific to Reels.

A keep-speed option applies the selected playback speed to every Reel and remains active after the app is relaunched, as stated in the release notes. Reels auto-advance also moves past sponsored Reels instead of leaving them looping.

  • Playback controls can be opened from the three-dot menu, a floating button or the Regram action button.
  • The speed selector has six choices between 0.5× and 2×.
  • The sheet includes scrubbing, Picture in Picture, frame saving, mute, full screen and Reel-specific volume.
  • Kept playback speed persists after relaunch.

Stories Tray filtering, ads and Safari handoff

A new Stories Filtering page appears under Interface > Stories Tray. It provides a switch for cards that Instagram inserts between Stories, including Join Trending, Popular, Your Turn, Music, Restyle, Meta AI and Threads, as well as other cards named in the release notes.

Advertising controls are now grouped in a new Ads section. The section includes a Hide All Ads master switch and separate switches for Feed, Stories, Explore and Reels. Existing ad settings carry over, while older locations under Feed / Reels Filtering and Interface now link to the new section.

The Open in Regram Safari extension also changes in this release. On Instagram pages, it can show a banner with an Open button, allowing links to reach Regram from the first page rather than only after tapping a Reel or using Open in Instagram.

  • Stories Tray filtering includes switches for multiple Instagram-inserted cards.
  • The Ads section contains a master switch and separate controls for Feed, Stories, Explore and Reels.
  • Existing ad settings are carried over to the reorganized section.
  • The Safari extension adds an Open banner on Instagram pages.

Profile spoofing remains local to the device

Profile > Spoofing is now organized as one page with a live preview, a master switch and separate sections for followers, following, posts and the verified badge. Version 6.2 adds username and display-name spoofing to those controls.

The release notes specifically state that spoofed names appear throughout the app but stay on the device. They also state that the real account remains untouched and that Edit Profile continues to show the real values. When the master switch is off, the release notes say that nothing related to spoofing runs.

These controls describe local presentation within the app. The supplied documentation does not describe them as server-side changes to the Instagram account.

  • The spoofing page now includes a live preview and master switch.
  • Username and display-name spoofing join controls for followers, following, posts and the verified badge.
  • The developer states that spoofed names remain local and that the real account is untouched.
  • The master switch disables spoofing-related behavior when turned off.

Crash Logs and fixes in version 6.2

Crash Logs have been added under App Utilities. Regram writes a report when Instagram crashes, and the report can be read, searched and shared when reporting a problem, according to the official release notes.

The update fixes “Fix Pop-ups & Emoji” reverting to on. The documented cause was that the setting was stored in the App Group container, which is missing from apps signed without App Group support. Version 6.2 addresses that behavior.

Another fix concerns the story mark-seen button menu. After moving to the next Story, the menu could show the previous account’s name and the wrong exclude/include action. The release notes state that this has been fixed.

Device ID masking now has a required warning screen explaining who the feature is for, followed by a How It Works page. The update also adds a Previous Versions button to What’s New, allowing users to browse highlights from Regram releases since version 5.0.

  • Crash reports are available under App Utilities and can be read, searched and shared.
  • The Fix Pop-ups & Emoji setting is addressed for apps without App Group support.
  • The story mark-seen menu no longer uses the previous account’s name and action state after moving between Stories.
  • Device ID masking includes a warning screen and How It Works page.

Installation and signing details

For jailbroken devices, the official instructions direct users to add the developer’s package source to Cydia, Zebra or Sileo and install Regram from there. The package metadata identifies the package as com.fouadraheb.regram.

For sideloading, the documentation provides builds for standard installation, a No-Plugins variant, a duplicate bundle and TrollStore. The standard and No-Plugins builds use com.burbn.instagram, while the duplicate uses com.fouadraheb.regram. The instructions say that no other Instagram app with the same bundle identifier should be installed when choosing a build.

The TrollStore instructions describe support for iOS 14 through 16.6.1 on iPhone X, A11 and older devices, and iOS 14 through 16.6 beta 1 on iPhone 11 and newer devices, as specified in the official README. The package depiction separately lists iOS 15.1+ under Supports, so the relevant method and device conditions should be checked before installation.

The documentation says that signing with a non-developer Apple account can cause an app to expire after seven days, while AltStore can automate re-signing when connected to a computer. It also states that push notifications generally require a Distribution or Ad-Hoc signing certificate, with TrollStore listed as an exception on supported devices. A paid certificate should use the original build and a Distribution or Ad-Hoc certificate for notifications, according to the installation notes.

  • Jailbroken installation uses a compatible package manager and the developer’s package source.
  • Sideloaded builds differ by bundle identifier and installation path.
  • The README specifies separate TrollStore device and iOS conditions.
  • Signing affects app expiry and push notification support.
  • The selected bundle identifier should not already be in use by another Instagram installation.

Frequently asked questions

What is Regram 6.2?

Regram 6.2 is an Instagram enhancement tweak for jailbroken or sideloaded iOS devices. The official description lists customization, privacy, media, Stories, Reels, messaging, profile-analysis and utility features.

Which Instagram version does Regram 6.2 target?

The release notes describe bug fixes and compatibility updates for Instagram 447. The official sideloading table lists Instagram 447.0 builds paired with Regram 6.2.

Does Regram 6.2 support jailbroken devices and sideloading?

Yes. The official documentation provides installation paths for jailbroken devices, AltStore-style sideloading and TrollStore on the specified supported iOS and device combinations.

Will profile spoofing change my real Instagram account?

The release notes say username and display-name spoofing remain on the device, the real account is untouched and Edit Profile continues to show the real values. The same page includes local controls for followers, following, posts and the verified badge.

Why might push notifications not work after sideloading?

The official documentation says sideloaded apps generally need a Distribution or Ad-Hoc signing certificate for push notifications, with TrollStore listed as an exception on supported devices. The selected build and signing setup should be checked before installation.
