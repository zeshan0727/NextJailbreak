Reo vs LSLyrics vs NextUp 3: Which Lock Screen Music Tweak Fits You?

Choose Reo for a redesigned player, LSLyrics for synchronized lyrics, or NextUp 3 for upcoming-track information and queue controls. They solve different jobs—and Reo 4.2.0 now lists NextUp3 as a dependency.

By Zeeshan Barvi · Published October 13, 2026 · Prices and releases checked against the official Havoc pages

Package compatibility is not jailbreak availability. These iOS ranges come from the package listings. Your exact device and firmware still need a compatible jailbreak, and rootless support does not make every listed iOS version jailbreakable.

Quick verdict

  • Choose Reo 4.2.0 when the main goal is a highly customizable, animated replacement for the stock Lock Screen player.
  • Choose LSLyrics 2.0 when time-synced lyrics, translation and lyric styling matter more than replacing the player itself.
  • Choose NextUp 3 1.2 when you want to see, skip, play or requeue the upcoming track across supported now-playing surfaces.
  • Do not treat Reo and NextUp 3 as mutually exclusive: Reo 4.2.0’s official changelog says it added NextUp3 as a dependency.

Reo: the full player redesign

Reo is the broadest visual overhaul of the three. Its official listing describes four player themes, artwork-based ColorFlow, separate maximized and minimized states, a seekable timeline, volume control, artwork backgrounds, glass or solid frames, notification positioning, Always-On Display behavior and detailed layout controls. It works with apps that feed the system Now Playing interface rather than being limited to one music service.

Version 4.2.0 also adds iOS 18 support, previous and next artwork inspired by the classic Flow tweak, Liquid (Gl)ass support, smoother animations and several layout fixes. The same changelog explicitly says NextUp3 was added as a dependency, so installing current Reo is not a decision to avoid NextUp 3.

Best for: users who want the Lock Screen player itself to look and behave differently. Read the dedicated Reo overview for more background.

LSLyrics: synchronized lyrics without a player replacement

LSLyrics focuses on the words behind the music. The listing says it can fetch time-synced lyrics for music players, including offline players, and lets you adjust position, size, color and opacity. It also offers artwork-aware ColorFlow styling, translation, animations and a two-finger fullscreen mode.

Version 2.0 adds SpicyLyrics, PetitLyrics and ListenBrainz sources, a dislike control for incorrect lyrics, translation outlines and chunk-based translation. The pinned setup note matters: playback timing can differ by device and player, so you may need to set the best delay manually in preferences.

Best for: people who want a karaoke-like Lock Screen and do not need to replace the entire Now Playing card. See our LSLyrics overview for the package-focused guide.

NextUp 3: queue context and controls

NextUp 3 adds an upcoming-track row to the system player on the Lock Screen, in Control Center and in the Dynamic Island. You can remove the next track, play it immediately, requeue the previous track, or use swipe gestures for queue actions. It also supports scrolling titles, per-app and per-surface toggles, accessibility features and 27 languages.

The tradeoff is app coupling. The developer lists the app versions used for YouTube Music, YouTube, Spotify and SoundCloud, and warns that future app updates can silently break those integrations until NextUp 3 is updated. SoundCloud also requires iOS 16.4 or later. Apple Music and Apple Podcasts are listed as fully supported without those third-party version targets.

Best for: users who care about what plays next and want queue control without a wholesale player redesign. Version 1.2 is free and open source; RootHide users are directed to the project’s GitHub releases for its separate build. Read our NextUp 3 1.2 update for the release changes.

Can you use them together?

Reo and NextUp 3 are designed to work together in the current Reo release because Reo 4.2.0 lists NextUp3 as a dependency. LSLyrics targets a different layer—the Lock Screen background—so its purpose does not duplicate either package.

That does not guarantee every three-way combination, theme or notification tweak will be conflict-free. Install from official sources, change one component at a time, and test music playback, notifications, AOD and respring behavior before adding another Lock Screen modification.

Compatibility and install checklist

  • Match the exact device, iOS build and jailbreak before buying; the package range alone is insufficient.
  • Use the official Havoc listings and the developer’s linked GitHub release for the RootHide-specific NextUp 3 build.
  • Check dependencies in Sileo or Zebra before confirming installation.
  • For NextUp 3, compare your third-party music-app version with the developer’s documented integration versions.
  • For LSLyrics, configure playback delay if the displayed line trails or leads the song.
  • For broader checks, use our jailbreak tweak compatibility checklist and Sileo vs Zebra comparison.

Bottom line: Reo changes how the player looks, LSLyrics changes what appears behind it, and NextUp 3 changes how much of the queue you can see and control. Pick by function—not by screenshot—and remember that current Reo already brings NextUp3 into its dependency chain.

Frequently asked questions

Which tweak is best for Spotify?

It depends on the goal. Reo supports Spotify through the system Now Playing interface, LSLyrics says all music players are supported, and NextUp 3 lists Spotify integration built against version 9.1.62. App updates can affect NextUp 3’s integration.

Is NextUp 3 included with Reo?

Reo 4.2.0’s changelog says NextUp3 was added as a dependency. The packages still have separate listings and separate functions.

Does LSLyrics need an API key?

No. The official listing says no API code or additional setup is required, though it recommends adjusting playback delay for the device and player.

Can iOS 26 users install all three?

No. The current Reo listing stops at iOS 18.7.9, while LSLyrics and NextUp 3 list iOS 26 ranges. Even for those two, a compatible jailbreak must exist for the exact device and firmware.
