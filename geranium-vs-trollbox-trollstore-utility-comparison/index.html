Geranium vs TrollBox: Which TrollStore Utility Should You Use?

Geranium is the maintained successor for location simulation, storage cleaning, daemon controls, Screen Time removal and supervision. TrollBox offers a broader legacy customization list, but its developer stopped development, archived the repository and tells users to move to Geranium.

By Zeeshan Barvi · Published October 26, 2026 · Verified against the current releases, tagged source and repository status

These are privileged system utilities. Cleaning caches, disabling daemons, removing Screen Time data, supervising a device or changing system presentation can cause data loss or broken services. Back up first, change one item at a time, and do not use supervision or Screen Time tools to bypass controls set by someone responsible for the device.

Quick answer

  • Use Geranium in 2026. Its latest release is 1.1.4 from July 4, 2026, and the developer still presents it as the supported TrollStore utility.
  • Do not start a new setup with TrollBox. Its final release is beta 0.2 from November 28, 2023; the repository is archived and the current README says development stopped.
  • Keep TrollBox only for a specific legacy tool you already understand. Some of its customization options were not carried into Geranium, but they now come without ongoing project support.
  • Neither app expands TrollStore compatibility. Geranium’s “iOS 15 or later” requirement still means the device must be on firmware and hardware that TrollStore actually supports.

Why Geranium is the current choice

The clearest signal comes from the developer, not a third-party download directory. The current TrollBox README says the project is canceled, development has stopped and users should use Geranium instead. GitHub also marks TrollBox read-only. Geranium, by contrast, received version 1.1.4 on July 4, 2026.

Release 1.1.4 adds altitude entry to LocSim, supports Chinese coordinates, updates translations and improves animation fluidity. The official release provides a single Geranium.tipa asset. Install it only from c22dev’s GitHub release, then open that file through TrollStore.

What Geranium actually includes

LocSim can save simulated-location bookmarks, import older Mika LocSim bookmarks and receive locations from Apple Maps. Version 1.1.4 adds altitude and Chinese-coordinate handling. Location simulation can affect navigation, Find My behavior and location-aware apps, so stop it when testing is complete.

Cleaner presents separate choices for Safari caches, general caches, OTA update caches and leftover app caches. The developer warns in the README that calculated sizes are not always accurate. Treat the estimate as guidance, not guaranteed recoverable space.

Daemon Manager can disable services the user chooses not to run. That is also the highest-risk everyday feature: an unfamiliar daemon may support notifications, accessories, networking or other background behavior. Record every change and re-enable the daemon first if a service stops working.

Screen Time removal and supervision make privileged account and device-management changes. Do not use them on a family-managed, school-managed or employer-managed phone without authorization.

What TrollBox still has that Geranium does not

TrollBox 0.2 lists carrier-name changes, passcode-key theming, gesture navigation for pre-iPhone X devices, lock-after-respring control, light/dark wallpapers, dock and Home Screen settings, Wallet image editing, custom fonts, custom Lock Screen text and camera-shutter sound control. Its final release also improved the LocSim picker and added TrollStore 2 support.

That larger checklist can make TrollBox look more capable, but “more features” is not the same as “better current choice.” The developer removed the separate TrollBox16 build in 0.2, warned that some DirtyCow changes in /System might fail on KFD devices, and later retired the project. There is no supported migration guarantee for every TrollBox customization.

If an existing TrollBox setup is stable, document what is enabled before removing it. Reverse risky system changes inside TrollBox where possible, reboot, then install Geranium separately. Do not assume deleting the old app reverses every change it made.

Compatibility is narrower than “iOS 15+”

Geranium’s README requires TrollStore 1.3 or later and iOS 15 or later “if TrollStore supports it.” Full TrollStore currently supports iOS/iPadOS 14.0 beta 2 through 16.6.1, iOS 16.7 RC build 20H18 and iOS 17.0. General iOS 16.7.x releases other than that RC and iOS 17.0.1 or later are outside the project’s documented CoreTrust support.

That means an app’s minimum deployment target is not proof that it can run on every newer iPhone. Check the TrollStore installation-method guide for your exact hardware and build. If the phone is already jailbroken and you are deciding between full TrollStore and its jailbreak package, read TrollStore vs TrollStore Lite.

Frequently asked questions

Is Geranium the official successor to TrollBox?

Yes in the practical sense used by the developer: TrollBox’s current README says development stopped and tells users to use Geranium instead. Both repositories are owned by c22dev.

Does Geranium include every TrollBox feature?

No. Geranium focuses on LocSim, Cleaner, Daemon Manager, Screen Time removal and supervision. TrollBox’s old list included more visual and system customizations.

Can Geranium run on iOS 18 or iOS 26 because it says iOS 15+?

Not through full TrollStore unless the exact firmware is supported. The minimum app target does not expand TrollStore’s CoreTrust compatibility.

Should I download TrollBox 0.2 from a mirror?

No. The official project is archived and points to Geranium. If you must preserve an existing legacy setup, use only the developer’s official release and understand that it is unsupported.

Is Geranium’s Cleaner guaranteed to recover the displayed amount?

No. The developer explicitly notes that calculated sizes are not always accurate.
