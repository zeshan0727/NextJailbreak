Apps listed here are privately signed for devices registered to the Next Jailbreak Apple Developer account. A device must be included in the provisioning profile embedded in the signed app.

Loading app catalog…
How it works: each app is signed with an Apple certificate and an Ad Hoc provisioning profile that contains the permitted device UDIDs. The website provides the OTA installation link; iOS enforces whether the signed app is allowed on that device.

Trust: with normal Ad Hoc distribution, the provisioning profile is embedded in the app and the registered UDID is the main authorization check. If iOS specifically shows a developer-trust prompt for a particular signing method, follow the device prompt under Settings → General → VPN & Device Management. Do not install or trust an unrelated profile.
