Jikan 1.0.2 Adds Swipe-to-Unlock Hiding and Expands Older iOS Support

The current Jikan release adds a switch to remove Apple’s Swipe to Unlock text, a Turkish translation and better behavior on older rootful systems. The complete update from 1.0.0 also includes iOS 14–15 date-row estimates, automatic estimator fallback, an iPad reset-crash fix and corrected RootHide helper setup.

By Zeeshan Barvi · Published October 9, 2026 · Updated October 24, 2026 · Verified against official Jikan 1.0.1 and 1.0.2 releases

Compatibility is environment-specific. Jikan publishes separate rootful, rootless and RootHide packages with an iOS 14.0 minimum. That does not establish jailbreak availability for every device or every firmware through the Havoc listing’s upper range.

What changed in Jikan 1.0.2

Developer waruhachi published Jikan 1.0.2 on October 20, 2026. Havoc lists the same current version with an October 21 date. The official 1.0.2 changelog is focused and specific:

  • Adds Hide Swipe to Unlock Text under Miscellaneous settings.
  • Adds Turkish language support.
  • Updates English, German, Swedish, Vietnamese and Turkish strings for the new option.
  • Improves rootful compatibility with older iOS versions.

The new hiding control changes only the Lock Screen’s instructional text. It does not change passcode, biometric or unlock behavior.

The important 1.0.1 changes are also included

Because the earlier article covered 1.0.0, moving directly to the newest 1.0.2 package also brings the larger 1.0.1 update released October 18:

  • Charging estimates can appear beside the Lock Screen date on iOS 14 and iOS 15, instead of limiting that layout to iOS 16 or later.
  • Jikan automatically chooses its own estimator when the Apple model’s required inputs are unavailable.
  • Manually choosing the Apple model without those inputs now produces a confirmation warning.
  • The Estimate Target icon is corrected on older iOS versions.
  • Resetting preferences no longer causes the reported iPad crash.
  • RootHide helper installation paths and entitlements were corrected.

Both calculations stay on-device. An estimate can still change with temperature, power-adapter output and foreground activity, so it should not be read as an exact completion time.

Lock Screen display choices

Jikan can show the estimate as a two-line Classic pill, a Progress Ring or a compact date-row item. Estimated Time is always included; wattage, temperature and battery voltage can be added to a tappable stack. Portrait and landscape positions are saved separately, and the pill can show a slow-charging warning or remain visible after the selected target is reached.

Version 1.0.2’s Swipe to Unlock control sits alongside Jikan’s existing option to hide the flashlight and camera quick-action buttons always or only while charging.

RootHide and older-iOS notes

The RootHide package is the official iphoneos-arm64e asset, not the ordinary rootless package renamed. The 1.0.1 fixes specifically adjust helper paths and entitlements for RootHide, so users on that environment should update instead of staying on 1.0.0.

For older rootful systems, 1.0.2 claims improved compatibility but does not list every device or jailbreak tested. The package’s iOS 14 minimum and the new iOS 14–15 date-row support are not proof that a jailbreak exists on every iOS 14/15 device.

ChargeLimiter sync is still estimate-only

If ChargeLimiter is installed, Jikan can import its configured percentage as the estimate target. Jikan does not enforce or stop charging itself. When the imported target is outside Apple mode’s five presets, the Jikan estimator is the suitable option.

Free GitHub build or paid Havoc build?

The developer says the free GitHub release and the $1.99 Havoc package have the same functionality, with no paid-only features. The Havoc purchase supports development. Use either official source; avoid repackaged DEBs and verify the filename and full digest shown on the GitHub release when downloading manually.

For safe package handling, follow our DEB installation guide for Sileo and check the package architecture before installing.

Should existing users update?

Yes, especially on RootHide, iOS 14–15 or an older rootful setup. The 1.0.1 compatibility and crash fixes are more important than the small 1.0.2 UI option. Users already stable on 1.0.1 gain the Swipe to Unlock toggle, Turkish localization and the latest rootful adjustments.

Frequently asked questions

What is new in Jikan 1.0.2?

A Hide Swipe to Unlock Text switch, Turkish localization, updated translations and improved compatibility for older rootful iOS versions.

Can Jikan now show the estimate beside the date on iOS 14 and 15?

Yes. That expansion arrived in 1.0.1 and is included in 1.0.2.

Does Jikan control the charging limit?

No. It predicts the time to a selected target. ChargeLimiter remains responsible for enforcing a limit.

Which package should RootHide users install?

Use the official iphoneos-arm64e asset. Do not install the conventional iphoneos-arm64 rootless build into RootHide.
