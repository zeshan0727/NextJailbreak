Jikan 1.0.0 Adds Lock-Screen Charge-Time Estimates and ChargeLimiter Sync

The open-source tweak puts an estimate-to-target pill or progress ring on the Lock Screen, with optional battery readings and separate builds for three jailbreak environments.

Published October 9, 2026 · Verified from the official Havoc listing, source repository and 1.0.0 release

Jikan 1.0.0 is now available for jailbroken iPhones and iPads. Developer waruhachi published the open-source GitHub release on October 6, 2026; its Havoc listing followed on October 9, 2026 at $1.99. The developer says the free GitHub and paid Havoc packages have the same features, with the store purchase offered as a way to support the project.

Compatibility boundary: Havoc lists iOS 14.0–26.0.1 and marks the package rootless, while the official GitHub release provides rootful, rootless and RootHide builds. That package range does not mean every device on those versions has an available jailbreak.

What Jikan adds to the Lock Screen

Jikan displays the estimated time remaining until a chosen battery target. The estimate can appear as a two-line Classic pill or a circular Progress Ring, and on iOS 16 or later it can use the date row and sit alongside an inline widget when space allows.

  • Choose any whole-number target from 1% to 100% with Jikan’s own algorithm.
  • Tap the pill to cycle through optional wattage, battery temperature and voltage readings.
  • Move the pill separately in portrait and landscape, lock an axis and adjust opacity.
  • Show a yellow indicator for slow charging and optionally keep the reached-target state visible.
  • Hide Lock Screen quick-action buttons always or only while charging.
  • Use Liquid Glass styling where the operating system supports it.

The tweak’s selected target is an estimate target, not a charging cutoff. Jikan does not change the phone’s charge limit.

Apple mode versus Jikan mode

ModeHow it estimatesTargetsImportant limit
AppleRuns reconstructed Apple iOS 26 Core ML model assets locally80%, 85%, 90%, 95%, 100%Needs compatible model files and battery telemetry; it does not call Apple’s Battery Intelligence service for live estimates
JikanLearns time-per-percentage from this device’s charging history and can fill gaps from live currentAny 1–100% targetSparse history relies more on an instantaneous-rate approximation, which cannot predict every future thermal or usage change

Both modes calculate on-device. The developer’s technical documentation says Apple mode was reconstructed from an iOS 26 investigation and also tested on an iOS 16.3.1 device. That is evidence about the estimator implementation, not a universal compatibility test for every device and jailbreak.

ChargeLimiter sync does not enforce charging

If ChargeLimiter is installed, Jikan can import its configured limit as the display target. Jikan still only predicts the time to that percentage; ChargeLimiter remains responsible for enforcement. A non-Apple preset target uses Jikan’s algorithm because Apple mode only supports its fixed target set.

Where to get Jikan 1.0.0

The safest sources are the developer’s official GitHub release and official Havoc listing. The GitHub release provides checksums for all three builds; verify the filename and digest if you download a DEB manually. The initial changelog is simply “Initial Release.”

Jikan is licensed under GPLv3 and supports English, German, Swedish and Vietnamese. Its package identifier is moe.waru.jikan.

Frequently asked questions

Does Jikan stop charging at the selected target?

No. It predicts time to the target. A separate tool such as ChargeLimiter would control charging.

Can Jikan run on every iOS 14–26.0.1 device?

No universal jailbreak exists across that full range. The package still needs a compatible jailbreak or RootHide environment for the exact device and firmware.

Are the free and paid builds different?

The developer says the GitHub and Havoc versions have the same functionality; the Havoc purchase supports development.
