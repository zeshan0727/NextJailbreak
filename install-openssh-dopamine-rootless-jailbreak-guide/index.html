How to Install OpenSSH and Transfer Files with SFTP on Dopamine

Set up the Procursus OpenSSH server on a supported Dopamine device, connect over a trusted local network, transfer files with SFTP or SCP, keep rootless paths and permissions intact, and diagnose the failures that commonly look like an SFTP problem.

By Zeeshan Barvi · Published October 22, 2026 · Updated November 20, 2026 · Verified against official Dopamine, Procursus, Theos and OpenSSH sources

Keep SSH local. Use a trusted private Wi-Fi network. Do not forward TCP port 22, expose the phone directly to the internet, or leave password access enabled with a weak credential.

Verified software and compatibility snapshot

Dopamine 3.0.13, released November 3, 2026, remains the current official release for this guide. Its 3.x README documents device-specific support: iOS 15.0–17.3.1 for arm64e, iOS 15.0–18.7.1 for documented arm64 and A12/A13 combinations, and iOS 26.0–26.0.1 only for the listed A12/A13 combinations. Installing OpenSSH does not expand those ranges.

The current public Procursus build recipe checked November 20 still pins OpenSSH 9.7p1-1. It builds separate client, server and SFTP-server packages with iOS-specific dependencies, launchd integration and rootless paths. Upstream OpenSSH 10.6p2 is newer, but its generic archive is not a replacement for a Procursus iOS package.

What installing OpenSSH adds

OpenSSH is not a jailbreak and it does not install tweaks. It adds remote shell and file-transfer services inside an already active jailbreak environment. Procursus defines openssh-server as depending on the matching OpenSSH client and openssh-sftp-server, along with required libraries.

The official Procursus installation script loads com.openssh.sshd.plist through launchd; its removal script unloads the daemon. This is why copying random binaries into /var/jb is not equivalent to installing the maintained package.

Before enabling remote access

  • Confirm the jailbreak is active: after a full reboot, run Dopamine again before expecting SSH or SFTP to answer.
  • Set a strong mobile password: use Dopamine Settings and follow the mobile and root password guide.
  • Use one trusted LAN: keep the iPhone and computer on the same private Wi-Fi network; guest networks often isolate clients.
  • Prepare a user-owned destination: transfer into the mobile account first rather than writing directly into the bootstrap.
  • Back up irreplaceable data: SFTP can overwrite files immediately and has no universal undo.

1. Install OpenSSH Server from Procursus

  1. Open Sileo or Zebra while Dopamine is active.
  2. Search for OpenSSH Server or package ID openssh-server.
  3. Verify that the source is the trusted Procursus repository used by the bootstrap.
  4. Review the transaction. The server should resolve the matching client and SFTP-server components.
  5. Install and allow every maintainer script to finish. Do not interrupt the launchd load step.

If Sileo shows an interrupted transaction or broken dependencies, repair the package state first with the dpkg and Sileo repair guide. Do not manually copy the daemon or its plist to work around a failed package installation.

2. Find the iPhone’s local address

Open Settings → Wi-Fi → tap the information button beside the connected network, then read the IPv4 address. A private address commonly starts with 192.168., 10., or 172.16 through 172.31. It may change when the phone reconnects.

This guide uses a same-network connection. Do not substitute the router’s public internet address.

3. Test SSH before configuring an SFTP app

From Terminal on macOS or another trusted OpenSSH client, connect as the normal mobile account:

ssh mobile@YOUR_IPHONE_IP

Replace the placeholder with the phone’s current private address. On the first connection, the client shows a host-key fingerprint. Accept it only when you initiated the connection to the correct device and address.

If this command fails, a graphical SFTP client will usually fail for the same underlying reason. Fix the jailbreak, network, daemon or credential issue before changing SFTP settings.

4. Connect with SFTP

OpenSSH’s official manual defines SFTP as file transfer over an encrypted SSH transport. The same iPhone address, mobile username, password or key, and normally TCP port 22 are used.

sftp mobile@YOUR_IPHONE_IP

Useful interactive commands include:

CommandPurposeSafe example

The OpenSSH manual warns that resumed transfers assume the existing partial file matches the source. Resuming against different content can create a corrupt result.

5. Configure a graphical SFTP client

FileZilla, Cyberduck, WinSCP and other reputable clients use the same connection fields. The labels differ, but the values should be:

  • Protocol: SFTP or SSH File Transfer Protocol—not plain FTP or FTPS.
  • Host: the iPhone’s current private IPv4 address.
  • Port: 22 unless you deliberately changed the server configuration.
  • Username: mobile.
  • Authentication: the strong mobile password initially, then preferably a protected SSH key.

Do not save a root password in a desktop client for routine file browsing. Start as mobile and elevate only a specific command when it is genuinely necessary.

6. Choose a safe destination

Create a dedicated transfer folder under the mobile account, for example inside /var/mobile/Documents. This separates incoming files from package-managed bootstrap content and makes cleanup easier.

The official Theos rootless documentation identifies /var/jb as the conventional rootless install prefix. That explains where jailbreak packages belong; it does not make the folder a safe general upload destination. Let dpkg and the package manager own package files.

7. Transfer a .deb without installing it blindly

Upload the file into the dedicated mobile-owned staging folder, then inspect its package name, architecture, dependencies and maintainer scripts before installation. A rootless Dopamine package normally uses the iphoneos-arm64 architecture; a rootful package is not made compatible merely by arriving over SFTP.

Use the .deb inspection guide and the tweak compatibility checklist before opening it in Sileo. SFTP verifies transport, not trust, compatibility or package safety.

8. Use SCP for a single scripted copy

Modern OpenSSH scp uses the SFTP protocol by default. A single upload can look like:

scp example.deb mobile@YOUR_IPHONE_IP:/var/mobile/Documents/

A download reverses the order:

scp mobile@YOUR_IPHONE_IP:/var/mobile/Documents/example.deb .

Quote paths that contain spaces. Avoid disabling strict checks or forcing legacy SCP unless a verified compatibility reason requires it.

9. Add a public key

Generate an Ed25519 key on the computer if you do not already have a suitable one:

ssh-keygen -t ed25519

Protect the private key with a passphrase. Never upload or share it. Copy only the public key to the mobile account:

ssh-copy-id mobile@YOUR_IPHONE_IP

Open a second session and verify that the key works before changing authentication settings. Keep the first working session open until the test succeeds.

Rootless is not RootHide

These path examples target conventional Dopamine rootless, where Theos documents /var/jb as the jailbreak prefix. RootHide uses a relocated, randomly named jailbreak root and RootHide-aware path translation. Do not paste /var/jb instructions into a RootHide environment or assume an ordinary rootless package is interchangeable.

Use the rootless vs rootful vs RootHide guide to identify the environment before transferring or modifying jailbreak files.

Remove remote access when finished

Disconnect every client, delete temporary staging files you no longer need, and remove openssh-server in Sileo or Zebra if you do not need ongoing remote access. Procursus’s official removal script unloads the launch daemon. Avoid deleting the plist or daemon by hand while leaving dpkg’s package state inconsistent.

Frequently asked questions

Which username should I use?

Use mobile for ordinary transfers. Upload to a mobile-owned staging folder and elevate only the specific action that needs additional privilege.

What port does SFTP use?

Normally TCP port 22, shared with SSH. Do not expose or forward it to the public internet.

Why does SFTP fail after a reboot?

Dopamine is semi-untethered. After a full reboot, reactivate the jailbreak before expecting rootless launch daemons and packages to work.

Can SFTP install a tweak?

No. It transfers the .deb. Inspect the package, confirm architecture and compatibility, then install it through Sileo or another appropriate package workflow.

Can I edit files in /var/jb?

Technically privileged access may allow it, but manual changes can conflict with dpkg ownership and break the bootstrap. Use the package manager for package files.

Does this work on RootHide?

Not as written. RootHide relocates its jailbreak root and requires RootHide-aware paths and packages.
