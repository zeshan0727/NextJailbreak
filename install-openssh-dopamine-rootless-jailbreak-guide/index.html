How to Install OpenSSH on Dopamine and Connect Safely

Install the Procursus OpenSSH server on a Dopamine rootless jailbreak, connect as mobile over a trusted LAN, add an SSH key, and remove remote access cleanly.

By Zeeshan Barvi · Published October 22, 2026 · Verified against official Dopamine, Procursus and OpenSSH sources

Use only a trusted local network. An SSH server accepts remote login attempts. Do not forward port 22, expose the phone directly to the internet, or leave password access enabled with a weak credential.

What the Procursus package installs

OpenSSH is not a jailbreak. It is a remote shell and file-transfer service inside an already active jailbreak environment. Procursus splits it into client, server and SFTP packages. Its openssh-server package depends on the matching client and SFTP components plus required libraries.

The official installation script loads com.openssh.sshd.plist with launchctl; the removal script unloads it. On a conventional rootless bootstrap, Procursus builds configuration and daemon paths under the bootstrap prefix rather than the stock system volume.

Do not download a random .deb or unpack an upstream OpenSSH tarball into /var/jb. Procursus applies iOS dependencies, signing, launchd integration and rootless paths that a generic build does not provide.

Before installing OpenSSH

  • Confirm Dopamine reports the device is currently jailbroken. After a full reboot, run Dopamine again before using jailbreak packages.
  • Use the current official Dopamine release when it supports your device and firmware. Version 3.0.12 is current for this guide.
  • Set a strong password for mobile in Dopamine Settings. Follow the Dopamine password guide first.
  • Connect the phone and computer to the same trusted Wi-Fi network. Avoid shared hotel, airport and café networks.

Dopamine’s project range is device-specific. Its 3.x README lists iOS 15.0–17.3.1 for arm64e, broader iOS 15.0–18.7.1 ranges for arm64 and certain A12/A13 combinations, and iOS 26.0–26.0.1 only for listed A12/A13 support. Package compatibility does not create jailbreak support for an unsupported device or firmware.

1. Install the server from Sileo or Zebra

  1. Open the package manager while Dopamine is active.
  2. Search for OpenSSH Server or package ID openssh-server.
  3. Verify the source is the trusted Procursus repository used by the bootstrap.
  4. Review the queued dependencies. The control file expects matching client and SFTP components plus Procursus libraries.
  5. Install and let every maintainer script finish. Do not interrupt the launchd load step.

If the package manager offers an openssh meta-package, the current Procursus source defines it as a dependency bundle for the client, server and SFTP server. Installing openssh-server directly is sufficient when the resolver pulls its required components.

2. Find the iPhone’s local address

Open iOS Settings → Wi-Fi → tap the information button beside the connected network, then read its IPv4 address. A private address commonly begins with 192.168., 10. or 172.16–172.31. It can change after reconnecting.

Do not publish the address or confuse it with a router’s public internet address. This guide covers same-LAN access only.

3. Connect as mobile

On the computer, open Terminal or another trusted OpenSSH client and run:

ssh mobile@YOUR_IPHONE_IP

Replace the placeholder with the phone’s private address. The first connection displays a host-key fingerprint. Accept it only if you initiated the connection to the correct local address. Enter the strong mobile password you set in Dopamine.

Use mobile for routine work. Avoid direct root login; elevate only commands that require it. The password guide explains the separate mobile and root credentials.

4. Add a key from the computer

Generate an Ed25519 key on the computer if you do not already have an appropriate key:

ssh-keygen -t ed25519

Protect the private key with a passphrase. Never copy or share it. If the computer includes ssh-copy-id, copy only the public key:

ssh-copy-id mobile@YOUR_IPHONE_IP

OpenSSH’s manuals document ssh-keygen and public-key authentication. Open a second terminal and verify a fresh key login before changing any authentication setting. Keep the first session open until the test succeeds.

Advanced manual setup should place one complete public-key line in the mobile account’s ~/.ssh/authorized_keys, keep ~/.ssh private and avoid editing unrelated system files.

5. Test SFTP

The server package depends on openssh-sftp-server, so a trusted SFTP client can use the same host, mobile account and key. Start in the mobile home directory; do not change bootstrap files unless you understand package ownership and permissions.

sftp mobile@YOUR_IPHONE_IP

Troubleshooting

SymptomCheck firstSafe next step
Connection refusedDopamine is active and openssh-server finished installing.Inspect the package state; do not manually copy daemon files.
Connection times outBoth devices share the same trusted LAN and peer isolation is off.Recheck the phone’s current local address.
Permission deniedThe username is mobile and the credential belongs to that account.Use Dopamine’s password control instead of weakening authentication.
Host key changedThe address may belong to another device, or the jailbreak environment was rebuilt.Verify the reason before removing the saved fingerprint.
SSH stops after rebootThe semi-untethered jailbreak is inactive.Run Dopamine, confirm jailbreak success, then retry locally.

Remove remote access cleanly

  1. Close SSH and SFTP sessions.
  2. Uninstall openssh-server in Sileo or Zebra.
  3. Review the removal queue; do not remove unrelated Procursus components.
  4. Let the removal script finish. Procursus’s official script unloads com.openssh.sshd.plist on removal or purge.

Removing the server stops inbound SSH. The separate client package may remain if another package depends on it or if you use the phone to connect outward.

What this guide does not claim

  • OpenSSH does not jailbreak a phone or expand Dopamine support.
  • An upstream release does not automatically become a compatible Procursus package.
  • Installing SSH does not make public internet exposure safe.
  • Key authentication does not excuse untrusted repositories or careless root commands.
  • This guide does not require disabling password authentication; verify key access and understand recovery before advanced changes.
