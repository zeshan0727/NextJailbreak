NowLyrics 1.0 Brings Synced Lyrics to the Lock Screen, Control Center and CarPlay

NowLyrics replaces the usual track-title line with the lyric currently being sung. The developer extends the same idea beyond the Lock Screen to Control Center, Dynamic Island and CarPlay, while keeping the actual artist or next lyric available as an optional secondary line.

By Zeeshan Barvi · Published October 1, 2026 · Package released September 28, 2026

What NowLyrics changes

When a supported music app publishes now-playing information, NowLyrics uses the track-title area to show line-synced lyrics. The official listing names the Lock Screen, Control Center, Dynamic Island and CarPlay as supported surfaces. This is a focused presentation tweak: it does not replace the full lyrics screen inside a music app, and the developer says the available sources provide line-by-line LRC timing rather than word-by-word animation.

The artist field can stay unchanged, show the normal track and artist credit, or display the next lyric line. A timing offset from minus three to plus three seconds can be adjusted with a slider or entered precisely, including values such as 0.25 seconds or −300 milliseconds. That should be useful when a lyrics file is consistently early or late rather than incorrectly matched.

Supported music apps and lyric sources

The developer lists full support for Spotify and Apple Music. YouTube Music, KKBOX, SoundCloud, TIDAL, Deezer and Amazon Music work through the system’s now-playing information. Other players may also work when they publish compatible metadata, and the preferences include an app picker.

NowLyrics can query LRCLIB and NetEase Cloud Music without an account. Musixmatch is also supported, but it requires the user’s own token or API key. A preferred service can be selected, with the other services used as fallbacks when the first source has no result. The listing notes that NetEase lyrics remain in Simplified Chinese without conversion.

Manual lyrics, caching and privacy

A manual .lrc file placed in the app’s Library/NowLyrics/manual/ folder takes priority over online results. Fetched lyrics are cached per app, and the preferences include a cache-clearing control. The developer also includes a diagnostic mode that identifies which lyrics source responded.

According to the official listing, only the track title, artist, album and duration are sent to lyrics services. A Musixmatch token remains stored on the device and is sent only to Musixmatch. The developer says the tweak does not require an account and does not include analytics. These are developer disclosures from the package page, not an independent code audit.

Compatibility and important limits

Havoc lists NowLyrics 1.0.0 for iOS 15.0–26.0.1, priced at US$1.99. The package is rootless only, built for arm64 and arm64e, and the developer specifically names Dopamine and palera1n. The preferences were verified by the developer on iOS 16.5, while newer iOS testing used Spotify on virtual devices.

The listing says NowLyrics cannot be installed alongside AMLyrics because both modify the same Apple Music item. Remove the conflicting package before installation rather than forcing both into the same environment. Package compatibility also does not prove that every device on every listed iOS version has an available jailbreak; confirm your device and jailbreak separately.

What to check after installation

Start with one music app and leave the offset at zero. Confirm that the correct song is identified, that lyric lines advance, and that the normal title returns when playback stops. Then check the Lock Screen and Control Center before enabling more players. If the timing is consistently wrong, adjust the offset in small steps rather than compensating for a badly matched song.

For Apple Music users, the developer lists one known behavior: the lyric line also appears inside Music’s own now-playing views. If that is undesirable, it is a product limitation in version 1.0.0 rather than a setting documented on the listing.
