InfoBar 1.3.0 Adds 13-Language Settings to the iOS System Monitor Overlay

InfoBar 1.3.0 makes its Settings bundle follow the device language across 13 localizations, one day after the free rootless system monitor reached Havoc.

Published October 7, 2026 · Verified from the developer release, source tree and official Havoc listing

InfoBar 1.3.0 was released by developer Mathelord on October 7, 2026. Its focused change is localization: the Settings bundle is now translated into 13 languages and follows the device language. The underlying tweak remains a movable SpringBoard overlay for CPU, memory, battery, network and system information.

Version note: Havoc still showed InfoBar 1.2.0 when this article was checked, but the developer’s official GitHub release page already had the newer 1.3.0 package. This article therefore covers 1.3.0 and links to the current developer release.

What changed in InfoBar 1.3.0

The official 1.3.0 release note contains one change: Settings are translated into 13 languages and automatically follow the device language. The developer published the release at 14:07 UTC on October 7, with an iphoneos-arm64 Debian package and a recorded SHA-256 digest of 6583cc01365707be26425857bc7a0739751b36e478f28d021d169d6c48a85af8.

This is a small update, but it lands immediately after the first public Havoc listing and replaces 1.2.0 as the newest official version. No performance, compatibility or monitoring changes are claimed in the 1.3.0 changelog.

What InfoBar shows

ModuleDeveloper-documented values
CPUUsage, clock speed, chip and core count; list view separates performance and efficiency cores
RAMUsage percentage and used/total memory
BatteryCharge, temperature, power, current, voltage, charger wattage, health and cycles
NetworkWi-Fi and cellular transfer speeds plus Wi-Fi IP address
SystemTime, free storage, uptime and thermal state

The overlay can be dragged and pinned, collapsed to a smaller readout, or switched between row and list layouts with a double tap. The source documentation says touches beside the overlay pass through to the app underneath.

Settings and runtime behavior

InfoBar’s PreferenceLoader panel controls the pin and collapse buttons, lock-screen visibility, landscape hiding, update interval, icon or text labels, threshold colors, blur, typography, opacity, corner radius and individual modules. The README says changes apply immediately without a respring.

The project also says monitoring stops while the display is off. CPU clock data is read through private IOReport interfaces and the device-tree DVFS table where available; a timing-loop estimate is used as a fallback and marked with a tilde. Battery values come from AppleSmartBattery, while the memory calculation follows the app-memory, wired-memory and compressed-memory approach documented in the project.

Compatibility: package range is not jailbreak availability

Havoc lists InfoBar for iOS 15.0 through 18.7.1 with rootless support. The tagged 1.3.0 Makefile targets iOS 15.0 and builds arm64 plus arm64e, while the control file requires MobileSubstrate, PreferenceLoader and firmware 15.0 or newer. The README specifically describes rootless jailbreaks such as Dopamine and says the release workflow supplies a modern arm64e build for A12 and newer devices.

Important: that firmware range describes the package, not a universal jailbreak. Your exact device and iOS version still need a compatible rootless jailbreak. InfoBar does not add jailbreak support to iOS versions or hardware that lack it.

The repository documents an optional RootHide build command, but the public 1.3.0 release asset is named as a rootless iphoneos-arm64 package. Treat RootHide as a separately built variant rather than assuming the downloadable release asset matches that environment. Our rootless, rootful and RootHide guide can help identify the active setup.

How to install InfoBar 1.3.0

  1. Open the official InfoBar 1.3.0 release.
  2. Download the developer’s com.mathelord.infobar_1.3.0_iphoneos-arm64.deb asset.
  3. Install it with Sileo, Zebra or Filza in a compatible rootless jailbreak. Your package manager should resolve MobileSubstrate/ElleKit and PreferenceLoader.
  4. Respring, then open Settings → InfoBar to enable and configure the overlay.
  5. Start with a slower update interval and only the modules you need, then adjust placement and visual options.

If you prefer a repository installation, the official Havoc page is the package source, but verify that it shows version 1.3.0 before installing. At the time checked, Havoc was still serving the earlier 1.2.0 listing.
