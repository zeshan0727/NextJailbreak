PS5 Relapse Jailbreak Officially Released for Firmware 7.00–13.60

Relapse Exploit is now officially public. The developer's repository lists PlayStation 5 firmware 7.00 through 13.60 as supported and provides three official access methods: a recommended DNS, an official GitHub Pages host, or a locally hosted copy.

Release confirmed: the official source is ntfargo/Relapse-Exploit on GitHub. The README explicitly lists PS5 firmware 7.00–13.60. Use the developer-controlled source rather than copied mirrors.

Relapse Exploit is officially public

The PS5 jailbreak that had been waiting on the end of firmware 13.60 PSN access is now publicly available. The official project is named PS5 Relapse Exploit and is hosted by ntfargo.

This moves the story beyond final checks. Users can inspect the source, use the official hosted exploit page, or run the project locally. The release is not limited to 13.60: the official compatibility statement covers firmware 7.00 through 13.60.

Supported PS5 firmware

  • Supported: PS5 firmware 7.00 through 13.60.
  • Maximum currently listed: 13.60.
  • PS5 14.00: not listed as supported.

If your console is already below 13.60, do not update just to reach 13.60. Staying on a lower firmware generally preserves more exploit options.

Official Relapse GitHub and hosted exploit

The project provides both the source repository and an official GitHub Pages host. Next Jailbreak does not mirror the exploit files.

Recommended DNS method

The current official README recommends setting the PS5 Primary DNS to:

45.56.67.85

Because DNS services can change, recheck the official README before using the value at a later date.

Local hosting method

Users who prefer to keep the exploit files on their own network can download or clone the official repository and run the included server with:

python serve.py

The official GitHub Pages version is also available for users who do not want to host the files locally.

ELF loader and payload flow

After a successful run, the README says the ELF loader listens on port 9021. Default payloads are stored in the project's payloads/ directory.

Once elfldr starts, the documented R2 flow can send:

  • kstuff.elf
  • shadowmountplus.elf
  • etaHEN.elf

Payload compatibility can still vary by firmware. Relapse provides the exploit and loader path; it does not automatically make every payload compatible with every supported PS5 version.

How the exploit chain works

The official technical summary says the browser stage uses JavaScriptCore information leaks together with a structured-clone object-pool mismatch to corrupt a typed array. The kernel stage then combines an address leak with an aio_multi_wait use-after-free race to establish kernel read/write.

Stability notes from the developer

The WebKit stage may require several attempts. If the browser stalls, reload and try again. The kernel exploit may also hang or panic the console; the developer recommends rebooting before retrying after that occurs.

Does Relapse support PS5 14.00?

Not according to the current official README. The listed compatibility range ends at firmware 13.60. Users preserving a jailbreak-capable console should not update to 14.00 expecting this exploit to work.

Does this mean full hypervisor access?

No. The Relapse project describes a browser and kernel exploit chain. It does not claim universal hypervisor exploitation for every firmware from 7.00 through 13.60. Kernel jailbreak access, payload support and hypervisor exploitation are separate technical layers.
