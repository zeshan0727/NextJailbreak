PS5 Relapse Update Removes Incompatible Payloads and R2 Auto-Load Flow

Relapse still lists PS5 firmware 7.00 through 13.60, but its post-release shape has changed. The official repository removed three bundled payloads and the R2 auto-send mechanism after identifying compatibility problems, then simplified the current usage notes.

By Zeeshan Barvi · First published September 29, 2026 · Updated October 2, 2026

Important correction: earlier instructions on this page described an R2 shortcut that sent kstuff.elf, shadowmountplus.elf and etaHEN.elf. The project removed that flow and those bundled files on September 29 because of compatibility issues. Do not follow cached copies of those withdrawn steps.

What the official project removed

Commit a4c6f3e, dated September 29, 2026, is explicitly titled “remove compatibility issue payloads.” It deletes payloads/etaHEN.elf, payloads/kstuff.elf and payloads/shadowmountplus.elf. The same commit removes the code that waited for an R2 press and automatically sent those three files to the ELF loader.

This is not a cosmetic documentation edit. The payload files, the socket-send helper and the controller shortcut were removed together. Readers should therefore treat any video, mirror or guide that still says “press R2 to load kstuff, shadowmountplus and etaHEN” as describing an earlier repository state.

What remains in the current repository

The current README continues to list PlayStation 5 firmware 7.00 through 13.60. It says the included ELF loader listens on port 9021 after a successful run and warns that the WebKit stage may need multiple attempts. The kernel stage may hang or panic the console; the developer advises rebooting before another attempt when that happens.

The repository’s present payloads/ directory contains elfldr-ps5-1360.elf and kexp_2026_05_25.bin. The three compatibility-problem payloads named above are no longer bundled. That distinction matters: Relapse providing a loader does not guarantee that every third-party payload is compatible with every firmware in the stated exploit range.

DNS and hosted instructions were also removed from the README

On September 30, commit dd8e4e0 removed the previous DNS recommendation and the line directing users to the GitHub Pages host or python serve.py. The current README now limits its usage section to the payload directory and port 9021 statement.

This change does not by itself prove that every older access method has stopped working. It does mean those directions are no longer present in the developer’s current instructions, so Next Jailbreak is not presenting the old DNS value or hosted route as the recommended method. Check the official repository before relying on copied setup details.

Firmware support did not expand

  • Current listed range: PS5 firmware 7.00–13.60.
  • Firmware 14.00: not listed as supported.
  • PS5 Pro: the current README does not provide a separate compatibility claim.

A firmware number inside the stated range means the exploit project lists that software version. It does not promise identical stability, automatic payload compatibility or hypervisor access on every console. Relapse describes a browser and kernel exploit chain; it does not claim universal hypervisor exploitation across the range.

How the project describes the exploit chain

The official README says the browser stage uses JavaScriptCore information leaks and a structured-clone object-pool mismatch to corrupt a typed array. The kernel stage combines an address leak with an aio_multi_wait use-after-free race to establish kernel read/write.

The repository credits Sonic_Iso for the kernel exploit, Jordy for the WebKit exploit and kernel bug, ntfargo and ufm42 for exploit development, and Dr. Yenyen for testing, with additional contributors listed in the README.

Practical advice for owners preserving a console

Do not update beyond a firmware you are intentionally preserving, and do not assume an unofficial mirror reflects the current source tree. Before following a guide, compare its payload names and steps with the latest official commit. If it still instructs the removed three-payload R2 sequence, it is outdated.

Expect instability and keep important data backed up. The maintainers describe possible browser stalls, kernel hangs, console panics, data loss and account-ban risk. Use the research project only on hardware you own or are authorized to test, and do not use it for piracy or unauthorized access.

Original source and update trail

The authoritative source is ntfargo/Relapse-Exploit. For the exact changes discussed here, see the payload-removal commit and the later README simplification.
