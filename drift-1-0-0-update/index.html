Drift 1.0.0 Expands the iOS Dock to Hold up to 50 Apps and Folders

Drift 1.0.0 is a new commercial jailbreak tweak from Antony .M that removes the stock dock’s four-app limit. It places apps and folders in a single horizontally scrollable row, while retaining stock-like spacing and support for normal edit-mode actions. The tweak is listed for jailbroken iPhone, iPad, and iPod touch devices running iOS 15.0 through 26.0, with iOS 15.0 also specified as its package-level minimum firmware requirement.

Key points

  • Drift 1.0.0 is the tweak’s initial release and is priced at $0.99 on the official Chariz listing.
  • The dock can contain up to 50 apps and folders, according to the developer’s feature list.
  • Users swipe left and right to move through the dock, with an option to snap to complete icons at the edges.
  • Edge effects include fading, shrinking, or no effect, and optional haptic ticks can signal icons passing the edge.
  • Dragging an icon toward either end scrolls the dock during the action, while edit mode continues to support rearranging and removing apps.
  • The official listing says Drift supports jailbroken iPhone, iPad, and iPod touch devices running iOS 15.0–26.0.

What Drift 1.0.0 changes

Drift 1.0.0 is designed for users who want more room in the iOS dock without giving up the familiar dock layout. The official description says it allows users to place as many apps as they like in the dock and browse them by swiping left or right. The accompanying feature list defines the practical limit as up to 50 apps and folders.

Instead of displaying only the conventional four dock positions, Drift presents the contents as one horizontally navigable row. The listing says the spacing remains the same as the stock dock, so the central idea is capacity rather than a completely different dock design. Version 1.0.0 is identified as the initial release, meaning the available feature set is the starting point for the tweak rather than a later expansion.

  • Up to 50 apps and folders in the dock.
  • Horizontal left-and-right navigation.
  • Stock-style icon spacing.
  • Initial release from Antony .M.

Scrolling, snapping, and edge behavior

The dock is navigated with horizontal swipes. Drift also includes a “Snap to Icons” behavior: the dock comes to rest with a whole icon at each end. This is intended to keep the visible layout aligned rather than stopping at an arbitrary partial-icon position.

The developer also lists configurable edge presentation options. Icons can fade or shrink as they enter or leave the visible area, or users can choose neither effect. Optional haptic ticks can play as icons pass the edge. The source describes these as features, but it does not specify separate preference names, intensity controls, or which devices provide the haptic feedback.

The interaction model extends to icon movement. According to the official listing, dragging an icon toward either end causes the dock to scroll along with the gesture. That may make rearranging a large dock more practical than repeatedly scrolling and repositioning icons, although the source does not provide a detailed interaction walkthrough.

  • Snap alignment keeps a complete icon at each end.
  • Edge icons may fade, shrink, or remain unchanged.
  • Haptic edge ticks are optional.
  • Dragging toward either end scrolls the dock during the gesture.

Edit mode and removal behavior

Drift’s listing says it works in edit mode, allowing users to rearrange and remove apps as usual. This is important because a larger dock would be less useful if its contents could not be managed through familiar system behavior.

The developer also describes what happens when Drift is removed: apps that do not fit in a regular dock return to the Home Screen. That statement addresses the contents beyond the standard dock capacity, but it does not describe whether the original order is preserved or how folders are handled during removal. Users who have heavily customized their dock should therefore review the tweak’s current support information before uninstalling it.

The listing says changes apply instantly and do not require a respring. This is a specific claim about applying configuration or layout changes; it should not be read as a general guarantee that every related jailbreak change or another installed tweak will behave without a respring.

  • Edit mode supports rearranging and removing apps as usual.
  • Apps that do not fit in a regular dock return to the Home Screen if Drift is removed.
  • The developer says changes apply instantly without a respring.

Compatibility and package requirements

The official Chariz product page lists support for iPhone, iPad, and iPod touch running iOS 15.0 through iOS 26.0, and states that a jailbreak is required. The package stanza separately declares firmware version 15.0 or newer as a dependency and identifies the package architecture as iphoneos-arm.

The package also lists MobileSubstrate and PreferenceLoader as dependencies. Those requirements matter when evaluating installation readiness: meeting the stated iOS range alone does not establish that a particular jailbreak environment, package manager, or substrate setup will support the tweak. The supplied source does not name specific jailbreak tools, device models, rootful or rootless packaging modes, or processor-generation limitations.

Drift is listed as version 1.0.0, with an installed size of 411 KB and a download size of 27,824 bytes in the package metadata. The official sales page lists a price of $0.99 in U.S. dollars and notes that sales tax may apply depending on location.

  • Listed compatibility: iPhone, iPad, and iPod touch on iOS 15.0–26.0.
  • Jailbreak required.

What to check before installing

Before purchasing or installing Drift, readers should compare their exact device and iOS version with the official compatibility statement rather than assuming that every jailbroken device in the broad iOS range is supported. The package metadata and product page agree on an iOS 15.0 minimum, while the product page provides the upper bound of iOS 26.0.

It is also worth checking whether the current jailbreak environment provides the package dependencies named by the official package record. The supplied materials do not provide a troubleshooting matrix for missing dependencies, conflicts with other dock or Home Screen tweaks, or behavior on specific device families, so those details should be confirmed through the developer’s current support channels or package documentation before installation.

Finally, users should distinguish Drift from the unrelated Dart and Flutter persistence library named Drift in the supplied source material. The iOS package is identified as com.antonym.drift and is sold by Antony .M, while the software repository describes a reactive SQLite-based library for Dart and Flutter. The shared name does not indicate that the two projects are connected.

  • Confirm the exact iOS version and device against the official listing.
  • Check that the required substrate and preference components are available in the jailbreak environment.
  • Look for current developer guidance about conflicts with other dock customizations.
  • Do not confuse the iOS tweak with the separately named Dart and Flutter software project.
