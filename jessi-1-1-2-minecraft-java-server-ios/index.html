JESSI 1.1.2 Adds Jailbreak Packages for Native Minecraft Java Servers on iPhone

Baconium’s JESSI runs Minecraft: Java Edition servers directly on an iPhone or iPad. Version 1.1.2 adds proper package-manager installation for jailbroken devices, PumpkinMC server and plugin tools, and a more general JIT-connection check.

By Zeeshan Barvi · Published October 10, 2026 · Verified against the official GitHub release, tagged source and Havoc package data

Compatibility needs three separate checks: JESSI targets iOS 14 or later, the new DEB must match the active rootful, conventional rootless or RootHide environment, and the app still requires JIT. Havoc’s iOS 14.0–26.0.1 package range does not prove that every device in that range has a compatible jailbreak or JIT method.

What changed in JESSI 1.1.2

Baconium published JESSI 1.1.2 on October 6, 2026. The official changelog names five changes:

  • Proper jailbreak support: jailbroken users can install JESSI through a package manager instead of first installing TrollStore or TrollStore Lite.
  • PumpkinMC support: the release can create or run PumpkinMC servers, while the developer still marks JIT as required.
  • PumpkinMC plugin downloads: plugin acquisition is integrated into the app.
  • Plugin permission management: JESSI now exposes controls for PumpkinMC plugin permissions.
  • Revised JIT detection: the built-in enabler probes for a loopback VPN connection instead of depending specifically on LocalDevVPN.

Havoc added the free package as version 1.1.2-1 on October 10 in Qatar, identifying it as com.baconmania.jessi. The store listing calls it rootless and lists iOS 14.0 through 26.0.1. The developer’s GitHub release additionally supplies three separate jailbreak DEBs plus the regular IPA.

JESSI is a server host, not a Minecraft client

JESSI’s name expands to “Java Edition Servers Suck on iOS.” It embeds the tools needed to run a Minecraft: Java Edition server process on the iPhone or iPad; it is not a replacement game client and it does not include a Minecraft license. Players still connect with compatible Minecraft clients under Mojang and Microsoft’s normal licensing terms.

The app’s current feature list includes built-in downloads for Java 8, 17, 21 and 25, a memory-allocation slider, guided server creation, a file manager, server configuration controls, Modrinth and CurseForge content downloads, playit.gg or UPnP networking, resource-pack merging, and an optional keep-alive workflow for running with the display off.

Those are developer-documented features, not a guarantee that every server jar, modpack or player count will perform well on every iPhone. Available RAM, heat, storage, the selected Java version and the server software all affect real-world behavior.

JIT is still required

The official README says JESSI requires JIT on both jailed and jailbroken iOS. Version 1.1.2 improves how its built-in enabler recognizes the loopback VPN connection; it does not remove JIT from the requirements.

JESSI advertises an automatic JIT enabler for iOS 17.4 or later, but the exact preparation still depends on the installation route and firmware. Its LiveContainer instructions say to launch JESSI without JIT first, import the pairing file into JESSI, and enable LiveContainer’s file-picker fix if the picker cannot reach that file. A pairing file is device-specific and should not be shared publicly.

TrollStore can simplify installation on supported CoreTrust firmware, but TrollStore availability does not extend beyond its own official version range. Likewise, a DEB package does not create a jailbreak on unsupported devices. Check the exact device, firmware, jailbreak and JIT route before downloading large JVM or server files.

Creating a server in JESSI

The official interface separates server creation from launch and management:

  1. Install the JVM version required by the intended server software.
  2. Create a server and select the supported server software and Minecraft version.
  3. Choose the RAM allocation conservatively; JESSI’s own screen recommends leaving memory available for iOS.
  4. Set player count, view distance, simulation distance, whitelist and world options.
  5. Start the server from the Launch tab and watch the Java console for completion or errors.
  6. Use playit.gg, UPnP or a network configuration you understand before inviting remote players.

A server exposed beyond the local network creates the usual security responsibilities. Use a whitelist, keep server software and plugins updated, do not publish administrator credentials, and understand what the selected tunneling service makes reachable.

Limits to understand before installing

  • Jailed process limit: the README says the JVM must currently run inside the app process on jailed iOS. Stopping a server or completing some Forge/NeoForge setup operations can therefore close the app, although the developer says the server data is preserved.
  • JIT setup: JIT must remain available through a compatible method. Installing the app or DEB alone is not enough.
  • Memory and heat: an iPhone is not a dedicated server. Large worlds, view distances and modpacks can exceed practical memory or thermal limits.
  • Networking: playit.gg and UPnP are convenience options, not a substitute for access control and safe plugin configuration.
  • Compatibility: “iOS 14+” describes the app target. Jailbreak, RootHide, TrollStore and automatic-JIT availability each have their own narrower device and firmware boundaries.

Where to download JESSI safely

Use the official JESSI 1.1.2 GitHub release for the signed release assets and changelog. Jailbroken users can also use the free official Havoc package. Avoid repackaged IPAs or DEBs because JESSI handles server files, plugins, network tunnels and device-specific pairing data.

The project is open source under the GNU AGPLv3 license. Its official repository is Baconium/JESSI, and the package identifier is com.baconmania.jessi.

Frequently asked questions

Does JESSI 1.1.2 remove the need for TrollStore on a jailbreak?

It adds proper package-manager installation through environment-specific DEBs, so a jailbroken user no longer needs TrollStore solely to install JESSI. The app still requires JIT according to the official README.

Can JESSI run a Minecraft Java server on every iOS 14–26 device?

No. That is the package’s advertised version span. The exact device still needs a compatible installation environment, JIT method, enough resources and server software that works with the chosen Java version.

Does JESSI include Minecraft Java Edition?

No. JESSI hosts server software. It does not replace the Minecraft client or a game license.

Which build should RootHide users install?

The official release names the iphoneos-arm64e DEB, and the tagged script maps that package to its RootHide scheme.
