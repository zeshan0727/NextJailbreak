Watusi 1.0 Rebuilds WhatsApp Tweak Around Media, Privacy and Account-Level Settings

Watusi for WhatsApp has reached version 1.0 with a substantial rebuild rather than a routine package update. The official package description lists iOS 15.1 or later as supported, while the release notes identify support for WhatsApp 26.44, WhatsApp Business and multiple accounts. The update adds or rebuilds major areas including video-call recording, sticker creation, message history, storage management, a Media Vault, themes, scheduling, auto-replies, privacy controls and account-specific settings.

Key points

  • Watusi 1.0 is described by its developer as rebuilt from scratch and released on November 11, 2026.
  • The package metadata lists firmware 15.1 or later, MobileSubstrate 0.9.5000 or later and the libmryipc dependency.
  • The release notes name WhatsApp 26.44 and WhatsApp Business as supported, with data kept separately for multiple accounts.
  • New headline features include video-call recording, Sticker Studio, Sticker Gallery, message history, Storage tools and Media Vault.
  • The release also rebuilds themes, Hide Chats, Passcode Lock, Message Scheduler, Auto Reply, Chat List Filters, Contacts Spoofing and settings.
  • The official installation guidance distinguishes jailbroken packages, standard sideloaded builds and TrollStore builds; signing and entitlement requirements differ between them.

A major release rather than a minor compatibility patch

Watusi 1.0 is presented as a new foundation for the WhatsApp tweak. The official release notes describe it as rebuilt from scratch and say that Stalky, OnlineNotify and ContactSync are now included. Those components are identified respectively as Updates Tracking, Online Activity and Contact Photos Sync.

The package was released on November 11, 2026. Its package metadata identifies the product as “Watusi for WhatsApp,” version 1.0, with an installed size of approximately 23.7 MB and a download size of about 5.96 MB in the accompanying depiction. The package is marked for iOS devices using the iphoneos-arm architecture.

The official package information lists iOS 15.1 or later as the supported firmware level. It also lists MobileSubstrate 0.9.5000 or later and the developer’s interprocess-communication library as dependencies. Those requirements matter primarily to jailbroken users: a sideloaded IPA follows a different signing and entitlement path than a package installed into a jailbreak environment.

WhatsApp and account compatibility

The release notes state that Watusi 1.0 supports WhatsApp 26.44 and WhatsApp Business. They also describe support for multiple accounts, with each feature keeping its data per account. That detail is particularly relevant for users who rely on more than one WhatsApp identity or use both standard WhatsApp and WhatsApp Business.

The supplied official README lists Watusi 3 version 1.3.31 builds paired with WhatsApp 26.44.72. The tables include standard WhatsApp, WhatsApp Business, duplicate bundle variants and TrollStore-specific builds. The README also says some releases are first made available for jailbroken devices and later for sideloading, so users should compare the WhatsApp version, Watusi version and installation method before updating.

The source does not claim that every historical WhatsApp release is compatible with Watusi 1.0. Users should therefore treat the named WhatsApp 26.44 and WhatsApp Business combinations as the relevant compatibility information, rather than assuming that an older or newer WhatsApp build will behave identically.

Recording, stickers and media management

Call Recording is expanded to video calls. According to the release notes, recordings keep the user and the other participant separate and include a new player, editor and export workflow. Recording another person’s call may have legal or consent implications, so users should check the rules that apply where they live and inform participants when required.

Sticker Studio can create regular and animated stickers from photos, videos, GIFs, text or drawings. The release notes also mention background removal and sticker packs that remain synchronized with WhatsApp. A separate Sticker Gallery stores stickers sent or received and adds search, favorites and collections.

Watusi also adds a Storage area designed to show what is using space across WhatsApp. The listed tools include Largest Files, a file browser, Clean Up and Auto Clear. Media Vault provides a separate place for photos, videos and audio from chats, with folders, smart folders, locked folders, imports from Photos or Files, editing tools and file information.

Media handling is extended with Send Audio, which can send an audio file from Files or Media Vault or extract the sound of a video from Photos. Upload to Video Note can send a video as a video note, with trimming and framing controls.

Privacy, history and everyday controls

The release adds Message History for deleted and edited messages and their media. The developer says that this history is kept by Watusi and can survive relinking or restoring WhatsApp. This is a storage and privacy-sensitive feature: users should understand where retained message data is kept and who could access it before enabling it.

The update adds Quick Controls, Message Info, Keep Disappearing Messages, Filter Statuses, Hide Last Seen When Closed and a Forwarded Label Button. Message Info includes a “Send Receipts Now” action for sending a read receipt for one message. A Last Seen display can appear beneath chats in the chat list in three formats.

Existing privacy and protection areas remain central to the package description. They include controls for last-seen visibility, read receipts, typing and recording indicators, delivery receipts, internet access, incoming calls, app protection, chat protection and hiding the last message. The package also lists private notifications, hidden chats and passcode protection.

The source describes Background Mode settings called System, Audio and Location, allowing users to choose how WhatsApp stays alive. Because these modes can affect battery use, location access and notification behavior, readers should review the relevant iOS permissions rather than enabling a mode without checking its implications.

Themes, automation and rebuilt settings

Watusi 1.0 rebuilds Themes so they can be applied instantly, per account, per chat or on a schedule. The listed theme options include custom fonts, wallpapers, Pure Black and a theme library. The release also says Watusi screens follow WhatsApp’s visual language and the selected theme in both light and dark modes.

Several major utilities are described as rebuilt: Hide Chats, Passcode Lock, Message Scheduler, Auto Reply, Chat List Filters and Contacts Spoofing. The release notes also mention rebuilt My Status Archive with Insights and People, plus Updates Tracking and Contact Photos Sync that work on linked devices.

Settings receive a new layout with search, profiles per account, a Backup Center with Google Drive and a Tab Bar editor with live preview. New Shortcuts and Links can open Watusi screens or toggle settings from Apple’s Shortcuts app. Ready-made themes, tones and sticker packs can be installed through new libraries.

Custom Tones now includes a tone library, trimming, recording and the ability to take a tone from a video. Polls gain Poll Insights, a list of people who have not voted with a Remind action, a full vote log, templates and result sharing.

Installation paths and checks before updating

The official README provides separate instructions for jailbroken devices, ordinary sideloading and TrollStore. Jailbroken users are directed to add the developer’s package source to a compatible package manager and install Watusi there. The package metadata identifies conflicts with several older Watusi package identifiers, so an existing conflicting Watusi installation should be checked before proceeding.

For standard sideloading, the README lists IPA builds with the Plugins folder removed and fixes intended to avoid crashes when the app is not signed with the required entitlements or a developer account. The guide says a computer, internet connection and Apple ID are required for AltStore-based installation. A non-developer signing setup expires after seven days, while the guide says AltStore can automate re-signing when connected to a computer.

The TrollStore section is different. The listed TrollStore IPAs retain their original entitlements but are described as fake-signed; the developer warns that they will crash if used outside TrollStore or without a proper certificate and entitlements. The README identifies supported TrollStore ranges as iOS 14 through 16.6.1 on iPhone X and older, and iOS 14 through 16.6 beta 1 on iPhone 11 and newer.

The official guide also documents duplicate-app linking, notification limitations, local notifications and manual chat backup procedures. It says chats cannot be restored from iCloud to sideloaded Watusi, although manual backup and restore through the Files app is documented. Users should confirm their installation method, signing status, WhatsApp build, account backup and notification expectations before deleting the existing app.

Frequently asked questions

What is Watusi 1.0?

Watusi 1.0 is a major rebuild of the Watusi tweak for WhatsApp Messenger. The official release notes describe new and rebuilt tools for privacy, media, stickers, themes, message history, storage, scheduling and account management.

What iOS version does the package support?

The official package information lists iOS 15.1 or later. Jailbreak and sideloading requirements are separate, so users should also check whether their signing or jailbreak environment meets the installation guide’s requirements.

Which WhatsApp versions are named as compatible?

The release notes state support for WhatsApp 26.44 and WhatsApp Business. The official README lists Watusi 3 version 1.3.31 builds paired with WhatsApp 26.44.72.

Does Watusi 1.0 support multiple accounts?

Yes. The release notes say multiple accounts are supported and that each feature keeps its data per account.

Can Watusi record video calls?

The release notes say Call Recording now records video calls as well as keeping the two sides separate, with a player, editor and export tools. Users should consider consent and local recording laws before using it.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
