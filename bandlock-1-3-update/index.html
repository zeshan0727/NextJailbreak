BandLock 1.3 brings LTE, 5G NR and country-based modem controls to iOS jailbreak users

Gokuencinar’s GokuEnREPO lists BandLock 1.3 as a standalone iOS modem-control utility for RootHide, Dopamine rootless and rootful jailbreak setups. The release is positioned around manual LTE/4G and supported 5G NR band selection, country-based references, Field Test access and separate builds for each package environment. The repository also lists BetterWiFi RH 0.3.11, while Nuke Wireless remains in development without a public package release.

Key points

  • BandLock 1.3 is listed in separate RootHide, Dopamine rootless and rootful builds.
  • The utility is described as supporting manual LTE/4G and supported 5G NR modem selections on iOS 16.
  • Country profiles prepare compatible bands for review; they do not automatically modify the modem.
  • The app includes network modes, independent LTE/NR pending selections, Field Test access and an offline catalogue covering 160 countries and territories.
  • The package index records additional compatibility metadata for some variants, so users should check the package-manager entry for their exact jailbreak environment before installing.

BandLock 1.3 is the headline release

Gokuencinar’s public GokuEnREPO repository lists BandLock 1.3 as its current BandLock version across RootHide, Dopamine rootless and rootful package variants. The project describes BandLock as a standalone jailbreak app for manually controlling LTE/4G and supported 5G NR modem selections on iOS 16.

The release is aimed at users who need more control than the standard cellular settings expose. Instead of presenting the update as an automatic carrier or network optimizer, the project emphasizes pending selections, review before applying changes and modem-reported band information. That distinction matters: BandLock is designed around deliberate manual configuration rather than silently changing the modem based on a location profile.

  • RootHide package identifier: com.gokuencinar.bandlock, architecture iphoneos-arm64e.
  • Dopamine rootless package identifier: com.gokuencinar.bandlock.dopamine, architecture iphoneos-arm64.
  • Rootful package identifier: com.gokuencinar.bandlock.rootful, architecture iphoneos-arm.

What the app is designed to do

According to the project documentation, BandLock combines LTE/4G and supported 5G NR controls with network modes and separate LTE and NR pending selections. The pending-selection model gives users an opportunity to review the proposed configuration before applying it, rather than treating a country choice as an instruction to immediately rewrite modem settings.

The app also provides access to Field Test and includes an offline catalogue covering 160 countries and territories. The catalogue is presented as a reference for country-specific compatible bands. The repository explicitly says that country profiles never modify the modem automatically; compatible bands are prepared for review before they are applied.

The package description adds further detail for the RootHide and Dopamine variants, describing isolated LTE/4G and 5G NR modem control, worldwide band references, Field Test, multilingual UI and write verification. Those descriptions explain why the release may appeal to advanced users troubleshooting carrier coverage or experimenting with supported modem selections, but they do not guarantee that every band is available on every iPhone, carrier plan or modem firmware.

  • Manual LTE/4G control and supported 5G NR selections.
  • Separate LTE and NR pending selections.
  • Network modes and Field Test access.
  • Offline country catalogue covering 160 countries and territories.
  • Review-before-apply workflow for country profiles.
  • Languages listed by the repository include English, Spanish, French, German, Traditional Chinese, Simplified Chinese/Mandarin and Japanese.

Compatibility requires attention to the build

The repository’s general compatibility section identifies iOS 16.x, RootHide, Dopamine rootless and rootful environments, with Sileo, Cydia, Zebra and Installer 5 listed as supported package managers. BandLock is not distributed as one universal package: the repository provides separate builds for the three jailbreak packaging environments.

The package index contains historical and current-looking entries with differing firmware ranges. For example, the repository’s current-package table lists BandLock 1.3 for RootHide, Dopamine and rootful users, while package-index entries describe some 1.3 variants with broader firmware ranges and experimental support language. Because those records are not identical, users should treat the package-manager metadata for their selected build as authoritative before proceeding.

The package index also shows dependencies and conflicts that vary by build. The Dopamine packages list mobilesubstrate, and some newer entries recommend com.opa334.ccsupport. Rootful packages likewise list mobilesubstrate, while RootHide entries may include the same support recommendation depending on the version. The variants conflict with one another, so installing a package intended for a different jailbreak environment is not a safe substitute for selecting the matching build.

  • Confirm the jailbreak type before choosing a package.
  • Check the exact firmware range shown for the selected package.
  • Review listed dependencies and recommendations.
  • Do not install conflicting RootHide, Dopamine and rootful variants together.
  • Treat iOS 17 or iOS 18 support claims in package metadata as experimental where explicitly stated; the repository README itself focuses on iOS 16.x.

The repository also lists BetterWiFi RH 0.3.11

BandLock is not the only maintained package in GokuEnREPO. The repository currently lists BetterWiFi RH 0.3.11 for iphoneos-arm64e, with a firmware range of iOS 16.x and a PreferenceLoader dependency. It is described as a RootHide-compatible Wi-Fi enhancement tweak for iOS Settings.

BetterWiFi RH expands connected-network information and diagnostic capabilities with a live signal monitor, signal history, a 2.4 GHz/5 GHz channel analyzer, network filters and diagnostic tools. The project also lists Shuffle and PreferenceLoader integration, a manual Automatic/Spanish/English language selector and no dedicated resident daemon.

Recent project commits show work on the 0.3.10 and 0.3.11 preference experience. The recorded changes include an inline segmented language selector, delayed preference reload handling, a credits footer, a repository button, a support button and language-aware preference text. These changes are specific to BetterWiFi RH and should not be mistaken for BandLock functionality.

  • BetterWiFi RH version listed: 0.3.11.
  • Architecture: iphoneos-arm64e.
  • The repository describes it as RootHide-compatible.
  • Its documented feature set centers on Wi-Fi information, monitoring, analysis and diagnostics.
  • No dedicated resident daemon is claimed in the project README.

Nuke Wireless is not ready for installation

The same repository identifies Nuke Wireless as a project in development. It states that public package releases are unavailable, so users should not expect to find an installable Nuke Wireless package through the repository’s published package set.

This status is important because the repository contains documentation and project files for Nuke Wireless, but documentation should not be confused with a public release. For now, the installable offerings described by the repository are BandLock and BetterWiFi RH, subject to their respective compatibility and dependency requirements.

What to verify before installing BandLock

BandLock changes cellular modem selections, so users should approach installation as a configuration task rather than a routine interface tweak. First, identify whether the device uses RootHide, Dopamine rootless or a rootful jailbreak. Then select the matching architecture and package identifier.

Next, compare the package-manager metadata with the repository README. Pay particular attention to firmware bounds, dependencies, conflicts and any experimental-support wording. The available source material contains multiple historical package records, so the version and compatibility information attached to the exact package currently offered by the package manager matters more than an older entry in the index.

Finally, review the country profile and pending selections before applying them. The developer’s documentation says country profiles do not modify the modem automatically, but users remain responsible for understanding carrier, device and network limitations. Field Test access and write verification may provide useful diagnostic context, yet the source does not promise that a selected band will improve coverage or performance in every environment.

  • Match the package to the jailbreak environment and architecture.
  • Check firmware compatibility and dependencies in the exact package entry.
  • Review conflicts with other BandLock variants.
  • Confirm the intended LTE and NR selections before applying them.
  • Do not interpret the country catalogue as a guarantee of carrier compatibility or improved reception.
