Watusi 3 for WhatsApp 1.3.25 Adds WhatsApp 26.37.X Support and Targeted Fixes

Watusi 3 for WhatsApp is listed at version 1.3.25, with the release focused on compatibility with WhatsApp 26.37.X and corrections to several existing features. The update fixes an issue that could prevent chats from being unpinned when Unlimited Pinned Chats was enabled, improves the coverage and presentation of edited-message history, and repairs the statuses bar for some accounts using WhatsApp’s newer internal status storage. The same source material describes Watusi as a broad WhatsApp customization tweak covering privacy, chats, media, themes, scheduling, auto reply, hidden chats, custom tones, and stickers. Separately, the WatusiZhHans project documents a Simplified Chinese language pack based on Watusi 1.3.9; its recent packaging work targets rootful, rootless, and roothide installations, but the supplied material does not confirm compatibility with Watusi 1.3.25.

Key points

  • Watusi 3 version 1.3.25 is listed with support for WhatsApp 26.37.X.
  • Unlimited Pinned Chats should no longer block users from unpinning chats.
  • Edited-message history now covers edits in disappearing chats, linked-device edits, and edited media captions.
  • The update fixes the chats-list statuses bar for some accounts using WhatsApp’s newer internal status storage.
  • Official package records list different minimum-version information: firmware 12.0 or later in the package stanza and iOS 15.1 or later in the depiction.
  • The separate Simplified Chinese language pack is based on Watusi 1.3.9, so compatibility with version 1.3.25 should be verified rather than assumed.

Version 1.3.25 focuses on WhatsApp 26.37.X compatibility

The official package information identifies Watusi 3 for WhatsApp as version 1.3.25. Its release notes describe the update as a bug-fix release with support for WhatsApp 26.37.X, continuing the project’s version-specific compatibility work. Earlier release notes similarly tied fixes to WhatsApp branches including 26.36.X, 26.32.X, and 26.30.X.

The package is identified as com.fouadraheb.watusi3 and is categorized as a tweak for the iphoneos-arm architecture. The official stanza lists a package size of 2,736,122 bytes, while the depiction reports 2.45 MB. These are metadata values from two official records and should not be treated as separate builds.

  • Version: 1.3.25
  • Listed WhatsApp target: 26.37.X
  • Package identifier: com.fouadraheb.watusi3
  • Package architecture: iphoneos-arm
  • Release date shown in the official depiction: September 27, 2026

Pinned chats and edited-message history receive direct fixes

One of the clearest corrections concerns Unlimited Pinned Chats. The changelog says the feature could prevent users from unpinning chats. Version 1.3.25 addresses that behavior, making the update particularly relevant to users who use Watusi’s expanded pinned-chat controls.

The release also fixes Keep Edited Messages History showing the edited text in place of the original message. This wording describes a display or history-recording problem in which the original content was not presented as intended.

The same feature now records edits made in disappearing chats, edits made from a linked device, and edits to media captions. The supplied notes establish these additional cases, but they do not specify retention limits, storage usage, or whether the presentation is identical across every chat type.

  • Unpinning is fixed when Unlimited Pinned Chats is enabled.
  • The edited-history display issue involving original and edited text is corrected.
  • Edit records now include disappearing chats, linked-device edits, and edited media captions.

Chats-list statuses bar repaired for some accounts

Watusi 1.3.25 also addresses a problem with the statuses bar in the chats list. According to the release notes, the bar did not appear at all for some accounts using WhatsApp’s newer internal status storage.

This is a compatibility correction rather than a newly announced status feature. The source does not say that every account is affected, nor does it state that WhatsApp’s newer storage implementation is enabled universally. Earlier Watusi releases also documented status-related fixes as WhatsApp rolled this internal change out to more users.

The broader Watusi description lists several status controls, including downloading statuses, manually marking statuses as viewed, keeping contacts’ deleted statuses, splitting long videos into multiple statuses, creating privacy groups, and hiding status-tab badges. Those capabilities belong to the tweak’s wider feature set; the 1.3.25 note specifically concerns the chats-list statuses bar.

  • The affected interface is the statuses bar in the chats list.
  • The issue concerns some accounts using newer internal status storage.
  • The release note does not claim a universal fix for every WhatsApp account.

Watusi’s wider feature set

The developer presents Watusi as an all-in-one WhatsApp tweak that can change many parts of the application. Its privacy section lists controls for freezing last seen, disabling read receipts, typing indicators, recording indicators, and delivery receipts. It also lists disabling internet access, hiding call mute, blocking incoming calls, automatically switching last-seen privacy, and applying a My Contacts privacy setting.

Protection features include app protection, chat protection, and hiding the last message. Chat and chat-list tools include continued audio messages, chat details, call confirmation, tap-to-record, disabling continuous playback, group-member information, message-forward controls, chat-list filtering and sorting, archive locking, groups lists, swipe actions, and a clear-chats button.

The package description also lists custom sharing tools, profile-photo saving, expanded photo selection, media controls, themes, private notifications, notification icons, message scheduling, configurable auto reply, hidden chats, contact customization, custom notification tones, and sticker-pack management. Options are configured from inside WhatsApp settings. The official description says the package includes a Control Center toggle and instructs users to install CCSupport and activate it through Control Center settings.

  • Feature categories include Privacy, Protection, Status, Chats, Chat List, Media, Notifications, and Theme.
  • Additional tools cover message scheduling, auto reply, hidden chats, contact customization, custom tones, and stickers.
  • The listed built-in languages are English, Arabic, German, Spanish, French, Italian, Portuguese, and Turkish.
  • These are existing capabilities described by the developer, not features newly introduced by version 1.3.25.

Package requirements and installation checks

The official package stanza lists dependencies on firmware version 12.0 or later, mobilesubstrate 0.9.5000 or later, com.f0u4d.watusitools 2.8.3 or later, and com.muirey03.libmryipc. The separate official depiction lists support for iOS 15.1 or later. Because the two records provide different minimum-version descriptions, users should rely on the package manager’s resolved requirements and their actual jailbreak environment rather than treating either value as the only applicable rule.

The package declares conflicts with several older or alternate Watusi identifiers, including com.fouadraheb.watusi, com.f0u4d.watusi, org.thebigboss.watusi, and com.b4db1r3.cleancopy. Users should review proposed removals, replacements, and dependency changes before confirming an installation.

The main package is marked iphoneos-arm. The separate Chinese localization package is described as iphoneos-arm64e. These architecture declarations belong to different packages and do not, by themselves, establish that the two packages can be installed together in every environment.

  • Check the package manager’s resolved firmware and dependency requirements.
  • Review conflicts with older Watusi packages and CleanCopy.
  • Do not treat the architecture of the main tweak as a compatibility guarantee for the language pack.

What the Simplified Chinese project has changed

The WatusiZhHans project describes its software as a Simplified Chinese language pack based on Watusi 1.3.9. Its stated functions are adding Chinese translations and using a minimal runtime hook to add “简体中文” to Watusi’s Other Settings → Language menu.

A recent commit reworked the build process to generate rootful, rootless, and roothide installation packages serially. It also reorganized localization generation so resources are staged for each target and only zh-Hans.lproj is retained. This is a packaging and resource-organization change; the supplied project material does not say that the translation base has been updated from Watusi 1.3.9 to 1.3.25.

The project README gives the following activation sequence: install the language-pack deb, fully terminate WhatsApp, reopen WhatsApp, then open Watusi → Other Settings → Language and select 简体中文. If the language is not selected manually, the project suggests trying Language = Auto while WhatsApp or the system language is Simplified Chinese.

Because the language pack identifies Watusi 1.3.9 as its base, compatibility with the newer 1.3.25 tweak remains unconfirmed. The project’s own maintenance notes recommend checking language-related hooks, the language-list construction method, and FRSListCell-related constructor signatures when Watusi changes.

  • The language pack is based on Watusi 1.3.9.
  • Recent packaging work generates rootful, rootless, and roothide targets.
  • The documented menu path is Watusi → Other Settings → Language → 简体中文.
  • The supplied sources do not confirm compatibility with Watusi 1.3.25.

What to verify before using version 1.3.25

The central compatibility question is whether the installed WhatsApp build matches the 26.37.X target named in the Watusi 1.3.25 release notes. Users should also reconcile the package stanza’s firmware requirement with the depiction’s iOS requirement through the package manager and their jailbreak setup.

Anyone planning to add Simplified Chinese should treat the localization package as a separate project rather than as part of the main Watusi release. Its Watusi 1.3.9 base means that menu behavior, translated strings, or runtime hooks may require verification after installing version 1.3.25.

Finally, users should inspect dependency resolution, package conflicts, architecture information, and the proposed installation changes. The official feature descriptions explain the intended behavior of options such as internet blocking, hidden chats, privacy controls, and auto reply, but the supplied sources do not provide broader assurances about service-side effects or account consequences.

  • Match the installed WhatsApp version against the stated 26.37.X target.
  • Resolve the firmware-versus-iOS requirement discrepancy in the package manager.
  • Verify the Chinese pack’s version alignment before installing it.
  • Review dependencies, conflicts, architecture, and proposed package changes.
