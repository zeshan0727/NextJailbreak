Regram for Instagram 7.1 adds Hidden Chats, playback controls and Instagram 455/456 support

Regram for Instagram 7.1 is a substantial update to Fouad Raheb’s Instagram enhancement tweak. The release adds a dedicated Hidden Chats page with Face ID or passcode protection, confirmation before sending Instant videos, more accurate activity status, redesigned playback controls, Hold to Pause for Reels, Live Text in the video player and several fixes for accounts, layouts and RootHide installations. The official package metadata lists version 7.1, while the package depiction lists iOS 15.1 or later as supported and the package dependency requires firmware 14.0 or later.

Key points

  • Regram 7.1 is released as version 7.1 on November 18, 2026.
  • The update includes bug fixes and compatibility updates for Instagram versions 455 and 456.
  • Hidden Chats now has a dedicated Privacy settings page, Face ID or passcode locking, badge and search exclusion, and username-based chat adding.
  • Playback controls have been redesigned across Reels, Stories and long videos, including 0.05× speed adjustments and customizable buttons.
  • The official package depiction lists support for iOS 15.1+, while package dependencies require firmware 14.0 or later.
  • The official README documents separate jailbroken and sideloading installation paths, with signing limitations that can affect notifications and app duration.

What Regram 7.1 changes

Regram for Instagram 7.1 is positioned as an all-in-one enhancement layer for the official Instagram app on jailbroken or sideloaded iOS devices. The release was listed as updated on November 18, 2026, and its headline compatibility note covers Instagram versions 455 and 456. The package is identified as com.fouadraheb.regram and uses the iphoneos-arm64 architecture.

This is more than a narrow compatibility rebuild. The changelog combines new privacy controls, messaging safeguards, video playback changes, account-analysis improvements and fixes for particular layouts or installation environments. Existing Regram users may therefore find the most visible changes in Settings, the messaging interface and the media player rather than in a single redesigned screen.

  • Version: 7.1, released November 18, 2026.
  • Instagram compatibility note: bug fixes and compatibility updates for Instagram 455 and 456.
  • Package architecture: iphoneos-arm64.
  • Official package size: 19.43 MB in the depiction, with package metadata reporting an installed size of approximately 60,956 KB.

Hidden Chats becomes a dedicated privacy feature

One of the most significant additions is the new Hidden Chats page under Settings › Privacy. Regram 7.1 allows hidden conversations to be locked behind Face ID or a passcode. The changelog also says hidden chats can be kept out of the messages badge and direct-message search, reducing the chance that a protected conversation appears through ordinary navigation.

Users can choose when hidden chats become hidden again, and chats can be added by username. When a hidden chat is revealed, Regram displays a lock indicator. There is also a separate option to remove Hide Chat from the long-press menu, found under Settings › Privacy › Hidden Chats. Together, these controls give users more control over both access and discoverability, rather than simply moving a conversation into another list.

  • Dedicated location: Settings › Privacy.
  • Protection: Face ID or passcode.
  • Optional exclusion from the messages badge and DM search.
  • Chats can be added by username.
  • Revealed hidden chats display a lock.
  • Hide Chat can be removed from the long-press menu.

New safeguards for Instants, likes and messaging

For Instants, Regram adds Confirm Instant Videos under Settings › Confirmations. After recording a video Instant, the user can preview it and choose Send or Discard before it is transmitted. This is designed to add a review step to a quick-capture workflow where an accidental send could otherwise happen immediately.

The update also adds confirmation before double-tapping a Repost Bubble. That prompt applies when the gesture would like someone else’s repost on a post or reel. Regram’s follow buttons receive a related change: follow actions in Regram lists now ask first through a small menu, while Profile Analyzer lists no longer place Follow and Unfollow in swipe actions.

Accurate Active Status is new under Settings › Messages. According to the changelog, people can appear offline as soon as they leave, with a faster refresh option. Offline activity alerts and history now use the time a person actually left. The release also fixes online and offline alerts and Activity History for some accounts, and makes Messages Only automatically turn off when its scheduled time window ends.

  • Confirm Instant Videos adds a preview-and-confirm step before sending.
  • Double-tapping a Repost Bubble can require confirmation before liking.
  • Accurate Active Status provides faster refresh behavior and updated offline timing.
  • Follow actions in Regram lists now ask for confirmation.

Playback controls receive a broad redesign

Regram 7.1 introduces a shorter playback-control design for Reels, Stories and long videos. Users can choose which buttons appear and arrange their order through Playback Controls › Customize Buttons. The release adds Action and Open in player buttons, making the controls more configurable across supported media types.

Speed adjustment is more precise: dragging the speed bar changes playback in 0.05× steps, while double-tapping the bar returns playback to 1×. Mute has moved to the volume bar, and Keep Speed sits beside the speed bar. Holding a button or tapping its three-dot control exposes additional options.

Stories gain a navigation shortcut: holding the previous or next buttons jumps to the previous or next person. In Reels, the floating playback button shows the current speed when it is not 1×, and holding the three-dot control opens playback controls. A new Hold to Pause option under Settings › Reels lets users hold a reel to pause it and hide its buttons instead of opening Instagram’s options.

  • Customize playback buttons and their order.
  • Adjust speed in 0.05× steps and double-tap to return to 1×.
  • Use Hold to Pause for Reels.
  • Hold Story navigation buttons to jump between people.
  • Mute and Keep Speed have dedicated positions in the updated controls.

Long videos and Live Text

Instagram’s landscape player for long videos gains the action button, playback controls and button-hiding behavior. Regram also adds an option under Settings › Reels › Long Videos to open every long landscape video in that player.

The video player now supports Live Text. When a video is paused, users can select visible text, translate it or copy it. A Live Text button can also be used to show all detected text. This makes the enhancement useful not only for playback but also for extracting information displayed inside a video.

  • Long landscape videos can open automatically in the landscape player.
  • The player receives action, playback and button-hiding controls.
  • Live Text can select, translate or copy text from paused video frames.

Other fixes and device-specific changes

The update adds two new Try These entries under IG Feature Flags: Sort Profile Reels, which force-enables the profile Reels sorting option, and Liquid Glass Design for iOS 26 or later devices that do not yet have Instagram’s glass-style appearance. Regram’s How It Works pages and the IG Feature Flags section also receive a clearer design.

Profile Analyzer’s Since last scan view now includes people followed and unfollowed. The release fixes select-mode buttons that could be hidden beneath the tab bar, changes Reel date access to a long press, and fixes a copied-link Search action that could work on only one account when accounts used different settings profiles.

For RootHide users, the changelog specifically says Regram no longer fails to load after conversion with RootHide Patcher. On iPhone Duo unfolded and iPad layouts, Mark Seen now applies to the story currently on screen and advances to its next story rather than the next person; download, mentions and playback buttons also apply to the story being viewed.

  • New IG Feature Flags picks include Sort Profile Reels and Liquid Glass Design.
  • Profile Analyzer now reports followed and unfollowed changes since the previous scan.
  • RootHide loading after RootHide Patcher conversion is fixed.
  • iPhone Duo unfolded and iPad story controls now target the story on screen.

Compatibility and installation considerations

The official package depiction lists Regram 7.1 as supporting iOS 15.1 or later. Separately, the package dependency declares firmware version 14.0 or later and mobilesubstrate 0.9.5000 or later. Because these source fields do not express compatibility in exactly the same way, users should check the package depiction and their installer’s dependency information before proceeding rather than assuming that every supported installation path behaves identically.

For jailbroken devices, the official README instructs users to add the developer’s package source in a compatible package manager such as Cydia, Zebra or Sileo and install Regram from there. The package also declares a conflict with com.b4db1r3.cleancopy, so an installer may need to account for that conflict before installation.

The README documents sideloading variants for the Instagram app, including an original-bundle build, a no-plugins build, a duplicate-bundle build and a TrollStore build. It says AltStore sideloading requires a Mac or Windows computer, an internet connection and an Apple ID; iOS 16 users may need Developer Mode enabled. The README also instructs users to avoid having another Instagram installation with the same bundle identifier present.

Signing affects lifespan and notifications. The official documentation says a non-developer account can cause an app to expire after seven days, while AltStore can automate re-signing when connected to a computer. It also says sideloaded builds do not receive push notifications unless signed with a Distribution or Ad-Hoc certificate, with TrollStore receiving notifications on supported devices. These are installation constraints documented by the developer, not guarantees that every certificate or sideloading workflow will behave the same way.

  • The depiction lists iOS 15.1+; package dependencies require firmware 14.0+ and mobilesubstrate 0.9.5000+.
  • Jailbreak installations use a compatible package manager and the developer’s package source.
  • Sideloaders must avoid conflicting installations with the same bundle identifier.
  • Non-developer signing may limit an app to seven days.
  • Push notifications require the signing conditions described in the official README, except for supported TrollStore installations.

Frequently asked questions

What is new in Regram for Instagram 7.1?

The release adds a dedicated Hidden Chats page, Face ID or passcode protection, Confirm Instant Videos, Accurate Active Status, Hold to Pause for Reels, redesigned playback controls, long-video player improvements, Live Text support and compatibility updates for Instagram 455 and 456.

Which iOS versions does Regram 7.1 support?

The official package depiction lists iOS 15.1 or later. The package dependency separately requires firmware 14.0 or later, so users should consult the depiction and their package manager’s dependency resolution for the installation path they intend to use.

Can Hidden Chats be excluded from search and notifications?

The changelog says Hidden Chats can be kept out of the messages badge and direct-message search. The feature is configured from Settings › Privacy and can be protected with Face ID or a passcode.

Does Regram 7.1 support sideloading without a jailbreak?

Yes. The official README documents sideloading with AltStore, a signing certificate and TrollStore on the device and operating-system combinations described by the developer. Each method has different signing, notification and compatibility considerations.

Will sideloaded Regram receive push notifications?

The official README says push notifications are not available for sideloading unless the app is properly signed with a Distribution or Ad-Hoc certificate, except for TrollStore on supported devices.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
