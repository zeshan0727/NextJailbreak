AntiNotch 0.0.1 Adds a Virtual Home Button to Notched iPhones

AntiNotch puts a software Home button beside the notch-era iPhone interface. Tap returns Home, hold invokes Siri, and a downward swipe requests Reachability—but the first release is a debug beta with very narrow official testing.

By Zeeshan Barvi · Published October 11, 2026 · Verified against the official release, README and both DEB packages

Compatibility warning: The developer only reports successful testing on an iPhone XS running iOS 14.4.2 with the rootful Taurine jailbreak. A rootless package is available, but the release explicitly says rootless support is untested. Do not treat the package architecture as proof that it works on Dopamine, palera1n, RootHide or newer iOS versions.

What AntiNotch does

AntiNotch 0.0.1 is a new jailbreak tweak by TheArma that brings a virtual Home button to notched iPhones. Its official description focuses on restoring a familiar physical-button-style control without removing the modern gesture interface. The included preferences reveal three actions:

  • Tap: return to the Home screen.
  • Hold: invoke Siri.
  • Swipe down on the button: request Reachability.

Haptic feedback accompanies interaction, and the tweak can use 3D Touch force input on supported hardware. Devices without 3D Touch fall back to normal touch according to the preference text included in both packages.

Settings and themes

The settings bundle contains an overall enable switch, a 3D Touch toggle and separate press and release thresholds. Press strength ranges from 40 to 200 with a default of 100; release strength ranges from 10 to 150 with a default of 60. The preference text says the release threshold is kept below the press threshold.

Three appearance choices are included:

  • iPhone 2G–iPhone 5: an older square-era Home-button theme.
  • iPhone 5s–iPhone 8: the Touch ID-era circular style.
  • Hidden: keeps the control functional without showing the button artwork.

The theme applies immediately, while the master enable option instructs users to respring after changing it.

Rootful and rootless packages are not equally verified

The official release contains two DEBs. Inspection confirms the rootful build installs its tweak and preferences under /Library. The arm64 build places the same files under /var/jb/Library, which is the conventional rootless layout.

That packaging is useful evidence that the developer produced a rootless-formatted build. It is not evidence that the tweak behaves correctly in every rootless jailbreak. The developer states that rootless support is currently untested, while the only documented successful test is Taurine rootful on iOS 14.4.2.

Users on Dopamine or another rootless environment should wait for explicit developer confirmation or test only if they are comfortable recovering from SpringBoard safe mode. RootHide users would additionally need an environment-specific package or conversion that the developer has not documented. Our rootless jailbreak basics explains why an arm64 package path and real compatibility are separate questions.

Should you install this first release?

AntiNotch is interesting because it combines three common actions in one reachable control and gives older iPhone hardware with 3D Touch a pressure-sensitive option. The configurable themes also make the button more than a generic AssistiveTouch replacement.

However, version 0.0.1 is best treated as an early test build:

  • The developer calls it beta and warns about bugs, glitches and compatibility issues.
  • The release files themselves contain +debug in their package versions.
  • Only one device, firmware and jailbreak combination is officially documented.
  • The public repository currently contains documentation and release binaries, not tweak source code that readers can independently audit.
  • The rootless build exists, but its runtime behavior has not been validated by the developer.

For a primary device, waiting for a release build and a broader compatibility report is the cautious choice. If you do test it, install only the package matching your jailbreak layout, keep a safe-mode recovery route available and know how to remove the tweak without relying on SpringBoard launching normally.

How to download safely

  1. Open the official AntiNotch 0.0.1 release.
  2. Choose iphoneos-arm only for a traditional rootful jailbreak or iphoneos-arm64 only for a conventional rootless jailbreak.
  3. Do not use third-party mirrors or renamed packages.
  4. Install through your trusted package manager or follow our local DEB installation guide for Sileo.
  5. Respring, then open Settings → AntiNotch. If SpringBoard enters safe mode, remove the tweak before trying other compatibility changes.

The official release publishes SHA-256 digests. We independently matched them during inspection: 3f834cec…66b772a for the rootful asset and aa118a71…7057e4f for the rootless asset.

Frequently asked questions

Does AntiNotch work with Dopamine?

The developer has not confirmed it. A rootless-formatted package exists, but the official release says rootless support is untested. Package availability alone is not a compatibility guarantee.

Does it replace the iPhone gesture bar?

The release describes an added virtual Home button and does not claim to remove or replace every system gesture. Treat it as an additional control.

Which gestures are supported?

The included preferences document tap for Home, hold for Siri and swipe down for Reachability.

Is AntiNotch open source?

The project is hosted publicly on GitHub, but the repository checked for this article contains a README and release binaries rather than the tweak’s source code, and it does not declare a license. Do not describe it as open source unless that changes.

Why is there no screenshot in this article?

The official repository and release contain no image assets. The developer’s Reddit demonstration was visible to search but blocked ordinary HTTP retrieval during publication, so no copied, generated or unrelated image was substituted.
