Bezelify Lite 1.2.3 vs Pro 1.2.3: Is the $4.99 Upgrade Worth It?

Both automatically place screenshots inside realistic iPhone or iPad frames. Lite covers the everyday capture workflow; Pro turns Bezelify into an image, video and GIF production tool.

Published November 20, 2026Source-checked comparison
Quick answer: start with Bezelify Lite 1.2.3 if you only need automatic screenshot framing, basic finishes, a signature and square exports. Pay $4.99 for Bezelify Pro 1.2.3 if you will use its editor, video and GIF export, custom frame colors, expanded backgrounds or social-media canvas sizes. Both official packages target iOS 15.0–18.5 and require a compatible jailbreak.

What the free Lite version actually includes

Lite is not a time-limited demo. It automatically frames new screenshots without opening a separate app. The current description includes Notchless, Notch and Dynamic Island styles, portrait and landscape capture, drop shadows, transparent, white, black and Midnight backgrounds, iPhone and iPad frames, a text signature, side buttons and nine interface languages.

Version 1.2.1 added Original and Square 1:1 canvas sizes, and 1.2.2 replaced the frames with more realistic metal mockups. Version 1.2.3 fixes framing when a display-resolution tweak is active and a case where certain other tweaks could turn Bezelify off. The Pro custom-color control appears in Lite’s settings as a locked feature; that does not make custom colors available in Lite.

What the $4.99 Pro upgrade adds

Pro is aimed at people who publish screenshots or recordings repeatedly. It installs a Home Screen app with an editor for imported images, supports more frame finishes and backgrounds, accepts custom fonts and logos, and offers finer signature placement. Its extra canvas ratios map to common social-post formats: 4:5, 9:16 and 16:9 in addition to square and original.

The video workflow adds mockup framing, trimming, zoom and positioning, backgrounds, green-screen output, original-audio control, imported background music and MP4 export. Version 1.2.2 added GIF creation from a selected segment of up to 15 seconds. Version 1.2.3 adds a custom frame-color picker that works across iPhone and iPad frames, screenshots, pictures, videos, GIFs and Settings previews.

That makes Pro worthwhile for a developer preparing repository depictions, a reviewer building tutorials, or anyone who needs consistent branded images and clips. If you only want screenshots to arrive in Photos with a clean frame, Lite already solves the core problem.

Compatibility and unsupported setups

Havoc’s live package data lists both 1.2.3 packages for iOS 15.0–18.5 with rootless support. The developer’s 1.2.x changelogs also state RootHide compatibility. Confirm that your package manager presents the correct build for your environment; do not install a standard rootless package into a different bootstrap merely because the description mentions RootHide.

Neither official page claims iOS 26 or iOS 27 support. The use of current-looking device mockups does not expand the firmware range. More importantly, package compatibility does not mean every device on iOS 15–18.5 has a jailbreak. Check the exact device, firmware and jailbreak first with our jailbreak tweak compatibility checklist.

Both packages depend on MobileSubstrate and PreferenceLoader. They conflict with and replace the older Bezelify package, and Lite and Pro replace one another. Do not try to keep both installed at the same time.

Privacy difference to know before upgrading

The Pro description discloses a purchase-verification request about once a month. It says the device UDID and model are sent over HTTPS to the Bezelify license server after the first-check prompt, nothing is stored on the server and only a hash remains on the device. That is the developer’s stated design, not an independent audit. If you do not accept that check, stay with Lite or do not install the package.

Safe install, upgrade and recovery

  1. Use only the official Lite or Pro Havoc listing. Avoid repackaged DEBs, especially for a paid package.
  2. Install one edition through Sileo or the package manager already supplied by your jailbreak, then respring. Our Sileo tweak-installation guide covers the normal package flow.
  3. Before upgrading from Lite, record any important settings. Havoc says Pro replaces Lite while keeping its settings, but a backup makes rollback easier.
  4. After installation, take a plain test screenshot and check Photos before enabling automatic framing, custom backgrounds or signatures for every capture.
  5. If screenshots stop saving correctly, disable Bezelify first, return display-resolution tweaks to stock settings, respring, and test again. Version 1.2.3 specifically addresses rescaled displays, but other conflicts can still exist.
  6. If SpringBoard enters a crash loop, boot without tweak injection, remove the newest Bezelify package and respring. Follow the Dopamine bad-tweak recovery guide for the safe sequence.
