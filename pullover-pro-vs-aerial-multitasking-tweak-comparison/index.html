PullOver Pro 3.0.1 vs Aerial 5.1: Quick Overlay or Full Stage Manager?

Compare PullOver Pro 3.0.1 and Aerial 5.1 by workflow, price, Rootless and RootHide support, iOS limits, conflicts, setup and recovery.

Published November 15, 2026By Zeeshan BarviOfficial sources checked

Short answer: choose PullOver Pro 3.0.1 if you want one app available from an edge handle, a free package, or an explicitly published RootHide build. Choose Aerial 5.1 if you want resizable windows, multiple stages, Split Stage, minimization and a Stage Manager-style workflow. Do not install both: Aerial’s official page warns about PullOver Pro-derived conflicts, and the two tweaks modify the same broad SpringBoard and app-scene territory.

The useful difference is not “free versus paid.” PullOver Pro is a fast overlay that keeps one chosen app close. Aerial is a window manager. Picking by workflow first avoids paying for complexity you will not use—or expecting a single overlay to behave like a desktop workspace.

Choose PullOver Pro for a fast single-app overlay

PullOver Pro’s strength is immediacy. Its handle stays near the screen edge, opens a selected app above what you are doing, and can expose recent or favorite apps. QuickSwitch lets you drag the overlay toward full screen. Version 3.0.1 specifically fixes the handle disappearing after a respring, so it is the current build to evaluate rather than the earlier 3.0 release.

It is the clearer option for RootHide users because the official package page explicitly lists both Rootless and RootHide. It also documents AltList as a dependency and points iOS 27 users to TweakSettings for preferences. Read the PullOver Pro 3.0.1 update notes for the release-specific setup and tested-device disclosures.

Choose Aerial for real window management

Aerial’s central menu can open, maximize, minimize, split and close windows. Resize handles preserve or change aspect ratio, Trim Mode changes the visible crop, and Split Stage arranges applications together. Version 5.1 replaces the earlier one-third iPad split with a four-way split, fixes landscape stage reversion and a close-animation enlargement bug, and attempts to improve keyboard sizing during iPad rotation.

That breadth is why Aerial costs more and has more interaction surface to test. It is the better fit when resizing, arranging and revisiting several windows matters more than reaching one utility quickly. The Aerial 5.1 update guide covers the point release in detail.

The iOS compatibility labels need different caution

PullOver Pro’s official depiction declares iOS 15–27 and publishes Rootless and RootHide packages, but that is package compatibility—not proof that every iPhone on those releases has a jailbreak. The project’s notes include checks on an iPhone XR with iOS 16.0.3, an iPhone 11 Pro with iOS 27.2.1 and a RootHide virtual iPhone; the iOS 17 fix was not confirmed on a physical iOS 17 device.

Aerial’s own Havoc page currently contains an inconsistency: store metadata lists iOS 15.0–26.0.1, and version 5.0 says iOS 26 support was added, while the product description still says iOS 15.0–17.7.10. Treat 17.7.10 as the conservative written limit until the seller clarifies the mismatch, and check the compatibility view shown in your package manager before purchasing. Havoc marks Aerial Rootless but does not make a RootHide promise.

Before either tweak, identify your exact model, build and jailbreak with the jailbreak compatibility pre-check. A broad iOS range never creates an installation path on unsupported hardware.

Why you should not install both

Aerial’s official page says unofficial PullOver Pro or tweaks based on it conflict with Aerial. The current PullOver Pro 3 package is a maintained port/rebuild of the original concept, so the safe interpretation is to choose one multitasking system at a time. Even if both packages install, overlapping gestures, scene hooks and window state can produce duplicate handles, failed launches or Safe Mode.

  1. Record your current tweak version and preferences.
  2. Remove the existing multitasking tweak in Sileo, then respring.
  3. Install only the replacement from its official repository or Havoc.
  4. Test app launching, rotation, keyboard display, lock/unlock and a second respring.
  5. If SpringBoard crashes, enter tweak-disabled or Safe Mode and remove the last package.

Use the Sileo installation guide for repository hygiene and the bad-tweak recovery guide before experimenting with another global SpringBoard tweak.

Which should you choose?

  • Choose PullOver Pro for a free, quick-access overlay, RootHide packaging or a simple one-app-at-a-time workflow.
  • Choose Aerial for resizable windows, multiple stages, Split Stage and a desktop-like workspace.
  • Choose neither yet if your exact device, firmware and jailbreak environment are not supported, or if you cannot reconcile Aerial’s current compatibility labels before purchase.
  • Never stack them to get “the best of both.” Their overlap is the main reason to compare and choose.

Frequently asked questions

Can PullOver Pro and Aerial be installed together?

Do not run them together. Aerial’s official page warns about PullOver Pro-derived conflicts, and both modify global multitasking and application scenes.

Which tweak supports RootHide?

PullOver Pro 3.0.1 explicitly publishes Rootless and RootHide builds. Havoc lists Aerial as Rootless; its official page does not claim RootHide support.

Does Aerial support iOS 26?

Havoc metadata lists iOS 15.0–26.0.1 and the 5.0 changelog says iOS 26 support was added, but the description still says iOS 15.0–17.7.10. Verify the live package-manager compatibility view before purchase.

Does PullOver Pro’s iOS 27 label mean every iOS 27 device can use it?

No. It describes package compatibility. A compatible jailbreak, device architecture and firmware path are still required.
