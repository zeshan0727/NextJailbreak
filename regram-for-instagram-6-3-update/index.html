Regram 6.3 Updates Instagram 448 Support and Adds Reels Time Limits

Regram for Instagram 6.3 is a compatibility-focused update for Instagram 448, released September 28, 2026. Alongside bug fixes, the release replaces the previous Reels Scrolling control with a more detailed Reels Limit system, adds tappable links in captions and comments, improves deleted-message navigation, reorganizes several settings pages, and changes how profile-tracking checks are scheduled. The official package metadata lists a firmware dependency of iOS 14 or later and MobileSubstrate 0.9.5000 or later, while the package depiction lists support for iOS 15.1 and newer. Users should therefore check the installation channel and device configuration before updating.

Key points

  • Regram 6.3 is marked as compatible with Instagram 448 and was released on September 28, 2026.
  • The new Reels Limit feature replaces Reels Scrolling and supports daily reel or minute limits, usage statistics, a seven-day chart, and break reminders.
  • Web links in Instagram captions and comments are now tappable through the new Tappable Links setting, which is enabled by default.
  • Profile Tracking now delays checks after launch, pauses for a day if Instagram limits the account, and runs no more often than every two hours.
  • The official package metadata lists iOS 14 or later and MobileSubstrate 0.9.5000 or later, but the package depiction states iOS 15.1+ support; readers should verify their exact installation route.

What Regram 6.3 changes

Fouad Raheb has released Regram for Instagram 6.3 as an update centered on Instagram 448 compatibility. The official changelog describes the release as containing bug fixes and compatibility updates for IG 448, making the bundled Instagram version an important part of the update rather than an incidental detail.

The release is available as a jailbroken package and as several sideloading variants in the project’s official installation instructions. The listed sideloading builds pair Regram 6.3 with Instagram 448.0, including an original Instagram build, a no-plugins build, a duplicate-bundle build, and a TrollStore build. These variants are not interchangeable in every setup because the original and duplicate options use different bundle identifiers.

  • Version: 6.3.0? The official sources identify the release simply as 6.3.
  • Release date: September 28, 2026.
  • Instagram compatibility named by the changelog: Instagram 448.
  • Package identifier: com.fouadraheb.regram.

A more useful limit for Reels viewing

The most substantial user-facing change is Reels Limit, which replaces the earlier Reels Scrolling feature. Instead of only controlling consecutive scrolling, the new system allows a daily limit based on either the number of reels watched or the number of minutes spent watching them.

Regram’s official changelog says the feature includes usage statistics, a seven-day chart, and break reminders. That gives users more feedback than a simple scrolling restriction: they can review recent usage and configure a limit around either content volume or viewing time. The source does not specify the available limit ranges or how reminders are scheduled, so those details should be checked inside Regram’s settings after installation.

  • Reels Limit replaces Reels Scrolling.
  • Limits can be based on daily reels or minutes.
  • Usage statistics and a seven-day chart are included.
  • Break reminders are part of the feature.

Links, deleted messages, and button controls

Regram 6.3 adds Tappable Links under General. According to the official release notes, web links in Instagram captions and comments can now be tapped to open, and the option is enabled by default. This is a convenience change for users who regularly encounter links in posts or discussions, although the source does not describe which types of web links are recognized or which browser destination is used.

The Deleted Messages Log also gains a Show in Chat action. Selecting it opens the relevant conversation and jumps to the location where the message was recorded. The changelog says users can tap text entries or long-press any entry, giving the log two ways to navigate back to the associated conversation context.

The previous Hide Buttons setting has been renamed and split into Post Buttons and Reel Buttons. The new pages let users show buttons, hide them, or hide only their counts. The release also includes controls for like and repost confirmations. This is more than a label change: the settings are now organized around the content surfaces where those controls appear.

  • Tappable Links is enabled by default.
  • Show in Chat can jump from a deleted-message log entry into the relevant chat location.
  • Post Buttons and Reel Buttons replace the older Hide Buttons page.
  • Button counts can be hidden separately from the buttons themselves.
  • Like and repost confirmations can be managed alongside the button controls.

Settings have been reorganized

Regram 6.3 moves Feed, Reels, and Stories Filtering out of the general Interface area and into the corresponding Feed, Reels, and Stories sections. The new button-control pages follow the same organizational approach. Users upgrading from an earlier version may therefore find familiar options in different locations rather than seeing entirely new functionality.

The Stories Hide Suggested Users option has also moved into Stories Filtering. This change should make the location of story-specific filtering controls more consistent, but it may require users to revisit the relevant section after updating.

  • Feed filtering is now grouped under Feed.
  • Reels filtering is now grouped under Reels.
  • Stories filtering is now grouped under Stories.
  • Hide Suggested Users is now part of Stories Filtering.

Profile Tracking receives safer scheduling

The update changes how Profile Tracking performs watchlist checks. The official description says checks now begin a few seconds after launch, pause for one day if Instagram limits the account, and run at most once every two hours.

This is a behavioral safeguard rather than a new tracking category. The stated goal is to make watchlist checks safer by reducing how aggressively they run and by responding to an Instagram account limitation. The source does not promise that tracking will avoid every account restriction, so users should treat the feature’s scheduling change as a mitigation rather than a guarantee.

  • Watchlist checks start a few seconds after launch.
  • Checks pause for a day if Instagram limits the account.
  • The maximum frequency is once every two hours.

Additional fixes and interface changes

Several smaller fixes address specific display and navigation problems. Regram 6.3 fixes Full Last Active Date not appearing in chats and removes Music for you and Suggested for you cards that continued to appear in Stories.

Notifications now use the Solid background by default, while Toast text is aligned next to its icon. The release also fixes IG+ Story Preview showing an upsell instead of the story when users long-press an avatar outside the Stories bar. The affected locations listed by the project include comments, direct messages, search, activity, and feed posts.

  • Fixed missing Full Last Active Date information in chats.
  • Fixed unwanted Music for you and Suggested for you cards in Stories.
  • Solid is now the default notification background.
  • Toast text now aligns beside its icon.
  • Fixed an IG+ Story Preview issue outside the Stories bar.

Compatibility and installation considerations

The official package stanza lists firmware version 14.0 or later and MobileSubstrate version 0.9.5000 or later as dependencies. Separately, the package’s Sileo depiction lists “iOS 15.1+” under Supports. Because those statements describe different layers of the package information, users should verify the support shown by their chosen package manager and installation method rather than assuming that every feature or distribution format applies identically to every iOS version.

For jailbroken devices, the project’s official README instructs users to add the project’s package source to a compatible package manager such as Cydia, Zebra, or Sileo. For non-jailbroken devices, the README documents AltStore-based sideloading and a TrollStore path for the supported iOS and device combinations listed there. The same documentation notes that the original Instagram build and duplicate build use different bundle identifiers, and that an existing Instagram app with the same identifier may need to be addressed before installation.

The project also distinguishes notification behavior by signing method. Its documentation says sideloaded installations generally do not receive push notifications unless signed with a Distribution or Ad-Hoc certificate, with TrollStore listed as an exception on supported devices. Non-developer signing can expire after seven days, while the README says AltStore can automate re-signing when the device remains connected to a computer. These are installation constraints documented by the project, not guarantees that apply to every signing service.

  • Check both the package dependency metadata and the package depiction’s iOS support label.
  • Use the official package or sideloading instructions rather than unofficial copies.
  • Confirm the bundle identifier of the selected Instagram build before installing.
  • Review signing and push-notification limitations before choosing a sideloading method.
  • Back up or document existing Regram settings if a package-manager migration is involved.

Frequently asked questions

What is new in Regram 6.3?

The release adds Instagram 448 compatibility updates and bug fixes, replaces Reels Scrolling with Reels Limit, introduces tappable caption and comment links, adds Show in Chat for the Deleted Messages Log, reorganizes button and filtering settings, changes Profile Tracking scheduling, and includes several notification, Stories, chat, and preview fixes.

Does Regram 6.3 support Instagram 448?

Yes. The official changelog describes compatibility updates for IG 448, and the project’s listed sideloading builds pair Regram 6.3 with Instagram 448.0.

What does Reels Limit do?

It replaces Reels Scrolling and supports daily limits based on reels watched or minutes watched. The feature also includes usage statistics, a seven-day chart, and break reminders.

Is Tappable Links enabled automatically?

The official changelog says the new Tappable Links setting is on by default. It allows web links in captions and comments to be tapped to open.

What iOS versions are supported?

The package stanza lists a firmware dependency of iOS 14.0 or later, while the package depiction lists support for iOS 15.1+. Because the sources present these as separate pieces of metadata, users should verify compatibility in their package manager and installation route before proceeding.
