BegoneCIA 1.0.0 Adds iOS 18 Support and Silences Siri’s New Mic Path

BegoneCIA 1.0.0 adds iOS 18 support by silencing Siri’s AVVoiceController microphone path while retaining rootless iOS 15–17 coverage.

Published October 6, 2026 · Updated October 6, 2026 after the final 1.0.0 release · Verified from developer source and repository metadata

BegoneCIA 1.0.0 is the first non-beta release of Jond-ie’s rootless port of Nepeta’s privacy toggle. The October 6 source update adds iOS 18 handling for Siri’s changed microphone path while retaining the iOS 15–17 work introduced by the earlier rootless builds.

Important: BegoneCIA is software-level tweak injection, not a hardware microphone, camera or GPS disconnect. The developer documents multiple audio paths, but users should still verify the result on their exact device, firmware and jailbreak environment.

What changed in BegoneCIA 1.0.0

  • iOS 18 support: the package and developer release note now list iOS 15 through iOS 18 on arm64 and arm64e.
  • Siri’s new microphone route is covered: iOS 18 moved CoreSpeech capture to an AVVoiceController callback, so the tweak now zeros each AVVCAudioBuffer before Siri reads it.
  • The beta label is gone: the developer describes 1.0.0 as the finished release following the rootless5 beta line.

The exact 1.0.0 source commit was authored on October 6, 2026. Its commit message specifically identifies the iOS 18 Siri path and AVVoiceController change.

This table describes the project’s implemented paths; it is not a promise that every microphone route on every device is covered. The README retains a caveat that different hardware or iOS versions may use another audio chain.

What BegoneCIA does

The tweak installs a Control Center module intended to silence microphone, camera and location activity system-wide without returning a normal permission error to apps. Its source zeros supported audio buffers, drops camera inputs and suppresses location delegates while the toggle is active.

The package is a rootless port for a compatible jailbreak environment. A package claiming iOS 18 compatibility does not mean every iPhone on iOS 18 can be jailbroken. Confirm the actual device and firmware range first; our Dopamine vs palera1n comparison separates jailbreak availability from tweak compatibility.

iOS 18 Control Center module note

The developer also published an interim CCSupport (iOS 18 fix) package for a separate iOS 18 issue where third-party Control Center modules can disappear after Safe Mode or a reboot. The fix is submitted upstream as CCSupport pull request #26.

  • Use it only on iOS 18 or later and only if the module-disappearance problem applies.
  • The developer says it has not been tested on iOS 26.
  • It is separate from BegoneCIA 1.0.0 and is intended to be replaced automatically when an official CCSupport update supersedes it.

Package requirements

The official repository lists BegoneCIA 1.0.0 as an iphoneos-arm64 rootless package with identifier com.johndie.begonecia. It depends on ElleKit, CCSupport and Cephei (ws.hbang.common), and it conflicts with and replaces Nepeta’s older me.nepeta.begonecia package.

Before installing, review the tweak compatibility checklist, confirm that your package manager uses the developer’s official repository, and keep a normal backup.

Verified installation source

  1. Add the developer’s official repository to Sileo or Zebra.
  2. Confirm the package identifier is com.johndie.begonecia.
  3. Confirm the version displayed is 1.0.0, not 0.2.0-rootless5.
  4. Install the listed dependencies and add the BegoneCIA module to Control Center.
  5. Test microphone, Siri, camera and location behavior on your own device before relying on the toggle.
