BegoneCIA 0.2.0-rootless5 Adds iOS 17 and A12+ Support

BegoneCIA 0.2.0-rootless5 adds iOS 17 microphone handling and confirms A12+ operation on an iPhone SE 2 running iOS 17.5.1.

Published October 6, 2026 · Verified from the developer’s source repository and package metadata

BegoneCIA 0.2.0-rootless5 is a new rootless build of Nepeta’s privacy toggle. Developer Jond-ie’s October 4 source commit adds handling for the audiomxd process used on iOS 17 and records a successful test on an A13 iPhone SE (2nd generation) running iOS 17.5.1.

Important: this is a software-level jailbreak tweak, not a hardware microphone or camera disconnect. The developer says the microphone process chain can differ by device and iOS version, so users should test the result on their own setup.

What changed in 0.2.0-rootless5

  • Adds the iOS 17 audiomxd process to BegoneCIA’s microphone handling.
  • Confirms A12-and-newer operation on an A13 iPhone SE (2nd generation) with iOS 17.5.1.
  • Retains the earlier rootless4 fix for Siri audio by avoiding suspension of corespeechd.

The exact rootless5 source commit is dated October 4, 2026. The preceding rootless4 commit, dated October 2, changed the audio path after the developer found that suspending corespeechd could break Siri audio.

What BegoneCIA does

The tweak installs a Control Center module intended to silence microphone, camera and location activity without producing the normal permission-denied behavior that an app can detect. It is a rootless port of Nepeta’s original BegoneCIA project, with current device and process handling maintained in Jond-ie’s source.

That design does not prove that every sensor path is blocked on every iPhone. The source README explicitly asks users to test their own device and report failures because Apple’s service chain varies across hardware and software releases.

Package requirements

The official repository metadata identifies version 0.2.0-rootless5 as an iphoneos-arm64 rootless package. It depends on ElleKit, CCSupport and Cephei (ws.hbang.common). It conflicts with and replaces Nepeta’s older me.nepeta.begonecia package, so the two should not be installed together.

Before installing, review the tweak compatibility checklist, confirm your package manager is using the developer’s official repository, and make a normal backup.

Verified source and installation

  1. Open the developer’s official package repository in your rootless package manager.
  2. Confirm the identifier is com.johndie.begonecia and the version is 0.2.0-rootless5.
  3. Install the listed dependencies, add the BegoneCIA Control Center module, and test microphone, camera and location behavior yourself.

For auditability, the project’s source repository and the rootless5 release commit are public. Next Jailbreak does not mirror or relink the package file.
