Super Complications 1.3 Fixes RootHide and Lock Screen Widget Editing

Super Complications 1.3 targets the details that make a customized Lock Screen usable: widget placement, saved shortcuts and previews that follow your edits. Havoc dates the release to September 29, 2026. For anyone who paused at version 1.2, this is the newer release to check.

By Zeeshan Barvi · Published October 1, 2026 · Package updated 2026-09-29

What changed in version 1.3?

The developer lists four changes: more precise widget arrangement, RootHide fixes, a fix for shortcut-widget changes failing to save, and a correction for module appearances not updating immediately in PosterBoard. The changelog does not identify the underlying RootHide bug, so it should not be read as a guarantee that every RootHide issue is resolved.

What can it put on your Lock Screen?

Mysteryexe’s tweak provides configurable complications for CPU and memory use, storage, battery readings and history, temperatures, connected accessories, Apple Watch battery, calendar events, app shortcuts and device information. The appeal is choosing the readings or actions you actually want to see when you wake the phone.

A useful starting layout would put one frequently used shortcut beside one information widget. That gives you something practical to evaluate immediately. Filling every available position on the first attempt makes it harder to tell which element is helping and which is simply making the screen busier. Treat the screenshot as a layout example, rather than a requirement to reproduce the whole arrangement.

Compatibility and price

Havoc lists iOS 16.0–17.7.11 and a US$1.99 price. The developer describes iPhone and iPad support across rootful, rootless and RootHide jailbreaks. An existing compatible jailbreak is required; these package requirements do not establish jailbreak availability for every device in that range.

Check the package offered to your own environment before purchasing. A matching iOS number is only one part of the decision: your device, jailbreak and other Lock Screen customizations also matter. If you already use another layout tweak, keep a screenshot of the current arrangement so you can compare the result and restore your preferred layout if necessary.

How to add the complications

The official setup route is to hold the Lock Screen, choose Customize in PosterBoard, tap the widget area and locate the Super Complications widgets. The developer also documents a licence check every ten days, with renewal available from the Lock Screen or preferences.

After installing through the official source, test one module before rebuilding your entire layout. Change its position, leave the editor and return. For an app shortcut, change the target and reopen the editor to check whether it stayed saved. These checks directly address the areas named in the 1.3 changelog and are more useful than assuming an update succeeded because the package manager completed installation.

What to check after updating

Compare the editing preview with the finished Lock Screen. If they differ, note which module and appearance setting produced the mismatch. If a shortcut still resets, record the target you selected and the steps taken before it changed. Include your device, iOS version, jailbreak environment and installed package version when reporting the problem through the developer’s support links on Havoc.
