Aerial 5.1 Adds Four-Way iPad Split and Fixes Landscape Stages

Aerial 5.1 replaces the iPad one-third split with a four-way layout, fixes landscape Split Stage reversion and close-animation enlargement, and targets keyboard sizing during rotation.

By Zeeshan Barvi · Published October 23, 2026 · Version 5.1 released October 22, 2026

At a glance: Aerial 5.1 is a focused stability and iPad-layout update, not a new jailbreak. Havoc lists the package at $5.99, marks it rootless, and requires an already compatible jailbreak environment.

What changed in Aerial 5.1

Developer uzra released Aerial 5.1 on October 22, 2026. The official changelog contains four changes:

  • Four-way iPad splitting: the previous one-third split option is replaced by a four-way split.
  • Landscape persistence: Split Stage no longer reverts when the device is in landscape.
  • Cleaner closing: a stage should no longer briefly enlarge when it is closed from Aerial’s menu.
  • Keyboard rotation work: the developer says this version attempts to fix keyboard display and sizing during iPad rotation.

The wording of that last item matters. It is an attempted fix, not a promise that every keyboard and rotation combination is solved. The official page does not provide a device-by-device test matrix, and we have not presented independent hands-on testing as fact.

Why the four-way split matters

Aerial’s Split Stage feature runs multiple applications in a windowed arrangement. Replacing the iPad one-third preset with a four-way split gives tablet users a denser option for dashboards, monitoring, reference material and messaging. It also better matches the large canvas that makes this style of multitasking useful.

The landscape fix addresses an adjacent problem: a layout is only useful if it remains in the selected mode when the device rotates. Version 5.1 specifically says Split Stage no longer reverts in landscape, while the keyboard item targets display and sizing during iPad rotation.

How Aerial works

Aerial describes itself as “Stage Manager, redesigned for iOS.” It can be triggered by long-pressing an app icon and choosing Open in Aerial, or by pinching outward on an app in the App Switcher.

Once an app is staged, the central menu offers controls to open it normally, maximize it, minimize it into a floating icon, enter Split Stage, crop the visible area with Trim Mode, or close the stage. Bottom-left and bottom-right handles change the aspect ratio, while the center handle resizes the stage.

This is system-level multitasking, so application layouts can react differently to nonstandard window sizes. The developer specifically suggests enabling Disable flex resize from an app icon’s context menu if an app such as YouTube or Calculator renders incorrectly.

Compatibility: read both pieces of Havoc data

Havoc’s current package metadata lists Aerial 5.1 for iOS 15.0 through 26.0.1 and marks rootless support. The 5.0 changelog also says iOS 26 support was added. However, the product-description text still says support extends from iOS 15.0 through 17.7.10.

Because those statements do not perfectly match, verify the compatibility range displayed by your configured package manager before purchasing or installing. Package compatibility also does not mean every device on that firmware has a jailbreak. You still need a compatible device, firmware, jailbreak or bootstrap, and repository configuration.

The listing does not claim universal RootHide support, so this article does not infer it from rootless compatibility. If you use RootHide, check for a dedicated package or developer guidance rather than assuming that an ordinary rootless build is interchangeable.

Known conflict and practical cautions

The developer warns that Aerial conflicts with unofficial PullOver Pro builds or tweaks based on them. That warning is important because two system-wide multitasking tweaks can hook the same application-scene behavior and create crashes, layout bugs or failed launches.

  • Remove conflicting multitasking tweaks before diagnosing Aerial.
  • Record your current package version and settings before updating.
  • Restart the userspace or respring if the package manager requests it.
  • Test rotation, keyboard appearance, minimize/restore and Split Stage with noncritical apps first.
  • Do not force-install a package whose architecture or dependencies do not match your environment.

If dependencies fail, use our rootless Sileo dependency troubleshooting guide. For unfamiliar package contents, follow the DEB inspection guide before installation.

Is version 5.1 worth installing?

For current Aerial users, version 5.1 is most relevant if you use Split Stage in landscape, run Aerial on an iPad, see the stage expand briefly during menu-based closing, or have keyboard-sizing trouble after rotation. The four-way iPad layout is the one clearly new capability; the other items are targeted fixes.

For new buyers, Aerial remains a specialized $5.99 multitasking tweak rather than a general jailbreak tool. The official listing provides useful interface examples, but the compatibility-text discrepancy means you should confirm your exact environment first.
