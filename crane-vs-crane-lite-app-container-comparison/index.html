Crane vs Crane Lite: Which App Container Tweak Should You Use?

Crane Lite is the right free test for one app. The $4.99 Crane package is the better fit when you need containers across several apps, full backup and migration tools, system integrations or developer-facing support.

By Zeeshan Barvi · Published October 12, 2026 · Source checked against Havoc and opa334’s Crane resources

Package compatibility is not jailbreak availability. Havoc lists both packages for iOS 11.0–26.0.1 and marks rootless support as available, but your exact device and firmware still need a compatible jailbreak.

Quick verdict

  • Choose Crane Lite to try containers for one selected app without paying.
  • Choose Crane if you need several containerized apps, global shortcuts and integrations, multi-container backups, Game Center handling or the libCrane developer API.
  • Plan before switching Lite’s selected app: its own warning says all non-default containers for the previously selected app will be deleted.

What both packages actually do

Crane creates separate data containers for an application, letting the same installed app open with different local data sets. Think of them as isolated profiles inside one app installation—not as separately signed duplicate apps. The default container remains the app’s normal data location, and Crane’s official settings text says it is used when the device is not jailbroken or the tweak is not loaded.

That distinction matters. A container can separate local files, preferences and certain account state, but it does not change server-side rules, subscription limits or an app service’s terms. It also does not jailbreak a device.

Why Crane Lite is useful—and where the limit bites

Lite is deliberately narrow: its Havoc description calls it a test version with fewer features and one application at a time. The settings screen asks you to select an application and then configure containers for that app. That is enough to learn whether the workflow suits a messaging, social or game app before purchasing the full package.

The important catch appears in the official interface: selecting a different app deletes all non-default containers belonging to the previous selection. Do not treat Lite as a rotating archive for many apps. Export or otherwise preserve anything you need before changing the selected application.

What the paid version adds

The full package removes the one-app bottleneck and exposes broader system-level workflows. Official localization resources document app shortcuts from the Home Screen, a global container-selection interface, Activator integration, a Shortcuts action named “Set Active Crane Container,” and creation or restoration of multi-container backups.

The same source distinguishes two other paid-version advantages. Game Center support is marked as unavailable in Crane Lite, and the public libCrane.h integration header is explicitly described as unsupported by Lite. Those are specialized features, but they make the upgrade meaningful for games and for other tweaks that need to interact with Crane.

For a focused look at the paid interface, see our existing Crane 1.3.18-2 article. The Crane Lite 1.3.18-2 article covers the free package separately.

Moving from Lite to Crane

The migration path is built into the full package. Crane’s official strings say that when Lite containers are detected, it can offer to import them, delete them or remind you later. The Lite settings screen makes the same promise in plain language. Upgrade before you switch Lite to another app if the current non-default containers matter to you.

  1. Keep the wanted app selected in Crane Lite.
  2. Install the full Crane package from its official Havoc listing on a compatible jailbreak.
  3. Open Crane’s preferences and use the offered Lite-container import.
  4. Confirm the imported container opens correctly before deleting the Lite copy.

Compatibility and safety checklist

  • Confirm your device, exact iOS build and jailbreak—not just the package’s iOS range.
  • Use the official Havoc packages; avoid redistributed DEBs with unknown changes.
  • Back up important app data before deleting a container or changing Lite’s selected app.
  • Do not assume separate containers bypass app bans, device checks or service policies.
  • For package-manager differences, read our Sileo vs Zebra comparison.
  • Check older package advice against our rootless jailbreak basics before applying it.

Bottom line: start with Crane Lite if one app is enough and you are evaluating the concept. Buy Crane when containers become part of a multi-app workflow or when backups, system integrations, Game Center or developer API support justify the upgrade.

Frequently asked questions

Is Crane Lite only a time-limited trial?

No time limit is stated on the official listing. Its functional limit is one selected application at a time with fewer features than the paid package.

Can I keep Lite containers after buying Crane?

Yes. The official interfaces say the full package can detect and import Crane Lite containers.

Will switching Lite to another app preserve the old profiles?

No. Crane Lite warns that all non-default containers of the previously selected application will be deleted.

Does iOS 26.0.1 compatibility mean every iOS 26 device can use Crane?

No. Havoc’s number is package compatibility. A supported jailbreak must also exist for the exact device and firmware.
