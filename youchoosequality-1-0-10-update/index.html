YouChooseQuality 1.0.10 updates package metadata and adds Turkish localization

PoomSmart’s YouChooseQuality has reached version 1.0.10. The release changes the package metadata from 1.0.9 to 1.0.10, while the preceding project update added Turkish localization for the tweak’s settings interface. The project describes itself as a tweak that automatically selects a preferred—or closest available—video quality in the iOS YouTube app, with separate scenario labels for Wi‑Fi, cellular data, AirPlay, and Low Power Mode.

Key points

  • YouChooseQuality is listed at version 1.0.10 in the official package control file.
  • The 1.0.10 commit changes only the package version field from 1.0.9 to 1.0.10; no functional code change is identified in that commit.
  • A preceding update added Turkish strings for the enabled state, description, and five quality-selection scenarios.
  • The project’s package metadata lists mobilesubstrate version 0.9.5000 or newer and firmware 11.0 or newer as dependencies.
  • The package metadata identifies the architecture as iphoneos-arm, so users should check how their package manager and jailbreak environment handle that format before proceeding.

What changed in YouChooseQuality 1.0.10

The latest official project commit updates the control file’s Version field from 1.0.9 to 1.0.10. The same diff leaves the package name, architecture, description, and maintainer fields unchanged. Based on the published diff, this is a packaging or version-metadata update rather than a documented feature change.

That distinction matters when deciding whether to update immediately. The available source does not describe a new quality-selection algorithm, new settings, a compatibility fix, or a YouTube-specific behavioral change in 1.0.10. Readers should therefore avoid assuming that the version bump alone changes how video quality is selected.

  • Package name: YouChooseQuality
  • Package identifier: com.ps.youchoosequality
  • Current version: 1.0.10
  • Architecture declared by the package: iphoneos-arm
  • Project description: automatic selection of a chosen video quality in the iOS YouTube app

Turkish localization arrived in the preceding update

The most visible user-facing change in the recent history is the addition of a Turkish localization file. The project added tr.lproj/Localizable.strings, containing Turkish translations for the enabled state, the tweak description, and labels used by the scenario-based quality settings.

The localized description says that YouChooseQuality automatically selects the video quality chosen for each scenario, or the closest available quality. The strings identify five scenarios: Wi‑Fi, cellular data, AirPlay over Wi‑Fi, AirPlay over cellular data, and Low Power Mode.

This is a settings-interface improvement rather than evidence of a new selection mode. The source shows translated labels for existing scenario keys, but it does not state that the update adds additional scenario logic or changes the underlying video-quality behavior.

  • Enabled state translated as “Etkin.”
  • Separate labels are provided for Wi‑Fi and cellular data.
  • AirPlay scenarios distinguish Wi‑Fi from cellular data.
  • Low Power Mode has its own full and short labels.
  • The localization was added in a commit titled “Add Turkish localization (tr.lproj).”

Why the scenario model matters

YouChooseQuality is designed around the idea that one preferred quality may not suit every playback condition. The project’s localization keys expose a separate setting for each of the five scenarios listed in the source. That gives users a clearer picture of the tweak’s intended configuration model, even though the supplied material does not document the exact available quality values or explain how the closest match is calculated.

For example, the source supports saying that Wi‑Fi and cellular data have separate quality labels. It does not support claiming that the tweak guarantees a particular resolution, prevents buffering, reduces data use, or overrides every YouTube playback decision. Those outcomes would require additional documentation or testing that is not present here.

The Turkish addition may be especially useful for users whose device or application language uses Turkish, but the source does not specify the complete language-detection behavior or say whether every screen outside the listed strings is localized.

  • The source documents scenario labels, not a list of selectable resolutions.
  • The source does not promise a specific streaming resolution in every situation.
  • The source does not document performance, battery, bandwidth, or buffering results.
  • The source does not identify a YouTube app version range for this update.

These are package requirements, not a complete statement of modern jailbreak compatibility. What users should verify before updating

Because the 1.0.10 diff only changes the package version field, users should first confirm that their package manager is offering the package from the expected official distribution channel and that the displayed version matches 1.0.10. The project source identifies the package by both its name and identifier, which can help distinguish it from similarly named packages.

Next, check the dependency and architecture information shown by the package manager. The control file lists mobilesubstrate and firmware requirements, but satisfying those fields does not by itself establish compatibility with every current jailbreak setup. Users should also review whether their installed YouTube version is supported by current project documentation or issue reports, since the supplied source does not provide a YouTube version range.

Finally, users who depend on Turkish interface text should confirm that their environment actually loads the newly added localization. The commit proves that the Turkish string file was added; it does not document language-selection controls or guarantee that every interface element will appear in Turkish.

  • Confirm the package name and identifier before updating.
  • Check that the offered version is 1.0.10.
  • Review the listed dependencies and architecture against the current environment.
  • Look for project-specific compatibility notes about the installed YouTube build.
  • Do not infer new functionality from the version bump alone.

A measured update, not a feature-heavy release

The recent project history presents two different kinds of change. The Turkish localization commit adds user-visible text for the existing scenario settings, while the later 1.0.10 commit updates package metadata. Together, they make the release more polished for Turkish-speaking users and keep the package version current, but the available evidence does not describe a new engine, additional playback controls, or a compatibility repair.

For users already relying on YouChooseQuality, the practical question is whether the package source, dependencies, architecture, and YouTube environment line up with their setup. For users considering it for the first time, the project description establishes its purpose, while the package metadata establishes its declared requirements. More specific expectations—such as exact quality choices, app-version support, or behavior during AirPlay—should be based on further official documentation rather than inferred from the localization or version change.
