Watusi 3 v1.3.24 Adds WhatsApp 26.36.x Support and Fixes Three User-Facing Issues

Watusi 3 for WhatsApp has reached version 1.3.24. According to the official package information and changelog, the update adds support for WhatsApp 26.36.x and addresses three specific issues: cleared notifications reappearing, long status videos failing to split on newer WhatsApp versions, and the chat-bar microphone button failing to use the selected theme tint on WhatsApp’s new circular microphone design. The package metadata lists iOS 15.1 and later as supported, while its dependency stanza requires firmware 12.0 or later, MobileSubstrate 0.9.5000 or later, and Watusi Tools 2.8.3 or later. A separate community-maintained Simplified Chinese language package is also documented, but its repository states that it was developed against Watusi 1.3.9, so users should not assume that it is automatically matched to Watusi 1.3.24.

Key points

  • Watusi 3 version 1.3.24 is listed as supporting WhatsApp 26.36.x.
  • The release fixes notifications that reappeared after being cleared.
  • The status-video splitter was fixed for newer WhatsApp versions.
  • The new circular chat-bar microphone button now receives the theme’s tint color, according to the changelog.
  • The official depiction lists support for iOS 15.1 and later; package dependencies separately specify firmware 12.0 or later.
  • The documented Simplified Chinese language pack is based on Watusi 1.3.9 and should be treated as a separate compatibility question.

What Watusi 3 v1.3.24 changes

The official Watusi 3 package is identified as version 1.3.24, with the release information dated September 14, 2026. The headline change is support for WhatsApp 26.36.x, alongside a set of focused bug fixes rather than a newly advertised feature category.

The changelog names three corrections. First, notifications that had already been cleared could reappear; version 1.3.24 is described as fixing that behavior. Second, the Split Long Videos feature could fail to split status videos on newer WhatsApp versions. Third, the chat-bar microphone button did not always pick up the tint color defined by the active Watusi theme after WhatsApp introduced a new circular microphone button design.

  • WhatsApp 26.36.x support is explicitly listed.
  • Cleared notifications should no longer reappear according to the release notes.
  • Status videos affected by the newer WhatsApp behavior are the target of the video-splitting fix.
  • The microphone tint correction applies to WhatsApp’s new circular chat-bar microphone button.

Why the WhatsApp compatibility note matters

Watusi is a tweak that changes or extends many parts of WhatsApp, including privacy controls, status handling, chat-list tools, media actions, notifications, themes, message scheduling, auto-reply, hidden chats, custom tones, and sticker management. Because these functions interact with WhatsApp’s internal interfaces, the version of WhatsApp named in a Watusi changelog is an important part of the release context.

The official version history shows that recent Watusi releases have repeatedly tracked WhatsApp changes. Earlier entries mention WhatsApp 26.32.x, 26.30.x, 26.29.x, 26.27.x, 26.25.x, 26.24.x, 26.21.x, 26.20.x, and 26.18.x. That history does not mean every feature works identically across all builds; it shows why users should compare their installed WhatsApp version with the specific compatibility range named by the tweak.

For version 1.3.24, the supplied official material specifically names WhatsApp 26.36.x. It does not provide a broader compatibility promise for other WhatsApp versions, so users on a different WhatsApp build should check the package’s current official release information before proceeding.

  • The changelog’s compatibility statement is tied to WhatsApp 26.36.x.
  • Recent Watusi releases have addressed breakage caused by WhatsApp interface and storage changes.
  • A general claim that all WhatsApp versions are supported is not provided by the source.

Compatibility, dependencies, and package details

The official depiction lists “iOS 15.1+” in its information section. The package stanza separately declares a firmware dependency of 12.0 or later, plus MobileSubstrate version 0.9.5000 or later and Watusi Tools version 2.8.3 or later. These entries describe package requirements, while the depiction’s iOS 15.1+ line is the explicit support statement readers should use when assessing the release.

The package architecture is iphoneos-arm64, and the package conflicts with several older or alternative Watusi package identifiers, including com.fouadraheb.watusi, com.f0u4d.watusi, org.thebigboss.watusi, and com.b4db1r3.cleancopy. In practical terms, those conflict declarations mean users should review what is already installed rather than attempting to stack overlapping Watusi packages.

The official package description calls Watusi an all-in-one tweak for WhatsApp Messenger. Its listed capabilities cover privacy, protection, status tools, chats, chat-list management, media, interface customization, notifications, themes, scheduled messages, auto-reply, hidden chats, contact customization, custom tones, and sticker management. The package also includes a Control Center toggle, but the official description says CCSupport must be downloaded and activated through Control Center settings.

  • Declared dependencies: firmware 12.0 or later, MobileSubstrate 0.9.5000 or later, and Watusi Tools 2.8.3 or later.
  • Architecture: iphoneos-arm64.

What users should check before installing

The first check is the installed WhatsApp version. The release specifically advertises support for WhatsApp 26.36.x, so users should avoid treating the update as a universal solution for every WhatsApp build. The second check is the device and jailbreak environment against the official iOS and dependency information. The package metadata and depiction do not establish support for every possible installation arrangement.

Users should also review existing packages for conflicts. The package explicitly lists several conflicting identifiers, making it important to remove or reconcile older Watusi variants through the normal package-management process before installing an overlapping package. Readers should preserve any important WhatsApp data and settings according to their own backup practices; the supplied release notes do not describe a backup or migration procedure.

Finally, readers should distinguish the Watusi tweak from optional language resources. The official Watusi page lists English, Arabic, German, Spanish, French, Italian, Portuguese, and Turkish as available languages. The separate Simplified Chinese project says it adds Chinese translation and uses a small runtime hook to add “简体中文” under Watusi’s language menu. However, that project states that it is based on Watusi 1.3.9, not 1.3.24. Its README also recommends rechecking language-related hooks and list-construction methods after a Watusi upgrade. That is a clear reason to verify compatibility rather than assuming the language pack follows the main tweak automatically.

  • Match the installed WhatsApp version against the 26.36.x statement.
  • Check iOS version, MobileSubstrate, and Watusi Tools requirements.
  • Review conflicting package identifiers before installation.
  • Treat the Simplified Chinese language pack as a separate component with its own compatibility status.
  • Do not assume a Watusi 1.3.9 language resource is validated for Watusi 1.3.24.

Simplified Chinese language pack status

The official repository metadata describes WatusiZhHans as a Simplified Chinese language project for Watusi 3. Its README says the package adds Chinese translations and uses a minimal runtime hook to add a Simplified Chinese option to Watusi’s language menu. The documented path is Watusi, Other Settings, Language, followed by selecting 简体中文. The README also says users can try Language set to Auto while WhatsApp or the system language is Simplified Chinese.

A recent repository restructuring commit says the build process was changed to generate rootful, rootless, and roothide packages serially, while the localization output was simplified to retain zh-Hans.lproj resources. Those build changes describe the project’s packaging workflow, not proof that every generated package is compatible with the latest Watusi release.

The most important limitation is version alignment. The project README explicitly says it is based on Watusi 1.3.9, and an earlier package manifest also identifies that baseline. The project’s own maintenance guidance says that when Watusi is upgraded, maintainers should recheck the language hook, language-list construction, and FRSListCell-related signatures. Users considering the Chinese package alongside Watusi 1.3.24 should therefore look for an updated compatibility statement from the language-pack maintainer.

  • The README documents manual selection through Watusi’s language settings.
  • Auto language detection may be attempted with Simplified Chinese selected at the WhatsApp or system level.
  • The project is explicitly based on Watusi 1.3.9.
  • Its own maintenance notes call for rechecking hooks after Watusi upgrades.

Frequently asked questions

What is new in Watusi 3 version 1.3.24?

The official changelog lists support for WhatsApp 26.36.x, a fix for cleared notifications reappearing, a fix for long status videos not splitting on newer WhatsApp versions, and a fix for the new circular chat-bar microphone button not receiving the theme tint color.

What iOS versions does the official package support?

The official package depiction lists iOS 15.1 and later. The package stanza separately declares firmware 12.0 or later as a dependency, so users should consider both entries along with their installed environment.

Does Watusi 3 v1.3.24 include Simplified Chinese?

The official Watusi description lists several languages but does not list Simplified Chinese. A separate language-pack project documents Simplified Chinese support, but its README says it was developed against Watusi 1.3.9. Compatibility with Watusi 1.3.24 should therefore be checked separately.

How is the Simplified Chinese language option enabled?

The language-pack README instructs users to install the language package, fully quit WhatsApp, reopen it, then navigate to Watusi, Other Settings, Language, and select 简体中文. It also suggests trying Auto with WhatsApp or the system language set to Simplified Chinese.

Does the update add new Watusi features?

The supplied version 1.3.24 changelog emphasizes compatibility and bug fixes. The official Watusi description continues to list a broad set of existing tools, but the 1.3.24 release notes do not announce a new major feature family.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
