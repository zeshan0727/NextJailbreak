Next Home Lock 1.0.5

Double-tap a genuinely empty Home Screen area to lock your iPhone. Version 1.0.5 keeps the physically verified lock method and replaces the former diagnostic-heavy pane with one clean on/off switch.

What version 1.0.5 does

This release intentionally focuses on one reliable convenience feature instead of adding unrelated controls.

2×

Double-tap to lock

Tap twice on empty Home Screen space and SpringBoard performs the same lock action used by the device lock button.

✓

One simple switch

Settings → Next Home Lock contains only Enable Next Home Lock. Turn it off to disable the gesture without uninstalling.

⌂

Home Screen only

The working implementation listens to the Home Screen icon-list background rather than adding a broad gesture across every app.

◎

No data collection

No network service, analytics, clipboard access, account access or background daemon is used.

Simple Settings concept

The release pane was deliberately reduced after device testing confirmed the core feature. Developer diagnostics, process IDs, hook status and test buttons are no longer shown to normal users.

Installation

  1. Add https://nextjailbreak.com/ to Sileo.
  2. Refresh package sources and search for Next Home Lock.
  3. Confirm the displayed version is 1.0.5.
  4. Select the package architecture that matches your jailbreak. Do not install both variants.
  5. Install or upgrade the package and complete the requested respring.
  6. Fully close Settings, reopen it, then open Settings → Next Home Lock.
  7. Keep Enable Next Home Lock turned on.

Recommended first test

  1. Confirm the package version in Sileo is 1.0.5 and respring.
  2. Open Settings → Next Home Lock and confirm only the enable switch is shown.
  3. Turn the switch on and return to the Home Screen.
  4. Double-tap a clearly empty wallpaper area between icons.
  5. Confirm the device locks without a SpringBoard crash or layout change.
  6. Unlock, turn the switch off, and confirm the same double-tap no longer locks the device.

Troubleshooting and recovery

Nothing happens

Confirm the switch is enabled, respring again and test a clearly empty Home Screen area rather than an icon, widget, dock or folder.

Wrong package variant

Remove the installed package, respring, then install only the build matching RootHide or standard rootless.

SpringBoard enters Safe Mode

Open Sileo while in Safe Mode, uninstall Next Home Lock, then respring. Keep access to Sileo before installing any SpringBoard tweak.

Remove the tweak

Uninstall com.nextsolution.nexthomelock in Sileo and respring. The Home Screen returns to stock behaviour.

FAQ

Does Next Home Lock work on stock iOS?

No. It requires a supported jailbroken iOS 16 environment.

Which build should RootHide users install?

Install NextHomeLock_1.0.5_RootHide.deb, architecture iphoneos-arm64e.

Which build should standard rootless users install?

Install NextHomeLock_1.0.5_Rootless.deb, architecture iphoneos-arm64.

Does it require a respring?

Yes. Respring after installation or upgrade so the SpringBoard tweak and preference bundle reload.

Can the feature be disabled?

Yes. Open Settings → Next Home Lock and turn off the single enable switch.

Why were the diagnostic rows removed?

They were temporary troubleshooting tools. Once the diagnostic release was physically confirmed, version 1.0.5 kept the working runtime and restored a clean user-facing pane.

Does it modify saved data?

No. It does not edit icons, app data, messages, contacts, accounts or files.

Where can I report a problem?

Use the Next Jailbreak contact links or YouTube channel and include your iOS version, jailbreak type and installed package variant.
