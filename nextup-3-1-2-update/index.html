NextUp 3 version 1.2 adds SoundCloud support and improves Apple Music playlist handling

NextUp 3 has reached version 1.2 with its largest recent expansion: SoundCloud is now a supported media source alongside Apple Music, Apple Podcasts, YouTube Music, YouTube and Spotify. The update also improves metadata and artwork handling for Apple Music tracks queued from library playlists, while refining the tweak’s Settings header layout for iOS 26 iPad interfaces. The project documents support for iOS 14.2 through iOS 26 and rootful, rootless and roothide jailbreak environments, but several integrations depend on specific app versions or platform requirements.

Key points

  • NextUp 3 version 1.2 adds SoundCloud support to the supported-app list.
  • SoundCloud support is limited to iOS 16.4 and later, matching the app’s stated minimum requirement.
  • The update handles Apple Music playlist entries that wrap song data inside a playlist-entry object, improving titles, artwork and identifiers.
  • The Settings header now accounts for iPad safe-area insets associated with the iOS 26 sidebar layout.
  • The tweak supports Lock Screen, Control Center and the expanded Dynamic Island player on devices that have a Dynamic Island.
  • Spotify, YouTube, YouTube Music and SoundCloud integrations are tied to documented app versions and may require updates when those apps change.

What changed in NextUp 3 version 1.2

The project’s latest version bump changes the package from 1.1.2 to 1.2. The most visible addition is SoundCloud support, making it the sixth media app listed by NextUp 3. The supported-app table now includes Apple Music, Apple Podcasts, YouTube Music, YouTube, Spotify and SoundCloud.

The update also changes the package and Settings bundle version values to 1.2. The project describes NextUp 3 as a modern revival of the earlier NextUp tweak, adding an Up Next row to Apple’s now-playing interfaces so users can see the upcoming item, skip it, play it immediately or re-queue the previous item where the integration supports those actions.

  • Package identifier: com.yves.nextup3.
  • License: GPL-3.0.
  • Documented compatibility: iOS 14.2–26 and rootful, rootless or roothide jailbreaks.

SoundCloud becomes the sixth supported source

SoundCloud support is the headline feature in version 1.2. The README lists the integration as full support, built against SoundCloud version 8.75.0. It also records an iOS 16.4 minimum for SoundCloud, described as the app’s own minimum requirement. That means the general NextUp 3 compatibility range should not be interpreted as a promise that every supported app works on every listed iOS version.

The integration is designed to read SoundCloud’s live playback queue and expose the upcoming track to the display side of the tweak. The project’s developer documentation says the SoundCloud provider uses the app’s Playback framework and signals queue changes through the app’s notifications and now-playing information rather than relying on Playback hooks for those changes.

SoundCloud’s queue can contain proxies, tracks, audio advertisements and video advertisements. The provider walks forward until it finds a real track, which the README summarizes as stepping over ads and not-yet-loaded placeholders. As a result, the intended display for a free account is the next real track rather than an advertisement.

The action paths are also app-specific. The developer notes explain that skipping uses a Swift-only queue-removal path, while playing the upcoming item immediately uses SoundCloud’s own jump-to-item behavior. Re-queueing the previous item uses the app’s exposed insertion method. These implementation details matter because the familiar MediaRemote next-track command does not reliably advance SoundCloud’s queue according to the project documentation.

  • SoundCloud integration target: version 8.75.0.
  • SoundCloud requirement: iOS 16.4 or newer.
  • Ads and placeholders are skipped when determining the next real track.
  • The project warns that an app update can silently break integrations built against specific versions.

Apple Music playlist entries are now unwrapped

A separate change improves how NextUp 3 obtains Apple Music metadata. Tracks queued from a library playlist may be represented as MPModelPlaylistEntry objects rather than exposing the song directly on the surrounding generic object. Earlier handling that looked only for a direct song could therefore leave important fields unavailable.

The new provider code unwraps the playlist entry to reach the underlying song. It applies the same approach when retrieving the artwork catalog. The documented purpose is to restore the information needed for the track title, artist, artwork, Apple Music identifier and play-previous behavior when the queue item comes from a library playlist.

This is a targeted compatibility correction rather than a new user-facing control. Users should notice it mainly when Apple Music’s queue contains playlist-derived entries: the Up Next row is intended to have usable metadata and artwork instead of remaining an incomplete placeholder. The source material does not claim a universal fix for every Apple Music queue or artwork issue, so the change should be understood specifically as support for the playlist-entry representation described in the code.

  • Playlist entries are unwrapped to locate the underlying MPModelSong.
  • Artwork lookup now checks the unwrapped song as well as the generic object.
  • The change also supplies the identifiers used by the provider’s queue and history handling.

Settings layout adjustment for iOS 26 iPad interfaces

Version 1.2’s recent source changes also adjust the NextUp 3 Settings header. The project explains that, from iOS 26, an iPad Settings sidebar can float over a detail column while UIKit provides a left safe-area inset instead of simply narrowing the table. Table rows account for that inset through their wrapper view, but the custom table header needs to apply it itself.

The header now derives its content bounds from the safe-area insets, uses those bounds for the icon and labels, and requests a new layout when the safe-area values change. The documented goal is to align the icon, name and version text with the Settings rows below it when the sidebar changes. Before iOS 26, the source says the relevant insets are zero, making the adjustment effectively unchanged on older layouts and on iPhone portrait layouts.

  • The change affects the custom Settings header rather than the media-player row.
  • The header responds to safe-area changes without requiring a separate feature toggle.
  • The source specifically describes the issue in the context of iOS 26 iPad Settings layouts.

What NextUp 3 provides across supported surfaces

NextUp 3 adds an Up Next row to the Lock Screen and Control Center now-playing interfaces. On iOS 16 and later, it also supports the expanded Dynamic Island player. The row displays the upcoming item and artwork, with controls for skipping the item or tapping its artwork to play it immediately where the current provider exposes that action.

The tweak also includes a previous-track action that re-queues what just played as the next item. Swipe gestures provide another way to move through the row: swiping left skips the next track, while swiping right places the recently heard track back into the queue. The project describes the carousel as showing neighboring artwork while the user drags.

A PreferenceLoader pane provides separate controls for supported apps and for the Lock Screen, Control Center and Dynamic Island surfaces. The README says those changes apply instantly without a respring, and that the pane lists installed apps and shows the Dynamic Island option only on devices with an island, including one enabled by a tweak such as VisibleIsland. Accessibility and localization support include VoiceOver, Reduce Motion, Increase Contrast, Dynamic Type and 27 languages.

  • Lock Screen and Control Center are supported surfaces.
  • Dynamic Island support applies to the expanded player on iOS 16 and later, where the device has an island.
  • App and surface toggles are independently configurable.
  • The project documents 27 languages and several accessibility features.

Compatibility and installation considerations

The project documents NextUp 3 for iOS 14.2 through iOS 26 and rootful, rootless and roothide jailbreaks. Those statements describe the tweak’s declared compatibility range; individual media integrations can have narrower requirements. In particular, the README lists build targets for YouTube Music, YouTube, Spotify and SoundCloud, and warns that updates to those apps may silently break their integrations until NextUp 3 is updated.

The official installation instructions identify Havoc as the recommended package source and also document installing the release package through a compatible package manager or Debian package tool. Dependencies listed by the project include libSandy, PreferenceLoader and either ElleKit or Substrate, with installation handled automatically by the package. The package restarts media apps itself, and the project says a respring is needed when the package manager requests one.

Before installing or updating, readers should compare their iOS version and jailbreak type with the project’s declared range, check the installed versions of any third-party media apps they plan to use, and confirm that the package is being obtained through the project’s documented official distribution channels. The source does not provide a guarantee that an unlisted app version will continue working.

  • General range: iOS 14.2–26.
  • Supported jailbreak modes listed by the project: rootful, rootless and roothide.
  • SoundCloud requires iOS 16.4 or newer.
  • Third-party app integrations may need a NextUp 3 update after the app itself changes.

Frequently asked questions

What is new in NextUp 3 version 1.2?

The main addition is SoundCloud support. The update also improves Apple Music playlist-entry handling and adjusts the custom Settings header for iOS 26 iPad safe-area layouts. The package and Settings bundle version are both changed to 1.2.

Which apps does NextUp 3 support?

The project lists Apple Music, Apple Podcasts, YouTube Music, YouTube, Spotify and SoundCloud. It gives specific build references for YouTube Music, YouTube, Spotify and SoundCloud, so compatibility with later app updates should be checked.

Does SoundCloud work on every iOS version supported by NextUp 3?

No. NextUp 3’s general range is iOS 14.2–26, but the README states that SoundCloud support is iOS 16.4 and newer because that is the app’s own minimum requirement.

Where does the NextUp row appear?

It appears in the Lock Screen and Control Center now-playing interfaces. The expanded Dynamic Island player is supported on iOS 16 and later on devices with a Dynamic Island.

Can NextUp 3 skip or immediately play every YouTube item?

The README distinguishes queue entries from standalone videos. Playlist, mix and Add to queue entries can be handled as queue items. A standalone video has no queue, so the autoplay suggestion is shown instead; that suggestion can be played but not skipped or reordered.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
