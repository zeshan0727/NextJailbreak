Please Stop The Music 0.1.1 Adds Swipe-to-Dismiss Controls for the Lock Screen Now Playing Card

Please Stop The Music 0.1.1 is a tweak by b4db1r3 that changes the way the Lock Screen’s Now Playing card can be dismissed. According to the official package description, users can swipe left to pause playback, dismiss the player and its Dynamic Island activity, and fade expanded artwork back to the wallpaper. A complete swipe clears the interface immediately, while a partial swipe reveals a Clear button. The source describes the package as rootless and lists iOS 16, 17, 18, and 26, but other metadata on the same source page lists only iOS 16, 17, and 18. iOS 26 support should therefore be verified before installation, and the source’s “iOS 27-inspired” wording should be understood as a design reference rather than a compatibility claim.

  • Please Stop The Music is version 0.1.1, package ID com.b4db1r3.swipeawaynowplaying, and is authored by b4db1r3.

A focused change to the Lock Screen music interface

Please Stop The Music is presented as a small, focused tweak for users who want a quicker way to remove the Lock Screen’s Now Playing card. The package stanza describes it as “Native Lock Screen music swipe dismissal,” while the longer source description says it brings an “iOS 27-inspired” swipe-to-dismiss gesture to the Lock Screen music interface. That phrase describes the stated design inspiration; it does not establish compatibility with iOS 27.

The documented interaction centers on a left swipe across the Now Playing card. The developer says that completing the gesture pauses playback, dismisses the player and its Dynamic Island activity, and fades expanded artwork back to the wallpaper. These behaviors are presented together as part of the dismissal action, although the source does not provide a technical explanation of how the tweak implements them or how it behaves with every audio application.

  • The target is the Lock Screen’s Now Playing card.
  • The documented gesture is a left swipe.
  • The source describes playback pausing and related music-interface dismissal as part of a completed swipe.
  • The “iOS 27-inspired” wording refers to design inspiration, not confirmed iOS 27 support.

Full swipe and partial swipe behavior

The source distinguishes between a complete swipe and a partial gesture. A full swipe clears the player immediately, according to the official description. A swipe that does not travel all the way reveals a Clear button, giving the user an intermediate action instead of treating every movement as an immediate dismissal.

That two-stage behavior is the central usability detail in the listing. Someone who wants an instant result can complete the gesture, while someone who stops partway can use the displayed Clear control. The source does not specify a distance threshold, animation timing, sensitivity setting, or whether the gesture can be customized.

The developer also says the player is designed to return when playback resumes. This indicates that the stated goal is temporary dismissal of the current Lock Screen presentation rather than permanently disabling the Now Playing card. However, the source does not define every playback condition that causes restoration, so the behavior should not be generalized beyond that description.

  • A full swipe is described as an immediate clear action.
  • A partial swipe reveals a Clear button.
  • The source says the player is designed to restore when playback resumes.
  • No gesture sensitivity, animation, or threshold settings are documented.
