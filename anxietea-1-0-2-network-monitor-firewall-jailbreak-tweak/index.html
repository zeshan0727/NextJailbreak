AnxieTea 1.0.5 Adds Company Blocking, Server Details and Statistics

AnxieTea 1.0.5 expands its network-control toolkit with company ownership data, per-server detail pages, company-wide blocking and daily or weekly security statistics. It also improves the World Map, large-iPhone meter behavior and rule updates from connection banners.

By Zeeshan Barvi · Published October 12, 2026 · Updated October 22, 2026 · Checked against Havoc version 1.0.5 and official interface media

This is a powerful network-control tweak, not a substitute for a supported jailbreak or a VPN. Havoc lists iOS 15.0–26.0.1 package compatibility and rootless support, but your exact device and firmware still need a compatible jailbreak.

What is new in AnxieTea 1.0.5?

Havoc lists AnxieTea 1.0.5 as the current release, published October 21, 2026. The package is 607.04 KB, costs $5.99, requires a jailbreak and is sold by AADiOS.

  • Company ownership on the World Map: each country can show which companies run its contacted servers and rank traffic by company.
  • Server detail pages: owner, labels, traffic, apps, addresses, the active rule and an online registration lookup appear in one place.
  • Block a company: block every network attributed to a company for all apps or for one selected app.
  • Daily and weekly statistics: review why requests were blocked, trackers that connected, unencrypted traffic, overnight activity, and the largest upload or cellular users.
  • Clearer identities: alerts, the map and Monitor can show plain company names such as Meta or Amazon.
  • Map improvements: full-screen display, double-tap zoom, crowded-dot country lists, smaller territories, Pacific routing, non-overlapping labels and stable list order.
  • Meter and rule fixes: iPhone 16, 17 and 18 Pro Max meter placement, hold-to-open on iOS 18 or later, and immediate app-page updates for rules created from a banner.
  • Interface fixes: right-to-left lists no longer cut off and the notice’s Ignore button stays on one line.

Version 1.0.4, released before this update, also fixed the VPN kill switch causing “No Service,” corrected misleading rule-status text and introduced a new icon. Version 1.0.5 includes those earlier fixes.

What AnxieTea does

The central idea is simple: show which apps and system services are connecting, then let the user decide which traffic is allowed. The developer says live entries can show the app, server, owner, country, transport and transferred data. A separate history includes open, recent and blocked requests.

Ask before an app reaches a new server

AnxieTea’s most distinctive mode is Ask. When an app first reaches a new server, a banner can pause that connection and offer Allow or Block. The developer says the answer can cover the wider site rather than repeatedly prompting for every host.

Default modes cover apps that do not yet have a specific rule: Allow, Ask or Deny. Individual apps can also be restricted to Wi-Fi only or cellular only. The listing says a specific server rule takes precedence over an app rule, which takes precedence over the global mode.

Monitoring, history and exports

The connection viewer can search hosts or apps and separate open, recent and blocked activity. The official description also lists per-app usage, charts from one minute to seven days, a request log and CSV export. Its server-name detection is described as using TLS and QUIC handshakes, including when encrypted DNS is enabled.

Version 1.0.5 turns the World Map into more than a country view. It can rank traffic by the companies operating the contacted networks, open a company breakdown for a country, and list crowded countries at a tapped point. Server pages connect that map data to the apps, addresses, traffic and active rule.

Company ownership is network attribution, not proof of which organization authored an app request or what an encrypted connection contained. Hosting and cloud networks can serve many unrelated customers, so review the server details before applying a company-wide block.

The developer also advertises Apple analytics and known-bad-network blocking, devices-on-Wi-Fi discovery, and a nearby AirTag, Tile and SmartTag scan. These are security-oriented controls, but Next Jailbreak has not independently validated their detection accuracy across every device and network.

Status-bar meter and on-device privacy claims

An optional status-bar meter shows live download and upload speeds, flashes when a request is blocked and can open a chosen AnxieTea page when held. Version 1.0.3 extended the meter to notchless iPhones and added horizontal positioning. Version 1.0.5 adds proper placement on iPhone 16, 17 and 18 Pro Max models and lets a hold open the app on iOS 18 or later. The listing says traffic data remains on the device, request contents are not stored, the database is root-only, and map/address lookups work offline. Those are developer-published claims rather than a third-party audit.

Safer first-run setup

  1. Start with Allow or Ask, not a global Deny policy.
  2. Open essential apps one at a time and confirm login, sync, notifications and media still work.
  3. Create narrow app or domain rules before applying a broad blocklist.
  4. Test Wi-Fi and cellular separately if using network-specific rules.
  5. Use the temporary Network Filter pause when diagnosing a broken app, then fix the rule rather than leaving filtering disabled.

Who should consider it?

AnxieTea is aimed at users who want visibility and control beyond iOS’s standard per-app cellular switch: jailbreak testers, privacy-conscious users, and developers tracing which services an app contacts. It is a poor fit for anyone who needs a set-and-forget configuration, because aggressive firewall rules require troubleshooting when legitimate domains change.

Bottom line: AnxieTea 1.0.5 is a substantial visibility update. Company attribution, server pages, company-wide blocking and security statistics make the firewall easier to investigate, while the map, meter and rule-display fixes reduce daily friction. Company blocks are broad, so the safest rollout remains gradual and the developer’s privacy and detection claims should not be treated as an independent audit.

Frequently asked questions

What does AnxieTea 1.0.5 add?

Company ownership and traffic rankings on the World Map, server details, company-wide blocking, daily and weekly statistics, map improvements, large-iPhone meter fixes and interface corrections.

Is AnxieTea a VPN?

No. It monitors and filters traffic on a jailbroken device. Its VPN kill-switch feature does not provide a VPN tunnel or VPN service.

Can AnxieTea block only cellular data for one app?

The official listing says an app can be set to Wi-Fi only, cellular only, Allow, Ask or Deny.

Will Ask mode prompt for every subdomain?

The developer says an Allow or Block decision can cover the whole site, reducing repeated prompts. Exact behavior depends on the resulting rule.

Does AnxieTea work on non-jailbroken iPhones?

No. Havoc explicitly marks the package as jailbreak-required.
