Watusi 3 version 1.3.28 adds WhatsApp 26.41 support and fixes status-related bugs

Fouad Raheb’s official package information lists Watusi 3 for WhatsApp version 1.3.28 as the latest release. The update is described as a bug-fix release with support for WhatsApp 26.41. It addresses viewed statuses being incorrectly marked as seen after WhatsApp relaunches, crashes when opening some statuses, and View Once screenshot or recording controls that stopped working on newer WhatsApp versions. The package metadata lists a firmware dependency of iOS 12.0 or later, while the official depiction separately lists support for iOS 15.1 and newer. Users should therefore treat iOS 15.1+ as the published support statement for this release and confirm their jailbreak environment, substrate implementation and WhatsApp build before installing. The supplied official Chinese localization project is a separate add-on based on Watusi 1.3.9, not a translation update specifically announced for Watusi 1.3.28.

Key points

  • Watusi 3 version 1.3.28 is described as adding support for WhatsApp 26.41.
  • The release fixes a status-viewing crash affecting some configurations with Download or Mark as Viewed enabled.
  • Viewed statuses should no longer be marked as seen for the sender after WhatsApp is relaunched when Mark as Viewed is enabled, according to the changelog.
  • The update fixes Allow View Once Screenshot/Recording on newer WhatsApp versions.
  • The official depiction lists iOS 15.1+ support, while package metadata declares a firmware dependency of iOS 12.0 or later; users should verify their exact environment.
  • A separate Simplified Chinese language-pack project is based on Watusi 1.3.9 and adds a Chinese option under Watusi’s language settings.

What changed in Watusi 3 version 1.3.28

The official Watusi package is identified as Watusi 3 for WhatsApp, package version 1.3.28, with Fouad Raheb listed as author and maintainer. Its latest-change notes describe the release as providing bug fixes and support for WhatsApp 26.41.

The most specific fix concerns viewed statuses. When Mark as Viewed was enabled, a status could reportedly be marked as seen for its sender after WhatsApp was relaunched. Version 1.3.28 lists a fix for that behavior. This matters for users who use Watusi’s status controls but do not want a local relaunch to alter the sender-facing viewed state.

The release also addresses a crash that could occur while viewing some statuses when the Download or Mark as Viewed buttons were enabled. The changelog does not define every affected status type or configuration, so users should not assume that every possible status-related issue is covered.

Finally, the update fixes Allow View Once Screenshot/Recording on newer WhatsApp versions. The changelog presents this as a compatibility correction rather than a new feature: the option already existed, but was not working on newer WhatsApp releases.

  • Support is specifically stated for WhatsApp 26.41.
  • Status-viewing behavior after relaunch is corrected when Mark as Viewed is enabled.
  • Some crashes involving status viewing and Download or Mark as Viewed are addressed.
  • Allow View Once Screenshot/Recording is restored on newer WhatsApp versions.

Why WhatsApp compatibility is the main reason to pay attention

Watusi’s changelog shows a close relationship between the tweak and WhatsApp’s internal changes. Earlier entries in the supplied history also reference WhatsApp 26.41.X, new internal status storage and status controls, but version 1.3.28 is the release that explicitly lists support for WhatsApp 26.41 and the three fixes above.

This does not mean that every WhatsApp build in the 26.41 family will behave identically. The official notes do not provide a complete build matrix, and they do not promise compatibility with future WhatsApp versions. Users should compare their installed WhatsApp version with the release information before updating either component.

The broader Watusi package includes privacy, protection, status, chat, media, interface, notification, theme, scheduling, auto-reply, hidden-chat, contact and sticker-management features. The official description says configuration is performed from inside WhatsApp settings. Version 1.3.28’s change notes, however, focus on compatibility and bug fixes rather than adding a new category of functionality.

  • Check the precise WhatsApp build, not only the major version number.
  • Do not treat support for WhatsApp 26.41 as a guarantee for later WhatsApp releases.
  • The 1.3.28 notes do not claim that every status or View Once issue has been fixed.

Compatibility and package requirements

The package stanza declares dependencies on firmware version 12.0 or later, mobilesubstrate 0.9.5000 or later, and WatusiTools 2.8.3 or later. It also identifies the package architecture as iphoneos-arm64 and lists conflicts with several older Watusi package identifiers and another conflicting package.

The official Sileo depiction lists “Supports: iOS 15.1+.” Because these are different kinds of statements, users should read them conservatively: the package dependency describes an installation requirement, while the depiction provides the published support line for this release. The supplied materials do not explain whether all iOS versions satisfying the firmware dependency are fully supported in practice.

The package also conflicts with older Watusi identifiers, including com.fouadraheb.watusi, com.f0u4d.watusi and org.thebigboss.watusi. A package manager should resolve declared conflicts, but users should still review what will be removed or replaced before proceeding. The package depends on WatusiTools, so that dependency must also be available in the user’s package environment.

  • Package dependency: firmware >= 12.0.
  • Official depiction support statement: iOS 15.1+.
  • Required components include mobilesubstrate >= 0.9.5000 and WatusiTools >= 2.8.3.
  • The package declares conflicts with older Watusi packages and another conflicting tweak.
  • The package architecture is iphoneos-arm64.

The separate Simplified Chinese language pack

The supplied official GitHub project describes WatusiZhHans as a Simplified Chinese language pack based on Watusi 1.3.9. Its stated purpose is to add Chinese translations and use a minimal runtime hook to add “简体中文” to Watusi’s language menu under Other Settings → Language.

This project should not be presented as part of Watusi 3 version 1.3.28. Its README explicitly says it is based on Watusi 1.3.9, while the package metadata shown in the supplied commit history changed between releases. One commit lists a package version of 1.3.9-2 with a dependency on Watusi, while a later commit lists version 0.0.1 and a looser dependency declaration. That history makes it especially important to inspect the current package control file before installing it alongside a newer Watusi release.

The project’s recent packaging refactor says it can generate rootful, rootless and roothide installation packages, and that localization output is streamlined around zh-Hans.lproj. The README’s user instructions are straightforward: install the language-pack package, fully terminate WhatsApp, reopen it, then navigate to Watusi → Other Settings → Language and select Simplified Chinese. It also suggests trying Language = Auto when WhatsApp or the system language is Simplified Chinese.

The source does not state that this language pack has been updated for Watusi 1.3.28. Users should therefore verify its declared dependency and check whether the language menu and translated resources remain compatible with their installed Watusi build.

  • The language pack is based on Watusi 1.3.9, not explicitly on 1.3.28.
  • It adds Simplified Chinese translations and a Simplified Chinese language-menu entry.
  • The project documentation instructs users to fully quit and reopen WhatsApp after installation.
  • Compatibility with Watusi 1.3.28 is not stated in the supplied material.

What to verify before installing

First, confirm that the installed WhatsApp build is the one targeted by the changelog. Version 1.3.28 explicitly names WhatsApp 26.41, but the source does not provide a complete list of supported sub-builds.

Next, check the package manager’s dependency and conflict plan. The package requires WatusiTools and mobilesubstrate versions meeting the declared minimums, and it conflicts with older Watusi package identifiers. Review any proposed removals before accepting the transaction.

Finally, separate the core tweak from optional localization. The Simplified Chinese project has its own package identity and its own historical versioning. Its documentation recommends closing WhatsApp after installation, but it does not claim compatibility with every Watusi release. Users who need Chinese localization should verify the language pack’s current dependency before adding it.

As always with a jailbreak tweak that modifies WhatsApp behavior, readers should preserve their existing app data and avoid assuming that a listed fix covers unrelated functions. The supplied sources provide release notes and package requirements, but no guarantee of uninterrupted operation across future WhatsApp updates.

  • Match WhatsApp’s exact version against the published target.
  • Review dependencies, architecture and conflicts.
  • Treat the Chinese localization as a separate project.
  • Verify current package declarations before installing optional components.
  • Do not update WhatsApp independently without checking Watusi compatibility again.

Frequently asked questions

What is new in Watusi 3 version 1.3.28?

The official changelog lists support for WhatsApp 26.41, a fix for viewed statuses being marked as seen for the sender after relaunch when Mark as Viewed is enabled, a fix for some status-viewing crashes, and a fix for Allow View Once Screenshot/Recording on newer WhatsApp versions.

Does Watusi 1.3.28 support iOS 12?

The package metadata declares a firmware dependency of iOS 12.0 or later, but the official depiction lists support for iOS 15.1 and newer. Because the supplied sources do not reconcile those statements, users should treat iOS 15.1+ as the published support statement and verify their exact environment.

Is Simplified Chinese included in Watusi 1.3.28?

The supplied Watusi description lists several built-in languages but does not list Simplified Chinese. A separate WatusiZhHans project provides a Simplified Chinese language pack, but its README says it is based on Watusi 1.3.9. Compatibility with 1.3.28 is not explicitly stated.

How is the Chinese language pack enabled?

Its README instructs users to install the language-pack package, fully terminate WhatsApp, reopen it, then go to Watusi → Other Settings → Language and select 简体中文. It also suggests trying Language = Auto with WhatsApp or the system set to Simplified Chinese.

Does version 1.3.28 add new Watusi features?

The supplied release notes describe bug fixes and WhatsApp 26.41 support. They do not announce a new feature category; the View Once screenshot or recording correction restores functionality that was not working on newer WhatsApp versions.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
