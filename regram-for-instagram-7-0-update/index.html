Regram 7.0 Rebuilds Its Instagram Toolkit for IG 454.1

Regram for Instagram 7.0 is a major update to Fouad Raheb’s Instagram enhancement tweak. Released November 5, 2026, the package adds compatibility updates for Instagram 454.1, overhauls its settings interface, expands privacy and media controls, and rewrites Profile Analyzer and Stories Archive. The release is available in a jailbreak package and in source-listed sideloading variants, but users should match the build to their installation method, Instagram version, iOS version, and signing setup before updating.

Key points

  • Regram 7.0 is built around Instagram 454.1 and includes bug fixes and compatibility updates for that release.
  • The settings system now includes search, a reorganized layout, setting links, New tags, and an optional update checker that can open an installer app.
  • Profile Analyzer and Stories Archive receive substantial rewrites, including dashboards, filters, history, analytics, exports, and audience information.
  • New tools cover privacy, Media Vault, backups, storage, video playback, Instagram feature flags, Shortcuts, API activity, and background-request pacing.
  • The package metadata lists firmware 14.0 or later and MobileSubstrate 0.9.5000 or later as dependencies, while the official depiction lists support as iOS 15.1+.
  • The official README lists jailbreak, AltStore-style sideloading, signing-certificate, and TrollStore paths with different notification and expiration implications.

A compatibility-focused release for Instagram 454.1

Regram 7.0 is presented as both a feature release and a compatibility update. The official changelog says it includes bug fixes and compatibility updates for Instagram 454.1, while the project’s release table pairs version 7.0 with Instagram 454.1 for its standard, No-Plugins, Duplicate, and TrollStore variants. The prior 6.5 entries were paired with Instagram 452.0, making the new application base one of the clearest changes for users upgrading from that release.

The package is identified as Regram for Instagram, version 7.0, with the identifier com.fouadraheb.regram. Its package metadata lists firmware version 14.0 or later and MobileSubstrate version 0.9.5000 or later as dependencies. Separately, the official package depiction lists support as iOS 15.1+. Because those statements describe different parts of the distribution metadata, users should check the installer’s own dependency resolution and the current depiction before proceeding.

  • Release date listed by the official package page: November 5, 2026.
  • Instagram build listed for the supplied Regram 7.0 variants: 454.1.
  • The package metadata lists an architecture of iphoneos-arm and a package size of about 19.67 MB on the depiction page.

Settings and account controls get a full redesign

The most visible usability change is a rebuilt settings system. Regram 7.0 adds search for locating settings, a new layout, one place for each setting, setting links, and New tags intended to make recently added controls easier to identify. The release also adds an update check that places new versions at the top of Settings and can open an installed updater or package manager such as Feather, AltStore, or Sileo. The update check can be disabled.

Privacy controls now extend to Instagram’s followers and following lists. The changelog says users can hide those lists from other people and hide themselves from other users’ lists. These choices are saved on the Instagram account, so the source describes them as applying across access rather than only to the local installation.

The update also adds an Activity Status button to the chats list. Users can turn online status on or off with one tap, or hold the control for more options; the same control is available in Quick Controls. Instagram banners for messages, activity, and other accounts can also be hidden while the app is open.

  • Setting links now work on jailbreak as well as in the listed app-utility workflows.
  • Follow confirmation was extended to suggested accounts in the Stories bar and follow or unfollow actions from long-press profile previews.
  • Hidden chats can now be removed from share-sheet suggestions and search until they are revealed again.

Profile Analyzer and Stories Archive are substantially expanded

Profile Analyzer has been rewritten around a native dashboard and a single list screen. The listed tools include search, filters, notes and tags, batch follow or unfollow actions with safety caps, scan-history timelines, comparisons, a Growth page for iOS 16 and later, ghost-follower information, and export. These additions make the feature more oriented toward reviewing account changes over time rather than only displaying a basic follower comparison.

Stories Archive also receives a rewrite. Its new Insights view compares results with the preceding period and includes audience information, the best-performing story and time, and top viewers. On iOS 16 and later, the release adds Story trends charts. The People list can show verified and private indicators, while viewer profiles gain a seen strip, follow status, and timeline filters. Regram also says the archive now saves sticker reactions and votes.

The package’s broader feature description continues to position Regram as an Instagram customization and privacy tool. Existing categories include anonymous story viewing, manual seen marking, download and expansion controls for media, direct-message read controls, screenshot and typing-notification controls, feed cleanup, and profile utilities. The 7.0 notes are more specific about what changed than the general feature list, so users should treat the changelog as the relevant reference for newly added behavior.

  • Profile Analyzer adds safety caps to batch follow and unfollow operations.
  • Stories Archive adds audience and viewer-oriented analytics rather than only local story storage.
  • The Growth page and Story trends charts are explicitly marked as iOS 16 or later features.

New media, playback, and backup tools

Media Vault is expanded with a photo and video editor, an information screen, and a Post to Instagram action. Its folder system is rebuilt around nested, smart, and locked folders, with date filtering and additional tools. A new video player is shared across Vault, Downloads, and expanded media views. It supports pinch-to-zoom, double-tap seeking, 2x playback while holding, speed controls, exact-frame scrubbing, Picture in Picture, AirPlay, and saving a frame to Photos or Vault.

The release adds backup and storage management. Regram data can be backed up to Google Drive on a schedule or exported to a file, then restored or reset by feature. Older exports remain accessible through Older Backups. Storage & Files shows space usage, provides access to Instagram folders, and adds cache cleanup and automatic clearing. The changelog says the existing Auto Clear schedule carries over after Clear Cache moves into this section.

Several media workflows gain additional coverage. Save All can now handle Highlights, including covers and one folder per highlight in ZIP files, plus tagged posts. Media Watch can save highlights and alert users when new highlight items appear. Story action controls now include a Links item for viewing, copying, opening, or sharing links found in a story.

  • Reels can continue playing in a floating Picture in Picture window when the user leaves Instagram, using Instagram’s own player.
  • New Reel Date and Repost Date controls expose the listed posting or repost timing through the Reels settings.
  • The iOS Tab Bar switch is available on iOS 26 or later and applies after a restart.

Tools for advanced users and request management

Regram 7.0 adds an IG Feature Flags area under Tools. The changelog describes a searchable catalog of approximately 38,000 flags, shareable links, a Try These page containing selected examples such as Extra Story Text Styles, and a crash guard that can undo problematic changes. Account-security flags are read-only, according to the release notes.

Shortcuts and Links add actions that open Regram screens or enable and disable settings from Apple Shortcuts. Regram asks for confirmation by default unless Skip Confirmation is enabled. The release also adds an IG API page under Settings > App, showing requests by feature, cache hits, hourly and daily limits, and a live paused-until state when Instagram rate-limits or flags the account. Pauses survive relaunch, while actions started directly by the user are not stopped by the described pacing system.

Background checks for watchlists, follow requests, Media Watch, and Save All now share one paced queue. The stated goal is to avoid a burst of requests when Instagram opens; checks manually started by the user continue to run immediately.

  • Feature flags that affect account security are described as read-only.
  • The API page exposes request and rate-limit information rather than presenting a general compatibility guarantee.
  • The changelog specifically describes pacing for background checks, not every Instagram request.

Installation paths and what to verify first

The official README documents a jailbreak installation through the project’s package source and separate sideloading variants for AltStore-style installation, TrollStore, and signing-certificate services. It lists standard, No-Plugins, Duplicate, and TrollStore packages, all paired with Instagram 454.1 and Regram 7.0. The Duplicate build uses a different bundle identifier, while the original Instagram variants use Instagram’s standard identifier.

For AltStore-style installation, the README lists a macOS or Windows computer, an internet connection, an Apple ID, and possible Developer Mode activation on iOS 16. It also warns that another Instagram installation with the same bundle identifier should not already be installed. A non-developer Apple account causes the signed app to expire after seven days, with AltStore able to automate re-signing while connected to the computer.

Push notifications depend on the signing method. The README says sideloaded installations do not receive push notifications unless signed with a Distribution or Ad-Hoc certificate, except for TrollStore on supported devices. It also says the original build should be used with a Distribution or Ad-Hoc certificate to receive notifications. TrollStore instructions are specifically associated with iOS 14–16.6.1 on iPhone X and older, or iOS 14–16.6 beta 1 on iPhone 11 and newer, as stated by the project.

Before updating, users should compare their Instagram build with 454.1, check the installer’s iOS and dependency requirements, confirm whether they need notifications or iCloud features, and decide whether the standard, No-Plugins, Duplicate, or TrollStore variant matches their current setup. Regram settings also include backups, so users who rely on stored configuration or feature data should review the new backup options before making a major installation change.

  • Use only the project’s official package or source-listed installation paths; do not substitute unofficial mirrors.
  • Check bundle identifiers before installing an original or Duplicate variant.
  • Review signing duration, notification support, and TrollStore eligibility separately; they are not equivalent installation outcomes.
  • The source does not claim that every listed feature works on every iOS version, so version-specific labels should be treated as requirements where provided.

Frequently asked questions

What is new in Regram 7.0?

The release updates compatibility for Instagram 454.1 and adds a redesigned settings system, account-level follower and following privacy controls, iPhone Duo support, rewritten Profile Analyzer and Stories Archive features, expanded Media Vault and video playback tools, backups, storage management, feature flags, Shortcuts actions, API monitoring, and paced background checks. It also includes fixes for several Instagram and Regram behaviors.

Which Instagram version is Regram 7.0 intended for?

The official release table pairs the Regram 7.0 variants with Instagram 454.1. The changelog also describes bug fixes and compatibility updates for IG 454.1. Users on another Instagram build should check for a matching Regram release before updating.

What iOS requirements are listed?

The package metadata lists firmware version 14.0 or later and MobileSubstrate 0.9.5000 or later. The official package depiction separately lists support as iOS 15.1+. Individual features have additional requirements: the Growth page and Story trends charts require iOS 16 or later, while several Liquid Glass-related controls require iOS 26 or later.

Can Regram 7.0 be used without a jailbreak?

The official README documents sideloading options, including AltStore-style installation, signing-certificate installation, and TrollStore on the supported device and iOS combinations described by the project. These methods have different expiration, notification, and iCloud implications.

Will sideloaded Regram receive push notifications?

The README says push notifications require a Distribution or Ad-Hoc signing certificate for sideloaded installations, with TrollStore on supported devices listed as an exception. A paid certificate should use the original build and the appropriate certificate according to the project’s instructions.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
