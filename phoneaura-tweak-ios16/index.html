Why the fixed keypad space matters

In earlier builds, saved-number results could appear and disappear while typing. That changed the available vertical space and shifted the digit grid, increasing the chance of tapping the wrong number.

PhoneAura now reserves the suggestion card at all times:

  • Matching saved contacts appear inside the reserved card.
  • When no contact matches, it displays Number not saved.
  • Before enough digits are entered, a neutral helper message appears.
  • The keypad digits, Call button and Delete button remain in fixed positions.

Keypad shortcuts

  • Long press 0 to enter the plus symbol.
  • Long press Delete to clear the complete number.
  • Use the lower Number Options menu to create or update a contact.
  • Tap the upper Next Jailbreak logo to open the YouTube channel.
PhoneAura 0.4.16 hotfix

Phone app crash fixed

Version 0.4.15 attached edit-menu interactions by globally modifying UILabel behavior inside the Phone process. On affected devices this caused MobilePhone to crash during launch or while views were updating.

  • The global long-press phone-number editing hooks have been removed.
  • The tweak now uses the proven 0.4.14 runtime file set.
  • Favorites, Recents, Contacts, Keypad, fixed suggestions, Number Options and the Next Jailbreak shortcut remain available.
  • RootHide and rootless builds were compiled separately as version 0.4.16.
Remove 0.4.15 immediately. Refresh the Next Jailbreak repository and upgrade to 0.4.16 before reopening the Phone app.
Compatibility

Choose the correct package

RootHide and standard rootless jailbreaks use different filesystem layouts and package architectures. Install only the version matching your jailbreak.

Package Architecture Use this when
RootHide iphoneos-arm64e Your device is jailbroken using the RootHide environment.
Rootless iphoneos-arm64 You use a standard rootless jailbreak environment such as a compatible Dopamine/palera1n setup.
Do not install both variants. They use the same package identifier and are alternative builds of the same tweak.

Questions

PhoneAura FAQ

Does PhoneAura work on stock iOS?

No. PhoneAura is a jailbreak tweak and requires a compatible iOS 16 jailbreak environment.

Which build should RootHide users install?

Install the RootHide iphoneos-arm64e package. Do not install the standard rootless package alongside it.

Why was long-press number editing removed?

The 0.4.16 implementation modified UILabel behavior globally and caused the Phone app to crash on affected devices. Version 0.4.16 removes that code and restores the stable 0.4.14 runtime.

What appears when no saved contact matches?

The fixed suggestion area displays “Number not saved” without moving the keypad.

Can I turn off individual redesigned tabs?

Yes. PhoneAura settings include separate replacement controls for Favorites, Recents, Contacts and Keypad.

Where can I report a problem?

Use the Next Jailbreak YouTube channel or social links on the main website and include your iOS version, jailbreak type and PhoneAura version.
