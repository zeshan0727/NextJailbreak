LockScreenRestore 1.9.6 Blocks iOS 17 Installs and Fixes Landscape Wallpaper

The current release fixes a landscape Lock Screen wallpaper bug and, more importantly, prevents the iOS 16-only tweak from being installed where it only half works.

Originally published September 28, 2026Updated November 20, 2026
Current status: LockScreenRestore 1.9.6 is the latest official release. It is a free rootless iOS 16 tweak; the package requires iOS 16.0 or later but lower than iOS 17. Dynamic Island iPhones remain unsupported, and the release does not add iOS 17, iOS 18, iOS 26 or iOS 27 support.

What changed in LockScreenRestore 1.9.6

The developer published 1.9.6 on GitHub on November 14, 2026 at 08:44 UTC; Havoc updated its repository copy on November 18. The release contains two focused changes:

  • Landscape wallpaper coverage: pulling down the Lock Screen while the device is in landscape now fills the whole display. Previously, the wallpaper could appear only as a strip through the center.
  • iOS 17 installation guard: the package now declares firmware (>= 16.0) and firmware (<< 17.0). Package managers should therefore refuse iOS 17 and later, where the developer says LockScreenRestore only half applied.

The second change is a compatibility correction, not a new jailbreak limitation. LockScreenRestore was already designed for iOS 16; version 1.9.6 makes the package enforce that boundary instead of letting users discover it after a broken partial install.

What arrived after the previous 1.9.4 coverage

Version 1.9.5 was a larger feature update and remains part of the current 1.9.6 build. It restored iOS 15’s own views for dynamic and still wallpapers, added downloadable Live wallpapers for every supported iPhone, and brought back pull-down-anywhere Lock Screen search.

It also added the lighter iOS 15 Home Screen icon-label shadow, iOS 15 sizing for notification cards and the music player, the older clock font, and the system wallpaper preview with Cancel and Set actions. On iPhone Plus models, the wallpaper can rotate with the Home Screen and the dock blurs the right landscape wallpaper.

Other non-Dynamic-Island iPhones receive screen-size positions but are not all tested. Package compatibility also does not make every iPhone on iOS 16 jailbreakable. Confirm your exact device, firmware and jailbreak with the tweak compatibility checklist before installing.

The official sources do not claim a rootful or RootHide package. Do not convert or repackage the DEB and treat the result as developer-supported.

Known limitations that 1.9.6 does not remove

  • Dynamic Island layout support is still absent.
  • Landscape behavior on Plus models is new; Perspective Zoom and dynamic-bubble motion direction remain untested there.
  • Home-button iPhones can briefly show the system wallpaper in the dock while the Home Screen rotates.
  • Enabling Live Wallpaper replaces the normal long-press route to the iOS 16 Lock Screen editor.
  • Wallpaper downloads depend on the external wallpaper archive being available.
  • Other tweaks that modify the clock, notifications, music player, wallpaper or unlock animation can conflict.

Safe update and troubleshooting

  1. Update from the developer’s repository or the official Havoc listing. The exact GitHub asset is com.aronsz26.lockscreenrestore_1.9.6_iphoneos-arm64.deb with SHA-256 5beed77d37cf11612287c18d1c87f52e21843e44c5e7ba0e42f97782497d8ddc.
  2. Confirm that the package manager shows an iphoneos-arm64 rootless package and an iOS 16 device. Our rootless DEB installation guide explains architecture and dependency checks.
  3. After updating, respring and test the Lock Screen in portrait first. Then rotate a Plus-model device to landscape and pull down the Lock Screen to confirm the wallpaper fills the display.
  4. If only one component misbehaves, disable that component in Settings → Tweaks → LockScreenRestore and use Apply (Respring). The tweak provides separate switches for clock, Focus, notifications, music player, unlock animation, icon-label shadows and Live Wallpaper.
  5. If SpringBoard enters Safe Mode, disable tweak injection, remove LockScreenRestore or the overlapping Lock Screen tweak, and respring. Follow the Dopamine crash-loop recovery guide if normal removal is unavailable.
