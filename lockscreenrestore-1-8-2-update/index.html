LockScreenRestore 1.9.1 Refines iOS 15 Clock Sizing Across iOS 16 iPhones

LockScreenRestore 1.9.1 is a beta rootless jailbreak tweak that recreates major parts of the iOS 15 Lock Screen on iOS 16. The release updates how the tweak determines clock size and placement, replacing a largely fixed approach with per-screen calculations based on iOS 15 measurements. The project still targets jailbroken iOS 16 devices, has been tested only on an iPhone 13 Pro running iOS 16.1.1 and an iPhone 12 Pro running iOS 16.5, and lists other devices as supported or reported but untested.

Key points

  • LockScreenRestore 1.9.1 changes the clock layout logic to use iOS 15-style sizes and positions for different iPhone screen classes.
  • The tweak restores iOS 15-style clock, Focus, notification, music-player, unlock-animation and wallpaper behavior, with separate switches for each component.
  • Compatibility is limited to rootless jailbreaks on iOS 16; the README specifically names Dopamine and ElleKit for the tested configurations.
  • The confirmed test devices are an iPhone 13 Pro on iOS 16.1.1 and an iPhone 12 Pro on iOS 16.5.
  • The package is a beta and requires PreferenceLoader; users should check the project’s compatibility notes before installing.

What changed in version 1.9.1

The main change in LockScreenRestore 1.9.1 is the way the tweak calculates the iOS 15-style clock. Earlier code used a general scaling ratio based on the iOS 16 clock, with an adjustable Clock Size control for devices where the result looked too small or too large. The 1.9.1 changes instead define iOS 15 clock sizes by screen class and calculate the clock’s vertical position from those values.

The project’s source describes 70-point clock sizing for the iPhone 8 and iPhone SE screen class, 80 points for devices such as the iPhone X, XS, 11 Pro, iPhone 12 and iPhone 13, and 90 points for the iPhone 8 Plus, XR, 11 and Pro Max screen classes. Devices with screen sizes that iOS 15 did not support, including Dynamic Island models, fall back to a scaled iOS 16 clock value.

Positioning has also been revised. On iPhones, the time baseline is calculated from the status-area height plus the clock size, subject to minimum values for Face ID, Plus-sized and Home Button devices. The date remains positioned 36 points below the time. Face ID padlock placement continues to use the iOS 15-style 76-point position, while Touch ID devices use a different calculation. The settings control remains available and scales the calculated iOS 15 size from 0.7 to 1.5.

  • Package version: 1.9.1.
  • The package identifier is com.aronsz26.lockscreenrestore.
  • The package metadata describes the release as beta and lists firmware 16.0 or newer, mobilesubstrate and PreferenceLoader as dependencies.

The iOS 15 experience it restores

LockScreenRestore is broader than a clock replacement. Its README describes a collection of independent components that can be enabled or disabled separately, allowing users to combine selected iOS 15 elements with parts of the native iOS 16 Lock Screen.

With the iOS 15 Clock switch enabled, the tweak uses a thin white clock with the written-out date below it. It also restores the larger padlock behavior described by the project, including an open padlock that remains visible after Face ID. The iOS 16 depth effect is disabled for this clock presentation, and the charging battery is placed where the clock normally appears.

The Focus switch moves the Focus pill below the date, matching the older layout. Notifications are placed immediately below the clock rather than collected at the bottom of the Lock Screen. The README specifies smaller 13-point card corners, tighter padding, narrower side margins and shorter one-line cards. Older notifications appear after swiping up, with the Notification Centre header and close button shown at that stage.

The music-player option restores an iOS 15-style layout with large artwork, a device name above the title, AirPlay beside the title, a progress bar with a knob, larger transport controls and a volume slider. The project also displays the artist and album together and prevents tapping the artwork from switching to iOS 16’s full-screen album-art presentation.

  • Each major area has its own switch in Settings → Tweaks → LockScreenRestore.
  • The available switches cover the clock, Focus, notifications, music player, unlock animation and live wallpaper behavior.
  • The project recommends setting Notifications to Display As → List for the full iOS 15-style presentation.

Wallpaper and unlock behavior

The live-wallpaper component brings back the iOS 15 wallpaper workflow described by the project. It supports Live wallpapers that play when the Lock Screen is pressed and held, Dynamic wallpapers with their animated bubbles, Perspective Zoom and automatic Light or Dark wallpaper variants based on system appearance.

Enabling the iOS 15 Live Wallpaper switch also replaces the iOS 16 wallpaper page with an iOS 15-style Settings → Wallpaper experience. The page includes separate Lock Screen and Home Screen previews, wallpaper categories for Dynamic, Stills and Live content, Light and Dark variants, Move & Scale for photos and separate options to set the Lock Screen, Home Screen or both. Wallpaper changes are intended to apply without a respring.

Apple’s wallpapers are not bundled with the package. The README says downloadable wallpaper entries appear under Available to Download in Settings → Wallpaper and that the files are fetched for the device’s screen size. The project also notes that the wallpaper download list depends on an external archive remaining available. Users who prefer the iOS 16 wallpaper page and Lock Screen editor can disable the iOS 15 Live Wallpaper option.

The unlock-animation component recreates the iOS 15-style transition in which the Home Screen wallpaper follows the swipe with a small parallax effect. The Lock Screen is described as blurring only when the Lock Screen and Home Screen use different wallpapers.

  • Turning on iOS 15 Live Wallpaper means a long press no longer opens the iOS 16 Lock Screen editor.
  • The Dock and folder backgrounds may still use a blurred version of the iOS 16 wallpaper.
  • The Home Screen preview is a screenshot that updates after unlocking to the Home Screen again.

Compatibility: what is confirmed and what is not

The project states that LockScreenRestore is for rootless jailbreaks on iOS 16 only. Its confirmed test configurations are an iPhone 13 Pro running iOS 16.1.1 and an iPhone 12 Pro running iOS 16.5, both using Dopamine. The README also names ElleKit in its compatibility description.

The compatibility table lists iPhone 12, 13 and 14 models with the same 390 × 844-point screen as devices that should work. It lists several other screen classes as supported, reported or untested rather than presenting them as confirmed test results. iPhone X, XR and related models have reports involving clock-position fixes, while notification overlap was still being examined for at least one 375 × 812-point configuration.

The iPhone 12 Pro Max, 13 Pro Max and 14 Plus screen class is marked supported but untested. Dynamic Island models, including the iPhone 14 Pro and iPhone 14 Pro Max, are also marked supported but untested, with the padlock identified as the least certain element. Touch ID devices are listed as supported but untested, although the README says a previously reported iPhone 8 Plus clock-size issue was addressed by the new calculations.

  • Confirmed testing does not cover every iOS 16 version, iPhone model or jailbreak.
  • Dynamic Island and Touch ID padlock behavior is specifically less certain in the project’s own notes.
  • The maintainer asks users to report their model, iOS version, jailbreak and a screenshot when checking an untested configuration.

Installation considerations for jailbreak users

The project’s installation instructions call for downloading the release DEB from the official project release area, opening it with a package installer such as Sileo, Zebra or Filza, and installing it. PreferenceLoader is required, and the README says the package manager installs it automatically if it is missing.

After installation, the tweak’s switches are managed from Settings → Tweaks → LockScreenRestore. Changes to those switches take effect after tapping Apply (Respring). The Fix Positions option shows the detected iPhone and screen size, recalculates the layout and resprings; the tweak also recalculates positions when SpringBoard starts.

Because the tweak runs in SpringBoard, the Lock Screen music player and Settings, the README advises disabling the component that caused a problem or uninstalling the package if the phone enters Safe Mode. Other tweaks that modify the Lock Screen clock, padlock, notification list, music player or wallpaper may conflict with LockScreenRestore.

The key installation decision is therefore not simply whether the phone runs iOS 16. Users should compare their exact iPhone screen class, iOS version and jailbreak against the project’s tested and untested entries, and should be prepared to disable individual components rather than enabling every feature immediately.

  • Use only the official project’s release package rather than unofficial mirrors.
  • Confirm that the device is using a rootless iOS 16 jailbreak.
  • Expect to respring after changing LockScreenRestore feature switches.
  • Review conflicts with other Lock Screen, music-player or wallpaper tweaks before installation.

Frequently asked questions

What is new in LockScreenRestore 1.9.1?

Version 1.9.1 updates clock sizing and positioning. It uses iOS 15-style clock sizes for different iPhone screen classes and calculates the time and date positions from those values instead of relying primarily on a general iOS 16 scaling ratio.

Which devices were actually tested?

The README names an iPhone 13 Pro running iOS 16.1.1 and an iPhone 12 Pro running iOS 16.5. Both were tested with Dopamine. Other devices and iOS 16 versions should be treated according to the project’s compatibility table rather than as confirmed.

Does LockScreenRestore support iOS 17 or iOS 15?

The package metadata and README target firmware 16.0 or newer within the project’s stated iOS 16 scope. The compatibility section specifically describes rootless jailbreaks on iOS 16 only, so the supplied source does not establish support for iOS 17 or for installing the tweak on iOS 15.

Can users keep some iOS 16 features?

Yes. The tweak provides separate switches for the clock, Focus, notifications, music player, unlock animation and live-wallpaper behavior. Each component can be disabled independently so users can mix selected iOS 15-style elements with iOS 16 behavior.

Is PreferenceLoader required?

Yes. The package metadata lists PreferenceLoader as a dependency, and the installation instructions say a package manager installs it automatically if it is missing.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
