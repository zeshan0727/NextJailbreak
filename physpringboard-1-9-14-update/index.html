Physpringboard 1.9.14 update: configurable physics for SpringBoard icons on rootless Dopamine

Physpringboard is a jailbreak tweak from WeWaffles that adds configurable physics to SpringBoard icons on rootless Dopamine jailbreaks. Users can shake the device to make icons move, then grab, fling, or spin them according to the tweak’s description. The package stanza identifies version 1.9.14 and lists mobilesubstrate and preferenceloader as dependencies. The accompanying official depiction also lists later changelog entries through version 1.9.23, creating a version-number discrepancy that users should resolve in their package manager before updating.

Key points

  • Physpringboard adds configurable physics to SpringBoard icons and also advertises support for Control Center icons.
  • The package metadata supplied for the current package identifies version 1.9.14, architecture iphoneos-arm64, and rootless Dopamine compatibility.
  • The 1.9.14 changelog describes bug fixes affecting presets, settings toggles, hitboxes, rotation gravity, friction, icon names, and bunching styles.
  • The official depiction lists later entries for versions 1.9.16, 1.9.19, and 1.9.23, so users should check which package version is actually available before installing.
  • The developer states that the tweak supports rootless jailbreaks and has only been tested on Dopamine, with no support promised for unlisted jailbreaks or versions.

What Physpringboard does

Physpringboard changes the usual static behavior of SpringBoard icons by applying configurable physics when the device is shaken. The official description says users can grab icons, fling them, and spin them, making the tweak primarily a visual and interactive customization rather than a productivity feature.

The depiction also presents the tweak as affecting Control Center icons. That gives the package a broader scope than a simple Home Screen animation, although the supplied material does not provide a detailed breakdown of which Control Center elements are supported or how each interaction behaves.

The word “configurable” is important here. Physpringboard is not described as using one fixed animation: its settings are intended to control the physics behavior. However, the source does not enumerate every available setting, slider, preset, or gesture trigger, so users should consult the settings interface after installation rather than assume a particular control exists.

  • Shake the device to activate physics on icons.
  • Grab, fling, and spin icons according to the official description.
  • Use configurable physics rather than a single fixed effect.
  • The depiction specifically mentions both SpringBoard and Control Center icons.

What version 1.9.14 changes

The package stanza identifies the release as version 1.9.14. Its changelog describes a broad bug-fixing update rather than a single headline feature. The listed fixes cover preset-settings graphical issues, settings toggles that were unintentionally left enabled, hitbox gaps and related hitbox bugs, rotation-gravity bugs, and friction behavior.

The release also changes defaults and removes some visual options. Icons are set not to show names by default, while some “bunching styles” are removed. These changes may be noticeable immediately after updating, especially for users who previously relied on icon labels or on one of the removed grouping behaviors.

The changelog does not say that every possible bug was eliminated. Instead, it says the release fixed “a lot of bugs including but not limited to” the listed items. That wording supports treating 1.9.14 as a maintenance release with several targeted corrections, without claiming complete stability across all supported devices or configurations.

  • Fixed graphical issues involving preset settings.
  • Removed unintentionally left-in settings toggles.
  • Addressed hitbox gaps and other hitbox bugs.
  • Fixed rotation-gravity bugs.
  • Improved friction.
  • Changed the default so icon names are not shown on icons by default rules described in the changelog context, and removed some bunching styles.

A version discrepancy users should notice

There is an important inconsistency in the supplied official material. The package stanza lists version 1.9.14, with a package size of 73,892 bytes and an installed size of 528 KB. The official depiction’s information section instead displays version 1.9.23, size 82.3 KB, and an update date of August 23, 2026. Its changelog includes entries for 1.9.16, 1.9.19, and 1.9.23.

The later changelog entries describe additional behavior: version 1.9.16 added hiding the dock by default while the tweak was activated; version 1.9.19 removed app-switcher dots above the dock and added a settings icon; and version 1.9.23 changed the dock so it slides down when the tweak is activated rather than disappearing.

Because the package metadata and depiction do not identify the same version, readers should not assume that installing the package represented by the 1.9.14 stanza will provide the later dock behavior. Check the version shown by the package manager and compare it with the changelog before proceeding. If the manager offers 1.9.23, the later changes may apply; if it offers 1.9.14, the 1.9.14 changelog is the relevant release information supplied here.

  • Package stanza: 1.9.14.
  • Depiction information section: 1.9.23.
  • Later listed changes concern dock behavior, app-switcher dots, and a settings icon.
  • Verify the actual offered version before updating or troubleshooting.

Compatibility and dependencies

The package is marked for rootless Dopamine in its official description. The developer’s note says the tweak only supports rootless jailbreaks and has only been tested on Dopamine. The same note says support will not be offered for jailbreaks or versions that are not listed.

That is a narrower compatibility statement than a general claim that the tweak works on every rootless environment. The available material does not provide a complete device list, an exhaustive iOS compatibility table for the 1.9.14 package, or confirmation for jailbreaks other than Dopamine. Users on another jailbreak should therefore treat compatibility as unconfirmed rather than implied.

The package metadata lists two dependencies: mobilesubstrate and preferenceloader. These are package requirements, so a package manager may need to install or update them as part of the process. The supplied metadata identifies the package architecture as iphoneos-arm64. It also says Physpringboard replaces, conflicts with, and provides the identifier associated with com.chloe.gravitation17. That relationship is relevant to users migrating from the older package identity and should be reviewed by the package manager before confirming an update.

  • Supported jailbreak model stated by the developer: rootless Dopamine.
  • Dependencies: mobilesubstrate and preferenceloader.
  • Architecture listed in the package stanza: iphoneos-arm64.
  • The package replaces, conflicts with, and provides com.chloe.gravitation17.

What to verify before installing

Start by confirming the version displayed by the package manager. The conflicting 1.9.14 and 1.9.23 entries mean the version number should be treated as a practical installation check, not a minor documentation detail. Also review any replacement or conflict prompt involving com.chloe.gravitation17, particularly if that package is already installed.

Next, confirm that the jailbreak is rootless and that the environment is Dopamine, since those are the conditions explicitly identified by the developer. Do not treat the depiction’s iOS range as a universal promise for every package build: the package stanza itself does not state an iOS range, while the depiction presents 15.0–26.0.1 alongside the later 1.9.23 information.

Finally, expect settings and visual defaults to change after the 1.9.14 update. Icon names may be hidden by default, some bunching styles may no longer be available, and preset or settings behavior was specifically revised. Users who depend on a particular appearance should record their preferred configuration before updating so they can compare the available options afterward.

  • Confirm whether the offered build is 1.9.14 or a later version.
  • Review dependency, replacement, and conflict prompts.
  • Confirm rootless Dopamine compatibility before proceeding.
  • Check settings after updating, especially icon names, presets, friction, and removed styles.
  • Use the official package source rather than unofficial mirrors or modified downloads.
