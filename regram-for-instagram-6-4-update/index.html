Regram 6.4 Adds Story and Reels Playback Controls, Profile Media Watch, and Instagram 450.1 Support

Regram for Instagram 6.4 is now available with compatibility updates for Instagram 450.1. The release adds dedicated playback controls for Stories and Reels, introduces automatic media monitoring for watched accounts, expands Profile Tracking, redesigns the Tab Bar editor, and fixes several download, messaging, and launch issues. The package metadata lists iOS 14.0 or later and MobileSubstrate 0.9.5000 or later as dependencies, while the official depiction lists support as iOS 15.1 or later, so users should check the installation source and method that apply to their device before updating.

Key points

  • Regram 6.4 was released on October 10, 2026, with bug fixes and compatibility updates for Instagram 450.1.
  • Stories gain playback controls for speed, scrubbing, skipping, volume, mute, Picture in Picture, frame saving, and moving to the next person.
  • Reels gain previous and next controls plus configurable skip actions, including frame-by-frame stepping while paused.
  • Profile Tracking now includes Media Watch, a per-account media screen, expanded profile fields, and an optional profile-visit recorder that is off by default.
  • The Tab Bar editor now provides a live preview, custom tabs, hide/show controls, and long-press actions without requiring a relaunch.
  • The official package declares firmware version 14.0 or later and MobileSubstrate 0.9.5000 or later; the package depiction separately lists iOS 15.1 or later as supported. Verify this difference before installing.

What Regram 6.4 changes

Regram 6.4 is a substantial feature and maintenance release for the Instagram enhancement tool from Fouad Raheb. The official release notes identify October 10, 2026 as the release date and describe the update as including bug fixes and compatibility updates for Instagram 450.1. The accompanying sideloading table lists Instagram 450.1 alongside Regram 6.4 for the original, no-plugins, duplicate, and TrollStore variants.

The update continues Regram’s broader approach of adding customization, downloading, privacy, profile-analysis, messaging, and interface controls inside Instagram. Version 6.4 is particularly focused on media playback, profile monitoring, and navigation customization, while also addressing several regressions in newer Instagram screens.

Stories get a dedicated playback control sheet

The new Story Playback Controls are one of the clearest user-facing additions. Regram says the controls support playback speed, scrubbing, skipping, volume, muting, Picture in Picture, saving a frame, and moving to the next person’s story. The controls can be opened by long-pressing the three-dot menu, using the new playback button, or using the action button.

The release also moves the Stop Auto Advance option into this playback control area. That change matters for users who previously relied on automatic story progression but want the playback and navigation options grouped together. The release notes do not specify every available speed value or whether each control works in every Story format, so those details should be checked in Regram’s settings and release documentation after updating.

  • Playback speed and scrubbing controls for Stories.
  • Skip, volume, mute, Picture in Picture, and save-frame actions.
  • A next-person action for moving through Stories.
  • Stop Auto Advance moved into the playback controls.

Reels playback becomes more navigable

Reels receive a separate set of playback improvements. Regram 6.4 adds previous and next Reel buttons, along with skip buttons configured to five seconds by default. When a Reel is paused, the skip action advances one frame; holding the control repeats the action. The same functions are also available as floating button actions.

This makes the update more useful for viewers who need precise navigation rather than simply scrolling through the feed. The notes describe the default skip interval but do not state that the five-second value is fixed, so users should look for the relevant control in Regram’s settings if they want to adjust it.

Profile Tracking expands into a media watch system

Profile Tracking gains a new Media Watch feature. Watched accounts can now have new Stories, posts, Reels, and profile pictures saved automatically. These events appear in the events list and can be viewed there, giving the feature a more active monitoring workflow than the previous change-tracking description alone suggests.

Version 6.4 also adds a per-account Media screen. It organizes saved media by type, includes a Deleted filter, offers a full-screen viewer, and can export items to Photos or Regram’s Vault. The release also adds Save All Media to the profile action button, covering posts, carousels, Reels, Stories, and a profile picture in bulk.

The Profile Tracking interface now centers on a Watchlist, opening on Watchlist | Changes. Recording profile visits is now optional and is off by default. In addition, tracking covers links and their titles, pronouns, category, account type, and contact information. Regram says it fixed false profile-picture changes, particularly for accounts that do not have a profile picture.

These features involve monitoring and saving account-related content, so users should review the relevant Profile Tracking and Media Watch settings before enabling automatic collection. The source describes what the feature records and saves, but does not make broader claims about Instagram account policy or how long collected media remains available.

  • Media Watch can automatically save new Stories, posts, Reels, and profile pictures from watched accounts.
  • The events list shows watched-media activity.
  • The new per-account Media screen supports type filters, a Deleted filter, full-screen viewing, and export to Photos or Vault.
  • Profile visit recording is optional and disabled by default.
  • Profile Tracking now records additional profile fields, including links, pronouns, category, account type, and contact information.

Navigation and download management are redesigned

The Tab Bar editor has been redesigned with a live preview and plus/minus controls for adding or hiding tabs. Changes apply without relaunching Instagram. Users can add custom tabs such as Instagram’s Saved and Notifications screens, or Regram destinations including Vault, Downloads, and Settings.

Holding any tab can now open a screen of the user’s choice, while the Home tab continues to open Regram Settings. Detect IG Links has moved into the Tab Bar editor as Explore’s hold action, and the source says existing settings carry over.

Downloads also receive organizational improvements. Filter chips now appear above the downloads list, and a Select button allows multiple downloads to be deleted at once, either with or without their associated media. Separately, the release adds Manually Mark as Seen for Instants: viewed Instants remain unseen until the eye button is tapped.

Fixes included in 6.4

The release fixes Hide Chats and the direct-message refresh confirmation on Instagram’s new chats list. It also corrects a problem where video Instants downloaded as photos, and addresses Instagram crashes at launch on some accounts.

Smaller interface changes include making stacked Toast notifications share one width instead of appearing with uneven, zig-zagging widths. Reels users can also hide Instagram’s new Save button or hide only its count.

Compatibility and installation considerations

The official package stanza identifies Regram 6.4 as package com.fouadraheb.regram, with an iphoneos-arm architecture. It declares dependencies on firmware version 14.0 or later and MobileSubstrate version 0.9.5000 or later, and lists a conflict with com.b4db1r3.cleancopy. However, the official package depiction lists “iOS 15.1+” in its support information. Because those two source fields do not express compatibility in exactly the same way, users should treat the depiction and package-manager requirements as separate checks rather than assuming that every device meeting one line is supported by the other.

The official installation instructions describe a jailbroken route through the project’s package source and a sideloading route using IPA builds. The published sideloading table identifies four Regram 6.4 variants based on Instagram 450.1: an original Instagram bundle, a no-plugins build, a duplicate bundle, and a TrollStore build. The instructions say the original Instagram app should not coexist with another installation using the same bundle identifier.

For AltStore-based installation, the source lists a macOS or Windows computer, an internet connection, and an Apple ID as requirements. It also notes that iOS 16 users may need Developer Mode enabled. The project’s instructions state that a non-developer Apple account causes a seven-day signing period, while AltStore can automate re-signing when connected to the computer.

Push notifications have separate signing implications. The official instructions say sideloaded builds do not receive push notifications unless properly signed with a Distribution or Ad Hoc certificate, except for TrollStore on supported devices. They also state that users with a paid certificate should use the original build and sign it with a Distribution or Ad Hoc certificate for notifications. These are signing conditions, not a guarantee that every sideloading configuration will provide identical behavior.

  • Check both the package dependency line and the package depiction’s iOS 15.1+ support entry.
  • Confirm that the Instagram bundle identifier is not already occupied by another installation.
  • For sideloading, choose the build that matches the intended bundle and signing method.
  • Review signing duration and push-notification requirements before replacing an existing Instagram installation.
  • Back up or review important downloads and settings before changing installation variants.

Frequently asked questions

What is new in Regram 6.4?

The release adds Story Playback Controls, expanded Reels playback controls, Media Watch for Profile Tracking, a per-account Media screen, bulk media saving, a redesigned Tab Bar editor, improved download management, manual seen marking for Instants, and fixes for chats, downloads, and launch crashes.

Which Instagram version is Regram 6.4 built for?

The official release notes describe compatibility updates for Instagram 450.1, and the sideloading table lists Instagram 450.1 builds paired with Regram 6.4.

What iOS versions are supported?

The package stanza declares firmware version 14.0 or later, while the official package depiction lists iOS 15.1 or later. Since these source entries differ, users should check the package manager or installation documentation for their exact device and jailbreak or sideloading method.

Can Regram 6.4 be sideloaded without a jailbreak?

Yes. The official README documents sideloading through IPA builds, including AltStore and TrollStore routes. The available method depends on the device, iOS version, signing setup, and selected bundle.

Will notifications work with a sideloaded build?

The official instructions say push notifications require proper Distribution or Ad Hoc signing, with an exception for TrollStore on supported devices. A standard non-developer signing setup may not provide push notifications.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
