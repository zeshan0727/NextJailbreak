Cylinder Reborn 1.2.0 Adds RootHide Support and Faster Icon Animations

Cylinder Reborn’s first update since July 2025 is more than a compatibility-label refresh. Version 1.2.0 adds explicit RootHide and all-rootless support, rebuilds important parts of the page-animation path, repairs several icon effects and upgrades its Lua scripting engine.

By Zeeshan BarviPublished October 21, 20266 min read
Release snapshot: Cylinder Reborn 1.2.0 was published on October 20, 2026. Chariz lists it as free for iOS 11.0–26.0 and requires a jailbreak. The developer now explicitly claims RootHide and all-rootless support.

What changed in Cylinder Reborn 1.2.0

The official changelog lists seven user-facing changes:

  • Full support for RootHide and all rootless jailbreaks.
  • Major performance improvements.
  • A fix for the recently closed app’s icon not animating.
  • Fixes for numerous effects broken in earlier versions.
  • A fix for effects not working during icon fly-in.
  • An upgrade to Lua 5.5.
  • New script access to each icon’s row, column and center through icon:center().

The GitHub release was published at 13:23 UTC on October 20 and provides separate rootful (iphoneos-arm) and rootless (iphoneos-arm64) packages. Use the package selected by the official repository or package manager; do not interchange the two builds manually.

Why the performance work matters

Cylinder Reborn animates SpringBoard pages as the user swipes between them. The corresponding developer commit describes pooled page-view contexts that stage, commit and restore icon transforms, positions and alpha values per frame. It also restores page state when SpringBoard lays out, adds or removes subviews during a swipe.

That architecture detail explains the “major performance improvements” line without promising a device-specific frame-rate result. It is designed to reduce repeated work and stale icon state, but Next Jailbreak has not benchmarked version 1.2.0 on hardware.

The same commit routes an app-closing icon flight through Cylinder’s transforms. That aligns with the changelog fixes for the recently closed app icon and for effects that failed during icon fly-in.

RootHide and rootless support

Version 1.2.0 is the first current release whose official changelog explicitly says it supports RootHide and all rootless jailbreaks. The implementation also resolves resource paths with libroot, a common way for jailbreak packages to find files across rootful, rootless and RootHide-style layouts.

This is still a package-support statement, not a universal jailbreak-availability claim. A device can use Cylinder Reborn only when its exact hardware and firmware already have a compatible jailbreak, working tweak injection and a supported SpringBoard environment. The Chariz range through iOS 26.0 does not mean every iOS 26 device can be jailbroken.

Lua 5.5 and better effect scripts

Cylinder effects are written in Lua. Updating the embedded engine to Lua 5.5 modernizes the runtime, while the new row, column and center values let an effect react to an icon’s exact grid position. Script authors can now build motion that radiates from the middle of an icon, travels across rows, or changes by column without estimating geometry outside the provided icon object.

Existing custom scripts should be checked after upgrading. A runtime jump can reveal assumptions in older code even when the package itself loads correctly. Start with the bundled effects, then re-enable third-party scripts one at a time.

How to update safely

  1. Refresh sources in Sileo or Zebra and confirm the official Chariz listing shows version 1.2.0.
  2. Review the transaction queue. The package manager should select the correct rootful, rootless or RootHide-compatible build for the environment.
  3. Record the active effect and any custom scripts before upgrading.
  4. Install the update and respring.
  5. Test a normal page swipe, app close and icon fly-in. If a custom effect misbehaves, switch to a bundled effect before blaming tweak injection.

For queue and recovery basics, use the safe Sileo tweak-installation guide. If SpringBoard crashes, collect a useful report with the KrashKop crash-log guide before contacting the developer.

Should you install 1.2.0?

RootHide and rootless users have the clearest reason to update because environment support is now explicit. Users affected by missing fly-in effects, a non-animated closing-app icon or effects broken in earlier versions also have a directly documented fix.

People who use custom Lua effects should update for the new runtime and icon-position APIs, but should keep a copy of their scripts and test them gradually. Users on an older rootful setup can use the dedicated rootful package; the developer commit specifically notes legacy rootful iOS 11–14 toolchain support.

Frequently asked questions

What is new in Cylinder Reborn 1.2.0?

RootHide and all-rootless support, performance work, repaired app-close and fly-in animations, fixes for broken effects, Lua 5.5 and new row, column and center data for effect scripts.

Does it support RootHide?

Yes. The official 1.2.0 changelog explicitly says “Full support for roothide and all rootless jailbreaks.”

Which iOS versions are listed?

Chariz lists iOS 11.0–26.0. That is package compatibility, not proof that every device and firmware combination has a jailbreak.

Is Cylinder Reborn free?

Yes. Chariz marks the package as free.

Where should I download it?

Use the official Chariz package page or the developer’s GitHub release. Avoid repackaged downloads and mirrors.
