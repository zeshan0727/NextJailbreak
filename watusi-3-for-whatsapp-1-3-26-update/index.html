Watusi 3 for WhatsApp 1.3.26 adds WhatsApp 26.38.X support and fixes sideloaded voice notes

Watusi 3 for WhatsApp has reached version 1.3.26. The official package description lists bug fixes and support for WhatsApp 26.38.X, while the detailed changelog highlights a fix for voice notes that could fail to play or record on sideloaded installations lacking WhatsApp’s extended-virtual-addressing entitlement. The package is identified as com.fouadraheb.watusi3, requires firmware 12.0 or newer in its package metadata, and is listed as supporting iOS 15.1+ in the official depiction. A separate community-maintained Simplified Chinese language pack has also been reorganized, but it is explicitly based on Watusi 1.3.9 rather than the current 1.3.26 release, so users should treat it as a separate compatibility consideration.

Key points

  • Watusi 3 version 1.3.26 is listed as supporting WhatsApp 26.38.X.
  • The release fixes voice-note playback or recording issues on sideloaded installs missing WhatsApp’s extended-virtual-addressing entitlement.
  • The official depiction lists iOS 15.1+ support, while package metadata declares a firmware dependency of iOS 12.0 or newer.
  • The tweak includes privacy, protection, status, chat, media, notification, theme, scheduling, auto-reply, hidden-chat, custom-tone, and sticker-management options.
  • The available Simplified Chinese language pack is based on Watusi 1.3.9 and should not be assumed to be updated for Watusi 1.3.26.
  • The package declares dependencies on MobileSubstrate and Watusi Tools, and conflicts with several older Watusi package identifiers.

What changed in Watusi 3 version 1.3.26

The official Watusi 3 release entry identifies version 1.3.26 as a maintenance update released on September 30, 2026. Its headline changes are bug fixes and support for WhatsApp 26.38.X. The changelog does not describe a new user-facing feature category for this version; instead, it concentrates on keeping the tweak aligned with a newer WhatsApp build and correcting a specific audio problem.

The most concrete fix concerns voice notes on sideloaded installations. According to the official changelog, voice notes that were not playing or recording on sideloaded installs missing WhatsApp’s extended-virtual-addressing entitlement should now be handled by the tweak. This is narrower than a general promise that every audio issue is resolved: the source ties the fix specifically to that entitlement-related sideloading scenario.

  • Version: 1.3.26.
  • Release date listed by the official depiction: September 30, 2026.
  • WhatsApp compatibility listed in the changelog: 26.38.X.
  • Specific fix: voice notes not playing or recording on affected sideloaded installations.

Why the WhatsApp compatibility update matters

Watusi modifies WhatsApp behavior across many parts of the application, so changes inside WhatsApp can affect individual tweak functions even when the tweak itself has not changed its overall feature set. The 1.3.26 entry explicitly connects this release to WhatsApp 26.38.X, making the update relevant to users running that WhatsApp branch.

The recent version history shows a continuing pattern of compatibility maintenance. Earlier releases listed support for WhatsApp 26.37.X, 26.36.X, 26.32.X, 26.30.X, and other builds, alongside fixes involving statuses, media selection, pinned chats, notifications, the in-app browser, audio controls, and custom tones. That history does not prove that every older issue is addressed in 1.3.26, but it explains why the current WhatsApp version should be checked before installing or upgrading the tweak.

  • The release is primarily a compatibility and reliability update rather than a newly announced feature expansion.
  • Users should compare their installed WhatsApp version with the explicitly listed 26.38.X support target.
  • The changelog does not state that 1.3.26 supports every future or unrelated WhatsApp build.

What Watusi offers beyond this release

The official package description presents Watusi as an all-in-one tweak for WhatsApp. Its privacy controls include freezing Last Seen, disabling read, typing, recording, and delivery indicators, disabling internet access, hiding call mute controls, blocking incoming calls, and automatically switching Last Seen privacy settings.

The tweak also exposes protection features such as app protection, chat protection, and hiding the last message. Status tools include downloading statuses, manually marking statuses as viewed, archiving personal statuses, retaining deleted contact statuses, splitting long videos into multiple statuses, and managing status-related privacy groups. Availability of any individual option can still depend on the WhatsApp build and the installation environment; the source lists these capabilities but does not claim that every option works identically on every version.

Additional categories cover chat behavior, chat-list filtering and sorting, unlimited pinned chats, archive locking, media sharing, user-interface controls, private notifications, themes, scheduled messages, advanced auto-reply, hidden chats, contact spoofing, custom notification tones, and sticker-pack management. The package also includes a Control Center toggle, with CCSupport required according to the official description.

  • Privacy and protection controls are central parts of the tweak’s feature set.
  • Status, chat-list, media, interface, notification, theme, and automation options are included in the official description.
  • Watusi says its options are configured from inside WhatsApp settings.
  • The official description lists English, Arabic, German, Spanish, French, Italian, Portuguese, and Turkish as available languages.

Compatibility and dependency checks before installation

The package stanza identifies the package as com.fouadraheb.watusi3, with iphoneos-arm64 architecture and version 1.3.26. It declares dependencies on firmware version 12.0 or newer, MobileSubstrate version 0.9.5000 or newer, and Watusi Tools version 2.8.3 or newer. The official depiction separately lists “iOS 15.1+” in its information table. Because these two source fields describe different thresholds, readers should use the package manager’s compatibility resolution and the official depiction together rather than treating the lower firmware dependency as a guarantee of full support on every iOS 12–14 setup.

The package also declares conflicts with older or alternate Watusi identifiers, including com.fouadraheb.watusi, com.f0u4d.watusi, org.thebigboss.watusi, and com.b4db1r3.cleancopy. This matters when upgrading from an older Watusi installation: a package manager may need to remove or replace a conflicting package before the current package can be installed. The source does not provide a migration procedure, so users should review the package manager’s proposed changes and preserve any important WhatsApp data before making system-level changes.

The official package record reports a download size of approximately 2.4 MB in the depiction and an installed size of 9,424 KB in the package stanza. Those are different measurements, so they should not be interpreted as contradictory download figures.

  • Check both the listed iOS support information and the package manager’s dependency resolution.
  • Confirm that MobileSubstrate and Watusi Tools meet the declared minimum versions.
  • Review conflicts with older Watusi packages before upgrading.
  • Back up important WhatsApp data and review package-manager changes before proceeding.

The Simplified Chinese language pack is a separate compatibility question

The official repository metadata for WatusiZhHans describes a Simplified Chinese language pack for Watusi 3. Its README says the project is based on Watusi 1.3.9, adds Chinese translations, and uses a minimal runtime hook to add “简体中文” to Watusi’s Other Settings, Language menu. The documented user flow is to install the language-pack deb, completely close WhatsApp, reopen it, then open Watusi, Other Settings, and Language before selecting Simplified Chinese.

The project’s recent packaging commit says its build process was reorganized to generate rootful, rootless, and roothide packages in sequence, while the localization output was reduced to zh-Hans.lproj resources. However, the same project documentation still identifies Watusi 1.3.9 as its base. The language pack’s package metadata also changed during the documented history, including a dependency that no longer pins an exact Watusi version in one revision. None of this establishes compatibility with Watusi 1.3.26.

Users considering the Chinese language pack should therefore verify its current package metadata, resource layout, and behavior against the installed Watusi version. The project README itself recommends rechecking the language hook, language-list construction, and FRSListCell-related signatures after a Watusi upgrade. That warning is particularly relevant here because Watusi 1.3.26 is several releases newer than the language pack’s stated 1.3.9 base.

  • The language pack is based on Watusi 1.3.9, not explicitly on 1.3.26.
  • Its documented menu path is Watusi → Other Settings → Language → 简体中文.
  • The project documents rootful, rootless, and roothide packaging output.
  • Compatibility with Watusi 1.3.26 should be verified rather than assumed.

Frequently asked questions

What is new in Watusi 3 version 1.3.26?

The official changelog lists bug fixes and support for WhatsApp 26.38.X. It also says the release fixes voice notes not playing or recording on sideloaded installations missing WhatsApp’s extended-virtual-addressing entitlement.

Does Watusi 1.3.26 support iOS 12?

The package metadata declares a firmware dependency of 12.0 or newer, but the official depiction lists “iOS 15.1+” under Supports. Because those fields differ, users should rely on the package manager’s dependency checks and confirm support for their specific environment rather than assuming full support on iOS 12.

What dependencies does Watusi 3 require?

The package stanza lists firmware 12.0 or newer, MobileSubstrate 0.9.5000 or newer, and Watusi Tools 2.8.3 or newer. The package architecture is iphoneos-arm64.

Does Watusi 1.3.26 include Simplified Chinese?

The official Watusi description lists several languages but does not list Simplified Chinese. A separate WatusiZhHans project provides a Simplified Chinese language pack and a menu hook, but its README says it is based on Watusi 1.3.9. Compatibility with 1.3.26 is not established by the supplied source.

How is the Simplified Chinese language pack enabled?

The language-pack README documents installing its deb, fully closing WhatsApp, reopening it, entering Watusi → Other Settings → Language, and selecting 简体中文. It also says users can try Language = Auto when WhatsApp or the system is set to Simplified Chinese.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
