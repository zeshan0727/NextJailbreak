Solo 1.0.1 Fixes SpringBoard Hangs, Liquid Glass Safe Mode and Atria Layouts

Solo 1.0.1 fixes medium-widget SpringBoard hangs, a Liquid (Gl)ass Safe Mode crash and Atria scaling. Check rootless iOS 15–26 support and recovery.

Published November 17, 2026By Zeeshan BarviOfficial Havoc package history

Solo 1.0.1 is a stability update for the iPhone Duo-inspired Home Screen tweak. Its official Havoc version history says the update fixes a SpringBoard hang linked to medium and large widgets, a Safe Mode crash involving an older Liquid (Gl)ass build, and several Atria layout problems.

This is more than a cosmetic patch: two fixes address failures that can make the Home Screen unusable until tweak injection is disabled. Solo remains a paid rootless tweak for iOS 15 through 26. RootHide is explicitly not supported.

The iOS 15–26 label is the tweak’s package range. It does not prove that every iPhone on those versions can be jailbroken. Your exact model, firmware and jailbreak still need a working rootless environment before Solo can load.

What Solo changes

Solo rebuilds the Home Screen around an iPhone Duo-inspired layout. It adds a vertical dock with up to five icons, a Home Screen status bar, a Spotlight button, custom unlock and page-bounce animations, and an optional large-icon style.

A carousel at the top of the Home Screen can contain medium widgets, media controls with lyrics, clocks, weather, calendar views and PowerSelector shortcuts. Because Solo moves widgets and app rows, layout compatibility matters more than it would for a small visual tweak.

What changed in Solo 1.0.1

  • Medium and large widget hang: fixes a case where SpringBoard could sometimes hang when one of these widgets was on the Home Screen.
  • Liquid (Gl)ass Safe Mode: stops Solo from looking for a missing method in an older Liquid (Gl)ass build.
  • Atria search scaling: fixes incorrect App Library search-bar scaling when Atria is installed.
  • Atria layout migration: existing stock Atria layouts now attempt to adapt to Solo on first installation and again when Solo is removed.
  • Carousel widgets: fixes Atria occasionally resizing widgets inside Solo’s carousel.
Important layout warning: Solo’s developer notes that the tweak modifies the Home Screen layout by design. Take screenshots of your pages and record Atria settings before installing or removing it; automatic adaptation does not guarantee an identical layout.

Safe update steps

  1. Open Solo’s Havoc page in Sileo or Zebra and confirm the update shown is 1.0.1.
  2. Take screenshots of each Home Screen page and note Atria’s grid, dock and App Library settings.
  3. If 1.0.0 is already hanging SpringBoard, restart the jailbreak with tweak injection disabled before opening the package manager.
  4. Update Solo by itself. Avoid updating Atria or Liquid (Gl)ass in the same transaction so any remaining problem has one clear cause.
  5. Respring once, then test the Home Screen before adding medium or large widgets back.
  6. Re-enable Atria or Liquid (Gl)ass one at a time and check the App Library, carousel and page layout after each change.

Havoc officially supports Sileo and Zebra for paid packages. Do not install a copied DEB from a file host; paid-package authentication, architecture and update metadata should remain tied to the official repository.

Troubleshooting Solo after the update

SpringBoard hangs with a widget

Boot or re-jailbreak with tweak injection disabled, open Sileo or Zebra, and verify that Solo 1.0.1—not 1.0.0—is installed. If the hang continues, remove Solo, respring, then add it back before restoring widgets. The Dopamine bad-tweak recovery guide covers the safe injection-disabled workflow.

Safe Mode starts when Liquid (Gl)ass is installed

Update Solo first. If the crash remains, disable Liquid (Gl)ass and confirm Solo works alone, then update or remove the older Liquid (Gl)ass build. Do not repeatedly respring with both tweaks enabled while SpringBoard is crashing.

Atria layout or App Library search looks wrong

Confirm Solo 1.0.1, then review Atria’s app-list and dock settings. The migration is described as a best effort, so restore grid values manually if the automatic layout differs from your previous setup. Avoid restoring an old layout blindly if it recreates the scaling problem.

Carousel widgets change size

Test a stock medium widget before third-party widgets. If only one widget fails, report its app name, widget size, iOS version, Atria version and Solo version to the developer.

Frequently asked questions

What is the current Solo version?

Solo 1.0.1 is the current version in Havoc’s official version history as of November 17, 2026.

Does Solo support RootHide?

No. The official package page explicitly says RootHide is not officially supported. Do not treat a converted package as developer-confirmed support.

Does iOS 15–26 compatibility mean my device can be jailbroken?

No. That is Solo’s declared tweak range. Jailbreak availability still depends on the exact iPhone model, firmware and available rootless jailbreak.

What should I do if SpringBoard hangs after installing Solo?

Start the jailbreak with tweak injection disabled, update to 1.0.1 or remove Solo through Sileo or Zebra, then respring before restoring widgets and other Home Screen tweaks.
