TransLux 1.6 Adds Live Translation Inside iOS Apps

TransLux 1.6 expands beyond selected-text translation by adding on-the-fly translation inside six frequently used apps, while retaining its system callout button and selectable translation engines.

By Zeeshan Barvi · Published October 16, 2026 · Verified against the official Havoc listing and developer release announcement

Compatibility is not jailbreak availability. Havoc lists TransLux for iOS 15.0–26.0.1, but the tweak requires a compatible jailbreak on the exact device and firmware. A package’s iOS range does not create a jailbreak for every iPhone in that range.

What changed in TransLux 1.6

AnubisTweaks released TransLux 1.6 on October 14, 2026. The developer’s release announcement says the update adds on-the-fly translation in:

  • App Store
  • Telegram
  • Discord
  • X
  • Sileo
  • Saily

This is a useful distinction from the tweak’s established selected-text workflow. TransLux already places a translation action in the iOS text-selection callout; version 1.6 adds app-specific integration so supported content can be translated without first copying it into another app.

The official announcement names those six apps. It does not claim universal automatic translation in every iOS app, so users should not assume the new live mode covers Safari, Messages, Reddit clients or arbitrary third-party software unless the developer documents them later.

How the translation workflow works

For ordinary editable text, select a word or passage and reveal the extra actions in the iOS callout menu. TransLux’s icon opens its translation interface. The official artwork shows a compact view with source and target language controls, a copy action and other tool buttons.

Version 1.6’s app integrations are meant for screens where selecting and translating content one fragment at a time is inconvenient. That makes the update most relevant to people who routinely browse multilingual app listings, chats, social posts or package-manager descriptions.

Translation engines and language setup

The current official settings screenshot shows four engine choices: Google, Baidu, ModernMT and Microsoft. The interface describes Google as the main engine and the other three as backups that can be selected from the top of the TransLux interface. Availability can vary by country or service status.

TransLux asks for language codes rather than only presenting a friendly language picker. The screenshot uses en for English and ar for Arabic and gives examples including es, fr, de, it, ja, ko and zh-CN. Entering the wrong code can produce a failed or unexpected translation even when the tweak itself is loading correctly.

Why the 1.5 and 1.5.1 changes still matter

TransLux moved quickly through three releases in the same week. The developer described 1.5 as the update that added iOS 18–26 support, refined the interface, added an opening animation, introduced a toggle for the callout button, and added a toggle related to the iOS 16-or-later paste alert.

Version 1.5.1 then fixed conversion of the rootless package with the RootHide patcher. That history matters because a cached 1.5 package is not equivalent to the current 1.6 build. RootHide users should refresh their package sources and verify the displayed version before installing.

Should you update?

Update to 1.6 if you use any of the six newly integrated apps, particularly when translating long app listings, chat threads, social posts or package descriptions. The new capability removes repeated selection and copy steps in the supported apps.

If you only use the selection-menu button, 1.6 is less dramatic, but it is still the current official build and follows the RootHide conversion fix in 1.5.1. Before changing a stable setup, note your current engine and two language codes so you can restore them after an update.

  1. Refresh Havoc in Sileo, Zebra or the package manager supplied by your jailbreak.
  2. Confirm the seller is AnubisTweaks and the version is 1.6.
  3. Review the queue so an unrelated dependency is not being removed.
  4. Install the update and perform only the restart action requested by the package manager.
  5. Test selected-text translation first, then test one of the newly supported apps.

Frequently asked questions

What apps gained live translation in TransLux 1.6?

The developer names App Store, Telegram, Discord, X, Sileo and Saily.

Does TransLux work without a jailbreak?

No. Havoc labels the package as jailbreak-required.

Does TransLux support RootHide?

The developer says version 1.6 is compatible with RootHide and other jailbreak environments. Havoc separately marks the package as rootless-compatible.

Does TransLux send text to online services?

The interface offers Google, Baidu, ModernMT and Microsoft engines, which are network translation services. Do not submit passwords, recovery keys or other sensitive text for translation.
