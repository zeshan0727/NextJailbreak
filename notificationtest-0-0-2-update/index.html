NotificationTest 0.0.2 Adds Pull-to-Clear Support for iOS 18 Through 26.2

NotificationTest has reached version 0.0.2 with a focused update for Notification Center interaction. The release adds support for clearing all notifications by pulling on the Cover Sheet on iOS 18 through 26.2, while the package depiction lists compatibility from iOS 13 to 26. The update also introduces a new icon and code optimization. It is available as a free tweak and depends on MobileSubstrate and PreferenceLoader.

Key points

  • NotificationTest 0.0.2 adds pull-to-clear support for iOS 18 through 26.2.
  • The official depiction lists testing on iOS 13.7 through 26.0.1, while the broader compatibility label says iOS 13 to 26.
  • The tweak is designed to test Notification Center and clear all notifications from the Cover Sheet with a pull gesture.
  • Version 0.0.2 includes a new icon and code optimization; the previous release was the initial release.
  • The package is listed as free and supports rootless, roothide, and rootful environments.
  • The package declares dependencies on mobilesubstrate and preferenceloader.

A small update aimed at a practical Notification Center action

NotificationTest 0.0.2 is a targeted jailbreak tweak update from ichitaso. Its main purpose is to test Notification Center behavior and provide a way to clear all notifications by pulling down on the Cover Sheet. The new release focuses specifically on extending that pull-to-clear behavior to newer iOS versions rather than introducing a large collection of unrelated settings or interface changes.

The official package description presents NotificationTest as a utility for testing notifications from Settings. Its depiction also says users can clear all notifications at once by swiping down on the Cover Sheet, with configuration options available in the Settings app. That makes the tweak relevant primarily to users who want to experiment with Notification Center behavior or restore a more direct bulk-clearing interaction.

  • Package identifier: com.ichitaso.notificationtest

What changed in version 0.0.2

The headline change is support for “Pull to clear” on iOS 18 through 26.2, according to the official change log. The same entry states that the feature was tested on iOS 13.7 through 26.0.1. These are two different pieces of information: the compatibility wording describes the intended range, while the testing note identifies the versions explicitly covered by the maintainer’s release entry.

The update also adds a new icon and includes code optimization. No further user-facing features are listed in the official change log. Version 0.0.1 is identified as the initial release, so 0.0.2 should be understood as an incremental feature and maintenance update rather than a major redesign.

The practical benefit is straightforward. Instead of clearing notifications individually, the tweak is intended to let users pull on the Cover Sheet to remove all notifications at once. The source describes this as clearing all notifications, but it does not document additional filtering, notification-group management, automatic deletion rules, or changes to notification delivery. Those behaviors should not be assumed from the release description.

  • Added: Pull-to-clear support for iOS 18 through 26.2
  • Release entry notes testing on iOS 13.7 through 26.0.1
  • Added a new icon
  • Code optimization
  • No additional feature changes are listed
