Double-tap an empty Home Screen area to lock your iPhone.

Version 1.0.4 · RootHide + Rootless · iOS 16+

Complete runtime rebuild

Version 1.0.4 removes the failed root-folder gesture recognizer. It now hooks the Home Screen’s native SBIconListView touch callback and simulates Apple’s lock-button action—the established method used by the open-source Lock Screen Without Button tweak.

Built like the working Next Jailbreak tweaks

The RootHide scheme, dual architectures, segment alignment, PreferenceLoader bundle, CFPreferences storage and Darwin notifications now follow the proven Next Aura and PhoneAura package conventions.

Live diagnostics

Settings → Next Home Lock shows SpringBoard injection, the runtime method, SBIconListView availability, whether its touch hook was reached, the last tap count, test-command delivery and the exact lock route used.

Test sequence

  1. Refresh the repo and confirm Sileo shows version 1.0.4.
  2. Upgrade the matching package and perform a full respring.
  3. Open Settings → Next Home Lock and confirm SpringBoard Injection says Active.
  4. Press Test Lock Now.
  5. After unlocking, tap empty Home Screen space once.
  6. Refresh Diagnostics and confirm Touch Hook says Reached.
  7. Double-tap the same empty area.

Privacy
