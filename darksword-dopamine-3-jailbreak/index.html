DarkSword and Dopamine: What the Documented Connection Means

DarkSword, also called darksword-kexploit, is described by opa334 as an iOS <=26.0.1 kernel exploit reimplemented in Objective-C. Its connection to Dopamine comes from an official Dopamine 2.5 beta release note that added the DarkSword kernel exploit as an option. Current Dopamine 3.x compatibility should be read separately from that historical beta information and checked against the documented architecture and iOS ranges.

Key points

  • DarkSword is a named kernel exploit reimplemented in Objective-C, not the documented name of the Dopamine jailbreak itself.
  • An official Dopamine 2.5 beta release note added DarkSword as an option, establishing a documented connection with Dopamine development.
  • The Dopamine 3.x README describes Dopamine as a rootless semi-untethered jailbreak.
  • Dopamine 3.x compatibility varies by architecture or chip family and exact iOS version.
  • Rootless jailbreak compatibility does not automatically establish compatibility for every tweak.

What DarkSword is

darksword-kexploit is described by opa334 as an iOS <=26.0.1 DarkSword kernel exploit reimplemented in Objective-C. The supplied facts identify it as an exploit component, rather than as the name of a complete jailbreak.

That distinction helps clarify why DarkSword and Dopamine may appear together in jailbreak documentation. DarkSword describes the documented exploit, while Dopamine is described separately as a rootless semi-untethered jailbreak. The supplied facts do not provide a standalone DarkSword installation procedure or establish that DarkSword alone is a complete jailbreak.

  • Also referenced as darksword-kexploit.
  • Reimplemented in Objective-C.
  • Described as an iOS <=26.0.1 kernel exploit.

How DarkSword is connected to Dopamine

An official Dopamine 2.5 beta release note added the DarkSword kernel exploit as an option. This establishes a documented relationship between DarkSword and Dopamine development in that beta context.

The note supports the narrower statement that DarkSword was included as an option within that Dopamine beta. It does not establish that the same option appears in every Dopamine release, nor does it establish that historical beta limitations or known issues apply to Dopamine 3.x.

  • The documented connection comes from a Dopamine 2.5 beta release note.
  • The note says DarkSword was added as an option within that beta.
  • Current Dopamine 3.x behavior should not be inferred from historical beta information.

What the Dopamine 3.x documentation says

The official Dopamine 3.x README describes Dopamine as a rootless semi-untethered jailbreak. The official Dopamine website also describes Dopamine as rootless and identifies Sileo and Zebra as associated package managers.

Rootless design affects the filesystem areas available to jailbreak modifications. The official website explains that rootless jailbreaks only allow writes to certain filesystem areas and that tweaks may need to be updated or recompiled for rootless support. Therefore, jailbreak compatibility and tweak compatibility are separate questions.

  • Dopamine 3.x is described as rootless.
  • Dopamine 3.x is described as semi-untethered.
  • Sileo and Zebra are identified as associated package managers.
  • Some tweaks may require rootless-specific updates or recompilation.

Documented Dopamine 3.x compatibility ranges

The official Dopamine 3.x README separates its listed ranges by architecture and chip family. For arm64e, it lists iOS 15.0 through 17.3.1. For A12 and A13 devices, it lists iOS 15.0 through 18.7.1, plus iOS 26.0 through 26.0.1. For arm64, it lists iOS 15.0 through 18.7.1.

These ranges should not be combined into one universal claim. The endpoint depends on the device category: arm64e ends at iOS 17.3.1, while the listed A12/A13 and arm64 ranges extend through iOS 18.7.1. The iOS 26.0 through 26.0.1 entry is listed only for A12 and A13 devices.

  • arm64e: iOS 15.0 through 17.3.1.
  • A12 and A13: iOS 15.0 through 18.7.1, plus iOS 26.0 through 26.0.1.
  • arm64: iOS 15.0 through 18.7.1.
  • The iOS 26 range applies only to A12 and A13 in the supplied README details.
  • Exact device architecture or chip family must be matched with the exact iOS version.

How to interpret the information

For readers searching for DarkSword, the most precise conclusion is that it is a documented kernel exploit associated with Dopamine development through the Dopamine 2.5 beta note. That relationship does not make DarkSword and Dopamine interchangeable terms.

For a current Dopamine 3.x compatibility question, the relevant details are the device category and installed iOS version listed in the 3.x README. Historical beta information can explain the development connection, but it should not be used to assign old limitations or known issues to the current branch without current confirmation.

  • Use DarkSword to refer to the documented exploit component.
  • Use Dopamine to refer to the documented jailbreak project.
  • Keep the 2.5 beta relationship separate from current 3.x compatibility claims.
  • Check rootless tweak support separately from jailbreak support.
