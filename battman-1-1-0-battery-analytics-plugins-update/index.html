Battman 1.1.0 Adds Battery Analytics and Native Plug-ins

Battman 1.1.0 is the battery manager’s largest recent update, adding a configurable Analytics page, ten data cards, native plug-ins, powerlog export and a broad set of charging and reliability fixes.

By Zeeshan Barvi · Published October 16, 2026 · Verified against the official v1.1.0 GitHub release and tagged source

Read the support table before installing. Battman’s package matrix does not mean every device can be jailbroken or run TrollStore. The developer marks iOS 17 and later combinations as untested and explicitly says RootHide was not considered.

What changed in Battman 1.1.0

Torrekie published Battman 1.1.0 on October 14, 2026. The headline feature is a real Analytics page whose cards can be added, removed, resized and rearranged. The release ships ten card types:

  • Live battery readings
  • Capacity observations
  • Cell voltages
  • Charging sessions
  • Battery discharge
  • Connection and charging states
  • Power readings
  • Time by battery level
  • Charging comparison
  • Discharge rhythm

Graphs include capacity history and comparisons of complete 20-to-80-percent charging sessions. The developer cautions that the available measurements depend on the hardware and the system history recorded on that device; missing data is not filled in or treated as a complete reading.

Native plug-ins arrive, with important limits

Version 1.1.0 adds native plug-in support, including .battman import, plug-in management, diagnostics and recovery mode. Third-party plug-ins require approval, and changes take effect only after Battman restarts.

The release also includes a public Plugin SDK and buildable example source. Charge Gauge is an example, not a production plug-in bundled for normal users. On TrollStore, activating an extra native plug-in requires a replacement TIPA that contains it; importing a .battman package by itself is not enough.

Native plug-ins run inside Battman with its permissions. A valid signature can identify a publisher and package, but it is not a safety guarantee. Install only plug-ins whose source and publisher you trust.

Other useful changes

  • Adds a temperature-unit setting with System, Celsius and Fahrenheit choices.
  • Adds Export Powerlog to the charging graph; long-press the graph to export the available system battery log.
  • Improves charging-limit settings, daemon connections and charging controls.
  • Adds clearer explanations for unavailable or invalid battery readings.
  • Fixes potential deadlocks in battery-status callbacks and improves refreshes while scrolling.
  • Improves crash logging for the app, daemon and worker processes.
  • Fixes DOD0 units, misleading authenticity warnings and invalid time-to-empty estimates.
  • Fixes crashes while reading accessory and UPS battery information.
  • Removes unused system-group entitlements to address the remaining iOS 17 backup issue.
  • Bundles the gettext runtime and adds Traditional Chinese localization.

Do not install a DEB and the TrollStore TIPA at the same time. The release notes say only one Battman installation should remain on the device. The DEB packages require libintl8 or libintl.

What the support matrix actually says

Battman’s baseline is iOS 12 or later on A11-or-newer hardware. The developer’s table lists jailbreak installation on various iOS 12–16 combinations and TrollStore as another method where both the device and firmware support it. It is not a promise that every listed iOS version has a jailbreak or TrollStore installation path.

For iOS 16, the matrix marks A16/M3-or-newer combinations untested. Every iOS 17-or-later combination is also marked untested. The notes explicitly say RootHide was not considered, so a generic rootless package label must not be read as confirmed RootHide support.

That distinction matters on newer hardware: an app’s technical minimum does not bypass the separate availability limits of Dopamine, TrollStore or another installation environment. Use the compatibility checklist before choosing a package.

Should existing users update?

Version 1.1.0 is a worthwhile update for users who want historical battery analytics, powerlog export, temperature-unit control or plug-in development. It is also relevant if older versions showed invalid estimates, accessory-battery crashes, scrolling refresh problems or confusing charging-state messages.

Before updating, record your charging-limit settings and confirm which installation method you currently use. Download only from the official v1.1.0 release, where the developer publishes SHA-256 inventories and a P-256 signature for verification.

  1. Choose exactly one DEB or the TIPA based on your installation environment.
  2. For a package manager, confirm the queued dependency and package architecture before applying.
  3. For TrollStore, replace the existing app using the official Battman.tipa.
  4. Restart Battman after the update, especially before enabling any plug-in.
  5. Allow time for Analytics history to populate; unavailable historical readings cannot be reconstructed.

For restart terminology after package changes, see respring vs userspace reboot vs full reboot. If a DEB must be removed, follow the safe Sileo uninstall guide.

Frequently asked questions

Is Battman 1.1.0 a jailbreak?

No. Battman is a battery-management utility. Its DEB builds require an existing compatible jailbreak, while the TIPA requires a compatible TrollStore setup.

Does Battman 1.1.0 support rootless jailbreaks?

The release provides an iphoneos-arm64 DEB for compatible rootless jailbreaks, typically iOS 15 or later. That does not confirm every rootless environment or device.

Does Battman support RootHide?

The developer explicitly says RootHide was not considered in the release support table, so support should not be assumed.

Can I install the TIPA and DEB together?

No. The release notes say to keep only one Battman installation.
