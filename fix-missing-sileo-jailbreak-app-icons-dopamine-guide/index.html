Sileo Icon Missing? Restore Jailbreak Apps on Dopamine Safely

If Sileo, Zebra, Filza or another jailbreak app is installed but absent from the Home Screen, do not immediately remove the jailbreak. Dopamine includes supported controls for refreshing jailbreak-app registrations and repairing its package managers.

By Zeeshan Barvi · Published October 20, 2026 · Verified against Dopamine 3.0.11 source and developer issue responses

Use this guide only when the jailbreak app package is still installed. A missing icon can be a registration problem. It is not proof that the app was deleted, and it is not a reason to install an unofficial “icon fix” package.

Quick recovery order

  1. Open Dopamine and confirm its status is Jailbroken.
  2. If you just jailbroke, wait up to two minutes for jailbreak apps to register.
  3. Open Dopamine → Settings → Actions and choose Refresh Jailbreak Apps.
  4. If the icon remains missing, return to Dopamine’s action menu and choose Restart SpringBoard.
  5. Use Reinstall Package Managers only if Sileo or Zebra itself is missing—not as the first response to every absent app icon.
  6. If registrations still do not return, perform a userspace reboot from Dopamine. Reserve a full device reboot for the last step, because you will need to run Dopamine again afterward.

Why rootless jailbreak apps can disappear

Dopamine’s developer explains that when iOS reloads the icon cache, the system may stop honoring jailbreak applications stored under /var/jb/Applications. The package and its files can remain present while SpringBoard no longer shows the app. That is different from a failed Sileo transaction or an intentionally uninstalled package.

The official 3.0.11 interface includes separate Refresh Jailbreak Apps, Reinstall Package Managers, Restart SpringBoard and Reboot Userspace controls. Keeping those actions separate matters: refreshing registrations is less disruptive than reinstalling a package manager or rebooting the device.

Step 1: confirm the jailbreak state

A normal full reboot returns a semi-untethered Dopamine setup to a non-jailbroken state. In that state, rootless jailbreak apps are not expected to work normally. Open Dopamine first. If it does not report Jailbroken, follow the re-jailbreak after reboot guide before troubleshooting the icon cache.

If Dopamine does report Jailbroken, do not repeatedly press the jailbreak button. Continue with registration recovery.

Step 2: wait before changing packages

In an official issue response, opa334 said uicache -a is normally quick but can take as long as two minutes in isolated cases because of an lsd lock-up. Wait briefly after the jailbreak completes. Reinstalling packages during that window can add a second problem without helping the delayed registration.

Step 3: use Refresh Jailbreak Apps

Open Dopamine Settings, find the Actions section and tap Refresh Jailbreak Apps. The 3.0.11 source labels this as a distinct action, and its environment manager exposes a dedicated refreshJailbreakApps routine. Let it finish, return to the Home Screen and check both the Home Screen and App Library.

If every jailbreak app was missing and they return together, the problem was registration—not package removal.

Step 4: restart SpringBoard

If refreshing registrations completes but SpringBoard still shows stale icons, use Dopamine’s Restart SpringBoard action. This reloads the iPhone interface; it does not perform a full hardware reboot and does not reinstall tweaks. See the respring, userspace reboot and full reboot comparison if you are unsure which restart type you are choosing.

Step 5: repair Sileo or Zebra only when necessary

If other jailbreak apps appear but Sileo or Zebra alone is absent, open Dopamine Settings and use Reinstall Package Managers. Select the manager you normally use; Dopamine’s own package-manager selection text says users who are unsure should select Sileo.

This action repairs the package manager. It is not a bulk reinstall of every tweak, and it should not be your first step when Filza, NewTerm and several other jailbreak apps are all missing at once.

What not to do

  • Do not remove the whole jailbreak merely because one icon is missing.
  • Do not install a third-party icon-refresh tweak from an unverified repository. In the official issue discussion, the developer said one proposed helper performed the same job as Dopamine and did not solve icons disappearing later.
  • Do not delete files inside /var/jb manually.
  • Do not run copied terminal commands as root when the supported Dopamine controls are available.
  • Do not confuse a missing icon with a broken tweak. Many tweaks have no standalone app icon and instead expose settings through the Settings app.

If the problem is actually TrollStore

Full TrollStore-installed apps use a separate persistence-helper and registration model. If TrollStore itself or its installed apps disappear after an icon-cache reload, use the official persistence helper described in the TrollStore IPA installation guide. Do not substitute Dopamine’s jailbreak-app refresh flow for TrollStore recovery.

RootHide Bootstrap also has a separate app-registration and injection environment. Follow RootHide’s own controls rather than assuming a Dopamine action or conventional rootless path applies.

  • Dopamine 3.0.11 environment manager — official refresh implementation.

  • Dopamine issue #868 — later report where a SpringBoard restart restored missing jailbreak apps.
Why did Sileo disappear after jailbreaking?

An icon-cache reload can leave rootless jailbreak applications unregistered even though their packages remain installed. Confirm Dopamine is active, wait briefly, then use Refresh Jailbreak Apps.

Should I reinstall Dopamine?

No. Use the supported refresh and SpringBoard restart first. Reinstall only the package manager if Sileo or Zebra itself remains missing.

Will a full reboot fix the icon?

It can reset a stuck state, but it also exits the semi-untethered jailbreak. After rebooting, run Dopamine again before expecting rootless jailbreak apps to return.

Does every tweak have an icon?

No. Many tweaks expose a Settings pane or modify an existing app and never install a standalone Home Screen application.

Sources checked October 20, 2026. This guide reports official controls and developer explanations; it does not claim hands-on testing on every device, firmware or jailbreak environment.

Then: Refresh Jailbreak Apps.
