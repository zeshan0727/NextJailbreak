Installation choices

  • Sileo: refresh the Next Jailbreak source and open Applications.
  • TrollStore: download the TIPA and install it over the existing app.
  • The bundle identifier remains unchanged to preserve existing app data.

Before installation

  • Confirm the package supports your iOS version and jailbreak environment.
  • Install one new package at a time.
  • Keep a list of recent changes for troubleshooting.
  • Do not mix incompatible rootful, rootless and RootHide builds.

Repository policy

The repository is intended for original Next Jailbreak packages and authorized dependencies. It does not intentionally distribute pirated paid tweaks, cracked applications, stolen credentials or tools for unauthorized access.

Package availability and compatibility can change. Read each package description before installation.

System modifications carry risk

A package manager can install code that changes system processes. Use only trusted sources, review package details and be prepared to remove a recent package if stability changes.
