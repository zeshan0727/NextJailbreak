LockGlass: Glass-Style Lock Screen Customization With Version and Compatibility Caveats

LockGlass is a Lock Screen customization tweak designed around a glass-style interface that combines clock, calendar, weather and Control Center elements in one layout. Its product depiction lists version 1.4 with calendar and reminder source selection, width and position controls, read-only Axon detection, camera-transition improvements and safer handling for different iPhone display sizes. However, the supplied package stanza identifies version 1.0 and requires firmware from 16.0 up to, but not including, 17.4. Because the two records conflict, the version and firmware range shown by the package manager should be treated as the practical installation reference.

Key points

  • LockGlass is described as a Lock Screen tweak with a modern glass-style interface.
  • The listed feature set includes clock, date, calendar, weather, reminders and Lock Screen Control Center customization.
  • The depiction’s version 1.4 changelog adds source selection, width and position controls, read-only Axon detection and camera-related improvements.
  • The package stanza identifies version 1.0, an iphoneos-arm64 architecture and firmware requirements of at least 16.0 but below 17.4.
  • The supplied package metadata and depiction do not agree, so users should verify the version and dependency range offered by their package manager.

What LockGlass is designed to change

LockGlass is described in the package information as a tweak for customizing and changing the Lock Screen. The accompanying product depiction presents a more specific concept: a modern glass-style interface that brings the clock, calendar, weather and Lock Screen Control Center controls together in a single design.

The feature list covers the visual presentation of the clock, date, calendar and weather. Users are told they can adjust font size, font weight and font color, while blur, glass tint and frame controls provide additional ways to shape the appearance. Weather city selection and a daily forecast are also listed, alongside calendar and reminders integration.

  • Clock, date, calendar and weather appearance controls
  • Font size, weight and color settings
  • Blur, glass tint and frame customization
  • Weather city selection and daily forecast support
  • Calendar and reminders integration
  • Lock Screen Control Center controls

Calendar, reminders and layout controls

The depiction’s version 1.4 changelog adds Calendar and Reminder Source selection. According to the description, these settings let users choose which calendars and reminder lists appear in LockGlass. The supplied material does not describe the exact selection interface, but the stated purpose is to provide more control over which sources are shown.

Version 1.4 also introduces LockGlass Width, Horizontal Position and Vertical Position controls. These options are intended to make the layout easier to adjust and to improve compatibility with other Lock Screen tweaks. They give users direct control over the size and placement of the LockGlass arrangement instead of requiring them to use only a fixed layout.

  • Calendar and Reminder Source selection
  • LockGlass Width control
  • Horizontal Position control
  • Vertical Position control

Axon compatibility and overlap handling

The 1.4 changelog says LockGlass adds automatic Axon compatibility through read-only AXNView detection. The description states that LockGlass adjusts its own position or size only when necessary to reduce overlap, without modifying Axon.

This distinction matters when evaluating the feature. The supplied information describes LockGlass detecting the relevant Axon view and changing its own layout; it does not claim that every Axon configuration will be free of overlap. Users who run Axon or other Lock Screen modifications may need to use the new width and position controls to refine the result.

  • Compatibility is described as automatic read-only AXNView detection.
  • LockGlass adjusts its own position or size when necessary.
  • The changelog says LockGlass does not modify Axon.
  • The source does not provide a complete compatibility list for other Lock Screen tweaks.

Camera transitions and display-size handling

Several 1.4 changes concern how the Lock Screen behaves around the camera. The changelog mentions additional camera presentation paths and fallback detection across supported iOS versions. It also lists improved compatibility with camera quick actions and swipe-to-camera transitions.

The same update mentions safer layout handling for small and large iPhone displays, including Pro Max models. It also improves the compact calendar layout when LockGlass temporarily needs to use a narrower width. These notes indicate attention to changing screen space and Lock Screen transitions, although the supplied material does not provide independent testing, performance measurements or a complete list of affected devices.

  • Additional camera presentation paths and fallback detection
  • Improved camera quick-action compatibility
  • Improved swipe-to-camera transitions
  • Safer handling for small and large iPhone displays
  • Specific mention of Pro Max layout handling
  • Improved compact calendar layout at narrower widths

Language and device claims in the depiction

The product depiction states that LockGlass uses an adaptive layout for iPhone and iPad. It also describes a Turkish interface with an English fallback for other languages. These statements come from the product material and should be understood as listed capabilities rather than independently verified behavior across every device.

The depiction’s feature list also combines several information sources on the Lock Screen, including calendar, reminders and weather. The supplied materials do not include a universal setup guide, so the exact appearance and available controls may depend on the package version actually installed and the surrounding Lock Screen configuration.

  • Adaptive layout is listed for iPhone and iPad.
  • The interface is described as Turkish with English fallback for other languages.
  • The supplied material does not include independent testing or device-by-device results.

Why the version and firmware information requires caution

The supplied official records contain a significant discrepancy. The package stanza identifies the package as version 1.0. It requires firmware version 16.0 or newer and strictly below 17.4, and it lists PreferenceLoader as a dependency. The stanza also specifies iphoneos-arm64 architecture, a package size of 226,032 bytes and an installed size of 1,100 KB.

The separate depiction lists version 1.4, a size of 1.3 MB and iOS versions 16.0–26.0.1. It gives an update date of September 7, 2026 and includes changelog entries for versions 1.4, 1.3, 1.2, 1.1 and 1.0. The 1.4 entry contains the calendar, layout, Axon, camera and display changes described above.

These records should not be merged into one unqualified release claim. Version 1.4 is the version listed by the depiction and its changelog, while version 1.0 is the version identified by the package stanza. Likewise, the depiction’s broader iOS range does not override the package stanza’s explicit firmware ceiling. The package manager’s currently displayed version, dependency resolution and firmware requirements are therefore the most important checks before installation or upgrade.

  • Package stanza: version 1.0.
  • Package stanza: firmware at least 16.0 and below 17.4.
  • Package stanza: PreferenceLoader dependency.
  • Package stanza: iphoneos-arm64 architecture.
  • Depiction: version 1.4 and iOS 16.0–26.0.1.
  • Confirm which record applies to the package currently offered.

What to verify before installing

First, check the exact version offered by the package manager. Do not assume that the presence of a 1.4 changelog means the package stanza’s version 1.0 entry has already been replaced. The displayed version should be confirmed directly before proceeding.

Next, review the resolved firmware requirement. The package stanza limits its firmware dependency to versions below 17.4, despite the depiction listing a broader range. If the package manager reports the lower ceiling, that is the constraint that applies to that installation entry.

PreferenceLoader should also be available because it is explicitly listed as a dependency. Users running Axon or other Lock Screen tweaks should review possible overlap and use the width, horizontal position and vertical position settings if necessary. Finally, inspect the calendar, reminders, weather and Control Center settings after installation, since the supplied source does not provide one universal configuration procedure.

  • Confirm the offered version and package metadata.
  • Check the firmware range resolved by the package manager.
  • Confirm that PreferenceLoader can be installed or is already available.
  • Review possible overlap with Axon and other Lock Screen tweaks.
  • Choose calendar and reminder sources carefully after installation.

Frequently asked questions

What is LockGlass?

LockGlass is a Lock Screen customization tweak described as using a glass-style interface for clock, calendar, weather and Control Center elements. Its listed controls include typography, blur, tint, frame, weather location and calendar-related settings.

What does the depiction’s version 1.4 changelog add?

It lists calendar and reminder source selection, width and horizontal and vertical position controls, automatic Axon compatibility through read-only AXNView detection, improved camera handling, safer display-size layouts, compact calendar improvements and general stability and compatibility changes.

Does the supplied package metadata confirm iOS 17.4 or later support?

No. The package stanza identifies version 1.0 and requires firmware from 16.0 up to, but not including, 17.4. The depiction separately lists iOS 16.0–26.0.1, so users should rely on the current package-manager metadata and dependency resolution for the package available to them.

Does LockGlass modify Axon?

The 1.4 changelog says LockGlass uses read-only AXNView detection and adjusts its own position or size when necessary to reduce overlap without modifying Axon.

Does LockGlass require another package?

Yes. The package stanza lists PreferenceLoader as a dependency and specifies an iphoneos-arm64 architecture.
