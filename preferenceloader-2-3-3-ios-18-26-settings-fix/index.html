PreferenceLoader 2.3.3 Fixes Tweak Settings on iOS 18 and iOS 26

A community-maintained PreferenceLoader fork moves tweak preferences back to the main Settings screen on iOS 18 and later. Its current 2.3.3 release also prevents connected Bluetooth accessories such as AirPods from hiding the entire tweak section.

Important: this is Yves000’s public fork of dhinakg’s PreferenceLoader, not a new upstream release. Version 2.3.3 was published on August 27, 2026. Install it only if you understand why your jailbreak setup needs this fork.

PreferenceLoader 2.3.3 at a glance

  • Latest fork release: 2.3.3, published August 27, 2026.
  • Main purpose: return tweak entries to the bottom of the main Settings screen on iOS 18 and later instead of placing them inside General.
  • Latest fix: a connected Bluetooth accessory such as AirPods no longer hides those entries.
  • Packages: separate rootful, rootless and RootHide DEB files.
  • Declared firmware: iOS 15.0 or later; the 2.3-series changes specifically target Settings behavior on iOS 18 and later.

What PreferenceLoader does

PreferenceLoader is infrastructure, not a visual tweak by itself. It lets jailbreak tweaks add configuration panes to Apple’s Settings app. If it is missing or incompatible, a tweak can remain installed while its switches, sliders and other options are absent or fail to open.

The project is a drop-in replacement originally authored by Dustin Howett and maintained in the modern upstream repository by dhinakg. Yves000’s fork builds on that code for the newer Settings application. Its package identifier remains preferenceloader, so the fork should be treated as a replacement build, not installed alongside another PreferenceLoader.

Changes from 2.3 through 2.3.3

The official fork release history documents four focused updates:

  • 2.3 — August 19: moved tweak preferences from General back to the main Settings screen on iOS 18 and later.
  • 2.3.1 — August 20: restored proper switch rows for PSSwitchCell entries without a preference bundle, preventing the link-style row and Settings crash; it also handled filtered entries and subdirectories on the root path.
  • 2.3.2 — August 21: stopped iPad Settings in expanded split view from bouncing back when opening a tweak subpage.
  • 2.3.3 — August 27: fixed the tweak section disappearing when a Bluetooth accessory such as AirPods is connected.

These are Settings-integration fixes. The release notes do not claim a new exploit, wider jailbreak availability or additional device support.

Rootful, rootless and RootHide builds

The 2.3.3 release attaches three packages. Choose by jailbreak environment, not by the iPhone CPU name alone:

  • Rootful: preferenceloader_2.3.3_iphoneos-arm.deb.
  • Rootless: preferenceloader_2.3.3_iphoneos-arm64.deb.
  • RootHide: preferenceloader_2.3.3_iphoneos-arm64e.deb.

The package control file declares MobileSubstrate and iOS 15.0 or later as dependencies. That does not mean every iPhone on those firmware generations can be jailbroken. A compatible jailbreak or bootstrap must already exist for the exact device and firmware. Use our rootless, rootful and RootHide explainer before selecting a package.

Who should consider the fork?

The clearest use case is a jailbroken iOS 18-or-later device where tweak preferences appear inside General, disappear with Bluetooth connected, crash when a root-list switch is tapped or bounce back on an iPad subpage. This can include supported iOS 26 setups, but availability is device-specific; check the Dopamine 3 iOS 26 compatibility guide rather than treating a package header as proof of support.

Users whose upstream PreferenceLoader already works as expected do not gain a new tweak feature by switching. Missing settings can also come from an incompatible tweak, the wrong rootless/rootful build, disabled tweak injection, a failed dependency or an unsupported preference bundle.

Safer update checklist

  1. Confirm the jailbreak environment and select only the matching package.
  2. Record the installed PreferenceLoader version and source so the change can be reversed.
  3. Use the fork’s official GitHub release; avoid renamed files from mirrors.
  4. Let the package manager resolve dependencies and perform its requested restart or respring.
  5. Test several preference panes, nested pages, and Settings with and without Bluetooth connected.
  6. If Settings crashes or entries disappear, return to the previous known-good build instead of stacking loaders.

Frequently asked questions

Is 2.3.3 an official upstream update?

No. It is a public fork by Yves000 based on dhinakg’s PreferenceLoader repository.

What does 2.3.3 fix?

The release note says Bluetooth accessories such as AirPods no longer hide tweak entries from the main Settings list on iOS 18 and later.

Does it support rootless jailbreaks?

The release provides a rootless iphoneos-arm64 package, plus separate rootful and RootHide builds.

Does iOS 15+ mean every device is supported?

No. It is a package dependency. A compatible jailbreak or bootstrap is still required for the exact hardware and firmware.

Why is there no screenshot?

The repository and releases provide source code and DEB assets but no official screenshot, banner or app icon suitable for reuse. Next Jailbreak did not fabricate one.
