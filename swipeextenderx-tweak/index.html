SwipeExtenderX Assigns Powerful Swipe Actions to iPhone Keyboard Keys

SwipeExtenderX turns ordinary keyboard keys into gesture shortcuts for editing, cursor movement, clipboard actions and more. Each key can be configured instead of being limited to its normal tap.

Version1.6.1 reviewed; 1.6.2 on Chariz
Listed supportiOS 14 and later
PriceCheck Chariz
SourceChariz

What SwipeExtenderX actually changes

The package supports swipe and long-press gestures on individual keys. The result is a keyboard that can expose common editing commands without adding a separate row of buttons.

Official screenshots show the per-key action picker and appearance controls. This is the real interface readers need to see before deciding whether the number of options will be useful or distracting.

  • Choose from 27 listed key actions using swipe or long-press gestures.
  • Assign editing actions including select, cut, copy, paste, undo, redo and delete.
  • Configure cursor movement, keyboard dismissal, dictation and menu actions.
  • Change key labels and keyboard colors from the preference pane.

Installation checklist

  1. Open Chariz and confirm the current version and compatibility.
  2. Install the package only through the official Chariz source in a trusted package manager.
  3. Respring if requested, then open SwipeExtenderX preferences.
  4. Assign one or two gestures first and choose keys where accidental swipes are unlikely.
  5. Test typing and cursor movement in several apps before configuring the rest of the keyboard.
