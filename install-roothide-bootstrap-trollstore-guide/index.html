How to Migrate RootHide Bootstrap 2.2.2 to Dopamine RootHide 3

RootHide Bootstrap 2.2.2 is not a new Bootstrap installer. It is the project’s official notice telling existing Bootstrap users to disable app injection, unbootstrap, then move to Dopamine RootHide 3 through TrollStore.

By Zeeshan Barvi · Published October 28, 2026 · Updated November 2, 2026 · Verified against the official Bootstrap 2.2.2 notice and Dopamine RootHide release 29

Current status: RootHide published Bootstrap 2.2.2 on October 25, 2026 without an installation asset. The release page directs Bootstrap users to Dopamine RootHide 3. The last standalone Bootstrap TIPA remains 2.2.1; do not download a file advertised as “Bootstrap 2.2.2 TIPA.”

What changed in Bootstrap 2.2.2

The complete 2.2.2 release note is a migration notice. RootHide says Dopamine 3 with RootHide has been released and provides four actions: disable injection for all apps, reboot and unbootstrap, install RootHide Dopamine 3 in TrollStore, then jailbreak with it.

This supersedes the previous recommendation to install standalone Bootstrap 2.2.1 for new use. It does not expand Bootstrap’s old iOS range, ship a new exploit, or prove Dopamine RootHide support for every device that could run Bootstrap.

Standalone Bootstrap officially listed iOS 15.0–17.0 on A8–A17 Pro and M1/M2 devices with TrollStore. That historical range is not a guarantee that every such combination can run Dopamine RootHide 3. The replacement inherits device-, chip-, firmware- and exploit-specific limits from Dopamine, while release 29 itself announces no broader matrix.

Official migration order

  1. Open Bootstrap → AppList and disable injection for every app. Do not leave selected apps enabled.
  2. Reboot the device. This clears the active Bootstrap session before removal.
  3. Open Bootstrap → Settings → Unbootstrap and let the application finish. Do not install Dopamine RootHide on top of a still-active standalone Bootstrap.
  4. Download either Dopamine.ipa or Dopamine.tipa from RootHide’s official release 29 page. The files have the same payload; choose the extension expected by your TrollStore workflow.
  5. Verify the download, install it with TrollStore, and confirm the application reports 3.0.12-29.
  6. Open Dopamine RootHide and jailbreak only after confirming that the build supports your exact device and firmware.

What not to carry across blindly

  • AppList choices: rebuild injection selections one app at a time. Enabling everything increases conflict and detection risk.
  • Converted packages: a package patched for standalone Bootstrap is not automatically validated for the new environment.
  • Detection assumptions: RootHide reduces common paths and offers per-app controls; it cannot guarantee that every banking, workplace or game app will accept the device.
  • Old installer files: Bootstrap 2.2.2 has no TIPA asset. The 2.2.1 TIPA remains historical and should not be confused with a current migration package.

If Unbootstrap fails

  1. Recheck AppList and disable every selected app.
  2. Reboot once more, then run Unbootstrap from Bootstrap settings before opening other jailbreak tools.
  3. Do not delete Bootstrap from the Home Screen as a substitute for Unbootstrap; removing the application icon alone is not the documented cleanup.
  4. If the device returns to an active Bootstrap state, stop before installing Dopamine RootHide and collect the exact on-screen error.
  5. Keep TrollStore and personal data intact while seeking help from the official RootHide project. Avoid scripts or “cleaners” from mirrors.

After Dopamine RootHide starts

  1. Confirm Sileo opens and refreshes official sources.
  2. Install only packages that explicitly support RootHide or have a documented conversion path.
  3. Enable injection for one target app, test it, then continue gradually.
  4. If Messages lags, confirm release 29 is installed; that release specifically fixes a RootHide Messages-lag issue and updates bundled Sileo.
  5. Use the Dopamine RootHide 3.0.12-29 release guide for asset details and the Dopamine recovery guide if a package causes a crash loop.

Can you still install Bootstrap 2.2.1?

The official 2.2.1 TIPA still exists, but the newer 2.2.2 notice tells Bootstrap users to upgrade to Dopamine RootHide 3. New users should not interpret the absence of a 2.2.2 asset as a broken download. If you have a special reason to retain standalone Bootstrap, its documented requirements remain TrollStore, Developer Mode, iOS/iPadOS 15.0–17.0 and supported A8–A17 Pro or M1/M2 hardware; that does not make it the current recommended path.
