How to Install RootHide Bootstrap 2.2.1 with TrollStore

RootHide Bootstrap must be installed through TrollStore. This guide uses the project’s official 2.2.1 TIPA, separates Bootstrap support from TrollStore availability, and follows the safeguards enforced by the application itself.

By Zeeshan Barvi · Published October 28, 2026 · Verified against the official 2.2.1 release, README, interface source and installation checks

Important: RootHide Bootstrap is not a universal jailbreak. Its own support range does not prove that TrollStore is installable on every device or every iOS version inside that range. You need a working, compatible TrollStore installation first.

Requirements

CheckOfficial requirementWhy it matters
FirmwareiOS or iPadOS 15.0–17.0This is the range stated by RootHide for Bootstrap 2.2.1.
HardwareA8–A17 Pro, plus M1 and M2 devicesThe project lists these chip families; hardware support still does not create a TrollStore path on unsupported firmware.

If TrollStore is not already installed, use the TrollStore compatibility and installation-method guide. Do not sideload Bootstrap with a seven-day certificate or install a re-signed copy; that is not the project’s documented setup.

Before downloading

  1. Reboot if another jailbreak is currently active. The 2.2.1 app refuses to continue while another jailbreak session is active.
  2. Do not combine this standalone Bootstrap with RootHide Dopamine. The application checks for RootHide Dopamine and warns that installing Bootstrap may break it.
  3. If an old RootHide Bootstrap beta is present, disable app tweaks, reboot and follow the app’s removal guidance before installing the current release.
  4. Back up important data. RootHide’s README warns that unofficial modifications can cause irreparable damage.

Verify the official 2.2.1 download

RootHide released version 2.2.1 on June 12, 2026. Its changelog adds the Procursus alternative repository by default and hides additional jailbreak traces. The release contains one maintainer-uploaded installation file:

Install RootHide Bootstrap with TrollStore

  1. Download Bootstrap.tipa from RootHide’s official 2.2.1 release.
  2. Open the downloaded file in TrollStore. If Safari shows the file in Downloads, use Share and select TrollStore.
  3. Review TrollStore’s prompt, then tap Install. RootHide Bootstrap should appear in TrollStore’s installed-app list and on the Home Screen.
  4. Open Bootstrap. If the app reports that TrollStore is too old, update TrollStore and reinstall Bootstrap rather than bypassing the check.
  5. If prompted about Developer Mode, enable it and reboot. TrollStore 2.0.9 or later can expose the on-device Developer Mode control where supported.
  6. Return to Bootstrap and tap Install. Leave the application open while it creates the environment, rebuilds applications and performs its respring or userspace-reboot step.
  7. After the interface reports Bootstrapped, confirm that the package manager opens normally before installing anything else.

Enable tweaks only for the apps that need them

RootHide does not inject tweaks into third-party applications by default. Open App List in Bootstrap and enable only the exact app targeted by a compatible tweak. Enabling every app increases conflict and detection risk without adding a benefit.

A package must explicitly support RootHide, or be converted through a supported workflow. A generic “iOS 17 compatible” claim does not establish RootHide compatibility. See the RootHide tweak-injection guide and RootHide Patcher guide before converting or enabling packages.

What RootHide Bootstrap does not provide

  • It does not make TrollStore available on firmware where the required CoreTrust installation path is unavailable.
  • It does not turn every conventional rootless or rootful tweak into a RootHide package.
  • It does not guarantee that banking, workplace, game or government apps will stop detecting modifications.
  • It should not be installed on top of RootHide Dopamine or an active unrelated jailbreak environment.
  • It does not prove support for iOS 17.0.1 or any iOS 18, 26 or 27 release; the official Bootstrap range ends at iOS 17.0.

Frequently asked questions

Does RootHide Bootstrap jailbreak an iPhone?

No. It creates a RootHide bootstrap environment on an already compatible TrollStore device. It does not add a kernel jailbreak or create TrollStore support.

Can I use RootHide Bootstrap on iOS 18 or newer?

The official 2.2.1 README lists iOS 15.0–17.0. Do not extend that statement to iOS 18, 26 or 27 without a newer official release.

Can I install it with AltStore, SideStore or a signing service?

The project explicitly requires TrollStore. A normal sideload is not the documented or supported installation path.

Should I enable every app in App List?

No. RootHide intentionally leaves third-party apps disabled by default. Enable only the app required by a verified compatible tweak.
