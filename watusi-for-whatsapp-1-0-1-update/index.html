Watusi 1.0.1 for WhatsApp Adds Online List, Backup Fixes and iOS 26 Theme Improvements

Watusi for WhatsApp has reached version 1.0.1, released November 13, 2026. The update restores the Online List, addresses missing media after WhatsApp backup restoration, improves Hidden Chats behavior, fixes several crashes, and updates theme handling for iOS 26. The package requires firmware 15.1 or newer, MobileSubstrate 0.9.5000 or newer, and an arm64 jailbroken environment. The developer’s documentation also lists Watusi 3 sideloading packages for WhatsApp 26.44.72 and Watusi 3 version 1.3.31, but those are separate from the new 1.0.1 package.

Key points

  • Watusi 1.0.1 was released on November 13, 2026, according to the official package page.
  • The Online List returns with online status, duration and last-seen information, plus its own contacts and multiple entry points.
  • WhatsApp backup restoration now addresses missing photos, videos and voice notes in chats.
  • Hidden Chats, themes, call recording, Control Center toggles and several crash scenarios receive fixes.
  • The package declares firmware version 15.1 or newer and MobileSubstrate version 0.9.5000 or newer as dependencies.
  • The official package is an iphoneos-arm64 tweak and conflicts with several older or related Watusi packages, so existing installations should be checked before upgrading.

Watusi 1.0.1 is a feature-and-fix release

Watusi 1.0.1 is presented by its developer as an update to the all-in-one WhatsApp tweak, rather than a minor metadata refresh. The official package page lists the release date as November 13, 2026, and gives the update a long set of changes covering privacy-related behavior, backups, calls, themes, notifications, contacts and stability.

The most visible addition is the return of Online List. According to the release notes, users can see who is online, how long contacts have been online and their last-seen information. The feature has its own contacts and can be opened from the chats list, from a row at the top of that list or from a dedicated tab. The source does not describe further privacy controls or explain how frequently the list refreshes, so those details should not be assumed from the feature name alone.

  • Official package version: 1.0.1
  • Release date listed by the developer: November 13, 2026
  • Package identifier: com.fouadraheb.watusi
  • Architecture: iphoneos-arm64

Backup restoration and hidden-chat fixes

One of the most practical fixes addresses WhatsApp backup restoration. The release notes say that restoring a WhatsApp backup could leave photos, videos and voice notes missing from chats; Watusi 1.0.1 fixes that behavior. This is specifically a fix for the restoration problem described by the developer, not a promise that every backup or migration scenario will work identically across all installations.

The update also revisits Hidden Chats. In-app notifications from hidden chats are hidden again on the latest WhatsApp, and statuses belonging to hidden chats are now hidden from the Updates tab. These changes are important because hiding a conversation while leaving related notifications or status entries visible can undermine the purpose of the feature.

Watusi 1.0.1 additionally fixes WhatsApp’s Unread filter showing every chat when Hidden Chats had hidden conversations. That change connects the privacy feature with normal chat-list filtering, reducing the chance that hidden content changes the apparent result of an unread-chat view.

  • Backup restoration: missing photos, videos and voice notes are addressed.
  • Hidden-chat notifications are hidden again in the app.
  • Statuses from hidden chats are hidden from the Updates tab.
  • The Unread filter no longer shows every chat because of hidden chats, according to the release notes.

Call recording and theme improvements

The release notes identify a fix for crackling and distorted sound in new Call Recordings. The source does not provide technical details about the audio pipeline or state that older recordings are repaired, so the change should be understood as a correction to newly created recordings.

Themes receive several targeted improvements. When a new app font requires a relaunch to appear across every screen, the Themes interface now tells the user and offers a relaunch. The theme editor’s app icon picker now displays icons, while Message Text Size and Sender Name Size apply after a restart and when switching themes.

The update also corrects a theme issue on iOS 26: the Top Bar color now applies instead of showing the background color. Separately, Watusi fixes a crash after selecting a wallpaper photo in the theme editor. These changes suggest that theme configuration is a major focus of this release, but the source does not claim that every theme or custom-font edge case has been eliminated.

  • New call recordings no longer have the listed crackling and distortion issue.
  • Theme font changes can prompt a relaunch when one is needed.
  • The theme editor’s app icon picker now shows icons.
  • Top Bar color handling is corrected for iOS 26.
  • Several theme-editor and theme-switching behaviors are fixed.

Stability, contacts and Control Center changes

Several crash fixes are included. Watusi 1.0.1 addresses a launch crash involving a spoofed group saved through Contacts Spoofing, as well as a crash when opening certain statuses while the Save or Mark as Viewed button is present. The release also brings contact groups created in Watusi 3 into the contacts picker.

Control Center integration receives a synchronization fix. The release notes specifically mention toggles such as Hide Chats, Last Seen and Read Receipts not matching their corresponding switches in Watusi. Version 1.0.1 fixes that mismatch. The package also includes a Control Center toggle component and identifies CCSupport as the required package for activating it from Control Center settings.

Updates Tracking gains a direct route to the updates list from its settings. The source does not specify which update events are tracked or add a new retention policy, so this should be treated as a navigation improvement rather than a newly documented tracking system.

  • Fixes a launch crash involving a spoofed group.
  • Fixes a crash involving certain status actions.
  • Carries Watusi 3 contact groups into the contacts picker.
  • Synchronizes selected Control Center toggles with Watusi settings.
  • Adds direct access to the updates list from Updates Tracking settings.

Compatibility and package considerations

The official package stanza declares a firmware dependency of version 15.1 or newer and a MobileSubstrate dependency of version 0.9.5000 or newer. It is built for iphoneos-arm64 and is categorized as a tweak. These declarations describe the package’s stated requirements; they do not identify every jailbreak, device model or package manager configuration that may be suitable.

The package also declares conflicts with several identifiers, including older Watusi packages and related tweaks such as Stalky, OnlineNotify and ContactSync. Before installing or upgrading, users should inspect their current package list and determine whether any conflicting identifier is already present. The source does not provide a universal migration procedure for every conflict.

The package page says Watusi can be configured from inside WhatsApp settings and lists support for English, Arabic, German, Spanish, French, Italian, Portuguese and Turkish. It also describes broad feature areas including privacy, protection, status management, chats, media, notifications, themes, message scheduling, auto reply, hidden chats, contact spoofing, custom tones and sticker management.

  • Declared firmware requirement: 15.1 or newer.
  • Declared MobileSubstrate requirement: 0.9.5000 or newer.
  • Package architecture: iphoneos-arm64.
  • Check for conflicts before upgrading from older Watusi packages or related tweaks.
  • CCSupport is required for the package’s Control Center toggle integration.

Watusi 3 sideloading information is separate

The developer’s README has also been updated for Watusi 3 version 1.3.31 and WhatsApp version 26.44.72. It lists standard WhatsApp, WhatsApp Business, duplicate builds and TrollStore-oriented variants. Those entries are separate from the repository package identified as Watusi 1.0.1, so readers should avoid treating the Watusi 3 build number as the version of the new package.

For sideloading, the README distinguishes between builds intended for ordinary signing and builds intended for TrollStore or signing with the necessary certificate and entitlements. It states that the standard sideloading IPAs have their Plugins folder removed and include fixes intended to avoid crashes when they are not signed with proper entitlements and a developer account. It separately warns that the TrollStore IPAs are fake-signed with their original entitlements and can crash if used outside TrollStore or without an appropriate certificate and entitlements.

The README documents installation routes for jailbroken devices, standard sideloading, linked-device use and TrollStore. It also warns about limitations: non-developer signing can expire after seven days, while push notifications and iCloud features are not generally available for sideloaded apps, with the README identifying TrollStore on supported devices as an exception. Readers should use only the developer’s official distribution channels and match the installation method to their device and signing setup.

  • Watusi 3 is listed at version 1.3.31 for WhatsApp 26.44.72.
  • Standard sideloading and TrollStore packages have different signing expectations.
  • Non-developer signing is described as expiring after seven days.
  • Push notifications and iCloud features have stated limitations for sideloaded apps.
  • The official README says some versions are released for jailbroken devices before sideloading builds.

What to check before installing

The safest preparation is to identify which Watusi branch and installation model you are using. A jailbroken-device package, a standard sideloaded IPA, a linked duplicate and a TrollStore installation do not share identical requirements. Confirm that the package or IPA matches the intended method before replacing an existing WhatsApp installation.

Users with important chats should also review their backup plan. The release fixes a specific issue involving missing media after WhatsApp backup restoration, but the README separately states that chats cannot be restored from iCloud to sideloaded Watusi. For sideloaded installations, the documented fallback is a manual Files-based backup and restore process, provided the app’s Document Browser feature is enabled.

Finally, review conflicts, dependencies, signing status and notification expectations. The official material does not promise that every device, jailbreak, WhatsApp build or signing configuration will behave the same way. Checking those conditions before changing an active WhatsApp installation can reduce the risk of losing access to chats, notifications or iCloud-related functionality.

  • Confirm whether the target is the 1.0.1 package or a Watusi 3 IPA.
  • Review declared dependencies and conflicting package identifiers.
  • Back up important WhatsApp data before replacing an installation.
  • For sideloading, understand the documented iCloud, notification and signing limitations.
  • Use the developer’s official package or README distribution path rather than unofficial copies.

Frequently asked questions

What is new in Watusi 1.0.1?

The release restores Online List, fixes missing photos, videos and voice notes after WhatsApp backup restoration, improves Hidden Chats behavior, fixes crackling and distortion in new call recordings, improves themes, synchronizes selected Control Center toggles and addresses several crashes.

What iOS or firmware version does the package require?

The official package declares firmware version 15.1 or newer. It also declares MobileSubstrate version 0.9.5000 or newer and is built for iphoneos-arm64.

Is Watusi 1.0.1 the same as Watusi 3 version 1.3.31?

No. Watusi 1.0.1 is the version shown in the official package stanza. The README separately lists Watusi 3 version 1.3.31 alongside WhatsApp version 26.44.72 for several sideloading and TrollStore builds.

Does Watusi 1.0.1 restore chats from iCloud for sideloaded installations?

The README says chats cannot be restored from iCloud to sideloaded Watusi. It documents a manual Files-based backup and restore method for sideloaded installations instead.

Why should users check conflicting packages before upgrading?

The package declares conflicts with several older Watusi identifiers and related tweaks, including Stalky, OnlineNotify and ContactSync. Existing packages with those identifiers may need attention before installation.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
