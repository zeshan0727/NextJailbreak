VidGrab 1.3.6c Adds Custom Themes, Backups and Automatic Engine Updates

The latest VidGrab release expands personalization and maintenance rather than the download workflow alone: it adds a unified theme gallery, user-built themes, portable backups, automatic engine updates, Arabic and a settings-crash fix for iOS 27.2 beta.

By Zeeshan Barvi · Published October 13, 2026 · Release checked against T4MAG0’s GitHub repository and Havoc listing

Latest-version note: the developer published VidGrab 1.3.6c on GitHub on October 13, 2026. At the time of checking, Havoc still showed 1.3.6b. This article follows the newer official GitHub release instead of treating the marketplace listing as current.

What changed in VidGrab 1.3.6c

  • Theme Gallery: built-in and custom themes now appear in one list, with Midnight Blue, Emerald and Sunset added.
  • Custom Themes: users can choose an accent color or HEX value, then use a color, gradient, photo or texture background. Advanced controls cover text, cards, buttons and other interface elements.
  • Theme management: custom themes can be renamed, duplicated, deleted, exported and imported.
  • Backup and Restore: one file can save settings, themes and saved playlists, replacing the older separate settings export/import workflow.
  • Automatic engine updates: the download engine can update itself, with an off switch under Settings > Engine.
  • Player additions: the landscape player can show a clock-and-temperature pill, while tapping album art can turn it into a spinning CD cover.
  • Language and state fixes: Arabic is now available, Shuffle and Repeat choices persist, and opening Settings no longer closes the app on iOS 27.2 beta.

Why automatic engine updates matter

VidGrab relies on yt-dlp to identify and process media links. Video sites change frequently, so an otherwise unchanged app can stop recognizing a site when its extraction rules move. Version 1.3.6c’s automatic engine updater gives the app a way to receive those extraction fixes without waiting for a full VidGrab package update.

The control remains optional. Users who prefer a fixed setup can disable it under Settings > Engine. The feature does not guarantee that every site or protected stream will work, and it does not override a site’s terms or copyright rules.

Backup and Restore replaces the older settings transfer

The new backup file covers three areas together: application settings, custom themes and saved playlists. That is more useful than a settings-only export when moving between installations or rebuilding a device, because the visual setup and playlist organization travel with the preferences.

The developer describes this as a replacement for Export and Import settings. It is still prudent to keep the backup file outside VidGrab’s own container before removing or reinstalling the app.

Theme Gallery and custom-theme controls

The gallery combines built-in themes with designs created by the user. A custom design can start with an accent color or HEX code and add a solid color, gradient, photo or texture as its background. Advanced Colors exposes more granular choices for text, cards and buttons.

Because themes can be exported and imported, this is more than a local color picker: a finished design can be preserved or moved. Version 1.3.6c also adds Midnight Blue, Emerald and Sunset to the built-in collection.

Player changes: clock, temperature and spinning artwork

When landscape-player controls hide, an optional pill can slide into the top-right corner with the time and temperature, then soften after several seconds. It can be disabled under Settings > Gestures. The music player also gains an optional circular album-art mode: tap the cover to turn it into a rotating CD, and tap again to return.

Shuffle and Repeat selections now persist instead of resetting. That small state fix should matter to anyone using VidGrab as a local music player rather than only as a downloader.

Installation options and compatibility

The official 1.3.6c release includes an IPA, a TIPA and three DEB variants: arm, arm64 and arm64e. The tagged README says the IPA route works on iOS 15 and newer without a jailbreak and can be installed through TrollStore or a sideloading app already configured by the user.

For jailbreak installations, the developer publishes rootful, rootless and RootHide packages through the repository at https://iamjhe08.github.io/repo/. Havoc’s 1.3.6b listing separately reports iOS 15.0–26.0 and rootless support for its jailbreak package. Do not assume that marketplace range describes every IPA, TrollStore or future iOS setup.

Choose the correct package: IPA/TIPA is the no-jailbreak or TrollStore/sideload path. DEB files are jailbreak packages. Do not install a randomly redistributed build when the developer publishes signed release assets and a repository directly.

What VidGrab already does

Beyond the new 1.3.6c features, the official project documentation lists link pasting, an in-app browser, quality selection up to 4K where available, audio-only output, playlists and channels, concurrent downloads, Picture in Picture, background playback, download folders, a local player, on-device subtitle generation and a protected Private Vault. Jailbreak builds can also show a floating download bubble over other apps.

Some abilities depend on the source site, the available media, the current extraction engine and the exact installation environment. The presence of a button does not mean every protected or account-restricted video can be saved.

Update checklist

  1. Open the official VidGrab 1.3.6c release.
  2. Select the IPA/TIPA or DEB that matches your installation method and architecture.
  3. Back up important saved media outside the app before replacing an older installation.
  4. After updating, open Settings and verify your engine-update preference.
  5. Confirm that themes, playlists and Shuffle/Repeat state behave as expected before removing the older app copy.
  6. If using TrollStore, version 1.3.6b fixed an updater problem that could create a second icon; verify that only the intended VidGrab registration remains.

Download responsibly

Use VidGrab only for media you own or have permission to save. The project’s own README asks users to respect each site’s rules. Paywalled, DRM-protected or copyrighted material does not become authorized merely because a tool can detect a URL.

Bottom line: VidGrab 1.3.6c is the current official release and a larger update than the 1.3.6b build still shown on Havoc at publication time. Custom themes and unified backups improve portability, while automatic engine updates address the fast-moving part of any yt-dlp-based downloader.

Frequently asked questions

Does VidGrab 1.3.6c require a jailbreak?

No for the IPA/TIPA route. The tagged README says VidGrab works on iOS 15 and newer and can be installed with TrollStore or an existing sideloading app. The DEB files are for jailbreak installations.

Why does Havoc show 1.3.6b?

Marketplace publication can lag behind the developer’s repository. During the October 13 source check, Havoc listed 1.3.6b while GitHub already had the official 1.3.6c release.

What does the engine updater change?

It lets VidGrab update its media-extraction engine independently. This can deliver compatibility fixes when video sites change, and it can be disabled in Settings.

What is included in a VidGrab backup?

The 1.3.6c release notes say one backup file includes settings, custom themes and saved playlists.
