Atria 1.9.3 vs Lynx 2: Home Screen Editor or Full iOS Suite?

Atria is the free, focused choice for per-page layouts and custom App Library categories, with separate RootHide and conventional rootless packages. Lynx 2 costs $1.99 and covers far more of iOS, but its official support stops at iOS 16.7.10. The right choice now depends as much on firmware and jailbreak environment as on features.

By Zeeshan Barvi · Published October 15, 2026 · Updated November 13, 2026 from official project and storefront sources

Neither tweak is a jailbreak. The compatibility ranges below describe the packages. They do not prove that a public jailbreak exists for every device on every listed firmware.

Quick verdict

  • Choose Atria 1.9.3 for per-page grids, spacing, presets and a deeper App Library category editor—especially on a native RootHide setup.
  • Choose Lynx 2 2.5.4 for one paid suite spanning Home Screen, Lock Screen, Status Bar, App Switcher, Control Center, apps and CarPlay on officially supported iOS 14–16.
  • Do not stack overlapping controls. If both packages are available on the same setup, give Atria ownership of Home Screen and App Library layout and disable the comparable Lynx options.

Why Atria 1.9.3 is better for layout and categories

CySxL’s maintained Atria fork keeps the visual layout editor that made the original useful: per-page rows and columns, icon and widget scale, spacing, page insets, offsets, labels, page-dot positioning and portable presets. It now also moves apps between App Library categories, creates, renames and reorders categories, hides selected groups and restores Apple’s stock grouping.

That focus matters if the goal is five icons across one page, a different widget scale on another or a deliberately reorganized App Library. Lynx 2 exposes many Home Screen controls, but its value is breadth rather than Atria’s dedicated editor and current category engine.

The fork changes installation planning. The official repository publishes a native iphoneos-arm64e RootHide build and a separate conventional rootless iphoneos-arm64 build. The developer explicitly labels the rootless build “not yet tested,” so package availability must not be presented as broad reliability.

Privacy warning for Atria exports

Atria 1.9.3 asks whether custom category data should be included in an exported preset because that data reveals the installed-app list. Keep exports private or omit category data before sharing. Imports from another device can also reference apps that are not installed locally.

Why Lynx 2 is better for broad customization

Lynx 2 is the broader product. Its official feature list covers System Wide, Apps, Home Screen, Lock Screen, Status Bar, App Switcher, Widgets, Icons, Control Center, Settings, Music, CarPlay, App Store, Camera, Phone, Notes and Photos. That makes it the better value when the goal is to change many parts of iOS from one preference bundle rather than perfect only SpringBoard’s icon grid.

The latest official version is 2.5.4. Its January 3, 2025 changelog added Always-On Display exceptions, an option to hide the black background behind the Timer live activity, CarPlay label fonts and icon-badge color, and localized settings search. It also fixed an iOS 16 Lock Screen gesture, the widget-menu Lock App shortcut, some settings font colors and Hide VPN behavior on iOS 16.

Havoc still lists Lynx 2.5.4 as current, priced at $1.99 for iOS 14.0 through 16.7.10, with a jailbreak required. The official repository requires Cephei and does not claim iOS 17 or later. Atria’s maintained fork documents iOS 16–17 use, but its firmware 15.0 minimum and iOS 26 crash fixes are not promises that every feature works across those releases.

Performance and conflict planning

Neither official product page makes a universal performance claim, so this comparison does not invent one. The safer setup is the narrower one: enable only the changes you need, respring after a small group of changes, and avoid asking two tweaks to rewrite the same Home Screen behavior.

  1. Confirm the device, firmware, jailbreak and rootful or rootless environment.
  2. Install Atria only from CySxL’s official repository or Lynx 2 from Havoc through the package manager supported by the jailbreak.
  3. Start with one tweak and one category of changes.
  4. If both are installed, use Atria for layout and disable overlapping Lynx Home Screen controls.
  5. Keep a list of changed settings so you can reverse the last group if SpringBoard becomes unstable.

Migration and recovery

If moving from the original Atria 1.4.1, export the layout first and store it privately. In Sileo or Zebra, verify that the Atria 1.9.3 transaction replaces the old me.lau.atria package with com.cysxl.atria instead of leaving two layout engines installed. Restore the layout before enabling custom categories, then test one category change at a time.

If SpringBoard enters safe mode, restart without tweak injection, remove the last package or disable the overlapping Home Screen options, and respring. For Atria category problems, use Reset Categories before importing a known-good layout without category data. Do not bypass Atria’s declared conflicts with the original Atria, Boxy 4 or HomePlus Pro.

Which one should you pick?

Pick Atria 1.9.3 for a free, purpose-built Home Screen editor, portable presets, custom App Library categories or native RootHide packaging. Accept that the separate conventional rootless build is officially untested. Pick Lynx 2.5.4 for a $1.99 suite that reaches far beyond SpringBoard—only on its officially listed iOS 14–16 range.

Read the full Atria 1.9.3 update and migration guide for hashes and package architecture details. Before installing either package, follow the tweak compatibility checklist, the rootless tweak guide and the bad-tweak recovery guide.

Frequently asked questions

Is Atria 1.9.3 or Lynx 2 better for changing the Home Screen grid?

Atria is the more focused choice. Rows, columns, spacing, scaling, offsets, per-page layouts and presets are its central purpose.

Can Atria and Lynx 2 be installed together?

The official listings do not promise conflict-free operation with every shared option. If both are installed, avoid enabling two controls that change the same Home Screen behavior.

Which tweak officially supports iOS 17?

Atria’s maintained fork documents iOS 16–17 use. Lynx 2 officially lists iOS 14.0 through 16.7.10 and does not claim iOS 17. Neither label establishes jailbreak availability for a specific device.

Is Lynx 2 a replacement for Atria?

Not exactly. Lynx 2 covers more of iOS, while Atria provides a dedicated visual layout editor and preset workflow for the Home Screen.
