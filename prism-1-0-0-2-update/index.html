Prism combines screen capture, OCR, translation and pinned references in one iOS tweak

Prism is designed as an all-in-one screen-content workflow rather than a basic screenshot utility. Its official description lists freeform capture, cropping, annotation, OCR, QR-code recognition, text segmentation, configurable LLM translation, sharing and persistent on-screen pins. The supplied repository package stanza identifies the package as version 1.0.0-2, while the official depiction contains a later 1.4.2 changelog and lists iOS 16.0 through 17.3.1. That discrepancy is important: readers should rely on the version and compatibility information shown by their package manager at installation time.

Key points

  • Prism combines screen capture, editing, recognition, translation and pinning in one workflow.
  • The feature set includes freeform selection, cropping, pens, lines, arrows, rectangles, text, color sampling, undo and redo.
  • OCR can use on-device recognition or optional cloud providers; cloud OCR requires manual API configuration.
  • Selected text can be segmented into individually selectable words, punctuation, spaces and line breaks, then copied or translated.
  • The tweak supports QR recognition, including a WeChat handoff for supported WeChat QR-code scenarios.
  • The official metadata requires iOS firmware 16.0 or newer, MobileSubstrate 0.9.7100 or newer, PreferenceLoader and CCSupport; the depiction says CCSupport is optional and only needed for Control Center access.

What Prism is intended to do

Prism is presented as a focused screenshot and screen-content tool. Its core idea is to let users capture only the relevant part of the display, work on that selection, recognize information inside it and keep the result available for reference. The official description specifically groups capture, cropping, annotation, recognition, translation, sharing and pinning into one workflow.

That makes Prism broader than a conventional screenshot shortcut. A user can select an area, adjust the crop, mark it up, extract text or scan a QR code, then export the result or place it above other content as a pin. The source does not claim that every operation is automatic; several advanced services require configuration or depend on the chosen provider.

Capture and annotation tools

The capture editor supports freeform screen capture, allowing an area of the display to be selected rather than limiting the user to a fixed full-screen image. Prism also provides cropping and editing controls with movable and resizable selections and a live size readout.

For markup, the listed tools include pens, lines, arrows, rectangles and text. Styling controls cover colors, line width, opacity, fills and text outlines. An integrated color sampler can pick a color directly from the captured image, which is useful when annotations need to match the source content. Undo and redo are also included, allowing edits to be revisited without abandoning the whole capture.

The changelog supplied with the official depiction adds scrolling screenshots and a setting for their output format. It also mentions improvements to the scrolling screenshot experience in version 1.4.2. Because the package stanza separately reports version 1.0.0-2, users should check which build their repository client actually offers before assuming that these later changes are included.

  • Freeform selection rather than only full-screen capture.
  • Pens, lines, arrows, rectangles and text annotations.
  • Adjustable color, opacity, line width, fills and text outlines.
  • Crop resizing with a live size readout.
  • Undo, redo and sampled colors from the captured image.

OCR, text segmentation and translation

Prism’s recognition tools are intended to extract text from a selected screen area. The official description distinguishes on-device OCR from optional cloud OCR providers. Cloud OCR requires the user to configure an API manually, so the listing does not promise cloud recognition without additional setup.

A feature called “Big Bang” text segmentation breaks recognized text into individually selectable words, punctuation, spaces and line breaks. That gives users more granular control over what they copy or translate instead of treating the OCR result as one indivisible block.

Translation is described as LLM-powered and configurable. The source says a provider must be configured through an API and that streaming output and language switching are supported. The 1.4.2 changelog also records the addition of MyMemory as a free translation provider. Earlier changelog text says Deep Thinking is off by default for faster translations and can be changed in Prism’s translation-service settings. These details apply to the depiction’s later release history, not necessarily to the 1.0.0-2 package stanza.

  • On-device OCR is listed alongside optional cloud OCR.
  • Cloud OCR requires manual API configuration.
  • Recognized text can be split into selectable words, punctuation, spaces and line breaks.
  • LLM translation supports configurable providers, streaming output and language switching.
  • MyMemory is listed as an added free translation provider in the 1.4.2 changelog.

QR recognition and WeChat routing

Prism can scan QR codes from a selected area. Recognized links can be opened immediately, and the description specifically mentions supported WeChat QR codes, including payment-code scenarios, being handed off to WeChat for native handling.

The changelog also describes a setting for sending standard QR codes to WeChat. It says users can choose WeChat in the Prism QR-code settings, after which Prism uses WeChat’s native scanner to recognize and open the code. Another 1.4.2 entry fixes a case where standard QR codes configured to open with WeChat could fail to redirect properly. Availability of these later fixes again depends on the build exposed by the package source.

Pins, shortcuts and exports

The on-screen pinboard is one of Prism’s defining features. Captured regions can be pinned above other content for comparison, quick reference and multitasking. Pins can be moved, resized, made more or less opaque, locked, unlocked and preserved. The changelog adds quick actions revealed by long-pressing a pin, including copying, saving, sharing and OCR.

For output, Prism lists copying, sharing, saving to Photos and exporting high-quality PNG images. The tweak also provides a draggable, dockable floating shortcut with adjustable icon size and auto-hide timing. A Control Center entry is available through CCSupport. The official description says CCSupport is optional and is only needed for that Control Center entry point.

The layout is described as orientation-aware. The editor, floating shortcut, recognition panels and pinned content adapt to the current screen orientation. A later changelog entry also adds a setting to recapture the active Prism interface: while Prism is active, pressing Volume Up and the Side button, or the Home button on supported devices, captures the current Prism interface and returns to annotation.

Compatibility and dependency checks

The package stanza lists an arm64 architecture and requires firmware version 16.0 or newer. It also lists MobileSubstrate 0.9.7100 or newer, PreferenceLoader and CCSupport as dependencies, while the depiction states that CCSupport is optional and only required for Control Center integration. This difference should be treated as a practical package-manager check rather than silently ignored.

The depiction’s information table reports iOS 16.0 through 17.3.1. However, the package metadata supplied alongside it identifies version 1.0.0-2, whereas the depiction’s latest visible changelog entry is 1.4.2. Before installing, confirm the offered package version, the displayed firmware range and the dependency resolution in the repository client. Also check whether your package manager treats CCSupport as optional for the specific build it presents.

The stanza lists a conflict with cn.blacknoisy.prism. Users should review whether that conflicting identifier is already installed before proceeding. The package is marked commercial in the supplied metadata, so pricing or purchase requirements should also be checked in the official package interface rather than inferred from the feature list.

  • Minimum package firmware requirement: iOS 16.0 or newer.
  • The depiction lists iOS 16.0 through 17.3.1.
  • Architecture listed: iphoneos-arm64.
  • Dependencies include MobileSubstrate and PreferenceLoader; CCSupport’s role differs between the stanza and depiction.
  • The package conflicts with cn.blacknoisy.prism.
  • The supplied metadata marks the package as commercial.

What to verify before installing

The source material provides a rich feature description but does not provide general performance measurements, privacy guarantees or universal compatibility claims beyond the stated metadata. Users should therefore verify the exact version offered, the firmware range, architecture and dependencies in their own package manager.

Advanced recognition and translation features deserve particular attention. On-device OCR is described separately from cloud OCR, while cloud OCR and LLM translation require API configuration. Users should review the provider settings and understand where selected content may be sent before enabling an external service. The source does not state that cloud processing is enabled automatically.

Finally, confirm whether you need Control Center integration. The depiction says CCSupport is only needed for that entry point, so users who launch Prism through its floating shortcut or other activation methods may not need that integration. The package manager’s dependency view should take precedence if it shows a build-specific requirement.

Frequently asked questions

What is Prism?

Prism is an iOS screen-content tweak for capturing, cropping, annotating, recognizing, translating, exporting and pinning selected screen regions.

Which iOS versions are listed?

The official depiction lists iOS 16.0 through 17.3.1. The package stanza separately requires firmware 16.0 or newer, so users should check the exact build offered by their package manager.

Does Prism support OCR?

Yes. The description lists on-device OCR and optional cloud OCR providers. Cloud OCR requires manual API configuration.

Does Prism translate recognized text?

Yes. It offers configurable LLM-powered translation with streaming output and language switching. API configuration is required, and the 1.4.2 changelog lists MyMemory as an added free provider.

Is CCSupport required?

The depiction says CCSupport is optional and only needed for Control Center integration. The supplied package stanza lists it as a dependency, so users should inspect dependency handling for the specific package build they are offered.

Before installing: confirm the current package version, compatibility and dependencies at the original developer/repository source for your exact device and jailbreak.
