How to Install Filza on a Rootless Jailbreak or TrollStore

Filza has separate official distribution paths. An already-jailbroken device should normally use TIGI Software’s package through Sileo; a compatible TrollStore device can use the developer’s IPA. Choose the path first, then protect your settings and files before making changes.

By Zeeshan Barvi · Published October 26, 2026 · Verified against TIGI Software’s current download archive and user guide

Important: Filza does not jailbreak an iPhone or add support for an unsupported firmware. A package saying “iOS 16” only describes the app’s compatibility; you still need a working jailbreak or a separately compatible TrollStore installation.

Choose the correct Filza build

Your setupUse this routeWhat it means
Dopamine, palera1n or another compatible rootless jailbreakInstall the official jailbreak package with Sileo from TIGI Software’s repo or BigBoss.This keeps the package inside APT/Sileo so dependencies, removal and future package updates remain manageable.
Compatible TrollStore device without a jailbreakInstall TIGI Software’s official TrollStore IPA from its Filza release page.This is an app installation route, not a jailbreak. Do not assume package-manager, tweak-injection or unrestricted jailbreak capabilities.
RootHide environmentUse only a build and conversion explicitly intended for your RootHide setup.A normal rootless package is not automatically a RootHide package. Follow the environment’s supported conversion workflow.
No jailbreak and no compatible TrollStoreDo not install a random “Filza IPA” from a mirror.Use Apple’s Files app or wait for a legitimate compatible installation method.

TIGI Software’s current archive lists jailbreak packages in both iphoneos-arm and iphoneos-arm64 forms. Modern rootless packaging uses iphoneos-arm64; traditional rootful packages commonly use iphoneos-arm. If you are unsure, first read the rootless, rootful and RootHide identification guide.

Install Filza on a rootless jailbreak with Sileo

  1. Confirm that your jailbreak is active and that Sileo opens normally. If the phone rebooted, re-jailbreak before continuing.
  2. Open Sileo, go to Sources, tap +, and add TIGI Software’s official repository: https://tigisoftware.com/repo/. Filza is also published through BigBoss, but the developer repo is TIGI Software’s own source.
  3. Refresh sources. Search for Filza File Manager or Filza File Manager 64-bit.
  4. Open the package page and verify that the developer is TIGI Software. On a modern rootless environment, confirm Sileo is selecting the rootless-compatible package rather than forcing an older rootful archive.
  5. Tap Get, inspect the queue, and install. Follow Sileo’s requested respring or return action.
  6. Open Filza once and allow its initial setup to finish. Do not immediately delete, move or change permissions on system or jailbreak files.

If the repository does not refresh, use the Sileo source troubleshooting guide. If Sileo proposes removing unrelated bootstrap packages, cancel the queue instead of forcing the transaction.

Install the official TrollStore IPA

  1. Make sure TrollStore already works on your exact device and firmware. If you are still choosing an installation method, use the TrollStore compatibility and installation-method guide.
  2. Open TIGI Software’s official Filza release page. The page currently lists a Filza 4.0.2 TrollStore IPA without the filza:// URL scheme, alongside earlier TrollStore downloads.
  3. Download only the developer-hosted IPA. Avoid re-signed mirrors, modified “full access” editions and files distributed through video descriptions.
  4. Share the downloaded IPA to TrollStore and tap Install.
  5. Open Filza from the Home Screen. If iOS refuses to launch a TrollStore-installed app after a reboot, repair TrollStore’s persistence helper before reinstalling Filza.

The no-URL-scheme build is intentional: it removes the public filza:// scheme that other apps can call. Choose it when that reduced app-to-app exposure fits your workflow. The developer’s page—not an unofficial filename—is the authoritative place to distinguish these builds.

Rootless paths: use /var/jb, not a copied preboot path

Procursus defines /var/jb as the prefix for its rootless iPhone packaging target. On a rootless jailbreak, use that stable prefix when you inspect jailbreak binaries, libraries or configuration. Do not copy a randomized /private/preboot/… path from someone else’s phone, and do not delete the underlying bootstrap folder manually.

For installed tweaks, let Sileo remove or upgrade packages whenever possible. Directly deleting individual files can leave package receipts, dependencies and launch daemons behind. If you need to learn which package owns a file, follow the dpkg file-owner guide before changing it.

Back up Filza before experimenting

  1. Open Filza’s Settings.
  2. Choose Backup Settings, then Backup.
  3. Filza creates an .fzs settings file. Copy it to Files, cloud storage or a computer rather than leaving the only copy on the phone.
  4. To restore later, open the .fzs file with Filza, continue, and relaunch the app when prompted.

This backs up Filza’s settings, not the entire jailbreak or every file visible in the browser. Keep separate backups for important documents and jailbreak configuration.

Safe first tasks in Filza

  • Inspect rather than edit: open a property list, text file or Debian control file to understand it before changing anything.
  • Copy before moving: make a clearly named backup in a user-writable folder before editing a configuration file.
  • Use Share for exports: send crash logs or configuration copies to Files instead of altering the originals.
  • Let Sileo install DEBs: Filza can view and extract packages, but Sileo’s queue provides clearer dependency and removal handling. See the local DEB installation guide.
  • Avoid permission guessing: changing an owner or executable bit without documentation can stop an app, daemon or bootstrap component from starting.

Quick choice

Already rootless-jailbroken: use Sileo and the official TIGI repo.

TrollStore only: use the official developer-hosted IPA.

RootHide: use only a compatible RootHide workflow.

No jailbreak/TrollStore: Filza cannot create compatibility.
